## 1. Descripción del Módulo

### 1.1 Propósito

Este módulo implementa un sistema de clasificación automática de conceptos contables mexicanos utilizando **embedding models** y técnicas de **machine learning**. El sistema transforma conceptos de CFDI (Comprobante Fiscal Digital por Internet) en representaciones vectoriales densas que capturan su significado semántico, permitiendo clasificarlos automáticamente en categorías contables correctas (activo, pasivo, patrimonio, ingreso, gasto) según las **Normas de Información Financiera (NIF)** mexicanas, específicamente la **NIF B-3** (Estado de Resultado Integral).

El módulo resuelve el problema de la clasificación manual de 10,000+ conceptos del catálogo del SAT, reduciendo el tiempo de captura contable en 75-80% y minimizando errores de clasificación que pueden generar inconsistencias en estados financieros y observaciones en auditorías.

### 1.3 Dolor Principal que Resuelve

**Problema crítico:** Los contadores en México deben clasificar manualmente cientos de conceptos de CFDI diariamente, utilizando catálogos del SAT con 10,000+ claves (c_ClaveProdServ). Esta tarea es:

1. **Repetitiva y propensa a errores:** La clasificación manual tiene una tasa de error estimada de 5-10%
2. **Requiere conocimiento especializado:** Necesita dominio de NIF, catálogo del SAT y criterios contables
3. **Consume tiempo valioso:** 2-4 horas semanales que podrían dedicarse a análisis financiero
4. **Genera inconsistencias:** Diferentes contadores clasifican el mismo concepto de forma distinta
5. **Riesgo de auditoría:** Clasificaciones incorrectas pueden generar observaciones en revisiones fiscales

**Ejemplo concreto:** Un concepto "Honorarios por servicios profesionales de arquitectura" (clave SAT 81101513) puede clasificarse como:
- ✅ **Gasto:** Honorarios profesionales (cuenta 5101-001)
- ❌ **Inversión:** Equipo de cómputo (cuenta 1504-001) - Incorrecto

El sistema elimina esta ambigüedad mediante clasificación automática basada en embeddings semánticos.

### 3.2 Algoritmos Específicos

#### Algoritmo 1: Preprocesamiento de Texto

```python
import re
import unicodedata
from typing import List

def normalizar_texto(texto: str) -> str:
    """
    Normaliza texto de conceptos CFDI para clasificación.
    
    Args:
        texto: Texto crudo del concepto CFDI
    
    Returns:
        Texto normalizado (lowercase, sin acentos, sin caracteres especiales)
    
    Ejemplo:
        >>> normalizar_texto("Honorarios por Servicios Profesionales de Arquitectura")
        'honorarios por servicios profesionales de arquitectura'
    """
    # Convertir a minúsculas
    texto = texto.lower()
    
    # Eliminar acentos (normalización Unicode NFD → eliminar diacríticos → NFC)
    texto = unicodedata.normalize('NFD', texto)
    texto = ''.join(c for c in texto if unicodedata.category(c) != 'Mn')
    
    # Eliminar caracteres especiales (excepto espacios)
    texto = re.sub(r'[^a-z0-9\s]', ' ', texto)
    
    # Eliminar espacios múltiples
    texto = re.sub(r'\s+', ' ', texto).strip()
    
    return texto


def tokenizar_concepto(concepto: str) -> List[str]:
    """
    Tokeniza un concepto CFDI en palabras individuales.
    
    Args:
        concepto: Concepto CFDI normalizado
    
    Returns:
        Lista de tokens (palabras)
    
    Ejemplo:
        >>> tokenizar_concepto("honorarios por servicios profesionales")
        ['honorarios', 'por', 'servicios', 'profesionales']
    """
    # Stop words en español (pueden expandirse)
    stop_words = {
        'el', 'la', 'los', 'las', 'un', 'una', 'unos', 'unas',
        'por', 'para', 'con', 'sin', 'de', 'del', 'al', 'en',
        'y', 'o', 'ni', 'que', 'cual', 'cuales'
    }
    
    tokens = concepto.split()
    tokens = [t for t in tokens if t not in stop_words]
    
    return tokens
```

#### Algoritmo 2: Generación de Embeddings

```python
from sentence_transformers import SentenceTransformer
import numpy as np
from typing import Union, List

class EmbeddingGenerator:
    """
    Generador de embeddings para conceptos contables mexicanos.
    Soporta múltiples backends: HuggingFace, OpenAI, Cohere, NVIDIA NIM.
    """
    
    def __init__(self, modelo: str = "paraphrase-multilingual-mpnet-base-v2"):
        """
        Inicializa el generador de embeddings.
        
        Args:
            modelo: Nombre del modelo a usar
                - "paraphrase-multilingual-mpnet-base-v2" (HuggingFace, gratis)
                - "all-MiniLM-L6-v2" (HuggingFace, ligero)
                - "openai:text-embedding-3-small" (OpenAI, $0.02/1M tokens)
                - "cohere:embed-multilingual-v3.0" (Cohere, $0.10/1M tokens)
        """
        self.modelo = modelo
        
        if modelo.startswith("openai:"):
            from openai import OpenAI
            self.client = OpenAI()
            self.modelo_api = modelo.replace("openai:", "")
        elif modelo.startswith("cohere:"):
            import cohere
            self.client = cohere.Client()
            self.modelo_api = modelo.replace("cohere:", "")
        else:
            # HuggingFace Sentence Transformers
            self.model = SentenceTransformer(modelo)
    
    def generar_embedding(self, texto: str) -> np.ndarray:
        """
        Genera embedding vector para un texto.
        
        Args:
            texto: Texto a convertir a embedding
        
        Returns:
            Vector numpy de dimensiones fijas (384-3072 dependiendo del modelo)
        
        Ejemplo:
            >>> gen = EmbeddingGenerator()
            >>> embedding = gen.generar_embedding("Honorarios profesionales")
            >>> embedding.shape
            (768,)
        """
        if self.modelo.startswith("openai:"):
            response = self.client.embeddings.create(
                input=[texto],
                model=self.modelo_api
            )
            return np.array(response.data[0].embedding)
        
        elif self.modelo.startswith("cohere:"):
            response = self.client.embed(
                texts=[texto],
                model=self.modelo_api,
                input_type="search_document"
            )
            return np.array(response.embeddings[0])
        
        else:
            # HuggingFace
            embedding = self.model.encode(texto, convert_to_numpy=True)
            return embedding
    
    def generar_embeddings_lote(self, textos: List[str]) -> np.ndarray:
        """
        Genera embeddings para múltiples textos en lote (más eficiente).
        
        Args:
            textos: Lista de textos
        
        Returns:
            Matriz numpy de forma (n_textos, dimensiones)
        """
        if self.modelo.startswith("openai:"):
            response = self.client.embeddings.create(
                input=textos,
                model=self.modelo_api
            )
            return np.array([item.embedding for item in response.data])
        
        elif self.modelo.startswith("cohere:"):
            response = self.client.embed(
                texts=textos,
                model=self.modelo_api,
                input_type="search_document"
            )
            return np.array(response.embeddings)
        
        else:
            embeddings = self.model.encode(textos, convert_to_numpy=True)
            return embeddings
```

#### Algoritmo 3: Clasificador con Random Forest

```python
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score
import numpy as np
from typing import Tuple, Dict, List

class ClasificadorContable:
    """
    Clasificador de conceptos contables usando Random Forest.
    Clasifica en 5 categorías: activo, pasivo, patrimonio, ingreso, gasto.
    """
    
    def __init__(self):
        self.clasificador = RandomForestClassifier(
            n_estimators=200,
            max_depth=20,
            min_samples_split=5,
            min_samples_leaf=2,
            class_weight='balanced',
            random_state=42,
            n_jobs=-1
        )
        self.categorias = ['activo', 'pasivo', 'patrimonio', 'ingreso', 'gasto']
        self.modelo_entrenado = False
    
    def entrenar(self, embeddings: np.ndarray, etiquetas: np.ndarray) -> Dict[str, float]:
        """
        Entrena el clasificador con embeddings de conceptos conocidos.
        
        Args:
            embeddings: Matriz de embeddings de forma (n_ejemplos, dimensiones)
            etiquetas: Array de etiquetas (n_ejemplos,) con valores en self.categorias
        
        Returns:
            Diccionario con métricas de evaluación
        
        Ejemplo:
            >>> clf = ClasificadorContable()
            >>> metrics = clf.entrenar(embeddings_train, etiquetas_train)
            >>> print(metrics['accuracy'])
            0.87
        """
        # Dividir en train/test
        X_train, X_test, y_train, y_test = train_test_split(
            embeddings, etiquetas, test_size=0.2, random_state=42, stratify=etiquetas
        )
        
        # Entrenar
        self.clasificador.fit(X_train, y_train)
        self.modelo_entrenado = True
        
        # Evaluar
        y_pred = self.clasificador.predict(X_test)
        
        metrics = {
            'accuracy': accuracy_score(y_test, y_pred),
            'precision': precision_score(y_test, y_pred, average='weighted'),
            'recall': recall_score(y_test, y_pred, average='weighted'),
            'f1_score': f1_score(y_test, y_pred, average='weighted')
        }
        
        return metrics
    
    def predecir(self, embedding: np.ndarray) -> Tuple[str, float]:
        """
        Predice la categoría contable de un embedding.
        
        Args:
            embedding: Vector de embedding del concepto
        
        Returns:
            Tupla (categoría, probabilidad)
        
        Ejemplo:
            >>> clf.predecir(embedding_concepto)
            ('gasto', 0.89)
        """
        if not self.modelo_entrenado:
            raise ValueError("El modelo no ha sido entrenado. Llamar a entrenar() primero.")
        
        prediccion = self.clasificador.predict([embedding])[0]
        probabilidades = self.clasificador.predict_proba([embedding])[0]
        confianza = max(probabilidades)
        
        return prediccion, confianza
    
    def predecir_lote(self, embeddings: np.ndarray) -> List[Tuple[str, float]]:
        """
        Predice categorías para múltiples embeddings.
        
        Args:
            embeddings: Matriz de embeddings (n_ejemplos, dimensiones)
        
        Returns:
            Lista de tuplas (categoría, probabilidad)
        """
        predicciones = self.clasificador.predict(embeddings)
        confianzas = np.max(self.clasificador.predict_proba(embeddings), axis=1)
        
        return list(zip(predicciones, confianzas))
```

#### Algoritmo 4: Fine-tuning con GPT-4

```python
from openai import OpenAI
import json
from typing import List, Dict

class FineTuningGPT4:
    """
    Fine-tuning de GPT-4 para clasificación contable especializada.
    Alternativa de mayor precisión pero mayor costo.
    """
    
    def __init__(self, api_key: str):
        self.client = OpenAI(api_key=api_key)
    
    def preparar_dataset_entrenamiento(
        self, 
        conceptos: List[str], 
        categorias: List[str]
    ) -> str:
        """
        Prepara dataset en formato JSONL para fine-tuning de GPT-4.
        
        Args:
            conceptos: Lista de conceptos CFDI
            categorias: Lista de categorías contables correspondientes
        
        Returns:
            Ruta al archivo JSONL generado
        
        Ejemplo:
            >>> ft = FineTuningGPT4(api_key)
            >>> ruta = ft.preparar_dataset_entrenamiento(conceptos, categorias)
        """
        ejemplos = []
        
        for concepto, categoria in zip(conceptos, categorias):
            ejemplo = {
                "messages": [
                    {
                        "role": "system",
                        "content": "Eres un clasificador contable experto en NIF mexicanas. Clasifica conceptos de CFDI en: activo, pasivo, patrimonio, ingreso, gasto."
                    },
                    {
                        "role": "user",
                        "content": f"Clasifica este concepto contable: {concepto}"
                    },
                    {
                        "role": "assistant",
                        "content": f"Este concepto se clasifica como: {categoria}"
                    }
                ]
            }
            ejemplos.append(ejemplo)
        
        # Guardar en archivo JSONL
        ruta_archivo = "dataset_entrenamiento_gpt4.jsonl"
        with open(ruta_archivo, 'w', encoding='utf-8') as f:
            for ejemplo in ejemplos:
                f.write(json.dumps(ejemplo, ensure_ascii=False) + '\n')
        
        return ruta_archivo
    
    def iniciar_fine_tuning(self, archivo_dataset: str) -> str:
        """
        Inicia proceso de fine-tuning en OpenAI.
        
        Args:
            archivo_dataset: Ruta al archivo JSONL
        
        Returns:
            ID del job de fine-tuning
        """
        # Subir archivo
        file_response = self.client.files.create(
            file=open(archivo_dataset, "rb"),
            purpose="fine-tune"
        )
        
        # Crear job
        job_response = self.client.fine_tuning.jobs.create(
            training_file=file_response.id,
            model="gpt-4-2024-08-06"  # O "gpt-3.5-turbo" para menor costo
        )
        
        return job_response.id
```

**Ejemplo de configuración NVIDIA NIM:**

```python
import requests

def generar_embedding_nvidia(texto: str, api_key: str) -> list:
    """
    Genera embedding usando NVIDIA NIM API.
    
    Args:
        texto: Texto a convertir
        api_key: API key de NVIDIA (nvapi-...)
    
    Returns:
        Lista de floats representando el embedding
    """
    url = "https://integrate.api.nvidia.com/v1/embeddings"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    payload = {
        "input": [texto],
        "model": "nvidia/nv-embedqa-e5-v5",
        "encoding_format": "float"
    }
    
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    
    return response.json()["data"][0]["embedding"]
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Conceptos Fuera de Dominio (Out-of-Scope)

**Problema:**
El modelo puede recibir conceptos que no existen en el catálogo del SAT o que pertenecen a dominios muy específicos (ej. "Servicios de perforación petrolera en aguas profundas") que no fueron incluidos en el dataset de entrenamiento. Esto genera clasificaciones incorrectas con alta confianza (overconfidence).

**Solución:**

```python
def clasificar_con_validacion(
    concepto: str, 
    umbral_confianza: float = 0.75,
    conceptos_conocidos: List[str] = None
) -> Dict:
    """
    Clasifica concepto con validación de dominio.
    
    Returns:
        Diccionario con clasificación y metadatos
    """
    # 1. Calcular similitud con conceptos conocidos
    embedding = generar_embedding(concepto)
    
    if conceptos_conocidos:
        similitudes = []
        for concepto_ref in conceptos_conocidos:
            emb_ref = generar_embedding(concepto_ref)
            sim = similitud_coseno(embedding, emb_ref)
            similitudes.append(sim)
        
        max_similitud = max(similitudes)
        
        # 2. Rechazar si está muy lejos de conceptos conocidos
        if max_similitud < 0.50:
            return {
                "estado": "fuera_de_dominio",
                "mensaje": "Concepto no reconocido en catálogo",
                "concepto": concepto,
                "requiere_revision_manual": True
            }
    
    # 3. Clasificar normalmente
    categoria, confianza = clasificador.predecir(embedding)
    
    # 4. Validar threshold de confianza
    if confianza < umbral_confianza:
        return {
            "estado": "baja_confianza",
            "categoria": categoria,
            "confianza": confianza,
            "requiere_revision_manual": True
        }
    
    return {
        "estado": "clasificado",
        "categoria": categoria,
        "confianza": confianza,
        "requiere_revision_manual": False
    }
```

**Impacto:**
- 5-10% de conceptos requerirán revisión manual inicial
- Sistema mejora con aprendizaje activo (correcciones de usuarios)

### 4.2 Limitación 2: Terminología Específica de Dominio

**Problema:**
Términos contables muy específicos (ej. "Deterioro acumulado de maquinaria y equipo") pueden no ser capturados correctamente por embeddings genéricos. Los modelos pre-entrenados no tienen conocimiento de jerarquías contables mexicanas.

**Solución:**
**Fine-tuning con dataset especializado:**

1. Recopilar 1,000-5,000 ejemplos de conceptos CFDI reales con clasificación correcta
2. Fine-tuning de modelo base (paraphrase-multilingual-mpnet-base-v2) con estos ejemplos
3. Validar mejora en precisión con dataset de prueba

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **Embeddings multilingües son críticos:** Modelos como `paraphrase-multilingual-mpnet-base-v2` o `Cohere embed-multilingual-v3.0` superan a modelos en inglés en 15-20% para conceptos en español mexicano.

2. **Combinación híbrida es óptima:** Embeddings + Random Forest/XGBoost ofrece mejor balance precisión/costo que LLM puro (GPT-4).

3. **Fine-tuning es necesario:** Modelos pre-entrenados genéricos alcanzan 70-75% de precisión; con fine-tuning (1,000-5,000 ejemplos mexicanos) se llega a 85-90%.

4. **Aprendizaje activo acelera mejora:** Sistema de correcciones de usuarios permite mejorar modelo continuamente sin recolección manual de datos.

5. **Costos son manejables:** 
   - OpenAI: $0.02/1M tokens → ~$50/mes para 10,000 clasificaciones
   - Cohere: $0.10/1M tokens → ~$100/mes para 10,000 clasificaciones
   - HuggingFace self-hosted: ~$200/mes en infraestructura GPU (ilimitado)

### 8.2 Recomendaciones Finales

| Área | Recomendación | Prioridad | Owner |
