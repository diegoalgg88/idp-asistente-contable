## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía técnica completa para el cálculo de cuotas obrero-patronales del IMSS e INFONAVIT vigentes en 2026, incluyendo:
- Tablas de cuotas por seguro (Riesgos de Trabajo, Enfermedades y Maternidad, Invalidez y Vida, Retiro, Cesantía y Vejez, Guarderías)
- Factores de prima de riesgo de trabajo (1.8572% - 15.36%)
- Topes de cotización (25 UMA para prestaciones, 10/15/25 UMA por seguro)
- Cuotas fijas y variables actualizadas 2026
- Aportaciones de vivienda INFONAVIT (5%)
- Fórmulas de cálculo con ejemplos prácticos

### 1.2 Actividades del Contador que Automatiza

### 1.3 Dolor Principal que Resuelve

**Problema:** El cálculo de cuotas IMSS es complejo y propenso a errores. Los contadores deben:
- Consultar múltiples tablas (5 seguros + INFONAVIT)
- Aplicar topes diferentes por seguro (10, 15, 25 UMA)
- Calcular cuotas fijas y variables
- Verificar factores de prima de riesgo
- Actualizar valores UMA anualmente

Un error en el cálculo genera:
- Diferencias en entero de cuotas
- Multas del IMSS (250-5,000 UMA)
- Ajustes en declaraciones complementarias

**Solución IDP-App:** Cálculo automático con tablas actualizadas, aplicación de topes por rango, y generación de archivos para SUA/IDSE.

#### Algoritmo 1: Cálculo de Cuotas IMSS 2026

```python
from dataclasses import dataclass
from typing import Dict, List, Tuple
from decimal import Decimal, ROUND_HALF_UP

@dataclass
class ParametrosIMSS2026:
    """Parámetros IMSS vigentes para 2026."""
    UMA_diaria: Decimal = Decimal('117.31')
    UMA_mensual: Decimal = Decimal('3566.22')
    salario_minimo_general: Decimal = Decimal('315.04')
    salario_minimo_fronterizo: Decimal = Decimal('440.87')
    tope_25_UMA: Decimal = Decimal('89155.50')  # 25 × UMA_mensual
    tope_15_UMA: Decimal = Decimal('53493.30')  # 15 × UMA_mensual
    tope_10_UMA: Decimal = Decimal('35662.20')  # 10 × UMA_mensual


@dataclass
class CuotaIMSS:
    """Representa una cuota IMSS calculada."""
    concepto: str
    base_cotizacion: Decimal
    tasa_patron: Decimal
    tasa_trabajador: Decimal
    tasa_gobierno: Decimal
    cuota_patron: Decimal
    cuota_trabajador: Decimal
    cuota_gobierno: Decimal
    cuota_total: Decimal


class CalculadoraIMSS2026:
    """
    Calcula cuotas obrero-patronales del IMSS vigentes para 2026.
    Implementa fórmulas según Ley del Seguro Social.
    """
    
    def __init__(self):
        self.parametros = ParametrosIMSS2026()
        
        # Tabla progresiva de Cesantía y Vejez 2026
        self.tabla_cesantia_vejez_2026 = [
            {'limite_inferior_UMA': 0, 'limite_superior_UMA': Decimal('1.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.03150')},
            {'limite_inferior_UMA': Decimal('1.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('1.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.03676')},
            {'limite_inferior_UMA': Decimal('1.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('2.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.04851')},
            {'limite_inferior_UMA': Decimal('2.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('2.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.05556')},
            {'limite_inferior_UMA': Decimal('2.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('3.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.06026')},
            {'limite_inferior_UMA': Decimal('3.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('3.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.06361')},
            {'limite_inferior_UMA': Decimal('3.5') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('4.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'cuota_patron': Decimal('0.06613')},
            {'limite_inferior_UMA': Decimal('4.0') * self.parametros.UMA_diaria / self.parametros.salario_minimo_general, 'limite_superior_UMA': Decimal('999'), 'cuota_patron': Decimal('0.07513')},
        ]
    
    def calcular_SBC(self, 
                     salario_diario: Decimal,
                     percepciones_fijas: Decimal,
                     percepciones_variables: Decimal,
                     prestaciones_integradas: Decimal) -> Decimal:
        """
        Calcula el Salario Base de Cotización (SBC) integrado.
        
        Args:
            salario_diario: Salario diario base
            percepciones_fijas: Percepciones fijas (bonos, primas, etc.)
            percepciones_variables: Percepciones variables (comisiones, horas extra, etc.)
            prestaciones_integradas: Prestaciones integradas al salario
            
        Returns:
            SBC integrado con aplicación de topes
        """
        # Integración del SBC
        SBC_bruto = salario_diario + percepciones_fijas + percepciones_variables + prestaciones_integradas
        
        # Aplicar tope máximo (25 UMA)
        SBC_topeado = min(SBC_bruto, self.parametros.tope_25_UMA / 30)  # Tope diario
        
        # Aplicar tope mínimo (1 UMA para algunos conceptos)
        SBC_final = max(SBC_topeado, self.parametros.UMA_diaria / 30)
        
        return SBC_final.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
    
    def calcular_riesgos_trabajo(self, 
                                  SBC: Decimal,
                                  prima_riesgo: Decimal) -> CuotaIMSS:
        """
        Calcula cuota del Seguro de Riesgos de Trabajo.
        
        Args:
            SBC: Salario Base de Cotización
            prima_riesgo: Prima de riesgo asignada (1.8572% - 15.36%)
            
        Returns:
            CuotaIMSS con cálculo de Riesgos de Trabajo
        """
        # Patrón paga 100% de la prima
        cuota_patron = SBC * prima_riesgo
        
        return CuotaIMSS(
            concepto='Riesgos de Trabajo',
            base_cotizacion=SBC,
            tasa_patron=prima_riesgo,
            tasa_trabajador=Decimal('0'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=Decimal('0'),
            cuota_gobierno=Decimal('0'),
            cuota_total=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        )
    
    def calcular_enfermedades_maternidad(self, SBC: Decimal) -> List[CuotaIMSS]:
        """
        Calcula cuotas del Seguro de Enfermedades y Maternidad.
        
        Incluye 4 conceptos:
        1. Cuota fija (hasta 3 UMA)
        2. Cuota excedente (diferencia SBC - 3 UMA)
        3. Gastos médicos pensionados
        4. Prestaciones en dinero
        
        Args:
            SBC: Salario Base de Cotización
            
        Returns:
            Lista de CuotaIMSS con los 4 conceptos
        """
        cuotas = []
        
        # 1. Cuota fija (hasta 3 UMA)
        base_cuota_fija = min(SBC, self.parametros.UMA_diaria / 30 * 3)
        cuota_patron_fija = base_cuota_fija * Decimal('0.2040')
        
        cuotas.append(CuotaIMSS(
            concepto='Enfermedades y Maternidad - Cuota Fija',
            base_cotizacion=base_cuota_fija,
            tasa_patron=Decimal('0.2040'),
            tasa_trabajador=Decimal('0'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron_fija.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=Decimal('0'),
            cuota_gobierno=Decimal('0'),
            cuota_total=cuota_patron_fija.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        ))
        
        # 2. Cuota excedente (diferencia entre SBC y 3 UMA)
        base_excedente = max(Decimal('0'), SBC - (self.parametros.UMA_diaria / 30 * 3))
        if base_excedente > 0:
            cuota_patron_excedente = base_excedente * Decimal('0.0110')
            cuota_trabajador_excedente = base_excedente * Decimal('0.0040')
            
            cuotas.append(CuotaIMSS(
                concepto='Enfermedades y Maternidad - Cuota Excedente',
                base_cotizacion=base_excedente,
                tasa_patron=Decimal('0.0110'),
                tasa_trabajador=Decimal('0.0040'),
                tasa_gobierno=Decimal('0'),
                cuota_patron=cuota_patron_excedente.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
                cuota_trabajador=cuota_trabajador_excedente.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
                cuota_gobierno=Decimal('0'),
                cuota_total=(cuota_patron_excedente + cuota_trabajador_excedente).quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
            ))
        
        # 3. Gastos médicos pensionados
        cuota_patron_gmp = SBC * Decimal('0.0105')
        cuota_trabajador_gmp = SBC * Decimal('0.00375')
        
        cuotas.append(CuotaIMSS(
            concepto='Gastos Médicos Pensionados',
            base_cotizacion=SBC,
            tasa_patron=Decimal('0.0105'),
            tasa_trabajador=Decimal('0.00375'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron_gmp.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=cuota_trabajador_gmp.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_gobierno=Decimal('0'),
            cuota_total=(cuota_patron_gmp + cuota_trabajador_gmp).quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        ))
        
        # 4. Prestaciones en dinero
        cuota_patron_ped = SBC * Decimal('0.0070')
        cuota_trabajador_ped = SBC * Decimal('0.0025')
        
        cuotas.append(CuotaIMSS(
            concepto='Prestaciones en Dinero',
            base_cotizacion=SBC,
            tasa_patron=Decimal('0.0070'),
            tasa_trabajador=Decimal('0.0025'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron_ped.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=cuota_trabajador_ped.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_gobierno=Decimal('0'),
            cuota_total=(cuota_patron_ped + cuota_trabajador_ped).quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        ))
        
        return cuotas
    
    def calcular_invalidez_vida(self, SBC: Decimal) -> CuotaIMSS:
        """Calcula cuota del Seguro de Invalidez y Vida."""
        cuota_patron = SBC * Decimal('0.0175')
        cuota_trabajador = SBC * Decimal('0.00625')
        cuota_gobierno = SBC * Decimal('0.00125')
        
        return CuotaIMSS(
            concepto='Invalidez y Vida',

            tasa_trabajador=Decimal('0.00625'),
            tasa_gobierno=Decimal('0.00125'),

            cuota_trabajador=cuota_trabajador.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_gobierno=cuota_gobierno.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_total=(cuota_patron + cuota_trabajador + cuota_gobierno).quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        )
    
    def calcular_retiro_cesantia_vejez(self, SBC: Decimal) -> List[CuotaIMSS]:
        """
        Calcula cuotas del Seguro de Retiro, Cesantía en Edad Avanzada y Vejez.
        
        Args:
            SBC: Salario Base de Cotización
            
        Returns:
            Lista de CuotaIMSS con Retiro y Cesantía y Vejez
        """
        cuotas = []
        
        # 1. Retiro (2.00% patrón)
        cuota_patron_retiro = SBC * Decimal('0.0200')
        
        cuotas.append(CuotaIMSS(
            concepto='Retiro',
            base_cotizacion=SBC,
            tasa_patron=Decimal('0.0200'),
            tasa_trabajador=Decimal('0'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron_retiro.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=Decimal('0'),
            cuota_gobierno=Decimal('0'),
            cuota_total=cuota_patron_retiro.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        ))
        
        # 2. Cesantía y Vejez (tabla progresiva 2026)
        # Determinar porcentaje según SBC
        porcentaje_cesantia = self._obtener_porcentaje_cesantia_vejez(SBC)
        
        cuota_patron_cesantia = SBC * porcentaje_cesantia
        cuota_trabajador_cesantia = SBC * Decimal('0.01125')
        
        # Gobierno federal aporta cuota social solo para salarios hasta 4 UMA
        if SBC <= (self.parametros.UMA_diaria / 30 * 4):
            cuota_gobierno_cesantia = SBC * Decimal('0.006378')  # Cuota social
        else:
            cuota_gobierno_cesantia = Decimal('0')
        
        cuotas.append(CuotaIMSS(
            concepto='Cesantía y Vejez',
            base_cotizacion=SBC,
            tasa_patron=porcentaje_cesantia,
            tasa_trabajador=Decimal('0.01125'),
            tasa_gobierno=cuota_gobierno_cesantia / SBC if SBC > 0 else Decimal('0'),
            cuota_patron=cuota_patron_cesantia.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=cuota_trabajador_cesantia.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_gobierno=cuota_gobierno_cesantia.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_total=(cuota_patron_cesantia + cuota_trabajador_cesantia + cuota_gobierno_cesantia).quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        ))
        
        return cuotas
    
    def _obtener_porcentaje_cesantia_vejez(self, SBC: Decimal) -> Decimal:
        """
        Obtiene el porcentaje de Cesantía y Vejez según tabla progresiva 2026.
        
        Args:
            SBC: Salario Base de Cotización diario
            
        Returns:
            Porcentaje aplicable (3.150% - 7.513% en 2026)
        """
        for rango in self.tabla_cesantia_vejez_2026:
            if rango['limite_inferior_UMA'] <= SBC < rango['limite_superior_UMA']:
                return rango['cuota_patron']
        
        # Si excede todos los rangos, aplicar porcentaje máximo
        return Decimal('0.07513')
    
    def calcular_guarderias(self, SBC: Decimal) -> CuotaIMSS:
        """Calcula cuota del Seguro de Guarderías y Prestaciones Sociales."""
        cuota_patron = SBC * Decimal('0.0100')
        
        return CuotaIMSS(
            concepto='Guarderías y Prestaciones Sociales',
            base_cotizacion=SBC,
            tasa_patron=Decimal('0.0100'),
            tasa_trabajador=Decimal('0'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=Decimal('0'),
            cuota_gobierno=Decimal('0'),
            cuota_total=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        )
    
    def calcular_infonavit(self, SBC: Decimal) -> CuotaIMSS:
        """Calcula aportación de vivienda INFONAVIT (5%)."""
        cuota_patron = SBC * Decimal('0.0500')
        
        return CuotaIMSS(
            concepto='INFONAVIT (Vivienda)',
            base_cotizacion=SBC,
            tasa_patron=Decimal('0.0500'),
            tasa_trabajador=Decimal('0'),
            tasa_gobierno=Decimal('0'),
            cuota_patron=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            cuota_trabajador=Decimal('0'),
            cuota_gobierno=Decimal('0'),
            cuota_total=cuota_patron.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        )
    
    def calcular_nomina_completa(self,
                                  salario_diario: Decimal,
                                  percepciones_fijas: Decimal,
                                  percepciones_variables: Decimal,
                                  prestaciones_integradas: Decimal,
                                  prima_riesgo: Decimal,
                                  dias_trabajados: int = 30) -> Dict:
        """
        Calcula todas las cuotas IMSS de una nómina completa.
        
        Args:
            salario_diario: Salario diario base
            percepciones_fijas: Percepciones fijas mensuales
            percepciones_variables: Percepciones variables mensuales
            prestaciones_integradas: Prestaciones integradas mensuales
            prima_riesgo: Prima de riesgo asignada (ej. 0.018572 para 1.8572%)
            dias_trabajados: Días trabajados en el mes
            
        Returns:
            Dict con resumen completo de cuotas
        """
        # Calcular SBC
        SBC = self.calcular_SBC(
            salario_diario=salario_diario,
            percepciones_fijas=percepciones_fijas / dias_trabajados,
            percepciones_variables=percepciones_variables / dias_trabajados,
            prestaciones_integradas=prestaciones_integradas / dias_trabajados
        )
        
        # Calcular todas las cuotas
        todas_las_cuotas = []
        
        # Riesgos de Trabajo
        todas_las_cuotas.extend([self.calcular_riesgos_trabajo(SBC, prima_riesgo)])
        
        # Enfermedades y Maternidad (4 conceptos)
        todas_las_cuotas.extend(self.calcular_enfermedades_maternidad(SBC))
        
        # Invalidez y Vida
        todas_las_cuotas.extend([self.calcular_invalidez_vida(SBC)])
        
        # Retiro, Cesantía y Vejez (2 conceptos)
        todas_las_cuotas.extend(self.calcular_retiro_cesantia_vejez(SBC))
        
        # Guarderías
        todas_las_cuotas.extend([self.calcular_guarderias(SBC)])
        
        # INFONAVIT
        todas_las_cuotas.extend([self.calcular_infonavit(SBC)])
        
        # Sumar totales
        total_cuota_patron = sum(c.cuota_patron for c in todas_las_cuotas)
        total_cuota_trabajador = sum(c.cuota_trabajador for c in todas_las_cuotas)
        total_cuota_gobierno = sum(c.cuota_gobierno for c in todas_las_cuotas)
        total_general = sum(c.cuota_total for c in todas_las_cuotas)
        
        return {
            'SBC': SBC,
            'SBC_mensual': SBC * dias_trabajados,
            'cuotas': todas_las_cuotas,
            'totales': {
                'cuota_patron': total_cuota_patron * dias_trabajados,
                'cuota_trabajador': total_cuota_trabajador * dias_trabajados,
                'cuota_gobierno': total_cuota_gobierno * dias_trabajados,
                'total_general': total_general * dias_trabajados
            },
            'parametros': {
                'UMA_diaria': self.parametros.UMA_diaria,
                'UMA_mensual': self.parametros.UMA_mensual,
                'salario_minimo': self.parametros.salario_minimo_general,
                'tope_25_UMA': self.parametros.tope_25_UMA
            }
        }
```

### 4.2 Limitación 2: Prima de Riesgo Variable por Empresa

**Problema:**
La prima de riesgo de trabajo varía por empresa (1.8572% - 15.36%) según siniestralidad. No hay API pública para consulta automática.

**Solución:**
```python
class PrimaRiesgoManager:
    """
    Gestiona primas de riesgo de trabajo por empresa.
    Permite captura manual y almacenamiento en DB.
    """
    
    def __init__(self, db_session):
        self.db = db_session
    
    def registrar_prima_riesgo(self, 
                               rfc_patron: str,
                               prima_riesgo: Decimal,
                               clase_riesgo: int,
                               vigencia_desde: date,
                               vigencia_hasta: date):
        """
        Registra prima de riesgo asignada por IMSS.
        
        Args:
            rfc_patron: RFC del patrón
            prima_riesgo: Prima asignada (ej. 0.025 para 2.5%)
            clase_riesgo: Clase de riesgo (I-V)
            vigencia_desde: Inicio de vigencia
            vigencia_hasta: Fin de vigencia
        """
        # Validar rango
        if not (Decimal('0.018572') <= prima_riesgo <= Decimal('0.1536')):
            raise ValueError('Prima de riesgo fuera de rango (1.8572% - 15.36%)')
        
        # Guardar en DB
        self._guardar_prima_riesgo({
            'rfc_patron': rfc_patron,
            'prima_riesgo': prima_riesgo,
            'clase_riesgo': clase_riesgo,
            'vigencia_desde': vigencia_desde,
            'vigencia_hasta': vigencia_hasta
        })
    
    def obtener_prima_vigente(self, rfc_patron: str, fecha: date = None) -> Decimal:
        """
        Obtiene prima de riesgo vigente para un patrón.
        
        Args:
            rfc_patron: RFC del patrón
            fecha: Fecha de consulta (default: hoy)
            
        Returns:
            Prima de riesgo vigente
        """
        if fecha is None:
            fecha = date.today()
        
        # Consultar DB
        prima = self._consultar_prima_riesgo(rfc_patron, fecha)
        
        if not prima:
            # Retornar prima mínima por defecto
            return Decimal('0.018572')
        
        return prima['prima_riesgo']
```

**Impacto:**
- Requiere captura manual de prima asignada por IMSS
- Sin prima registrada, usar mínima (1.8572%)
