## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación proporciona una guía práctica completa para la implementación de **muestreo estadístico según la Norma Internacional de Auditoría 530 (NIA 530)**. El módulo permite automatizar el cálculo de tamaños de muestra, selección de elementos y evaluación de resultados en auditorías financieras, reduciendo el tiempo de 8-12 horas a 30-45 minutos por auditoría.

La NIA 530 es aplicable cuando el auditor decide emplear muestreo de auditoría para diseñar y seleccionar la muestra, realizar pruebas de controles y de detalle, así como para evaluar los resultados del muestreo.

#### Algoritmo 1: Calculadora de Tamaño de Muestra (Fórmula NIA 530)

```python
import math
from typing import Dict, Tuple
from scipy import stats

class MuestreoNIA530:
    """
    Implementación de muestreo estadístico según NIA 530.
    
    Referencias:
    - NIA 530, párrafos 7-12 (diseño de muestra)
    - NIA 530, Anexo 2 (factores que influyen en tamaño de muestra)
    - NIA 520 para procedimientos analíticos complementarios
    """
    
    def __init__(self, nivel_confianza: float = 0.95, 
                 precision: float = 0.05,
                 desviacion_estandar: float = None):
        """
        Inicializa calculadora de muestreo.
        
        Args:
            nivel_confianza: Nivel de confianza (0.90, 0.95, 0.99)
            precision: Precisión deseada (0.03 a 0.07 típico)
            desviacion_estandar: Desviación estándar poblacional (si se conoce)
        """
        self.nivel_confianza = nivel_confianza
        self.precision = precision
        self.desviacion_estandar = desviacion_estandar
        
    def calcular_tamano_muestra_proporciones(self, 
                                              poblacion: int,
                                              proporcion_esperada: float = 0.5) -> int:
        """
        Calcula tamaño de muestra para variables de proporción.
        
        Fórmula NIA 530 para atributos:
        n = (Z² × p × (1-p)) / e²
        
        Con corrección por población finita:
        n_ajustado = n / (1 + (n - 1) / N)
        
        Args:
            poblacion: Tamaño de la población (N)
            proporcion_esperada: Proporción esperada de desviaciones (p)
            
        Returns:
            Tamaño de muestra requerido (n)
            
        Ejemplo:
            >>> muestreo = MuestreoNIA530(nivel_confianza=0.95, precision=0.05)
            >>> n = muestreo.calcular_tamano_muestra_proporciones(poblacion=10000)
            >>> print(f"Tamaño de muestra: {n}")
            Tamaño de muestra: 370
        """
        # Valor Z para nivel de confianza
        z = stats.norm.ppf(1 - (1 - self.nivel_confianza) / 2)
        
        # Fórmula base para proporciones
        p = proporcion_esperada
        e = self.precision
        
        n_base = (z ** 2 * p * (1 - p)) / (e ** 2)
        
        # Corrección por población finita (NIA 530, párrafo A11)
        if poblacion < 100000:  # Aplicar corrección si N < 100,000
            n_ajustado = n_base / (1 + (n_base - 1) / poblacion)
        else:
            n_ajustado = n_base
            
        return math.ceil(n_ajustado)
    
    def calcular_tamano_muestra_medias(self,
                                        poblacion: int,
                                        desviacion_estandar: float = None) -> int:
        """
        Calcula tamaño de muestra para variables continuas (medias).
        
        Fórmula NIA 530 para variables:
        n = (Z × σ / e)²
        
        Args:
            poblacion: Tamaño de la población (N)
            desviacion_estandar: Desviación estándar estimada (σ)
            
        Returns:
            Tamaño de muestra requerido (n)
            
        Ejemplo:
            >>> muestreo = MuestreoNIA530(nivel_confianza=0.95, precision=500)
            >>> n = muestreo.calcular_tamano_muestra_medias(
            ...     poblacion=5000, 
            ...     desviacion_estandar=2500
            ... )
            >>> print(f"Tamaño de muestra: {n}")
            Tamaño de muestra: 96
        """
        z = stats.norm.ppf(1 - (1 - self.nivel_confianza) / 2)
        sigma = desviacion_estandar or self.desviacion_estandar or 1
        
        n_base = (z * sigma / self.precision) ** 2
        
        # Corrección por población finita
        if poblacion < 100000:
            n_ajustado = n_base / (1 + (n_base - 1) / poblacion)
        else:
            n_ajustado = n_base
            
        return math.ceil(n_ajustado)
```

#### Algoritmo 2: Muestreo Aleatorio Simple

```python
import random
from typing import List, Tuple
import pandas as pd

class MuestreoAleatorioSimple:
    """
    Implementa muestreo aleatorio simple según NIA 530, párrafo 8.
    
    Cada elemento de la población tiene probabilidad conocida e igual
    de ser seleccionado.
    """
    
    def __init__(self, semilla: int = None):
        """
        Inicializa muestreador aleatorio.
        
        Args:
            semilla: Semilla para reproducibilidad (opcional)
        """
        if semilla is not None:
            random.seed(semilla)
    
    def seleccionar_muestra(self, 
                           poblacion: List[int], 
                           tamano_muestra: int) -> List[int]:
        """
        Selecciona muestra aleatoria simple sin reemplazo.
        
        Args:
            poblacion: Lista de identificadores de población
            tamano_muestra: Número de elementos a seleccionar
            
        Returns:
            Lista de identificadores seleccionados
            
        Ejemplo:
            >>> muestreador = MuestreoAleatorioSimple(semilla=42)
            >>> poblacion = list(range(1, 1001))  # 1000 facturas
            >>> muestra = muestreador.seleccionar_muestra(poblacion, 50)
            >>> len(muestra)
            50
        """
        if tamano_muestra > len(poblacion):
            raise ValueError(
                f"El tamaño de muestra ({tamano_muestra}) no puede ser "
                f"mayor que la población ({len(poblacion)})"
            )
        
        return random.sample(poblacion, tamano_muestra)
    
    def seleccionar_muestra_dataframe(self,
                                      df: pd.DataFrame,
                                      tamano_muestra: int,
                                      columna_id: str = None) -> pd.DataFrame:
        """
        Selecciona muestra aleatoria de un DataFrame.
        
        Args:
            df: DataFrame con la población
            tamano_muestra: Número de registros a seleccionar
            columna_id: Columna para identificar registros (opcional)
            
        Returns:
            DataFrame con la muestra seleccionada
        """
        if tamano_muestra > len(df):
            raise ValueError(
                f"El tamaño de muestra ({tamano_muestra}) no puede ser "
                f"mayor que la población ({len(df)})"
            )
        
        muestra = df.sample(n=tamano_muestra, random_state=42)
        return muestra.reset_index(drop=True)
```

#### Algoritmo 3: Muestreo Estratificado

```python
class MuestreoEstratificado:
    """
    Implementa muestreo estratificado según NIA 530, párrafo A13.
    
    La población se divide en subpoblaciones (estratos) con características
    similares, y se selecciona muestra de cada estrato.
    """
    
    def __init__(self, metodo_asignacion: str = 'proporcional'):
        """
        Inicializa muestreador estratificado.
        
        Args:
            metodo_asignacion: 'proporcional' o 'optimo'
        """
        self.metodo_asignacion = metodo_asignacion
    
    def crear_estratos(self,
                       valores: List[float],
                       num_estratos: int = 3,
                       metodo: str = 'rangos_iguales') -> Dict[int, Tuple[float, float]]:
        """
        Crea estratos basados en valores.
        
        Args:
            valores: Lista de valores de la población
            num_estratos: Número de estratos a crear
            metodo: 'rangos_iguales' o 'percentiles'
            
        Returns:
            Diccionario {id_estrato: (limite_inferior, limite_superior)}
            
        Ejemplo:
            >>> estratificador = MuestreoEstratificado()
            >>> valores = [100, 500, 1000, 5000, 10000, 50000]
            >>> estratos = estratificador.crear_estratos(valores, num_estratos=3)
            >>> print(estratos)
            {1: (100, 1000), 2: (1000, 10000), 3: (10000, 50000)}
        """
        import numpy as np
        
        valores_array = np.array(valores)
        min_val = valores_array.min()
        max_val = valores_array.max()
        
        if metodo == 'rangos_iguales':
            # Divide el rango en intervalos iguales
            limites = np.linspace(min_val, max_val, num_estratos + 1)
        elif metodo == 'percentiles':
            # Usa percentiles para estratos balanceados
            percentiles = np.linspace(0, 100, num_estratos + 1)
            limites = np.percentile(valores_array, percentiles)
        else:
            raise ValueError(f"Método '{metodo}' no reconocido")
        
        estratos = {}
        for i in range(num_estratos):
            estratos[i + 1] = (limites[i], limites[i + 1])
        
        return estratos
    
    def asignar_muestra_estratificada(self,
                                      poblacion_df: pd.DataFrame,
                                      columna_valor: str,
                                      tamano_muestra_total: int,
                                      estratos: Dict[int, Tuple[float, float]]) -> pd.DataFrame:
        """
        Asigna muestra a estratos proporcionalmente.
        
        Args:
            poblacion_df: DataFrame con la población completa
            columna_valor: Columna con valores para estratificación
            tamano_muestra_total: Tamaño total de muestra deseado
            estratos: Diccionario de estratos
            
        Returns:
            DataFrame con muestra estratificada y columna 'estrato' asignada
        """
        import numpy as np
        
        # Asignar cada registro a su estrato
        def asignar_estrato(valor):
            for id_estrato, (lim_inf, lim_sup) in estratos.items():
                if lim_inf <= valor <= lim_sup:
                    return id_estrato
            return None
        
        poblacion_df['estrato'] = poblacion_df[columna_valor].apply(asignar_estrato)
        
        # Calcular tamaño de muestra por estrato (asignación proporcional)
        muestra_estratos = []
        
        for id_estrato in estratos.keys():
            estrato_df = poblacion_df[poblacion_df['estrato'] == id_estrato]
            n_estrato = len(estrato_df)
            n_poblacion = len(poblacion_df)
            
            if self.metodo_asignacion == 'proporcional':
                # Asignación proporcional al tamaño del estrato
                tamano_muestra_estrato = round(
                    tamano_muestra_total * (n_estrato / n_poblacion)
                )
            else:
                # Asignación óptima (considera varianza)
                # Simplificado: usa proporcional con mínimo de 1
                tamano_muestra_estrato = max(1, round(
                    tamano_muestra_total * (n_estrato / n_poblacion)
                ))
            
            if tamano_muestra_estrato > 0 and len(estrato_df) > 0:
                muestra_estrato = estrato_df.sample(
                    n=min(tamano_muestra_estrato, len(estrato_df)),
                    random_state=42
                )
                muestra_estratos.append(muestra_estrato)
        
        if not muestra_estratos:
            return pd.DataFrame()
        
        muestra_completa = pd.concat(muestra_estratos, ignore_index=True)
        return muestra_completa
```

```python
class MuestreoSistematico:
    """
    Implementa muestreo sistemático según NIA 530, Anexo 4.
    
    Selecciona elementos con intervalo fijo (k) después de un inicio aleatorio.
    """
    
    def seleccionar_muestra_sistematica(self,
                                        poblacion: List[int],
                                        tamano_muestra: int,
                                        inicio_aleatorio: int = None) -> List[int]:
        """
        Selecciona muestra sistemática con intervalo fijo.
        
        Args:
            poblacion: Lista ordenada de identificadores
            tamano_muestra: Número de elementos a seleccionar
            inicio_aleatorio: Punto de inicio (si None, se genera aleatorio)
            
        Returns:
            Lista de identificadores seleccionados
            
        Ejemplo:
            >>> muestreador = MuestreoSistematico()
            >>> poblacion = list(range(1, 1001))  # 1000 facturas ordenadas
            >>> muestra = muestreador.seleccionar_muestra_sistematica(
            ...     poblacion, tamano_muestra=50
            ... )
            >>> len(muestra)
            50
        """
        import random
        
        N = len(poblacion)
        k = N // tamano_muestra  # Intervalo de muestreo
        
        if inicio_aleatorio is None:
            inicio_aleatorio = random.randint(0, k - 1)
        
        indices = [(inicio_aleatorio + i * k) % N for i in range(tamano_muestra)]
        muestra = [poblacion[i] for i in indices]
        
        return muestra
```

```python
class EvaluadorResultadosNIA530:
    """
    Evalúa resultados de muestra y proyecta errores según NIA 530 y NIA 450.
    
    Referencias:
    - NIA 530, párrafos 13-15 (evaluación de resultados)
    - NIA 450, Evaluación de incorrecciones identificadas
    """
    
    def __init__(self, materialidad: float, nivel_confianza: float = 0.95):
        """
        Inicializa evaluador.
        
        Args:
            materialidad: Materialidad de la auditoría (en pesos)
            nivel_confianza: Nivel de confianza para intervalos
        """
        self.materialidad = materialidad
        self.nivel_confianza = nivel_confianza
    
    def proyectar_error_proporcional(self,
                                     valor_muestra: float,
                                     error_encontrado: float,
                                     valor_poblacion: float) -> Dict[str, float]:
        """
        Proyecta error encontrado en muestra a toda la población (método proporcional).
        
        Fórmula: Error proyectado = (Error encontrado / Valor muestra) × Valor población
        
        Args:
            valor_muestra: Valor total de la muestra auditada
            error_encontrado: Error total encontrado en muestra
            valor_poblacion: Valor total de la población
            
        Returns:
            Diccionario con error proyectado y métricas
            
        Ejemplo:
            >>> evaluador = EvaluadorResultadosNIA530(materialidad=100000)
            >>> proyeccion = evaluador.proyectar_error_proporcional(
            ...     valor_muestra=500000,
            ...     error_encontrado=5000,
            ...     valor_poblacion=5000000
            ... )
            >>> print(f"Error proyectado: ${proyeccion['error_proyectado']:,.2f}")
            Error proyectado: $50,000.00
        """
        if valor_muestra == 0:
            return {
                'error_proyectado': 0,
                'tasa_error': 0,
                'materialidad_alcanzada': False,
                'conclusion': 'No se puede proyectar (valor muestra = 0)'
            }
        
        tasa_error = error_encontrado / valor_muestra
        error_proyectado = tasa_error * valor_poblacion
        
        return {
            'error_proyectado': error_proyectado,
            'tasa_error': tasa_error,
            'error_encontrado_muestra': error_encontrado,
            'valor_muestra': valor_muestra,
            'valor_poblacion': valor_poblacion,
            'materialidad_alcanzada': error_proyectado > self.materialidad,
            'porcentaje_materialidad': (error_proyectado / self.materialidad) * 100,
            'conclusion': self._generar_conclusion(error_proyectado, tasa_error)
        }
    
    def _generar_conclusion(self, error_proyectado: float, tasa_error: float) -> str:
        """Genera conclusión cualitativa basada en resultados."""
        if error_proyectado > self.materialidad:
            return (
                f"ALERTA: Error proyectado (${error_proyectado:,.2f}) excede "
                f"materialidad (${self.materialidad:,.2f}). "
                f"Requiere procedimientos adicionales."
            )
        elif error_proyectado > self.materialidad * 0.5:
            return (
                f"PRECAUCIÓN: Error proyectado (${error_proyectado:,.2f}) es "
                f"significativo (>50% materialidad). Considerar procedimientos "
                f"adicionales."
            )
        else:
            return (
                f"ACEPTABLE: Error proyectado (${error_proyectado:,.2f}) está "
                f"por debajo de materialidad. Tasa de error: {tasa_error:.2%}"
            )
    
    def calcular_intervalo_confianza(self,
                                     error_encontrado: int,
                                     tamano_muestra: int,
                                     metodo: str = 'wilson') -> Dict[str, float]:
        """
        Calcula intervalo de confianza para tasa de error.
        
        Args:
            error_encontrado: Número de errores encontrados
            tamano_muestra: Tamaño de la muestra
            metodo: 'wilson', 'agresti-coull', o 'exacto'
            
        Returns:
            Diccionario con límite inferior, superior y punto estimado
        """
        from statsmodels.stats.proportion import proportion_confint
        
        if tamano_muestra == 0:
            return {
                'limite_inferior': 0,
                'limite_superior': 0,
                'estimacion_puntual': 0,
                'nivel_confianza': self.nivel_confianza
            }
        
        tasa_error = error_encontrado / tamano_muestra
        
        li, ls = proportion_confint(
            count=error_encontrado,
            nobs=tamano_muestra,
            alpha=1 - self.nivel_confianza,
            method=metodo
        )
        
        return {
            'limite_inferior': li,
            'limite_superior': ls,
            'estimacion_puntual': tasa_error,
            'nivel_confianza': self.nivel_confianza,
            'metodo': metodo
        }
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Poblaciones Pequeñas (<30 elementos)

**Problema:**
Cuando la población es menor a 30 elementos, los métodos estadísticos tradicionales pierden validez debido al Teorema del Límite Central.

**Solución:**
```python
def muestreo_poblacion_pequena(poblacion: List, materialidad: float) -> Dict:
    """
    Maneja poblaciones pequeñas con censo completo (100%).
    
    Según NIA 530, párrafo A10, para poblaciones pequeñas
    el auditor puede decidir examinar 100% de la población.
    """
    if len(poblacion) < 30:
        return {
            'metodo': 'censo_completo',
            'tamano_muestra': len(poblacion),
            'justificacion': 'Población < 30 elementos (NIA 530 A10)',
            'muestra': poblacion,
            'advertencia': 'Resultados no proyectables estadísticamente'
        }
    # Continuar con muestreo normal
```

**Impacto:**
- Requiere auditoría 100% de la población
- Mayor tiempo de auditoría para poblaciones pequeñas
- No aplicable proyección estadística

### 4.2 Limitación 2: Datos No Normales

**Problema:**
Las poblaciones contables (saldos de cuentas, transacciones) frecuentemente tienen distribuciones sesgadas (muchos valores pequeños, pocos valores grandes).

**Solución:**
```python
def estratificacion_datos_no_normales(valores: List[float]) -> Dict:
    """
    Estratifica datos no normales usando transformaciones.
    
    Aplica transformación logarítmica para normalizar
    y luego crea estratos.
    """
    import numpy as np
    from scipy import stats
    
    valores_array = np.array(valores)
    
    # Verificar normalidad (test de Shapiro-Wilk)
    estadistico, p_valor = stats.shapiro(valores_array[:5000])  # Máx 5000 para Shapiro
    
    if p_valor < 0.05:  # No normal
        # Aplicar transformación logarítmica
        valores_transformados = np.log1p(valores_array)
        
        # Crear estratos en escala logarítmica
        estratos = crear_estratos_percentiles(valores_transformados, num_estratos=5)
        
        return {
            'distribucion': 'no_normal',
            'p_valor': p_valor,
            'transformacion': 'logarítmica',
            'estratos': estratos,
            'recomendacion': 'Usar muestreo estratificado con estratos logarítmicos'
        }
    else:
        # Datos normales, usar método estándar
        return {
            'distribucion': 'normal',
            'p_valor': p_valor,
            'recomendacion': 'Usar muestreo aleatorio simple'
        }
```

**Impacto:**
- Requiere estratificación adicional
- Mayor complejidad en selección de muestra
- Necesita validación de normalidad previa

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **NIA 530 permite flexibilidad:** La norma acepta tanto enfoques estadísticos como no estadísticos, pero requiere que el tamaño de muestra reduzca el riesgo de muestreo a un nivel aceptablemente bajo.

2. **Estratificación es crítica:** Para poblaciones contables típicas (altamente sesgadas), la estratificación por valor reduce el tamaño de muestra necesario en 30-50%.

3. **Herramientas comerciales vs. open-source:** IDEA/ACL cuestan $2,500-6,000 USD/año, pero Python + scipy/statsmodels puede lograr resultados equivalentes con inversión en capacitación.

4. **Validación es esencial:** Los algoritmos deben validarse contra cálculos manuales de contadores certificados y herramientas establecidas (IDEA, ACL).
