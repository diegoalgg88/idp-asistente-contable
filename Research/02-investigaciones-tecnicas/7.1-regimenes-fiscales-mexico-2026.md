## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía completa de regímenes fiscales vigentes en México para 2026, incluyendo:
- RESICO (Régimen Simplificado de Confianza) para personas físicas y morales
- Régimen general de ley (personas morales)
- Sueldos y salarios (personas físicas)
- Honorarios profesionales (personas físicas)
- Arrendamiento de bienes inmuebles
- Actividades agrícolas, ganaderas, pesqueras y silvícolas
- Régimen de incorporación fiscal (RIF) - en transición
- Tasas de ISR aplicables por régimen
- Deducciones autorizadas por régimen
- Obligaciones accesorias (declaraciones mensuales, anuales, informativas)
- Límites de ingresos por régimen

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Identificación de régimen fiscal | Por cliente | 15-30 min/cliente | Automático | 95-98% |
| Cálculo de ISR por régimen | Mensual | 1-2 horas/cliente | 5 min/cliente | 90-95% |
| Validación de deducciones | Mensual | 30-60 min/cliente | Automático | 95-98% |
| Verificación de límites de ingresos | Trimestral | 20-30 min/cliente | Automático | 100% |
| Asesoría de cambio de régimen | Anual | 1-2 horas/cliente | 15 min/cliente | 85-90% |

### 1.3 Dolor Principal que Resuelve

**Problema:** Los contadores deben identificar y aplicar el régimen fiscal correcto para cada cliente. Un error en la identificación genera:
- Tasas de ISR incorrectas (1-3% RESICO vs. 1.92-35% régimen general)
- Deducciones no aplicables (RESICO no tiene deducciones personales)
- Multas por cambio de régimen no notificado ($2,000-$50,000 MXN)
- Pérdida de beneficios fiscales (exención de declaración anual RESICO)

**Problema específico 2026:**
- RESICO consolidado como régimen preferente para ingresos < $3.5M MXN
- Nuevas obligaciones (Buzón Tributario obligatorio desde 2027)
- Mayor fiscalización (cancelación de RFC por incumplimiento)
- Tasas diferenciadas por nivel de ingresos (1% - 2.75%)

**Solución IDP-App:** Identificación automática de régimen fiscal óptimo + cálculo de ISR con tasas correctas + alertas de cambios de régimen.

|----------|-------|
| Tiempo liberado en identificación | 2-3 horas/semana |
| Valor de hora de contador | $300 MXN |
| Ahorro semanal | $600-$900 MXN |
| Multas evitadas (promedio) | $10,000-$50,000 MXN/año |

### 2.4 Requisitos para Tributar en RESICO 2026

#### Personas Físicas

| Requisito | Descripción |
|-----------|-------------|
| **Ingresos máximos** | $3.5 millones de pesos anuales (incluyendo salarios e intereses) |
| **Actividades permitidas** | Empresariales, profesionales (honorarios), arrendamiento, agrícolas/ganaderas/pesqueras/silvícolas |
| **No estar excluido** | No ser socio de personas morales, no tener ingresos por plataformas digitales exclusivamente, no ser intermediario financiero |
| **Aviso de cambio** | Presentar aviso de actualización de actividades y obligaciones antes del 31 de enero 2026 |
| **e.firma vigente** | Certificado de sello digital vigente |
| **Buzón Tributario** | Obligatorio activarlo (exigible plenamente desde 1-ene-2027) |

#### Personas Morales

| Requisito | Descripción |
|-----------|-------------|
| **Ingresos máximos** | $35 millones de pesos anuales |
| **Tipo de entidad** | Personas morales nuevas o existentes que cumplan límites |
| **No estar excluida** | No ser entidad financiera, no ser parte de grupo consolidable |
| **Aviso de cambio** | Presentar aviso dentro del primer mes del ejercicio |

### 2.5 Quiénes NO Pueden Tributar en RESICO 2026

| Supuesto | Descripción |
|----------|-------------|
| **Ingresos > $3.5M** | Personas físicas con ingresos superiores a $3.5 millones anuales |

| **Plataformas digitales** | Quienes obtengan ingresos exclusivamente por plataformas digitales (apps, marketplaces) |
| **Intermediarios financieros** | Entidades del sistema financiero |

```python
from dataclasses import dataclass

from decimal import Decimal, ROUND_HALF_UP
from enum import Enum


class TipoContribuyente(Enum):
    PERSONA_FISICA = 'PF'

class ActividadEconomica(Enum):

    PROFESIONAL = 'profesional'

    AGROPECUARIA = 'agropecuaria'

@dataclass

    descripcion: str

    tasa_maxima: Decimal
    limite_ingresos: Optional[Decimal]

class IdentificadorRegimenFiscal:
    """

    def identificar_regimen_optimo(self, perfil: PerfilContribuyente) -> List[RegimenFiscal]:
        """
        Identifica el régimen fiscal óptimo para un contribuyente.
        
        Args:
            perfil: Perfil del contribuyente
            
        Returns:
            Lista de regímenes recomendados (ordenados por conveniencia)
        """
        regimenes_sugeridos = []
        
        # Validar tipo de contribuyente
        if perfil.tipo_contribuyente == TipoContribuyente.PERSONA_FISICA:
            # Personas Físicas
            regimenes_sugeridos = self._identificar_regimen_pf(perfil)
        else:
            # Personas Morales
            regimenes_sugeridos = self._identificar_regimen_pm(perfil)
        
        return regimenes_sugeridos
    
    def _identificar_regimen_pf(self, perfil: PerfilContribuyente) -> List[RegimenFiscal]:
        """Identifica régimen para personas físicas."""
        regimenes = []
        
        # Validar exclusiones de RESICO
        puede_resico = True
        exclusiones = []
        
        if perfil.ingresos_anuales_estimados > Decimal('3500000'):
            puede_resico = False
            exclusiones.append('Ingresos superiores a $3.5M anuales')
        
        if perfil.es_socio_persona_moral:
            puede_resico = False
            exclusiones.append('Socio de persona moral')
        
        if perfil.tiene_ingresos_exclusivamente_plataformas:
            puede_resico = False
            exclusiones.append('Ingresos exclusivamente por plataformas digitales')
        
        if perfil.es_intermediario_financiero:
            puede_resico = False
            exclusiones.append('Intermediario financiero')
        
        # Actividades permitidas en RESICO
        actividades_resico = [
            ActividadEconomica.EMPRESARIAL,
            ActividadEconomica.PROFESIONAL,
            ActividadEconomica.ARRENDAMIENTO,
            ActividadEconomica.AGROPECUARIA
        ]
        
        actividades_permitidas = all(act in actividades_resico for act in perfil.actividades)
        
        if not actividades_permitidas:
            puede_resico = False
            exclusiones.append('Actividad no permitida en RESICO')
        
        # Si puede RESICO, sugerirlo primero (tasas más bajas)
        if puede_resico:
            # Determinar régimen RESICO específico según actividad
            if ActividadEconomica.ARRENDAMIENTO in perfil.actividades:
                regimenes.append(self._obtener_regimen_por_clave('606'))  # Arrendamiento RESICO
            else:
                regimenes.append(self._obtener_regimen_por_clave('603'))  # RESICO PF
        
        # Sugerir régimen general como alternativa
        if ActividadEconomica.SUELDOS_SALARIOS in perfil.actividades:
            regimenes.append(self._obtener_regimen_por_clave('605'))  # Sueldos y Salarios
        
        if any(act in [ActividadEconomica.EMPRESARIAL, ActividadEconomica.PROFESIONAL] 
               for act in perfil.actividades):
            regimenes.append(self._obtener_regimen_por_clave('612'))  # Actividades Empresariales
        
        if ActividadEconomica.ARRENDAMIENTO in perfil.actividades:
            regimenes.append(self._obtener_regimen_por_clave('606'))  # Arrendamiento
        
        if ActividadEconomica.AGROPECUARIA in perfil.actividades:
            regimenes.append(self._obtener_regimen_por_clave('610'))  # Agropecuario
        
        return regimenes
    
    def _identificar_regimen_pm(self, perfil: PerfilContribuyente) -> List[RegimenFiscal]:
        """Identifica régimen para personas morales."""
        regimenes = []
        
        # Validar si puede RESICO PM
        puede_resico_pm = True
        
        if perfil.ingresos_anuales_estimados > Decimal('35000000'):
            puede_resico_pm = False
        
        if perfil.es_intermediario_financiero:
            puede_resico_pm = False
        
        # Si puede RESICO PM, sugerirlo primero
        if puede_resico_pm:
            regimenes.append(self._obtener_regimen_por_clave('626'))  # RESICO PM
        
        # Régimen general como alternativa
        regimenes.append(self._obtener_regimen_por_clave('601'))  # General de Ley PM
        
        return regimenes
    
    def _obtener_regimen_por_clave(self, clave: str) -> Optional[RegimenFiscal]:
        """Obtiene régimen por clave SAT."""
        for regimen in self.regimenes_disponibles:
            if regimen.clave == clave:
                return regimen
        return None
    
    def calcular_tasa_efectiva_resico(self, ingresos_anuales: Decimal) -> Decimal:
        """
        Calcula la tasa efectiva de ISR para RESICO según nivel de ingresos.
        
        Args:
            ingresos_anuales: Ingresos anuales acumulados
            
        Returns:
            Tasa efectiva aplicable (1% - 2.75%)
        """
        if ingresos_anuales <= Decimal('100000'):
            return Decimal('1.00')
        elif ingresos_anuales <= Decimal('250000'):
            return Decimal('1.10')
        elif ingresos_anuales <= Decimal('500000'):
            return Decimal('1.50')
        elif ingresos_anuales <= Decimal('1000000'):
            return Decimal('2.00')
        elif ingresos_anuales <= Decimal('2500000'):
            return Decimal('2.50')
        elif ingresos_anuales <= Decimal('3500000'):
            return Decimal('2.75')
        else:
            # Fuera de RESICO
            return Decimal('30.00')  # Tasa general PM o tabla progresiva PF
    
    def calcular_isr_resico_mensual(self, ingresos_mes: Decimal, ingresos_acumulados_anio: Decimal) -> Decimal:
        """
        Calcula ISR mensual para RESICO.
        
        Args:
            ingresos_mes: Ingresos del mes
            ingresos_acumulados_anio: Ingresos acumulados en el año (incluyendo mes actual)
            
        Returns:
            ISR a pagar del mes
        """
        tasa_efectiva = self.calcular_tasa_efectiva_resico(ingresos_acumulados_anio)
        isr_mensual = ingresos_mes * (tasa_efectiva / 100)
        return isr_mensual.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Cambios de Régimen Solo en Enero

**Problema:**
El cambio de régimen fiscal solo puede realizarse al inicio del ejercicio fiscal (enero). Un cliente que identifica en marzo que debería estar en RESICO debe esperar hasta enero siguiente.

**Solución:**
```python
class GestorCambiosRegimen:
    """
    Gestiona cambios de régimen fiscal.
    Valida fechas y notifica plazos.
    """
    
    def validar_fecha_cambio(self, fecha_solicitud: date, tipo_cambio: str) -> Dict:
        """
        Valida si es posible realizar cambio de régimen en la fecha solicitada.
        
        Args:
            fecha_solicitud: Fecha de solicitud de cambio
            tipo_cambio: Tipo de cambio ('inicio_ejercicio', 'durante_ejercicio')
            
        Returns:
            Dict con resultado de validación
        """
        # Cambio al inicio del ejercicio (enero)
        if fecha_solicitud.month == 1 and fecha_solicitud.day <= 31:
            return {
                'valido': True,
                'mensaje': 'Cambio válido para inicio de ejercicio',
                'fecha_limite_aviso': date(fecha_solicitud.year, 1, 31)
            }
        
        # Cambio durante el ejercicio (solo casos específicos)
        if tipo_cambio == 'inicio_actividades':
            return {
                'valido': True,
                'mensaje': 'Cambio válido por inicio de actividades',
                'fecha_limite_aviso': fecha_solicitud + timedelta(days=30)
            }
        
        # Fuera de plazo
        proximo_enero = date(fecha_solicitud.year + 1, 1, 31)
        return {
            'valido': False,
            'mensaje': f'Fuera de plazo. Próxima oportunidad: {proximo_enero}',
            'fecha_sugerida': proximo_enero
        }
```

**Impacto:**
- Notificar clientes en diciembre sobre cambios de régimen
- Aviso obligatorio antes del 31 de enero

### 4.2 Limitación 2: RESICO No Permite Deducciones Personales

**Problema:**
Los contribuyentes RESICO no pueden aplicar deducciones personales (gastos médicos, colegiaturas, etc.). Esto puede generar confusión y reclamos de clientes.

**Solución:**
```python
class ValidadorDeducciones:
    """
    Valida si un contribuyente puede aplicar deducciones personales.
    """
    
    def puede_aplicar_deducciones(self, regimen_fiscal: str) -> bool:
        """
        Valida si el régimen fiscal permite deducciones personales.
        
        Args:
            regimen_fiscal: Clave del régimen fiscal (603 = RESICO, 612 = General, etc.)
            
        Returns:
            bool: True si permite deducciones, False si no
        """
        regimenes_sin_deducciones = ['603', '606']  # RESICO PF y Arrendamiento RESICO
        
        return regimen_fiscal not in regimenes_sin_deducciones
    
    def calcular_ahorro_fiscal_comparativo(
        self,
        ingresos_anuales: Decimal,
        deducciones_personales: Decimal,
        regimen_actual: str
    ) -> Dict:
        """
        Calcula ahorro fiscal comparativo entre RESICO y Régimen General.
        
        Args:
            ingresos_anuales: Ingresos anuales del contribuyente
            deducciones_personales: Total de deducciones personales
            regimen_actual: Régimen fiscal actual
            
        Returns:
            Dict con comparativa de ahorro
        """
        # Calcular ISR en RESICO (sin deducciones)
        isr_resico = self._calcular_isr_resico_anual(ingresos_anuales)
        
        # Calcular ISR en Régimen General (con deducciones)
        base_gravable_general = ingresos_anuales - deducciones_personales
        isr_general = self._calcular_isr_general_anual(base_gravable_general)
        
        return {
            'isr_resico': isr_resico,
            'isr_general': isr_general,
            'ahorro_resico': isr_general - isr_resico if isr_general > isr_resico else Decimal('0'),
            'recomendacion': 'RESICO' if isr_resico < isr_general else 'Régimen General'
        }
```

**Impacto:**
- Explicar claramente a clientes que RESICO no tiene deducciones
- Comparar ahorro real entre regímenes antes de recomendar cambio
