## 1. Descripción del Módulo

### 1.1 Propósito

Este documento proporciona una guía técnica completa para implementar forecasting de impuestos (ISR e IVA) utilizando Facebook Prophet, específicamente adaptado al contexto fiscal mexicano. El módulo permite:

- **Predecir cargas fiscales futuras** basadas en histórico de operaciones
- **Identificar estacionalidad específica** de México (picos marzo por declaración anual, diciembre por aguinaldo)
- **Incorporar holidays fiscales** mexicanos al modelo (Semana Santa, Día de Muertos, Navidad, etc.)
- **Validar modelos** con métricas estándar (MAPE <10%, RMSE optimizado)

El forecasting es crítico para que empresas mexicanas puedan:
- Planificar flujo de caja para pagos trimestrales (marzo, junio, septiembre, diciembre)
- Anticipar declaraciones anuales (31 de marzo para personas morales)
- Optimizar estrategia fiscal antes del cierre del ejercicio

**Problema:** Los contadores en México realizan proyecciones fiscales manuales basadas en:
- Promedios simples de meses anteriores (ignora estacionalidad)
- Experiencia empírica (no escalable, propenso a errores)

**Solución:** Prophet automatiza el forecasting con:
- Modelado automático de tendencia no-lineal
- Detección de estacionalidad yearly/weekly/daily
- Incorporación de holidays mexicanos específicos
- Métricas de validación objetivas (MAPE, RMSE, MAE)

#### Algoritmo 1: Preprocesamiento de Datos (Formato Prophet)

```python
import pandas as pd
import numpy as np
from typing import Tuple, Optional

def preprocess_tax_data(
    df: pd.DataFrame,
    date_column: str = 'fecha',
    amount_column: str = 'monto_impuesto',
    winsorize_limits: Tuple[float, float] = (0.01, 0.99)
) -> pd.DataFrame:
    """
    Preprocesa datos históricos de impuestos para formato Prophet.
    
    Args:
        df: DataFrame con datos históricos
        date_column: Nombre de columna con fechas
        amount_column: Nombre de columna con montos de impuesto
        winsorize_limits: Límites para winsorización (inferior, superior)
    
    Returns:
        DataFrame con columnas 'ds' y 'y' para Prophet
    
    Ejemplo:
        >>> df = pd.DataFrame({
        ...     'fecha': ['2025-01-17', '2025-02-17', '2025-03-17'],
        ...     'monto_impuesto': [15000, 18000, 45000]  # Marzo: pico anualidad
        ... })
        >>> df_prophet = preprocess_tax_data(df)
        >>> print(df_prophet.columns)
        Index(['ds', 'y'], dtype='object')
    """
    # Copia para no modificar original
    df_clean = df.copy()
    
    # 1. Convertir fecha a datetime
    df_clean['ds'] = pd.to_datetime(df_clean[date_column])
    
    # 2. Renombrar columna de monto
    df_clean['y'] = df_clean[amount_column]
    
    # 3. Winsorización para outliers (picos extremos)
    lower_limit = df_clean['y'].quantile(winsorize_limits[0])
    upper_limit = df_clean['y'].quantile(winsorize_limits[1])
    df_clean['y'] = df_clean['y'].clip(lower=lower_limit, upper=upper_limit)
    
    # 4. Manejo de valores nulos (interpolación lineal)
    df_clean = df_clean.sort_values('ds')
    df_clean['y'] = df_clean['y'].interpolate(method='linear')
    
    # 5. Seleccionar solo columnas requeridas por Prophet
    df_prophet = df_clean[['ds', 'y']].reset_index(drop=True)
    
    return df_prophet


# Ejemplo de uso con datos sintéticos realistas
if __name__ == "__main__":
```

#### Algoritmo 3: Configuración de Prophet con Estacionalidad Mexicana

```python
from prophet import Prophet
from prophet.diagnostics import cross_validation, performance_metrics
import pandas as pd
import numpy as np
from typing import Dict, Tuple

def configure_prophet_mexico(
    growth: str = 'logistic',
    yearly_seasonality: bool = True,
    weekly_seasonality: bool = False,
    daily_seasonality: bool = False,
    holidays: pd.DataFrame = None,
    changepoint_prior_scale: float = 0.05,
    seasonality_prior_scale: float = 10.0,
    holidays_prior_scale: float = 10.0,
) -> Prophet:
    """
    Configura modelo Prophet optimizado para datos fiscales mexicanos.
    
    Args:
        growth: 'linear' o 'logistic' (recomendado para impuestos)
        yearly_seasonality: True para estacionalidad anual (picos marzo/diciembre)
        weekly_seasonality: False para datos mensuales
        daily_seasonality: False para datos mensuales
        holidays: DataFrame de holidays de México
        changepoint_prior_scale: Flexibilidad de cambios de tendencia (0.001-0.5)
        seasonality_prior_scale: Fuerza de estacionalidad (0.01-100)
        holidays_prior_scale: Impacto de holidays (0.01-100)
    
    Returns:
        Modelo Prophet configurado
    
    Referencia:
        - [Prophet Documentation](https://facebook.github.io/prophet/docs/quick_start.html)
        - [Prophet Parameter Tuning](https://facebook.github.io/prophet/docs/diagnostics.html)
    """
    model = Prophet(
        growth=growth,
        yearly_seasonality=yearly_seasonality,
        weekly_seasonality=weekly_seasonality,
        daily_seasonality=daily_seasonality,
        holidays=holidays,
        changepoint_prior_scale=changepoint_prior_scale,
        seasonality_prior_scale=seasonality_prior_scale,
        holidays_prior_scale=holidays_prior_scale,
        interval_width=0.95,  # Intervalos de confianza al 95%
    )
    
    # Agregar estacionalidad personalizada para México
    # Pico marzo (anualidad) y diciembre (aguinaldo)
    model.add_seasonality(
        name='mexico_fiscal',
        period=365.25,
        fourier_order=10,
        prior_scale=10.0,
        mode='additive',
    )
    
    return model


def train_prophet_model(
    df: pd.DataFrame,
    holidays: pd.DataFrame = None,
    cap: float = None,
    floor: float = None,
) -> Tuple[Prophet, pd.DataFrame]:
    """
    Entrena modelo Prophet con datos fiscales mexicanos.
    
    Args:
        df: DataFrame con columnas 'ds' y 'y'
        holidays: DataFrame de holidays de México
        cap: Capacidad máxima para crecimiento logístico
        floor: Piso mínimo para crecimiento logístico
    
    Returns:
        Tuple con modelo entrenado y DataFrame de forecast
    """
    # Preparar DataFrame para crecimiento logístico
    if cap is not None:
        df['cap'] = cap
        df['floor'] = floor if floor is not None else 0
    
    # Configurar modelo
    model = configure_prophet_mexico(holidays=holidays)
    
    # Entrenar
    model.fit(df)
    
    # Crear DataFrame futuro para predicción
    if cap is not None:
        future = model.make_future_dataframe(periods=12, freq='M')
        future['cap'] = cap
        future['floor'] = floor if floor is not None else 0
    else:
        future = model.make_future_dataframe(periods=12, freq='M')
    
    # Predecir
    forecast = model.predict(future)
    
    return model, forecast


# Ejemplo completo de entrenamiento
```

```python
from prophet.diagnostics import cross_validation, performance_metrics
from prophet import Prophet
import pandas as pd
import numpy as np
from typing import Dict, Tuple

def cross_validate_prophet(
    df: pd.DataFrame,
    holidays: pd.DataFrame = None,
    initial: str = '365 days',
    period: str = '30 days',
    horizon: str = '90 days',
) -> Tuple[pd.DataFrame, Dict[str, float]]:
    """
    Realiza cross-validation para modelo Prophet con métricas completas.
    
    Args:
        df: DataFrame con datos históricos ('ds', 'y')
        holidays: DataFrame de holidays de México
        initial: Período inicial de entrenamiento (ej: '365 days')
        period: Período entre cutoffs (ej: '30 days')
        horizon: Horizonte de predicción (ej: '90 days')
    
    Returns:
        Tuple con DataFrame de CV y diccionario de métricas
    
    Métricas:
        - MAPE: Mean Absolute Percentage Error (target: <10%)
        - RMSE: Root Mean Squared Error (target: optimizado)
        - MAE: Mean Absolute Error
        - MASE: Mean Absolute Scaled Error
        - SMAPE: Symmetric Mean Absolute Percentage Error
    
    Referencia:
        - [Prophet Cross-Validation](https://facebook.github.io/prophet/docs/diagnostics.html)
        - [MAPE, RMSE, MAE Guide](https://www.machinelearningmastery.com/time-series-forecasting-performance-measures-with-python/)
    """
    # Configurar modelo
    model = configure_prophet_mexico(holidays=holidays)
    
    # Cross-validation
    df_cv = cross_validation(
        model=model,
        initial=initial,
        period=period,
        horizon=horizon,
        parallel="processes",  # Paralelización
    )
    
    # Calcular métricas
    df_metrics = performance_metrics(df_cv)
    
    # Métricas resumen (promedio)
    metrics_summary = {
        'mape': df_metrics['mape'].mean(),
        'rmse': df_metrics['rmse'].mean(),
        'mae': df_metrics['mae'].mean(),
        'mase': df_metrics['mase'].mean() if 'mase' in df_metrics.columns else None,
        'smape': df_metrics['smape'].mean() if 'smape' in df_metrics.columns else None,
    }
    
    return df_cv, metrics_summary


def evaluate_forecast_accuracy(
    actual: pd.Series,
    predicted: pd.Series,
) -> Dict[str, float]:
    """
    Calcula métricas de precisión de forecasting.
    
    Args:
        actual: Serie con valores reales
        predicted: Serie con valores predichos
    
    Returns:
        Diccionario con métricas de evaluación
    
    Fórmulas:
        MAPE = (1/n) * Σ|((actual - predicted) / actual) * 100|
        RMSE = √((1/n) * Σ(actual - predicted)²)
        MAE = (1/n) * Σ|actual - predicted|
    """
    # Asegurar que son arrays de numpy
    actual = np.array(actual)
    predicted = np.array(predicted)
    
    # Evitar división por cero
    mask = actual != 0
    
    # MAPE (Mean Absolute Percentage Error)
    mape = np.mean(np.abs((actual[mask] - predicted[mask]) / actual[mask])) * 100
    
    # RMSE (Root Mean Squared Error)
    rmse = np.sqrt(np.mean((actual - predicted) ** 2))
    
    # MAE (Mean Absolute Error)
    mae = np.mean(np.abs(actual - predicted))
    
    # MASE (Mean Absolute Scaled Error) - requiere histórico
    # naive_forecast = np.roll(actual, 1)[1:]
    # naive_errors = np.abs(actual[1:] - naive_forecast)
    # mase = mae / np.mean(naive_errors)
    
    return {
        'mape': mape,
        'rmse': rmse,
        'mae': mae,
        # 'mase': mase,
    }
```

```python
# Ejemplo: Extraer datos de CFDI con NVIDIA NIM
import requests

def extract_cfdi_data_with_nim(pdf_path: str, api_key: str) -> dict:
    """
    Extrae datos de CFDI usando NVIDIA NIM OCR.
    
    Args:
        pdf_path: Ruta al archivo PDF del CFDI
        api_key: API key de NVIDIA NIM
    
    Returns:
        Diccionario con fecha, monto, RFC emisor/receptor
    """
    url = "https://integrate.api.nvidia.com/v1/chat/completions"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json"
    }
    
    # Leer PDF y convertir a base64
    import base64
    with open(pdf_path, 'rb') as f:
        pdf_base64 = base64.b64encode(f.read()).decode()
    
    payload = {
        "model": "nvidia/nim-google/gemma-3n-e4b-it",
        "messages": [
            {
                "role": "user",
                "content": [
                    {
                        "type": "image_url",
                        "image_url": f"data:application/pdf;base64,{pdf_base64}"
                    },
                    {
                        "type": "text",
                        "text": "Extrae del CFDI: fecha, monto total, RFC emisor, RFC receptor, concepto. Responde en JSON."
                    }
                ]
            }
        ],
        "temperature": 0.1,
        "max_tokens": 500
    }
    
    response = requests.post(url, headers=headers, json=payload)
    result = response.json()
    
    # Parsear respuesta
    import json
    extracted_data = json.loads(result['choices'][0]['message']['content'])
    
    return extracted_data
```

### 4.1 Limitación 1: Datos Históricos Insuficientes

**Problema:**
- Prophet requiere mínimo 1 año de datos para detectar estacionalidad yearly
- Muchas PyMEs mexicanas no tienen histórico digitalizado
- Datos en papel o spreadsheets desorganizados

**Solución:**

```python
def handle_insufficient_data(df: pd.DataFrame) -> tuple:
    """
    Maneja casos con datos históricos insuficientes.
    
    Args:
        df: DataFrame con datos históricos
    
    Returns:
        Tuple con (es_suficiente, mensaje, recomendación)
    """
    min_records = len(df)
    date_range = (df['ds'].max() - df['ds'].min()).days
    
    if min_records < 12:
        return (
            False,
            f"Se requieren mínimo 12 registros, se tienen {min_records}",
            "Capturar al menos 12 meses de histórico antes de entrenar"
        )
    
    if date_range < 365:
        return (
            False,
            f"Se requiere mínimo 1 año de histórico, se tienen {date_range} días",
            "Esperar a completar 365 días de datos"
        )
    
    return (True, "Datos suficientes", "Proceder con entrenamiento")


# Workaround: Usar datos sintéticos basados en promedios de industria
def generate_synthetic_data_based_on_industry(
    industry: str,
    months: int = 12,
) -> pd.DataFrame:
    """
    Genera datos sintéticos basados en promedios de industria.
    
    Args:
        industry: Industria (comercio, servicios, manufactura)
        months: Número de meses a generar
    
    Returns:
        DataFrame sintético para entrenamiento inicial
    """
    # Promedios por industria (ejemplos)
    industry_averages = {
        'comercio': {'base': 15000, 'march_multiplier': 2.5, 'december_multiplier': 1.8},
        'servicios': {'base': 25000, 'march_multiplier': 2.0, 'december_multiplier': 1.5},
        'manufactura': {'base': 50000, 'march_multiplier': 3.0, 'december_multiplier': 2.0},
    }
    
    params = industry_averages.get(industry, industry_averages['comercio'])
    
    fechas = pd.date_range(end=pd.Timestamp.now(), periods=months, freq='M')
    montos = []
    
    for fecha in fechas:
        base = params['base']
        if fecha.month == 3:
            base *= params['march_multiplier']
        elif fecha.month == 12:
            base *= params['december_multiplier']
        
        # Variación aleatoria
        monto = base + np.random.normal(0, base * 0.1)
        montos.append(max(0, monto))
    
    return pd.DataFrame({'ds': fechas, 'y': montos})
```

- Retraso en implementación: 3-6 meses para acumular histórico
- Solución temporal: Usar promedios de industria (menos preciso)

### 4.2 Limitación 2: Cambios en Legislación Fiscal

**Problema:**
- Reformas fiscales anuales modifican tasas, deducciones, obligaciones
- Prophet no puede predecir cambios legislativos
- Modelo entrenado con datos 2024 puede no ser válido para 2026

**Solución:**
- **Re-entrenamiento trimestral:** Actualizar modelo con datos más recientes
- **Ajuste manual de parámetros:** Modificar `changepoint_prior_scale` ante reformas
- **Scenario planning:** Crear múltiples modelos (optimista, pesimista, base)

```python
def adjust_for_fiscal_reform(
    model: Prophet,
    reform_date: pd.Timestamp,
    reform_impact: float,
) -> Prophet:
    """
    Ajusta modelo para reforma fiscal conocida.
    
    Args:
        model: Modelo Prophet entrenado
        reform_date: Fecha de entrada en vigor de reforma
        reform_impact: Impacto estimado en % (ej: 0.10 = +10%)
    
    Returns:
        Modelo ajustado
    """
    # Agregar holiday para reforma fiscal
    reform_df = pd.DataFrame({
        'holiday': ['Reforma Fiscal'],
        'ds': [reform_date],
        'lower_window': [0],
        'upper_window': [12],  # Impacto por 12 meses
    })
    
    model.add_country_holidays('Mexico')  # Si no está agregado
    model.holidays = reform_df
    
    return model
```

**Impacto:**
- Requiere monitoreo constante de DOF, SAT
- Re-entrenamiento manual o automático

## Apéndice A: Dataset Sintético de Ejemplo

```python
import pandas as pd
import numpy as np

def generate_mexico_tax_dataset(
    start_year: int = 2024,
    end_year: int = 2025,
    industry: str = 'comercio',
    seed: int = 42,
) -> pd.DataFrame:
    """
    Genera dataset sintético de impuestos para testing.
    
    Args:
        start_year: Año de inicio
        end_year: Año de fin
        industry: Industria (comercio, servicios, manufactura)
        seed: Seed para reproducibilidad
    
    Returns:
        DataFrame con columnas 'ds', 'y', 'industry'
    
    Características:
        - Pico marzo: 2.5x (declaración anual)
        - Pico diciembre: 1.8x (aguinaldo, cierre)
        - Ruido aleatorio: 10-15% variación
    """
    np.random.seed(seed)
    
    # Parámetros por industria
    params = {
        'comercio': {'base': 15000, 'march': 2.5, 'december': 1.8},
        'servicios': {'base': 25000, 'march': 2.0, 'december': 1.5},
        'manufactura': {'base': 50000, 'march': 3.0, 'december': 2.0},
    }
    
    p = params.get(industry, params['comercio'])
    
    # Generar fechas (día 17 de cada mes, pago provisional)
    fechas = pd.date_range(
        start=f'{start_year}-01-17',
        end=f'{end_year}-12-17',
        freq='MS'
    ) + pd.Timedelta(days=16)
    
    # Generar montos con estacionalidad
    montos = []
    for fecha in fechas:
        base = p['base']
        
        # Tendencia anual (crecimiento por inflación)
        base *= (1 + 0.045) ** (fecha.year - start_year)  # 4.5% inflación
        
        # Estacionalidad
        if fecha.month == 3:
            base *= p['march']
        elif fecha.month == 12:
            base *= p['december']
        
        # Ruido aleatorio
        monto = base + np.random.normal(0, base * 0.1)
        montos.append(max(0, monto))
    
    df = pd.DataFrame({
        'ds': fechas,
        'y': montos,
        'industry': industry,
    })
    
    return df


# Ejemplo de uso
if __name__ == "__main__":

    df_servicios = generate_mexico_tax_dataset(industry='servicios')
```
