## Marco Normativo

### ¿Qué es el ISSB?

**ISSB** (International Sustainability Standards Board): Organismo establecido por la IFRS Foundation en noviembre 2021 (COP26) para desarrollar estándares globales de revelación de sostenibilidad.

**Objetivo**: Crear un lenguaje común para reportes de sostenibilidad que permita comparabilidad global para inversionistas.

### Los Dos Primeros Estándares

| **NIIF S2** | Revelaciones Relacionadas con el Clima | Establece requisitos específicos para revelar información sobre riesgos y oportunidades relacionados con el clima |

## NIIF S1: Requisitos Generales

### Los 4 Pilares de Revelación

La NIIF S1 se basa en los 4 pilares del TCFD:

```
┌─────────────────────────────────────────────────────────┐
│              NIIF S1 - 4 PILARES DE REVELACIÓN          │
├─────────────────────────────────────────────────────────┤
│  1. GOBERNANZA                                          │
│     ¿Cómo supervisa la administración los riesgos       │
│     y oportunidades de sostenibilidad?                  │
│                                                         │
│  2. ESTRATEGIA                                          │
│     ¿Cuál es el impacto de los riesgos y oportunidades  │
│     de sostenibilidad en el modelo de negocio?          │
│                                                         │
│  3. GESTIÓN DE RIESGOS                                  │
│     ¿Cómo identifica, evalúa y gestiona la entidad      │
│     los riesgos de sostenibilidad?                      │
│                                                         │
│  4. MÉTRICAS Y OBJETIVOS                                │
│     ¿Qué métricas utiliza la entidad para medir         │
│     el desempeño en sostenibilidad?                     │
└─────────────────────────────────────────────────────────┘
```

### 1. Gobernanza (Requisitos de Revelación)

**Objetivo**: Revelar cómo la entidad supervisa y gestiona riesgos y oportunidades de sostenibilidad.

**Revelaciones requeridas:**

```
GOB-1: Órganos de gobierno responsables
  - Identificar el órgano (consejo, comité)
  - Composición del órgano
  - Frecuencia de reuniones
  - Cómo se integra la sostenibilidad en la agenda

GOB-2: Procesos de supervisión
  - Cómo se monitorea el progreso
  - Cómo se evalúa el desempeño
  - Cómo se remunera el desempeño en sostenibilidad

GOB-3: Roles de la administración
  - ¿Quién es responsable a nivel ejecutivo?
  - ¿Cómo se informa al consejo?
  - ¿Qué controles existen?
```

**Ejemplo de revelación:**
```
El Consejo de Administración de [EMPRESA] supervisa los riesgos 
de sostenibilidad a través del Comité de Auditoría y Riesgos, 
que se reúne trimestralmente. 

El Comité está compuesto por 5 consejeros, 3 de ellos independientes, 
con experiencia en sostenibilidad y gestión de riesgos.

El Director de Sostenibilidad (CSO) reporta directamente al CEO 
y presenta actualizaciones trimestrales al Consejo.

La remuneración variable del equipo ejecutivo incluye un 15% 
vinculado a metas de sostenibilidad (reducción de emisiones, 
diversidad de género, seguridad laboral).
```

### 2. Estrategia (Requisitos de Revelación)

**Objetivo**: Revelar cómo los riesgos y oportunidades de sostenibilidad afectan el modelo de negocio y la estrategia.

**Revelaciones requeridas:**

```
EST-1: Riesgos y oportunidades identificados
  - Lista de riesgos significativos
  - Lista de oportunidades significativas
  - Horizonte de tiempo (corto, mediano, largo plazo)

EST-2: Impacto en el modelo de negocio
  - ¿Cómo afecta la cadena de valor?
  - ¿Qué activos están en riesgo?
  - ¿Qué oportunidades de mercado existen?

EST-3: Impacto financiero
  - Efectos en estado de situación financiera
  - Efectos en estado de resultados
  - Efectos en flujos de efectivo

EST-4: Resiliencia de la estrategia
  - Análisis de escenarios climáticos
  - Pruebas de estrés
  - Planes de adaptación
```

**Horizontes de tiempo:**
| Horizonte | Período | Ejemplo |
|-----------|---------|---------|
| **Corto plazo** | 1-3 años | Próximos ejercicios fiscales |
| **Mediano plazo** | 3-10 años | Vida útil de activos principales |
| **Largo plazo** | 10+ años | Metas net-zero, infraestructura crítica |

### 3. Gestión de Riesgos (Requisitos de Revelación)

**Objetivo**: Revelar cómo la entidad identifica, evalúa y gestiona riesgos de sostenibilidad.

**Revelaciones requeridas:**

```
GES-1: Procesos de identificación
  - ¿Cómo se identifican los riesgos?
  - ¿Con qué frecuencia?
  - ¿Qué fuentes de información se utilizan?

GES-2: Procesos de evaluación
  - ¿Cómo se evalúa la materialidad?
  - ¿Cómo se priorizan los riesgos?
  - ¿Qué metodologías se utilizan?

GES-3: Procesos de gestión
  - ¿Cómo se mitigan los riesgos?
  - ¿Existen planes de contingencia?
  - ¿Cómo se integran en la gestión de riesgos corporativa?

GES-4: Integración con gestión de riesgos
  - ¿Cómo se relaciona con ERM (Enterprise Risk Management)?
  - ¿Existe un mapa de riesgos integrado?
```

### 4. Métricas y Objetivos (Requisitos de Revelación)

**Objetivo**: Revelar las métricas y objetivos utilizados para medir y gestionar riesgos y oportunidades de sostenibilidad.

**Revelaciones requeridas:**

```
MET-1: Métricas utilizadas
  - Lista de métricas clave (KPIs)
  - Metodología de cálculo
  - Línea base y período de reporte

MET-2: Objetivos establecidos
  - Objetivos cuantitativos
  - Plazos de cumplimiento
  - Progreso hacia objetivos

MET-3: Desempeño vs. objetivos
  - Comparativo actual vs. objetivo
  - Análisis de desviaciones
  - Planes de acción correctiva

MET-4: Vinculación con remuneración
  - ¿Qué objetivos están vinculados a remuneración?
  - ¿Qué porcentaje de la remuneración variable?
```

## NIIF S2: Revelaciones Relacionadas con el Clima

### Requisitos Específicos de NIIF S2

La NIIF S2 complementa la NIIF S1 con requisitos específicos para **riesgos y oportunidades relacionados con el clima**.

### Riesgos Climáticos Cubiertos

```
┌─────────────────────────────────────────────────────────┐
│              RIESGOS CLIMÁTICOS - NIIF S2               │
├─────────────────────────────────────────────────────────┤
│  RIESGOS FÍSICOS                                        │
│  - Agudos: huracanes, inundaciones, incendios           │
│  - Crónicos: aumento de temperatura, estrés hídrico     │
│                                                         │
│  RIESGOS DE TRANSICIÓN                                  │
│  - Políticos/regulatorios: impuestos al carbono         │
│  - Tecnológicos: obsolescencia de activos               │
│  - De mercado: cambios en preferencias de consumidores  │
│  - De reputación: presión de stakeholders               │
└─────────────────────────────────────────────────────────┘
```

### Revelaciones Cruzadas (Cross-Industry Metrics)

La NIIF S2 requiere revelar **4 categorías de métricas transversales**:

#### 1. Emisiones de Gases de Efecto Invernadero (GEI)

**Requisitos:**
```
- Alcance 1: Emisiones directas
- Alcance 2: Emisiones por energía comprada
- Alcance 3: Emisiones de la cadena de valor (si son materiales)

Metodología: GHG Protocol Corporate Standard
Unidad: tCO2e (toneladas de CO2 equivalente)
```

#### 2. Riesgos Climáticos

**Requisitos:**
```
- Activos en zonas de riesgo climático
- Exposición a eventos climáticos extremos
- Activos varados (stranded assets)
```

#### 3. Oportunidades Climáticas

**Requisitos:**
```
- Inversión en tecnologías bajas en carbono
- Productos/servicios sostenibles
- Mercados emergentes verdes
```

#### 4. Metas Climáticas

**Requisitos:**
```
- Metas de reducción de emisiones
- Metas de energía renovable
- Metas de eficiencia energética
- Alineación con Acuerdo de París (1.5°C, 2°C)
```

### Análisis de Escenarios Climáticos

**Requisito clave de NIIF S2**: Realizar análisis de escenarios para evaluar resiliencia.

**Escenarios recomendados:**
| Escenario | Temperatura | Fuente |
|-----------|-------------|--------|
| **Escenario 1.5°C** | 1.5°C sobre niveles preindustriales | IPCC, IEA NZE |
| **Escenario 2°C** | 2°C sobre niveles preindustriales | IPCC, IEA SDS |
| **Escenario >3°C** | Más de 3°C (business as usual) | IPCC, IEA STEPS |

**Elementos del análisis:**
```
1. Identificar riesgos climáticos relevantes
2. Seleccionar escenarios apropiados
3. Evaluar impacto en activos y operaciones
4. Cuantificar efectos financieros potenciales
5. Revelar supuestos clave y limitaciones
```

## Implementación Técnica

### Funciones Python para NIIF S1/S2

```python
"""
Módulo: implementacion_niif_s1_s2.py
Propósito: Implementar requisitos de revelación NIIF S1 y S2
Versión: 1.0
Fecha: 2026-03-10
"""

from dataclasses import dataclass
from typing import Dict, List, Optional
from datetime import datetime
from enum import Enum


class HorizonteTiempo(Enum):
    """Horizontes de tiempo para análisis de riesgos."""
    CORTO_PLAZO = "1-3 años"
    MEDIANO_PLAZO = "3-10 años"
    LARGO_PLAZO = "10+ años"


class TipoRiesgoClimatico(Enum):
    """Tipos de riesgos climáticos según NIIF S2."""
    FISICO_AGUDO = "Físico agudo (huracanes, inundaciones)"
    FISICO_CRONICO = "Físico crónico (aumento temperatura)"
    TRANSICION_REGULATORIO = "Transición regulatorio"
    TRANSICION_TECNOLOGICO = "Transición tecnológico"
    TRANSICION_MERCADO = "Transición de mercado"
    TRANSICION_REPUTACION = "Transición de reputación"


@dataclass
class RiesgoClimatico:
    """Representa un riesgo climático identificado."""
    id: str
    nombre: str
    tipo: TipoRiesgoClimatico
    horizonte: HorizonteTiempo
    probabilidad: int  # 1-5
    impacto: int  # 1-5
    descripcion: str
    activos_expuestos: List[str]
    medidas_mitigacion: List[str]


@dataclass
class MetaClimatica:
    """Representa una meta climática según NIIF S2."""
    id: str
    descripcion: str
    linea_base: float
    año_linea_base: int
    objetivo: float
    año_objetivo: int
    unidad: str
    progreso_actual: float
    alcances_gei: List[str]  # ['scope1', 'scope2', 'scope3']


class ImplementacionNIIFS1S2:
    """
    Implementa requisitos de revelación NIIF S1 y S2.
    """
    
    def __init__(self, empresa: str, ejercicio: int):
        """
        Inicializa la implementación.
        
        Args:
            empresa: Nombre de la empresa
            ejercicio: Año del ejercicio
        """
        self.empresa = empresa
        self.ejercicio = ejercicio
        self.riesgos: List[RiesgoClimatico] = []
        self.metas: List[MetaClimatica] = []
        self.gobernanza = {}
        self.metricas = {}
    
    def agregar_riesgo_climatico(self, riesgo: RiesgoClimatico):
        """
        Agrega un riesgo climático identificado.
        
        Args:
            riesgo: Objeto RiesgoClimatico
        """
        self.riesgos.append(riesgo)
    
    def agregar_meta_climatica(self, meta: MetaClimatica):
        """
        Agrega una meta climática.
        
        Args:
            meta: Objeto MetaClimatica
        """
        self.metas.append(meta)
    
    def configurar_gobernanza(self, gobernanza: Dict):
        """
        Configura información de gobernanza.
        
        Args:
            gobernanza: Diccionario con información de gobernanza
        """
        self.gobernanza = gobernanza
    
    def calcular_nivel_riesgo(self, riesgo: RiesgoClimatico) -> str:
        """
        Calcula nivel de riesgo (bajo, medio, alto, crítico).
        
        Args:
            riesgo: Riesgo a evaluar
        
        Returns:
            Nivel de riesgo como string
        """
        score = riesgo.probabilidad * riesgo.impacto
        
        if score >= 20:
            return "Crítico"
        elif score >= 15:
            return "Alto"
        elif score >= 8:
            return "Medio"
        else:
            return "Bajo"
    
    def analizar_resiliencia_escenarios(self, 
                                         escenarios: List[Dict]) -> Dict:
        """
        Analiza resiliencia de la estrategia bajo diferentes escenarios.
        
        Args:
            escenarios: Lista de escenarios climáticos
        
        Returns:
            Diccionario con análisis de resiliencia
        """
        analisis = {
            'empresa': self.empresa,
            'ejercicio': self.ejercicio,
            'escenarios_analizados': [],
            'riesgos_por_escenario': {},
            'activos_en_riesgo': [],
            'recomendaciones': []
        }
        
        for escenario in escenarios:
            nombre = escenario['nombre']
            temperatura = escenario['temperatura']
            fuente = escenario['fuente']
            
            analisis['escenarios_analizados'].append({
                'nombre': nombre,
                'temperatura': temperatura,
                'fuente': fuente
            })
            
            # Identificar riesgos relevantes para este escenario
            riesgos_escenario = []
            for riesgo in self.riesgos:
                # Lógica simplificada para ejemplo
                if 'físico' in riesgo.tipo.value.lower() and temperatura >= 2:
                    riesgos_escenario.append(riesgo.nombre)
                elif 'transición' in riesgo.tipo.value.lower() and temperatura <= 1.5:
                    riesgos_escenario.append(riesgo.nombre)
            
            analisis['riesgos_por_escenario'][nombre] = riesgos_escenario
        
        # Identificar activos en riesgo
        activos_unicos = set()
        for riesgo in self.riesgos:
            for activo in riesgo.activos_expuestos:
                activos_unicos.add(activo)
        
        analisis['activos_en_riesgo'] = list(activos_unicos)
        
        # Generar recomendaciones
        if len(activos_unicos) > 5:
            analisis['recomendaciones'].append(
                "Diversificar ubicación de activos para reducir concentración de riesgo"
            )
        
        riesgos_critic os = [r for r in self.riesgos 
                           if self.calcular_nivel_riesgo(r) == 'Crítico']
        
        if len(riesgos_critic os) > 0:
            analisis['recomendaciones'].append(
                f"Desarrollar planes de contingencia para {len(riesgos_critic os)} riesgos críticos"
            )
        
        return analisis
    
    def calcular_progreso_metas(self) -> List[Dict]:
        """
        Calcula progreso hacia metas climáticas.
        
        Returns:
            Lista de diccionarios con progreso de cada meta
        """
        progreso_metas = []
        
        for meta in self.metas:
            # Calcular progreso
            reduccion_total_requerida = meta.linea_base - meta.objetivo
            reduccion_lograda = meta.linea_base - meta.progreso_actual
            
            if reduccion_total_requerida > 0:
                porcentaje_progreso = (reduccion_lograda / reduccion_total_requerida) * 100
            else:
                porcentaje_progreso = 100
            
            # Calcular trayectoria requerida
            años_totales = meta.año_objetivo - meta.año_linea_base
            años_transcurridos = self.ejercicio - meta.año_linea_base
            
            if años_totales > 0:
                trayectoria_requerida = (años_transcurridos / años_totales) * 100
            else:
                trayectoria_requerida = 100
            
            # Determinar estatus
            if porcentaje_progreso >= trayectoria_requerida:
                estatus = "En camino"
            elif porcentaje_progreso >= trayectoria_requerida * 0.8:
                estatus = "Con retraso menor"
            else:
                estatus = "Con retraso significativo"
            
            progreso_metas.append({
                'meta_id': meta.id,
                'descripcion': meta.descripcion,
                'linea_base': f"{meta.linea_base} {meta.unidad}",
                'objetivo': f"{meta.objetivo} {meta.unidad}",
                'progreso_actual': f"{meta.progreso_actual} {meta.unidad}",
                'porcentaje_progreso': f"{porcentaje_progreso:.1f}%",
                'trayectoria_requerida': f"{trayectoria_requerida:.1f}%",
                'estatus': estatus,
                'año_objetivo': meta.año_objetivo
            })
        
        return progreso_metas
    
    def generar_reporte_niif_s1_s2(self) -> str:
        """
        Genera reporte completo NIIF S1 y S2.
        
        Returns:
            Reporte en formato texto
        """
        reporte = f"""
================================================================================
              REPORTE DE SOSTENIBILIDAD - NIIF S1 y S2
================================================================================
Empresa: {self.empresa}
Ejercicio: {self.ejercicio}
Fecha de generación: {datetime.now().strftime('%Y-%m-%d')}
================================================================================

1. GOBERNANZA
-------------
"""
        
        if self.gobernanza:
            reporte += f"""
Órgano responsable: {self.gobernanza.get('organo', 'N/A')}
Composición: {self.gobernanza.get('composicion', 'N/A')}
Frecuencia de reuniones: {self.gobernanza.get('frecuencia', 'N/A')}
Responsable ejecutivo: {self.gobernanza.get('responsable_ejecutivo', 'N/A')}
Vinculación con remuneración: {self.gobernanza.get('vinculacion_remuneracion', 'N/A')}
"""
        
        reporte += """
2. ESTRATEGIA
-------------
"""
        
        reporte += f"""
Total de riesgos climáticos identificados: {len(self.riesgos)}
Total de metas climáticas establecidas: {len(self.metas)}

Riesgos por horizonte de tiempo:
"""
        
        # Agrupar riesgos por horizonte
        riesgos_por_horizonte = {}
        for riesgo in self.riesgos:
            horizonte = riesgo.horizonte.value
            if horizonte not in riesgos_por_horizonte:
                riesgos_por_horizonte[horizonte] = 0
            riesgos_por_horizonte[horizonte] += 1
        
        for horizonte, cantidad in riesgos_por_horizonte.items():
            reporte += f"  - {horizonte}: {cantidad} riesgos\n"
        
        reporte += """
3. GESTIÓN DE RIESGOS
---------------------
"""
        
        for riesgo in self.riesgos:
            nivel = self.calcular_nivel_riesgo(riesgo)
            reporte += f"""
{riesgo.id} - {riesgo.nombre}
  Tipo: {riesgo.tipo.value}
  Horizonte: {riesgo.horizonte.value}
  Probabilidad: {riesgo.probabilidad}/5
  Impacto: {riesgo.impacto}/5
  Nivel de riesgo: {nivel}
  Medidas de mitigación: {', '.join(riesgo.medidas_mitigacion)}
"""
        
        reporte += """
4. MÉTRICAS Y OBJETIVOS
-----------------------
"""
        
        progreso = self.calcular_progreso_metas()
        
        for meta in progreso:
            reporte += f"""
{meta['meta_id']} - {meta['descripcion']}
```
