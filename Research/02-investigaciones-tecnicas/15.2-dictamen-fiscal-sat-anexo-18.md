## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación documenta los requisitos técnicos y obligaciones fiscales del Dictamen de Estados Financieros para Efectos Fiscales (Anexo 18 RMF 2026), también conocido como SIPRED 2025. El módulo permite la generación automatizada del dictamen fiscal en formato XML, validación de estructura, y envío al SAT a través del portal.

**Problema que resuelve:** Los contadores públicos dedicados 40-80 horas por dictamen en captura manual de información en SIPRED, validación de campos, generación de XML, y corrección de errores de rechazo. La automatización reduce este tiempo a 4-8 horas, eliminando errores de captura y asegurando cumplimiento normativo.

#### Algoritmo 1: Generador de XML para Dictamen Fiscal (Anexo 18)

```python
from dataclasses import dataclass, field
from typing import List, Optional, Dict
from datetime import datetime
from decimal import Decimal
import xml.etree.ElementTree as ET
from xml.dom import minidom

@dataclass
class DatosContribuyente:
    """Datos de identificación del contribuyente."""
    rfc: str
    razon_social: str
    calle: str
    numero_exterior: str
    numero_interior: Optional[str]
    colonia: str
    codigo_postal: str
    municipio: str
    entidad_federativa: str
    email: str
    telefono: str

@dataclass
class DatosContador:
    """Datos del contador público inscrito."""
    rfc: str
    nombre_completo: str
    cedula_profesional: str
    rfc_despacho: str
    nombre_despacho: str
    email: str
    telefono: str
    numero_registro_sat: str  # Número de registro ante el SAT

@dataclass
class BalanzaComprobacion:
    """Balanza de comprobación del ejercicio."""
    cuenta_contable: str
    descripcion_cuenta: str
    saldo_inicial_debe: Decimal
    saldo_inicial_haber: Decimal
    movimientos_debe: Decimal
    movimientos_haber: Decimal
    saldo_final_debe: Decimal
    saldo_final_haber: Decimal

@dataclass
class EstadoFinanciero:
    """Estado financiero individual (Balance, Estado de Resultados, etc.)."""
    tipo_estado: str  # "balance", "resultados", "cambios_capital", "flujo_efectivo"
    concepto: str
    monto: Decimal
    orden_presentacion: int

class GeneradorXMLDictamen:
    """
    Genera XML de dictamen fiscal según Anexo 18 RMF 2026.
    
    El XML debe cumplir con:
    - Estructura definida en Anexo 18 RMF 2026
    - Catálogos del SAT
    - Formatos de fecha (AAAA-MM-DD)
    - Formatos de monto (Decimal con 2 decimales)
    
    Ejemplo:
        >>> generador = GeneradorXMLDictamen()
        >>> xml_string = generador.generar(datos_contribuyente, datos_contador, balanza, estados)
        >>> print(xml_string[:100])
        '<?xml version="1.0" encoding="UTF-8"?>\\n<DictamenFiscal ...'
    """
    
    # Versión del esquema
    VERSION_ESQUEMA = "1.0"
    
    # Catálogos SAT
    TIPOS_DICTAMEN = {
        "normal": "N",
        "complementario": "C",
        "sin_opinion": "S"
    }
    
    TIPOS_ESTADO_FINANCIERO = {
        "balance": "B",
        "resultados": "R",
        "cambios_capital": "C",
        "flujo_efectivo": "E"
    }
    
    def __init__(self):
        self.root = None
    
    def crear_elemento(self, tag: str, atributos: Dict = None, texto: str = None) -> ET.Element:
        """
        Crea un elemento XML con atributos opcionales.
        
        Args:
            tag: Nombre del elemento
            atributos: Diccionario de atributos
            texto: Texto contenido (opcional)
            
        Returns:
            Elemento XML creado
        """
        elemento = ET.Element(tag)
        
        if atributos:
            for key, value in atributos.items():
                elemento.set(key, str(value))
        
        if texto:
            elemento.text = str(texto)
        
        return elemento
    
    def formatear_monto(self, monto: Decimal) -> str:
        """
        Formatea monto según especificaciones SAT (2 decimales).
        
        Args:
            monto: Monto en Decimal
            
        Returns:
            String con formato "0.00"
        """
        return f"{monto:.2f}"
    
    def formatear_fecha(self, fecha: datetime) -> str:
        """
        Formatea fecha según especificaciones SAT (AAAA-MM-DD).
        
        Args:
            fecha: Objeto datetime
            
        Returns:
            String con formato "YYYY-MM-DD"
        """
        return fecha.strftime("%Y-%m-%d")
    
    def generar(self, 
                datos_contribuyente: DatosContribuyente,
                datos_contador: DatosContador,
                balanza: List[BalanzaComprobacion],
                estados_financieros: List[EstadoFinanciero],
                ejercicio: int,
                tipo_dictamen: str = "normal") -> str:
        """
        Genera XML completo del dictamen fiscal.
        
        Args:
            datos_contribuyente: Datos del contribuyente
            datos_contador: Datos del contador
            balanza: Lista de cuentas de balanza de comprobación
            estados_financieros: Lista de estados financieros
            ejercicio: Año del ejercicio a dictaminar
            tipo_dictamen: "normal", "complementario", o "sin_opinion"
            
        Returns:
            String con XML formateado
        """
        # Elemento raíz
        self.root = self.crear_elemento("DictamenFiscal", {
            "version": self.VERSION_ESQUEMA,
            "tipoDictamen": self.TIPOS_DICTAMEN.get(tipo_dictamen, "N"),
            "ejercicio": str(ejercicio),
            "fechaElaboracion": self.formatear_fecha(datetime.now())
        })
        
        # Datos del contribuyente
        contribuyente = self.crear_elemento("Contribuyente", {
            "rfc": datos_contribuyente.rfc,
            "razonSocial": datos_contribuyente.razon_social,
            "calle": datos_contribuyente.calle,
            "numeroExterior": datos_contribuyente.numero_exterior,
            "codigoPostal": datos_contribuyente.codigo_postal,
            "municipio": datos_contribuyente.municipio,
            "entidadFederativa": datos_contribuyente.entidad_federativa,
            "email": datos_contribuyente.email,
            "telefono": datos_contribuyente.telefono
        })
        
        if datos_contribuyente.numero_interior:
            contribuyente.set("numeroInterior", datos_contribuyente.numero_interior)
        if datos_contribuyente.colonia:
            contribuyente.set("colonia", datos_contribuyente.colonia)
        
        self.root.append(contribuyente)
        
        # Datos del contador
        contador = self.crear_elemento("ContadorPublico", {
            "rfc": datos_contador.rfc,
            "nombreCompleto": datos_contador.nombre_completo,
            "cedulaProfesional": datos_contador.cedula_profesional,
            "rfcDespacho": datos_contador.rfc_despacho,
            "nombreDespacho": datos_contador.nombre_despacho,
            "email": datos_contador.email,
            "telefono": datos_contador.telefono,
            "numeroRegistroSAT": datos_contador.numero_registro_sat
        })
        
        self.root.append(contador)
        
        # Balanza de comprobación
        balanza_elem = self.crear_elemento("BalanzaComprobacion")
        
        for cuenta in balanza:
            cuenta_elem = self.crear_elemento("Cuenta", {
                "cuentaContable": cuenta.cuenta_contable,
                "descripcionCuenta": cuenta.descripcion_cuenta,
                "saldoInicialDebe": self.formatear_monto(cuenta.saldo_inicial_debe),
                "saldoInicialHaber": self.formatear_monto(cuenta.saldo_inicial_haber),
                "movimientosDebe": self.formatear_monto(cuenta.movimientos_debe),
                "movimientosHaber": self.formatear_monto(cuenta.movimientos_haber),
                "saldoFinalDebe": self.formatear_monto(cuenta.saldo_final_debe),
                "saldoFinalHaber": self.formatear_monto(cuenta.saldo_final_haber)
            })
            balanza_elem.append(cuenta_elem)
        
        self.root.append(balanza_elem)
        
        # Estados financieros
        estados_elem = self.crear_elemento("EstadosFinancieros")
        
        for estado in estados_financieros:
            estado_elem = self.crear_elemento("EstadoFinanciero", {
                "tipoEstado": self.TIPOS_ESTADO_FINANCIERO.get(estado.tipo_estado, "O"),
                "ordenPresentacion": str(estado.orden_presentacion)
            })
            
            concepto_elem = self.crear_elemento("Concepto", {
                "descripcion": estado.concepto,
                "monto": self.formatear_monto(estado.monto)
            })
            estado_elem.append(concepto_elem)
            estados_elem.append(estado_elem)
        
        self.root.append(estados_elem)
        
        # Convertir a string
        xml_str = ET.tostring(self.root, encoding="unicode")
        
        # Formatear con indentación
        dom = minidom.parseString(xml_str)
        xml_pretty = dom.toprettyxml(indent="  ")
        
        # Eliminar línea de declaración doble
        lines = xml_pretty.split("\n")
        if lines[0].startswith("<?xml") and lines[1].startswith("<?xml"):
            lines.pop(1)
        
        return "\n".join(lines)
    
    def validar_estructura(self, xml_string: str) -> dict:
        """
        Valida estructura básica del XML generado.
        
        Returns:
            Diccionario con:
            - es_valido: bool
            - errores: lista de errores encontrados
        """
        errores = []
        
        try:
            root = ET.fromstring(xml_string)
            
            # Validar elemento raíz
            if root.tag != "DictamenFiscal":
                errores.append(f"Elemento raíz incorrecto: {root.tag}. Se espera 'DictamenFiscal'")
            
            # Validar atributos requeridos
            if "version" not in root.attrib:
                errores.append("Falta atributo 'version' en elemento raíz")
            
            if "tipoDictamen" not in root.attrib:
                errores.append("Falta atributo 'tipoDictamen' en elemento raíz")
            
            if "ejercicio" not in root.attrib:
                errores.append("Falta atributo 'ejercicio' en elemento raíz")
            
            # Validar secciones requeridas
            secciones_requeridas = ["Contribuyente", "ContadorPublico", "BalanzaComprobacion", "EstadosFinancieros"]
            
            for seccion in secciones_requeridas:
                if root.find(seccion) is None:
                    errores.append(f"Falta sección requerida: {seccion}")
            
            # Validar datos del contribuyente
            contribuyente = root.find("Contribuyente")
            if contribuyente is not None:
                if "rfc" not in contribuyente.attrib:
                    errores.append("Falta RFC del contribuyente")
                if "razonSocial" not in contribuyente.attrib:
                    errores.append("Falta razón social del contribuyente")
            
            # Validar datos del contador
            contador = root.find("ContadorPublico")
            if contador is not None:
                if "rfc" not in contador.attrib:
                    errores.append("Falta RFC del contador")
                if "numeroRegistroSAT" not in contador.attrib:
                    errores.append("Falta número de registro SAT del contador")
            
        except ET.ParseError as e:
            errores.append(f"Error de parseo XML: {str(e)}")
        
        return {
            "es_valido": len(errores) == 0,
            "errores": errores
        }
```

#### Algoritmo 2: Validador de Dictamen Fiscal

```python
from dataclasses import dataclass
from typing import List, Dict, Tuple
from decimal import Decimal

@dataclass
class ErrorValidacion:
    """Representa un error de validación encontrado."""
    campo: str
    descripcion: str
    severidad: str  # "critico", "mayor", "menor"
    sugerencia: str

class ValidadorDictamenFiscal:
    """
    Valida el dictamen fiscal antes del envío al SAT.
    
    Validaciones implementadas:
    1. Campos obligatorios
    2. Formato de RFC
    3. Formato de fechas
    4. Sumas de balanza (debe == haber)
    5. Catálogos SAT
    6. Cruces de información
    """
    
    # Errores críticos que causan rechazo automático
    ERRORES_CRITICOS = [
        "RFC inválido",
        "Falta e.firma",
        "Sumas de balanza no cuadran",
        "Ejercicio incorrecto"
    ]
    
    def validar_rfc(self, rfc: str) -> Tuple[bool, str]:
        """
        Valida formato de RFC.
        
        Returns:
            Tuple con (es_valido, mensaje_error)
        """
        if not rfc:
            return False, "RFC vacío"
        
        rfc = rfc.upper().strip()
        
        # Validar longitud
        if len(rfc) not in [12, 13]:  # 12 para moral, 13 para física
            return False, f"RFC debe tener 12 o 13 caracteres, tiene {len(rfc)}"
        
        # Validar formato (primeros 10 caracteres alfanuméricos)
        import re
        patron = r'^[A-ZÑ&]{3,4}\d{6}[A-Z0-9]{2,3}$'
        
        if not re.match(patron, rfc):
            return False, "Formato de RFC inválido"
        
        # Validar homoclave (últimos 3 caracteres)
        # Aquí iría el algoritmo de validación de homoclave del SAT
        
        return True, ""
    
    def validar_sumas_balanza(self, balanza: List[BalanzaComprobacion]) -> Tuple[bool, str]:
        """
        Valida que sumas de balanza cuadren (debe == haber).
        
        Returns:
            Tuple con (es_valido, mensaje_error)
        """
        total_debe = Decimal("0.00")
        total_haber = Decimal("0.00")
        
        for cuenta in balanza:
            total_debe += cuenta.saldo_final_debe
            total_haber += cuenta.saldo_final_haber
        
        # Tolerancia de 1 centavo por redondeo
        diferencia = abs(total_debe - total_haber)
        
        if diferencia > Decimal("0.01"):
            return False, f"Sumas de balanza no cuadran. Diferencia: ${diferencia:,.2f}"
        
        return True, ""
    
    def validar_campos_obligatorios(self, 
                                    datos_contribuyente: DatosContribuyente,
                                    datos_contador: DatosContador) -> List[ErrorValidacion]:
        """
        Valida campos obligatorios de contribuyente y contador.
        
        Returns:
            Lista de errores encontrados
        """
        errores = []
        
        # Validar contribuyente
        if not datos_contribuyente.rfc:
            errores.append(ErrorValidacion(
                campo="Contribuyente.RFC",
                descripcion="RFC del contribuyente es requerido",
                severidad="critico",
                sugerencia="Capturar RFC del contribuyente"
            ))
        
        if not datos_contribuyente.razon_social:
            errores.append(ErrorValidacion(
                campo="Contribuyente.RazonSocial",
                descripcion="Razón social es requerida",
                severidad="critico",
                sugerencia="Capturar razón social completa"
            ))
        
        if not datos_contribuyente.codigo_postal:
            errores.append(ErrorValidacion(
                campo="Contribuyente.CodigoPostal",
                descripcion="Código postal es requerido",
                severidad="mayor",
                sugerencia="Capturar código postal válido"
            ))
        
        # Validar contador
        if not datos_contador.rfc:
            errores.append(ErrorValidacion(
                campo="Contador.RFC",
                descripcion="RFC del contador es requerido",
                severidad="critico",
                sugerencia="Capturar RFC del contador"
            ))
        
        if not datos_contador.cedula_profesional:
            errores.append(ErrorValidacion(
                campo="Contador.CedulaProfesional",
                descripcion="Cédula profesional es requerida",
                severidad="critico",
                sugerencia="Capturar número de cédula profesional"
            ))
        
        if not datos_contador.numero_registro_sat:
            errores.append(ErrorValidacion(
                campo="Contador.NumeroRegistroSAT",
                descripcion="Número de registro SAT es requerido",
                severidad="critico",
                sugerencia="Capturar número de registro ante el SAT"
            ))
        
        return errores
    
    def validar_completo(self, 
                         datos_contribuyente: DatosContribuyente,
                         datos_contador: DatosContador,
                         balanza: List[BalanzaComprobacion],
                         ejercicio: int) -> dict:
        """
        Ejecuta todas las validaciones.
        
        Returns:
            Diccionario con resultados de validación
        """
        todos_errores = []
        
        # Validar campos obligatorios
        errores_campos = self.validar_campos_obligatorios(datos_contribuyente, datos_contador)
        todos_errores.extend(errores_campos)
        
        # Validar RFC
        es_valido_rfc, error_rfc = self.validar_rfc(datos_contribuyente.rfc)
        if not es_valido_rfc:
            todos_errores.append(ErrorValidacion(
                campo="Contribuyente.RFC",
                descripcion=error_rfc,
                severidad="critico",
                sugerencia="Verificar formato de RFC"
            ))
        
        es_valido_rfc_contador, error_rfc_contador = self.validar_rfc(datos_contador.rfc)
        if not es_valido_rfc_contador:
            todos_errores.append(ErrorValidacion(
                campo="Contador.RFC",
                descripcion=error_rfc_contador,
                severidad="critico",
                sugerencia="Verificar formato de RFC del contador"
            ))
        
        # Validar sumas de balanza
        es_valido_balanza, error_balanza = self.validar_sumas_balanza(balanza)
        if not es_valido_balanza:
            todos_errores.append(ErrorValidacion(
                campo="BalanzaComprobacion.Sumas",
                descripcion=error_balanza,
                severidad="critico",
                sugerencia="Revisar captura de saldos en balanza"
            ))
        
        # Validar ejercicio
        ejercicio_actual = datetime.now().year
        if ejercicio < ejercicio_actual - 2 or ejercicio > ejercicio_actual:
            todos_errores.append(ErrorValidacion(
                campo="Dictamen.Ejercicio",
                descripcion=f"Ejercicio {ejercicio} fuera de rango válido",
                severidad="mayor",
                sugerencia=f"Verificar ejercicio (rango válido: {ejercicio_actual - 2} - {ejercicio_actual})"
            ))
        
        # Clasificar errores
        errores_criticos = [e for e in todos_errores if e.severidad == "critico"]
        errores_mayores = [e for e in todos_errores if e.severidad == "mayor"]
        errores_menores = [e for e in todos_errores if e.severidad == "menor"]
        
        return {
            "es_valido": len(errores_criticos) == 0,
            "errores_criticos": errores_criticos,
            "errores_mayores": errores_mayores,
            "errores_menores": errores_menores,
            "total_errores": len(todos_errores),
            "listo_para_enviar": len(errores_criticos) == 0 and len(errores_mayores) == 0
        }
    
    def generar_reporte_validacion(self, resultados: dict) -> str:
        """
        Genera reporte de validación para el contador.
        
        Returns:
            Reporte formateado
        """
        reporte = "=" * 80 + "\n"
        reporte += "REPORTE DE VALIDACIÓN DE DICTAMEN FISCAL\n"
        reporte += "=" * 80 + "\n\n"
        
        if resultados["es_valido"]:
            reporte += "✅ DICTAMEN VÁLIDO PARA ENVÍO\n\n"
        else:
            reporte += "❌ DICTAMEN INVÁLIDO - CORREGIR ERRORES\n\n"
        
        # Errores críticos
        if resultados["errores_criticos"]:
            reporte += "ERRORES CRÍTICOS (impiden envío):\n"
            reporte += "-" * 80 + "\n"
            for error in resultados["errores_criticos"]:
                reporte += f"⚠️  [{error.campo}] {error.descripcion}\n"
                reporte += f"    Sugerencia: {error.sugerencia}\n\n"
        
        # Errores mayores
        if resultados["errores_mayores"]:
            reporte += "ERRORES MAYORES (pueden causar rechazo):\n"
            reporte += "-" * 80 + "\n"
            for error in resultados["errores_mayores"]:
                reporte += f"⚡ [{error.campo}] {error.descripcion}\n"
                reporte += f"    Sugerencia: {error.sugerencia}\n\n"
        
        # Errores menores
        if resultados["errores_menores"]:
            reporte += "ERRORES MENORES (advertencias):\n"
            reporte += "-" * 80 + "\n"
            for error in resultados["errores_menores"]:
                reporte += f"📋 [{error.campo}] {error.descripcion}\n"
                reporte += f"    Sugerencia: {error.sugerencia}\n\n"
        
        reporte += "=" * 80 + "\n"
        reporte += f"Total errores: {resultados['total_errores']} "
        reporte += f"(Críticos: {len(resultados['errores_criticos'])}, "
        reporte += f"Mayores: {len(resultados['errores_mayores'])}, "
        reporte += f"Menores: {len(resultados['errores_menores'])})\n"
        
        if resultados["listo_para_enviar"]:
            reporte += "\n✅ DICTAMEN LISTO PARA ENVÍO AL SAT\n"
        else:
            reporte += "\n❌ DICTAMEN NO LISTO PARA ENVÍO\n"
        
        return reporte
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: e.firma Vigente Requerida

**Problema:**
La firma electrónica (e.firma) es obligatoria para contador y contribuyente. El trámite de renovación toma 2-3 semanas en el SAT.

**Solución:**
```python
class GestorEFirma:
    """
    Gestiona validación de vigencia de e.firma.
    
    La e.firma tiene vigencia de 4 años.
    """
    
    VIGENCIA_EFIRMA = 4 * 365  # 4 años en días
    
    def verificar_vigencia(self, fecha_emision: datetime, fecha_vencimiento: datetime) -> dict:
        """
        Verifica vigencia de e.firma.
        
        Returns:
            Diccionario con:
            - es_valida: bool
            - dias_restantes: int
            - requiere_renovacion: bool
        """
        ahora = datetime.now()
        dias_restantes = (fecha_vencimiento - ahora).days
        
        es_valida = ahora < fecha_vencimiento
        requiere_renovacion = dias_restantes < 30  # Alerta 30 días antes
        
        return {
            "es_valida": es_valida,
            "dias_restantes": dias_restantes,
            "requiere_renovacion": requiere_renovacion,
            "mensaje": f"e.firma {'vigente' if es_valida else 'vencida'}. {dias_restantes} días restantes."
        }
```

**Impacto:**
- Retraso de 2-3 semanas si e.firma está vencida
- Costo de trámite: Gratuito, pero requiere cita en SAT
- Renovación cada 4 años obligatoria

### 4.2 Limitación 2: SIPRED 2025 Sin API Pública

**Problema:**
El SAT no proporciona API pública para envío automatizado de dictámenes. Requiere interacción manual con portal o automatización vía browser (Playwright/Selenium).

**Solución:**
- Usar Playwright para automatización de navegador
- Programar envío con anticipación para evitar caídas del portal
- Alternativa: Usar PACs autorizados (Finkok, SW Sapien) que tienen API

**Impacto:**
- Automatización frágil (cambios en portal SAT rompen script)
- Requiere mantenimiento constante
- Tiempos de respuesta variables (5-30 minutos por dictamen)
