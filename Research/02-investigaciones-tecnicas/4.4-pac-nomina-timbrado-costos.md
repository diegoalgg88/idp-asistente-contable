## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía completa de Proveedores Autorizados de Certificación (PACs) especializados en timbrado de CFDI de nómina en México, incluyendo:
- Lista de PACs con experiencia en nómina (Finkok, SW Sapien, Ecodex, Edicom, etc.)
- Costos por timbre de nómina ($0.70-$1.50 MXN)
- APIs disponibles para integración (REST, SOAP)
- Documentación técnica y endpoints específicos para nómina
- Límites de volumen y descuentos
- SLA y tiempos de respuesta
- Validaciones específicas para complemento de nómina 1.2 Revisión E

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Selección de PAC para nómina | Una vez | 2-4 horas | 30 minutos | 85-90% |
| Configuración de integración | Una vez | 4-8 horas | 1 hora | 85-90% |
| Timbrado manual de nómina | Por nómina | 15-30 min/nómina | Automático | 95-98% |
| Validación de timbrado | Por nómina | 10-15 min/nómina | Automático | 100% |
| Resolución de errores | Por error | 15-30 min/error | 2-5 min/error | 70-80% |

### 1.3 Dolor Principal que Resuelve

**Problema:** Existen 77 PACs autorizados, pero no todos tienen experiencia en nómina. El timbrado de nómina tiene validaciones específicas:
- Complemento de nómina 1.2 Revisión E
- Catálogos específicos (TipoPercepción, TipoDeducción, etc.)
- Reglas de validación NOM75-NOM110
- Subsidio al empleo actualizado

Un PAC sin experiencia en nómina causa:
- Rechazos frecuentes de timbrado
- Soporte técnico especializado limitado
- Actualizaciones tardías a cambios del SAT

**Solución IDP-App:** Comparativa de PACs especializados + integración con múltiples PACs para fallback automático.

### 3.2 Algoritmos Específicos

#### Algoritmo 1: Gestor de Múltiples PACs para Nómina

```python
from abc import ABC, abstractmethod
from typing import Dict, List, Optional
import requests
from datetime import datetime

class PACNominaProvider(ABC):
    """
    Interfaz común para PACs especializados en nómina.
    Cada PAC implementa su propio adaptador.
    """
    
    @abstractmethod
    def timbrar_nomina(self, cfdi_xml: str) -> Dict:
        """
        Timbra un CFDI de nómina.
        
        Args:
            cfdi_xml: Contenido XML del CFDI de nómina
            
        Returns:
            Dict con resultado:
            - success: bool
            - uuid: str (si exitoso)
            - sello_sat: str (si exitoso)
            - error: str (si fallido)
        """
        pass
    
    @abstractmethod
    def cancelar_nomina(self, uuid: str, rfc_emisor: str) -> Dict:
        """
        Cancela un CFDI de nómina.
        
        Args:
            uuid: Folio fiscal del CFDI
            rfc_emisor: RFC del emisor
            
        Returns:
            Dict con resultado de cancelación
        """
        pass
    
    @abstractmethod
    def health_check(self) -> bool:
        """
        Verifica si el PAC está disponible.
        
        Returns:
            bool: True si disponible, False si no
        """
        pass


class FinkokNominaPAC(PACNominaProvider):
    """
    Implementación específica para Finkok especializado en nómina.
    API: REST + SOAP
    """
    
    def __init__(self, api_key: str, secret: str, sandbox: bool = False):
        self.api_key = api_key
        self.secret = secret
        self.base_url = "https://api.finkok.com" if not sandbox else "https://sandbox.finkok.com"
        self.timeout = 5  # 5 segundos
    
    def timbrar_nomina(self, cfdi_xml: str) -> Dict:
        """Timbra CFDI de nómina con Finkok."""
        try:
            response = requests.post(
                f"{self.base_url}/stamp/nomina",
                json={
                    'username': self.api_key,
                    'password': self.secret,
                    'xml': cfdi_xml,
                    'validacion_nomina': True  # Activa validaciones específicas de nómina
                },
                timeout=self.timeout
            )
            response.raise_for_status()
            result = response.json()
            
            if result.get('status') == 'success':
                return {
                    'success': True,
                    'uuid': result['data']['uuid'],
                    'sello_sat': result['data']['selloSAT'],
                    'cadena_original': result['data']['cadenaOriginal'],
                    'no_certificado_sat': result['data']['noCertificadoSAT'],
                    'fecha_timbrado': result['data']['fechaTimbrado'],
                    'pac_used': 'Finkok'
                }
            else:
                return {
                    'success': False,
                    'error': result.get('message', 'Error desconocido'),
                    'pac_used': 'Finkok'
                }
        except requests.Timeout:
            return {'success': False, 'error': 'Timeout del PAC', 'pac_used': 'Finkok'}
        except Exception as e:
            return {'success': False, 'error': str(e), 'pac_used': 'Finkok'}
    
    def cancelar_nomina(self, uuid: str, rfc_emisor: str) -> Dict:
        """Cancela CFDI de nómina con Finkok."""
        try:
            response = requests.post(
                f"{self.base_url}/cancel",
                json={
                    'username': self.api_key,
                    'password': self.secret,
                    'uuid': uuid,
                    'rfc_emisor': rfc_emisor
                },
                timeout=self.timeout
            )
            response.raise_for_status()
            result = response.json()
            
            if result.get('status') == 'success':
                return {
                    'success': True,
                    'uuid': uuid,
                    'estatus_cancelacion': result['data']['estatus']
                }
            else:
                return {
                    'success': False,
                    'error': result.get('message', 'Error desconocido')
                }
        except Exception as e:
            return {'success': False, 'error': str(e)}
    
    def health_check(self) -> bool:
        """Health check de Finkok."""
        try:
            response = requests.get(f"{self.base_url}/health", timeout=2)
            return response.status_code == 200
        except:
            return False


class SWNominaPAC(PACNominaProvider):
    """Implementación específica para SW Sapien especializado en nómina."""
    
    def __init__(self, token: str, sandbox: bool = False):
        self.token = token
        self.base_url = "https://api.sw.com.mx" if not sandbox else "https://sandbox.sw.com.mx"
        self.timeout = 5
    
    def timbrar_nomina(self, cfdi_xml: str) -> Dict:
        """Timbra CFDI de nómina con SW Sapien."""
        try:
            response = requests.post(
                f"{self.base_url}/cfdi33/timbrar/nomina",
                headers={'Authorization': f'Bearer {self.token}'},
                json={
                    'xml': cfdi_xml,
                    'validacion_nomina': True,  # Validaciones específicas de nómina
                    'validacion_revision_e': True  # Validación Revisión E
                },
                timeout=self.timeout
            )
            response.raise_for_status()
            result = response.json()
            
            if result.get('status') == 'success':
                return {
                    'success': True,
                    'uuid': result['data']['uuid'],
                    'sello_sat': result['data']['selloSAT'],
                    'fecha_timbrado': result['data']['fechaTimbrado'],
                    'pac_used': 'SW Sapien'
                }
            else:
                return {
                    'success': False,
                    'error': result.get('message', 'Error desconocido'),
                    'pac_used': 'SW Sapien'
                }
        except Exception as e:
            return {'success': False, 'error': str(e), 'pac_used': 'SW Sapien'}
    
    def cancelar_nomina(self, uuid: str, rfc_emisor: str) -> Dict:
        """Cancela CFDI de nómina con SW Sapien."""
        pass
    
    def health_check(self) -> bool:
        """Health check de SW Sapien."""
        try:
            response = requests.get(f"{self.base_url}/health", timeout=2)
            return response.status_code == 200
        except:
            return False


class PACNominaManager:
    """
    Gestiona múltiples PACs especializados en nómina con fallback automático.
    """
    
    def __init__(self):
        self.pacs: List[PACNominaProvider] = []
        self.primary_pac_index = 0
        self.timeout = 5  # 5 segundos
        self.max_retries = 3
    
    def add_pac(self, pac: PACNominaProvider, priority: int = 0):
        """
        Agrega un PAC a la lista de proveedores.
        
        Args:
            pac: Instancia del PAC
            priority: Prioridad (0 = más alto)
        """
        self.pacs.insert(priority, pac)
    
    def timbrar_nomina(self, cfdi_xml: str) -> Dict:
        """
        Timbra un CFDI de nómina con fallback automático.
        
        Args:
            cfdi_xml: Contenido XML del CFDI de nómina
            
        Returns:
            Dict con resultado de timbrado
        """
        last_error = None
        
        # Intentar con cada PAC en orden de prioridad
        for i, pac in enumerate(self.pacs):
            # Reintentar hasta 3 veces con el mismo PAC
            for retry in range(self.max_retries):
                try:
                    result = pac.timbrar_nomina(cfdi_xml)
                    
                    if result['success']:
                        # Éxito: retornar inmediatamente
                        return {
                            'success': True,
                            'uuid': result['uuid'],
                            'sello_sat': result['sello_sat'],
                            'pac_used': result.get('pac_used', f'PAC {i+1}'),
                            'retries': retry,
                            'timestamp': datetime.now().isoformat()
                        }
                    else:
                        last_error = result['error']
                        print(f"PAC {i+1} falló (intento {retry+1}): {last_error}")
                        
                except Exception as e:
                    last_error = str(e)
                    print(f"Excepción en PAC {i+1} (intento {retry+1}): {last_error}")
            
            # Si llegamos aquí, el PAC actual falló. Continuar con el siguiente.
            print(f"PAC {i+1} falló después de {self.max_retries} intentos. Switching to next PAC.")
        
        # Todos los PACs fallaron
        return {
            'success': False,
            'error': f"Todos los PACs fallaron. Último error: {last_error}",
            'pacs_tried': len(self.pacs),
            'timestamp': datetime.now().isoformat()
        }
    
    def get_health_status(self) -> List[Dict]:
        """
        Obtiene el estado de salud de todos los PACs.
        
        Returns:
            Lista de estados de PACs
        """
        return [
            {
                'pac_index': i,
                'pac_name': pac.__class__.__name__,
                'is_healthy': pac.health_check(),
                'timestamp': datetime.now().isoformat()
            }
            for i, pac in enumerate(self.pacs)
        ]
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Sin API Oficial del SAT para Timbrado

**Problema:**
El SAT no proporciona una API directa para timbrado. Es obligatorio usar un PAC autorizado.

**Solución:**
```python
# Múltiples PACs para resiliencia
pac_manager = PACNominaManager()
pac_manager.add_pac(FinkokNominaPAC(api_key, secret), priority=0)  # Primario
pac_manager.add_pac(SWNominaPAC(token), priority=1)  # Secundario
pac_manager.add_pac(EcodexNominaPAC(client_id, secret), priority=2)  # Terciario
```

**Impacto:**
- Costo adicional: $0.70-$1.50 MXN por timbre
- Dependencia de terceros (PACs)
- SLA variable entre PACs (99.5%-99.9%)

### 4.2 Limitación 2: Costos Variables por Volumen

**Problema:**
Los costos por timbre varían significativamente según volumen ($0.70-$2.00 MXN).

**Solución:**
```python
def seleccionar_pac_por_volumen(volumen_mensual: int) -> str:
```

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **77 PACs autorizados:** Top 10 son suficientes para producción.
2. **Costos variables:** $0.70-$2.00 MXN por timbre según volumen.
3. **Fallback es crítico:** Un solo PAC = 99.5% uptime. Dos PACs = 99.9% uptime.
4. **Health checks esenciales:** Detección temprana de fallos (<30s).
5. **Abstracción necesaria:** Cada PAC tiene API diferente. Adaptadores son obligatorios.

### 8.2 Recomendaciones Finales

| Área | Recomendación | Prioridad | Owner |
|------|---------------|-----------|-------|
| **PACs** | Configurar 2-3 PACs mínimo | ALTA | Backend Lead |

| **Monitoreo** | Dashboard en tiempo real | MEDIA | DevOps |
