## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación documenta la integración con SPEI (Sistema de Pagos Electrónicos Interbancarios) a través de STP (Sistema de Transferencias y Pagos) para permitir cobros y pagos automatizados mediante transferencias electrónicas en el IDP-App Asistente Contable. El módulo resuelve la necesidad de recibir pagos directamente en cuenta bancaria, con conciliación automática y generación de comprobantes fiscales.

**Problema que resuelve:** Los contadores y despachos reciben pagos de clientes mediante transferencias SPEI manualmente, sin automatización en la conciliación, sin validación de cuentas CLABE, sin generación de comprobantes CEP (Comprobante Electrónico de Pago), y con retrasos en la identificación de pagos. Esto genera 6-10 horas semanales de trabajo manual, errores de conciliación, y retrasos en la aplicación de pagos.

### 1.2 Actividades del Contador que Automatiza

|-----------|------------|---------------|-----------------|--------|
| Validación de cuentas CLABE antes de cobrar | Diaria | 1 hora | 5 minutos | 91% |

### 1.3 Dolor Principal que Resuelve

**Dolor 1: Identificación manual de pagos**
- Revisar extracto bancario para identificar cada transferencia recibida
- Cruzar manualmente referencias numéricas con clientes
- Tiempo perdido: 2-3 horas diarias durante cierres

**Dolor 2: Validación de cuentas CLABE**
- Verificar que la cuenta del cliente sea válida antes de cobrar
- Errores por CLABE incorrecto generan devoluciones y retrasos
- 15-20% de transferencias fallan por errores de captura

**Dolor 3: Comprobantes de pago (CEP)**
- STP genera CEP por cada transferencia recibida
- Sin integración, hay que descargar manualmente de la banca en línea
- Riesgo de perder comprobantes para deducción fiscal

    def calcular_digito_verificador(self, clabe_sin_digito: str) -> int:
        """
        Calcula el dígito verificador de una CLABE.
        
        Args:
            clabe_sin_digito: CLABE de 17 dígitos (sin dígito verificador)
            
        Returns:
            Dígito verificador calculado
            
        Ejemplo:
            >>> validador = ValidadorCLABE()
            >>> digito = validador.calcular_digito_verificador("01218001234567890")
            >>> print(digito)
            1
        """
        if len(clabe_sin_digito) != 17:
            raise ValueError("La CLABE debe tener 17 dígitos (sin dígito verificador)")
        
        if not clabe_sin_digito.isdigit():
            raise ValueError("La CLABE debe contener solo dígitos")
        
        # Factores multiplicadores (patrón: 3, 7, 1 repetido)
        factores = [3, 7, 1, 3, 7, 1, 3, 7, 1, 3, 7, 1, 3, 7, 1, 3, 7]
        
        # Multiplicar cada dígito por su factor correspondiente
        suma = 0
        for i, digito in enumerate(clabe_sin_digito):
            producto = int(digito) * factores[i]
            suma += producto
        
        # Calcular dígito verificador
        residuo = suma % 10
        digito_verificador = (10 - residuo) % 10
        
        return digito_verificador
    
    def validar(self, clabe: str) -> ResultadoValidacionCLABE:
        """
        Valida una cuenta CLABE completa.
        
        Args:
            clabe: CLABE de 18 dígitos
            
        Returns:

                es_valida=False,
                banco_codigo="",
                banco_nombre="",
                mensaje_error="La CLABE debe contener solo dígitos"

#### Algoritmo 2: Gestor de Transferencias SPEI vía STP

```python
from datetime import datetime
from dataclasses import dataclass
from typing import List, Optional
from decimal import Decimal
import xml.etree.ElementTree as ET

@dataclass
class TransferenciaSPEI:
    """Representa una transferencia SPEI."""
    id_operacion: str
    cuenta_ordenante: str  # CLABE de origen
    cuenta_beneficiario: str  # CLABE de destino
    monto: Decimal
    concepto: str
    referencia_numerica: str  # 7 dígitos
    estado: str  # "pendiente", "procesada", "rechazada", "devuelta"
    fecha_operacion: datetime
    cep_xml: Optional[str] = None  # Comprobante Electrónico de Pago

class GestorTransferenciasSTP:
    """
    Gestiona transferencias SPEI a través de STP.
    
    Incluye:
    - Envío de transferencias
    - Recepción de CEP
    - Validación de estado
    - Conciliación automática
    
    Ejemplo:
        >>> gestor = GestorTransferenciasSTP()
        >>> transferencia = TransferenciaSPEI(...)
        >>> resultado = gestor.enviar_transferencia(transferencia)
        >>> print(resultado.estado)
        'procesada'
    """
    
    LIMITE_MAXIMO_SPEI = Decimal("8000000.00")  # $8M MXN por operación (Banxico)
    LIMITE_MTU_DEFAULT = Decimal("12500.00")  # $12,500 MXN si no configurado (2026)
    
    def __init__(self, certificado_csd: str, llave_privada: str, password: str):
        """
        Inicializa gestor STP.
        
        Args:
            certificado_csd: Ruta al archivo .cer del CSD
            llave_privada: Ruta al archivo .key del CSD
            password: Contraseña de la llave privada
        """
        self.certificado_csd = certificado_csd
        self.llave_privada = llave_privada
        self.password = password
    
    def validar_antes_de_enviar(self, transferencia: TransferenciaSPEI) -> dict:
        """
        Valida transferencia antes de enviar a STP.
        
        Returns:
            Diccionario con:
            - es_valida: bool
            - errores: lista de errores encontrados
            - advertencias: lista de advertencias
        """
        validador_clabe = ValidadorCLABE()
        errores = []
        advertencias = []
        
        # Validar CLABE ordenante
        resultado_ordenante = validador_clabe.validar(transferencia.cuenta_ordenante)
        if not resultado_ordenante.es_valida:
            errores.append(f"CLABE ordenante inválida: {resultado_ordenante.mensaje_error}")
        
        # Validar CLABE beneficiario
        resultado_beneficiario = validador_clabe.validar(transferencia.cuenta_beneficiario)
        if not resultado_beneficiario.es_valida:
            errores.append(f"CLABE beneficiario inválida: {resultado_beneficiario.mensaje_error}")
        
        # Validar monto
        if transferencia.monto <= 0:
            errores.append("El monto debe ser mayor a cero")
        elif transferencia.monto > self.LIMITE_MAXIMO_SPEI:
            errores.append(f"El monto excede el límite SPEI de ${self.LIMITE_MAXIMO_SPEI:,.2f} MXN")
        
        # Validar referencia numérica (7 dígitos)
        if not transferencia.referencia_numerica.isdigit() or len(transferencia.referencia_numerica) != 7:
            errores.append("La referencia numérica debe ser de 7 dígitos")
        
        # Advertencia por MTU
        if transferencia.monto > self.LIMITE_MTU_DEFAULT:
            advertencias.append(
                f"El monto supera el MTU default de ${self.LIMITE_MTU_DEFAULT:,.2f} MXN. "
                "El beneficiario debe tener configurado su límite."
            )
        
        return {
            "es_valida": len(errores) == 0,
            "errores": errores,
            "advertencias": advertencias
        }
    
    def enviar_transferencia(self, transferencia: TransferenciaSPEI) -> TransferenciaSPEI:
        """
        Envía transferencia a STP para procesamiento SPEI.
        
        Args:
            transferencia: Datos de la transferencia
            
        Returns:
            Transferencia con estado actualizado y CEP si está disponible
            
        Raises:
            ValueError: Si la transferencia no pasa validaciones
        """
        # Validar antes de enviar
        validacion = self.validar_antes_de_enviar(transferencia)
        if not validacion["es_valida"]:
            raise ValueError(f"Transferencia inválida: {', '.join(validacion['errores'])}")
        
        # Simular envío a STP (en producción, llamar API real)
        # STP procesa en <30 segundos, 24/7
        transferencia.estado = "procesada"
        transferencia.fecha_operacion = datetime.now()
        
        # Generar CEP simulado (en producción, STP lo envía vía webhook)
        transferencia.cep_xml = self._generar_cep_simulado(transferencia)
        
        return transferencia
    
    def _generar_cep_simulado(self, transferencia: TransferenciaSPEI) -> str:
        """
        Genera CEP (Comprobante Electrónico de Pago) simulado.
        
        En producción, STP envía el CEP real vía webhook después de procesar.
        """
        cep = f"""<?xml version="1.0" encoding="UTF-8"?>
<ComprobanteElectronicoPago version="1.0">
    <DatosGenerales>
        <IdOperacion>{transferencia.id_operacion}</IdOperacion>
        <FechaOperacion>{transferencia.fecha_operacion.isoformat()}</FechaOperacion>
        <Monto>{transferencia.monto}</Monto>
        <Moneda>MXN</Moneda>
    </DatosGenerales>
    <Ordenante>
        <Cuenta>{transferencia.cuenta_ordenante}</Cuenta>
    </Ordenante>
    <Beneficiario>
        <Cuenta>{transferencia.cuenta_beneficiario}</Cuenta>
    </Beneficiario>
    <Concepto>{transferencia.concepto}</Concepto>
    <ReferenciaNumerica>{transferencia.referencia_numerica}</ReferenciaNumerica>
</ComprobanteElectronicoPago>"""
        return cep
    
    def procesar_cep_recibido(self, cep_xml: str) -> dict:
        """
        Procesa CEP recibido de STP.
        
        Args:
            cep_xml: XML del Comprobante Electrónico de Pago
            
        Returns:
            Diccionario con datos del CEP parseados
        """
        root = ET.fromstring(cep_xml)
        
        datos = {
            "id_operacion": root.find(".//IdOperacion").text,
            "fecha_operacion": root.find(".//FechaOperacion").text,
            "monto": Decimal(root.find(".//Monto").text),
            "moneda": root.find(".//Moneda").text,
            "cuenta_ordenante": root.find(".//Ordenante/Cuenta").text,
            "cuenta_beneficiario": root.find(".//Beneficiario/Cuenta").text,
            "concepto": root.find(".//Concepto").text,
            "referencia_numerica": root.find(".//ReferenciaNumerica").text
        }
        
        return datos
    
    def conciliar_pagos(
        self,
        transferencias_recibidas: List[TransferenciaSPEI],
        facturas_pendientes: List[dict]
    ) -> List[dict]:
        """
        Concilia transferencias recibidas con facturas pendientes.
        
        Args:
            transferencias_recibidas: Lista de transferencias SPEI recibidas
            facturas_pendientes: Lista de facturas por cobrar
            
        Returns:
            Lista de conciliaciones encontradas
        """
        conciliaciones = []
        
        for transferencia in transferencias_recibidas:
            # Buscar factura por referencia numérica o monto
            referencia = transferencia.referencia_numerica
            monto = transferencia.monto
            
            factura_match = next(
                (f for f in facturas_pendientes 
                 if f.get("referencia") == referencia or f.get("monto") == monto),
                None
            )
            
            if factura_match:
                conciliaciones.append({
                    "transferencia": transferencia,
                    "factura": factura_match,
                    "estado": "conciliado",
                    "monto": monto,
                    "fecha": transferencia.fecha_operacion
                })
            else:
                conciliaciones.append({
                    "transferencia": transferencia,
                    "factura": None,
                    "estado": "sin_conciliar",
                    "monto": monto,
                    "fecha": transferencia.fecha_operacion
                })
        
        return conciliaciones
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Límites de Transferencia (MTU 2026)

**Problema:**
Desde enero 2026, los usuarios que no configuraron su MTU (Monto Transaccional del Usuario) tienen un límite automático de $12,500 MXN (1,500 UDIS) por transferencia. Esto afecta cobros de montos superiores.

**Solución:**
```python
class GestorMTU:
    """
    Gestiona límites MTU para transferencias SPEI.
    
    MTU 2026:
    - Default: $12,500 MXN (1,500 UDIS) si no configurado
    - Configurable: Usuario define límite en app bancaria
    - Aplica a: SPEI, CoDi, DiMo, banca digital
    """
    
    LIMITE_DEFAULT_UDIS = 1500  # UDIS
    VALOR_UDI_2026 = Decimal("8.695877")  # Valor UDI 2026 (Banxico)
    
    def calcular_limite_default(self) -> Decimal:
        """Calcula límite default en MXN."""
        return self.LIMITE_DEFAULT_UDIS * self.VALOR_UDI_2026
    
    def verificar_excede_mtu(self, monto: Decimal, mtu_configurado: Optional[Decimal]) -> dict:
        """
        Verifica si monto excede MTU.
        
        Returns:
            Diccionario con:
            - excede: bool
            - limite: Decimal
            - diferencia: Decimal
            - recomendacion: str
        """
        limite = mtu_configurado or self.calcular_limite_default()
        excede = monto > limite
        
        if excede:
            recomendacion = (
                f"El monto (${monto:,.2f} MXN) excede tu MTU de ${limite:,.2f} MXN. "
                "Solicita al beneficiario configurar su MTU en la app bancaria."
            )
        else:
            recomendacion = "Monto dentro del límite MTU."
        
        return {
            "excede": excede,
            "limite": limite,
            "diferencia": monto - limite if excede else Decimal("0.00"),
            "recomendacion": recomendacion
        }
```

**Impacto:**
- Cobros >$12,500 MXN requieren que cliente configure MTU
- Necesidad de notificar a clientes sobre configuración de MTU
- Posibles retrasos en cobros si MTU no está configurado

### 4.2 Limitación 2: Certificado CSD Requerido

**Problema:**
La integración con STP requiere Certificado de Sello Digital (CSD) vigente, tramitado en el SAT. El proceso toma 2-3 semanas y requiere e.firma vigente.

**Solución:**
```python
class GestorCSD:
    """
    Gestiona certificados CSD para integración STP.
    
    Requisitos:
    - e.firma vigente
    - Aplicación CERTIFICA (SAT)
    - Trámite en línea (2-3 semanas)
    """
    
    VIGENCIA_CSD = 4 * 365  # 4 años en días
    
    def verificar_vigencia_csd(self, fecha_emision: datetime, fecha_vencimiento: datetime) -> dict:
        """
        Verifica vigencia de CSD.
        
        Returns:
            Diccionario con:
            - es_valido: bool
            - dias_restantes: int
            - requiere_renovacion: bool
            - mensaje: str
        """
        ahora = datetime.now()
        dias_restantes = (fecha_vencimiento - ahora).days
        
        es_valido = ahora < fecha_vencimiento
        requiere_renovacion = dias_restantes < 30  # Alerta 30 días antes
        
        if not es_valido:
            mensaje = "CSD VENCIDO. Tramitar renovación inmediatamente."
        elif requiere_renovacion:
            mensaje = f"CSD por vencer en {dias_restantes} días. Iniciar renovación."
        else:
            mensaje = f"CSD vigente. {dias_restantes} días restantes."
        
        return {
            "es_valido": es_valido,
            "dias_restantes": dias_restantes,
            "requiere_renovacion": requiere_renovacion,
            "mensaje": mensaje
        }
```

**Impacto:**
- Retraso de 2-3 semanas para obtener CSD
- Costo de trámite: Gratuito, pero requiere tiempo administrativo
- Renovación cada 4 años obligatoria
