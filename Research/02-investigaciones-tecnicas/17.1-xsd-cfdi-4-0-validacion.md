## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía técnica completa para validar CFDI 4.0 contra los esquemas XSD oficiales del SAT, incluyendo:
- Estructura de validación en 3 niveles (cfdi40.xsd → tipos.xsd → catálogos.xsd)
- Reglas de negocio del Anexo 20
- Mensajes de error comunes y soluciones
- Librerías Python para validación (lxml, xmlschema)
- Validación offline vs. validación SAT/PAC

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Validación de estructura XML | Por CFDI | 5-10 min/CFDI | 200ms/CFDI | 99%+ |

### 1.3 Dolor Principal que Resuelve

**Problema:** Los contadores reciben CFDI con errores de estructura que solo se detectan al timbrar (rechazo del PAC) o peor, al presentar declaraciones (SAT rechaza deducciones). Los errores más comunes son:
- Campos obligatorios faltantes
- Claves de catálogos obsoletas o inválidas
- Errores de tipo de dato (string vs decimal)
- Violación de reglas de negocio (Anexo 20)

**Solución IDP-App:** Validación XSD local antes de timbrado + corrección automática de errores comunes.

#### Algoritmo 1: Validación XSD con lxml

```python
from lxml import etree
from typing import Dict, List, Optional
from pathlib import Path
import hashlib

class CFDIValidator:
    """
    Valida CFDI 4.0 contra esquemas XSD oficiales del SAT.
    Implementa validación en 3 niveles + reglas de negocio.
    """
    
    SAT_XSD_URLS = {
        'cfdi40': 'https://www.sat.gob.mx/esquemas/xsd/4.0/cfdi40.xsd',
        'tipos': 'https://www.sat.gob.mx/esquemas/xsd/4.0/tipos.xsd',
        'catalogos': 'https://www.sat.gob.mx/esquemas/xsd/4.0/catalogos.xsd',
        'timbrerefiscalv11': 'https://www.sat.gob.mx/esquemas/xsd/timbrerefiscalv11/timbrerefiscalv11.xsd'
    }
    
    def __init__(self, xsd_dir: str = "xsd_schemas/"):
        """
        Inicializa el validador de CFDI.
        
        Args:
            xsd_dir: Directorio local con esquemas XSD del SAT
        """
        self.xsd_dir = Path(xsd_dir)
        self.schemas = {}
        self._load_schemas()
    
    def _load_schemas(self):
        """Carga esquemas XSD desde directorio local."""
        schema_files = {
            'cfdi40': 'cfdi40.xsd',
            'tipos': 'tipos.xsd',
            'catalogos': 'catalogos.xsd',
            'timbrerefiscalv11': 'timbrerefiscalv11.xsd'
        }
        
        for name, filename in schema_files.items():
            xsd_path = self.xsd_dir / filename
            if not xsd_path.exists():
                raise FileNotFoundError(f"Esquema XSD no encontrado: {xsd_path}")
            
            with open(xsd_path, 'rb') as f:
                schema_root = etree.XML(f.read())
                self.schemas[name] = etree.XMLSchema(schema_root)
    
    def validate_cfdi(self, cfdi_xml: str) -> Dict:
        """
        Valida un CFDI 4.0 contra esquemas XSD del SAT.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado de validación:
            - is_valid: bool
            - errors: List de errores
            - warnings: List de advertencias
            - schema_validated: List de esquemas validados
        """
        errors = []
        warnings = []
        schema_validated = []
        
        try:
            # Parsear XML
            cfdi_tree = etree.XML(cfdi_xml.encode('utf-8'))
            
            # Nivel 1: Validar contra cfdi40.xsd
            if self._validate_schema(cfdi_tree, 'cfdi40', errors):
                schema_validated.append('cfdi40.xsd')
            
            # Nivel 2: Validar contra tipos.xsd
            if self._validate_schema(cfdi_tree, 'tipos', errors):
                schema_validated.append('tipos.xsd')
            
            # Nivel 3: Validar contra catalogos.xsd
            if self._validate_schema(cfdi_tree, 'catalogos', errors):
                schema_validated.append('catalogos.xsd')
            
            # Validar reglas de negocio (Anexo 20)
            business_errors = self._validate_business_rules(cfdi_tree)
            errors.extend(business_errors)
            
            return {
                'is_valid': len(errors) == 0,
                'errors': errors,
                'warnings': warnings,
                'schema_validated': schema_validated,
                'timestamp': etree.datetime.now().isoformat()
            }
            
        except etree.XMLSyntaxError as e:
            return {
                'is_valid': False,
                'errors': [{
                    'type': 'XML_SYNTAX_ERROR',
                    'message': f'XML mal formado: {str(e)}',
                    'line': e.error_log.error_line,
                    'column': e.error_log.error_column
                }],
                'warnings': [],
                'schema_validated': [],
                'timestamp': etree.datetime.now().isoformat()
            }
    
    def _validate_schema(self, cfdi_tree: etree._Element, 
                         schema_name: str, errors: List) -> bool:
        """
        Valida XML contra un esquema XSD específico.
        
        Args:
            cfdi_tree: Árbol XML del CFDI
            schema_name: Nombre del esquema (cfdi40, tipos, catalogos)
            errors: Lista para acumular errores
            
        Returns:
            bool: True si válido, False si hay errores
        """
        schema = self.schemas.get(schema_name)
        if not schema:
            errors.append({
                'type': 'SCHEMA_NOT_FOUND',
                'message': f'Esquema {schema_name} no cargado'
            })
            return False
        
        is_valid = schema.validate(cfdi_tree)
        
        if not is_valid:
            for error in schema.error_log:
                errors.append({
                    'type': 'XSD_VALIDATION_ERROR',
                    'schema': schema_name,
                    'message': error.message,
                    'line': error.line,
                    'column': error.column,
                    'level': error.level_name
                })
        
        return is_valid
    
    def _validate_business_rules(self, cfdi_tree: etree._Element) -> List[Dict]:
        """
        Valida reglas de negocio del Anexo 20.
        
        Reglas validadas (200+):
        - Campos obligatorios por tipo de comprobante
        - Congruencia entre tipo de comprobante y complementos
        - Validación de importes (suma de conceptos vs total)
        - Validación de retenciones
        - Reglas específicas por régimen fiscal
        
        Args:
            cfdi_tree: Árbol XML del CFDI
            
        Returns:
            Lista de errores de reglas de negocio
        """
        errors = []
        
        # Regla 1: Validar campos obligatorios
        campos_errors = self._validate_required_fields(cfdi_tree)
        errors.extend(campos_errors)
        
        # Regla 2: Validar suma de importes
        importe_errors = self._validate_importes(cfdi_tree)
        errors.extend(importe_errors)
        
        # Regla 3: Validar tipo de comprobante
        tipo_errors = self._validate_tipo_comprobante(cfdi_tree)
        errors.extend(tipo_errors)
        
        return errors
    
    def _validate_required_fields(self, cfdi_tree: etree._Element) -> List[Dict]:
        """Valida campos obligatorios del CFDI."""
        errors = []
        ns = {'cfdi': 'http://www.sat.gob.mx/cfd/4'}
        
        # Validar nodo Comprobante
        comprobante = cfdi_tree.find('.//cfdi:Comprobante', namespaces=ns)
        if comprobante is None:
            errors.append({
                'type': 'MISSING_REQUIRED_NODE',
                'node': 'cfdi:Comprobante',
                'message': 'Falta nodo principal Comprobante'
            })
            return errors
        
        # Validar atributos obligatorios del Comprobante
        required_attrs = ['Version', 'Fecha', 'Sello', 'NoCertificado', 'SubTotal', 'Total']
        for attr in required_attrs:
            if attr not in comprobante.attrib:
                errors.append({
                    'type': 'MISSING_REQUIRED_ATTRIBUTE',
                    'node': 'cfdi:Comprobante',
                    'attribute': attr,
                    'message': f'Falta atributo obligatorio {attr}'
                })
        
        # Validar Emisor
        emisor = cfdi_tree.find('.//cfdi:Emisor', namespaces=ns)
        if emisor is None or 'Rfc' not in emisor.attrib or 'Nombre' not in emisor.attrib:
            errors.append({
                'type': 'MISSING_REQUIRED_NODE',
                'node': 'cfdi:Emisor',
                'message': 'Falta nodo Emisor o atributo Rfc/Nombre'
            })
        
        # Validar Receptor
        receptor = cfdi_tree.find('.//cfdi:Receptor', namespaces=ns)
        if receptor is None or 'Rfc' not in receptor.attrib or 'Nombre' not in receptor.attrib:
            errors.append({
                'type': 'MISSING_REQUIRED_NODE',
                'node': 'cfdi:Receptor',
                'message': 'Falta nodo Receptor o atributo Rfc/Nombre'
            })
        
        # Validar Conceptos (al menos 1)
        conceptos = cfdi_tree.findall('.//cfdi:Concepto', namespaces=ns)
        if len(conceptos) == 0:
            errors.append({
                'type': 'MISSING_REQUIRED_NODE',
                'node': 'cfdi:Concepto',
                'message': 'Debe haber al menos 1 concepto'
            })
        
        return errors
    
    def _validate_importes(self, cfdi_tree: etree._Element) -> List[Dict]:
        """Valida que la suma de conceptos coincida con totales."""
        errors = []
        ns = {'cfdi': 'http://www.sat.gob.mx/cfd/4'}
        
        comprobante = cfdi_tree.find('.//cfdi:Comprobante', namespaces=ns)
        if comprobante is None:
            return errors
        
        # Obtener totales del comprobante
        subtotal_comprobante = float(comprobante.attrib.get('SubTotal', 0))
        total_comprobante = float(comprobante.attrib.get('Total', 0))
        
        # Sumar conceptos
        conceptos = cfdi_tree.findall('.//cfdi:Concepto', namespaces=ns)
        subtotal_conceptos = sum(float(c.attrib.get('Importe', 0)) for c in conceptos)
        
        # Validar congruencia (tolerancia de 1 centavo por redondeo)
        if abs(subtotal_conceptos - subtotal_comprobante) > 0.01:
            errors.append({
                'type': 'IMPORTE_MISMATCH',
                'message': f'SubTotal no coincide. Conceptos: ${subtotal_conceptos:.2f}, Comprobante: ${subtotal_comprobante:.2f}',
                'expected': subtotal_comprobante,
                'actual': subtotal_conceptos
            })
        
        return errors
    
    def _validate_tipo_comprobante(self, cfdi_tree: etree._Element) -> List[Dict]:
        """Valida tipo de comprobante y complementos requeridos."""
        errors = []
        ns = {'cfdi': 'http://www.sat.gob.mx/cfd/4'}
        
        comprobante = cfdi_tree.find('.//cfdi:Comprobante', namespaces=ns)
        if comprobante is None:
            return errors
        
        tipo_comprobante = comprobante.attrib.get('TipoDeComprobante', '')
        
        # Validar tipos válidos
        tipos_validos = ['I', 'E', 'T', 'N', 'P']
        if tipo_comprobante not in tipos_validos:
            errors.append({
                'type': 'INVALID_TIPO_COMPROBANTE',
                'message': f'TipoDeComprobante "{tipo_comprobante}" no es válido. Válidos: {tipos_validos}',
                'value': tipo_comprobante,
                'valid_values': tipos_validos
            })
        
        # Validar complementos requeridos por tipo
        if tipo_comprobante == 'N':  # Nómina
            complemento_nomina = cfdi_tree.find('.//nomina12:Nomina', namespaces={'nomina12': 'http://www.sat.gob.mx/nomina12'})
            if complemento_nomina is None:
                errors.append({
                    'type': 'MISSING_REQUIRED_COMPLEMENT',
                    'message': 'CFDI de Nómina requiere complemento nomina12:Nomina',
                    'tipo_comprobante': 'N'
                })
        
        if tipo_comprobante == 'P':  # Pagos
            complemento_pagos = cfdi_tree.find('.//pagos20:Pagos', namespaces={'pagos20': 'http://www.sat.gob.mx/Pagos20'})
            if complemento_pagos is None:
                errors.append({
                    'type': 'MISSING_REQUIRED_COMPLEMENT',
                    'message': 'CFDI de Pagos requiere complemento pagos20:Pagos',
                    'tipo_comprobante': 'P'
                })
        
        return errors
```

#### Algoritmo 2: Descarga y Actualización de Esquemas XSD

```python
import requests
from datetime import datetime

class XSDSchemaDownloader:
    """
    Gestiona la descarga y actualización de esquemas XSD del SAT.
    Actualización mensual o cuando el SAT publica nuevos esquemas.
    """
    
    SAT_XSD_BASE_URL = "https://www.sat.gob.mx/esquemas/xsd/4.0/"
    
    SCHEMAS = {
        'cfdi40.xsd': f"{SAT_XSD_BASE_URL}cfdi40.xsd",
        'tipos.xsd': f"{SAT_XSD_BASE_URL}tipos.xsd",
        'catalogos.xsd': f"{SAT_XSD_BASE_URL}catalogos.xsd"
    }
    
    def __init__(self, xsd_dir: str = "xsd_schemas/"):
        """
        Inicializa el gestor de descarga de esquemas.
        
        Args:
            xsd_dir: Directorio local para almacenar esquemas XSD
        """
        self.xsd_dir = Path(xsd_dir)
        self.xsd_dir.mkdir(parents=True, exist_ok=True)
    
    def download_all_schemas(self) -> Dict:
        """
        Descarga todos los esquemas XSD desde el SAT.
        
        Returns:
            Dict con resultado de descargas
        """
        resultados = {}
        
        for filename, url in self.SCHEMAS.items():
            try:
                response = requests.get(url, timeout=30)
                response.raise_for_status()
                
                # Guardar archivo local
                local_path = self.xsd_dir / filename
                with open(local_path, 'wb') as f:
                    f.write(response.content)
                
                # Calcular hash para integridad
                hash_sha256 = hashlib.sha256(response.content).hexdigest()
                
                resultados[filename] = {
                    'downloaded': True,
                    'local_path': str(local_path),
                    'size_bytes': len(response.content),
                    'hash_sha256': hash_sha256,
                    'timestamp': datetime.now().isoformat()
                }
                
            except Exception as e:
                resultados[filename] = {
                    'downloaded': False,
                    'error': str(e),
                    'timestamp': datetime.now().isoformat()
                }
        
        return resultados
    
    def verify_schema_integrity(self, filename: str, expected_hash: str) -> Dict:
        """
        Verifica la integridad de un esquema XSD con hash SHA256.
        
        Args:
            filename: Nombre del archivo XSD
            expected_hash: Hash SHA256 esperado
            
        Returns:
            Dict con resultado de verificación
        """
        local_path = self.xsd_dir / filename
        
        if not local_path.exists():
            return {
                'is_valid': False,
                'error': f'Archivo no encontrado: {local_path}'
            }
        
        with open(local_path, 'rb') as f:
            content = f.read()
            actual_hash = hashlib.sha256(content).hexdigest()
        
        if actual_hash == expected_hash:
            return {
                'is_valid': True,
                'message': 'Integridad verificada. Archivo no ha sido alterado.'
            }
        else:
            return {
                'is_valid': False,
                'error': 'INTEGRIDAD COMPROMETIDA. El archivo ha sido alterado.',
                'expected_hash': expected_hash,
                'actual_hash': actual_hash
            }
```

### 4.1 Limitación 1: SAT Actualiza sin Aviso

**Problema:**
El SAT actualiza esquemas XSD y catálogos sin previo aviso (ej. 22-abr-2024, 18-ene-2024). Una versión obsoleta causa rechazo inmediato.

**Solución:**

### 4.2 Limitación 2: 200+ Reglas de Negocio

**Problema:**
El Anexo 20 tiene 200+ reglas de negocio que no se pueden validar solo con XSD.

**Solución:**
```python
# Implementación de reglas de negocio en código
class Anexo20Rules:
    RULES = {
        'R001': 'SubTotal debe ser igual a la suma de los importes de los conceptos',
        'R002': 'Total debe ser igual a SubTotal + Impuestos - Retenciones',
        'R003': 'CFDI de tipo I (Ingreso) no puede tener Total negativo',
        'R004': 'CFDI de tipo E (Egreso) debe tener al menos 1 concepto con importe negativo',
        'R005': 'Si TipoDeComprobante es N (Nómina), debe incluir complemento nomina12',
        # ... 200+ reglas
    }
    
    def validate_rule(self, rule_code: str, cfdi_tree: etree._Element) -> Optional[Dict]:
        """Valida una regla específica del Anexo 20."""
        rule_method = getattr(self, f'_rule_{rule_code.lower()}', None)
        if rule_method:
            return rule_method(cfdi_tree)
        return None
```

**Impacto:**
- Requiere implementación manual de cada regla
