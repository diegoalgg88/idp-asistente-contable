## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía técnica completa para implementar descarga masiva de CFDI desde el web service del SAT, incluyendo:
- Autenticación con e.firma (CSD): certificado .cer, llave .key, contraseña
- URLs del servicio web (producción y pruebas)
- Formatos de solicitud (metadata vs XML completo)
- Límites operativos (200,000 CFDI/solicitud, 72 horas de vida)
- Procesamiento de respuestas SOAP
- Almacenamiento seguro de XMLs descargados
- Manejo de errores y reintentos automáticos

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Descarga manual desde portal SAT | Semanal | 2-4 horas/semana | 15 minutos/semana | 90-95% |

### 1.3 Dolor Principal que Resuelve

**Problema:** Los contadores deben ingresar manualmente al portal del SAT para descargar CFDI. Este proceso es:
- Lento y tedioso (múltiples clicks, navegación manual)

- Propenso a errores (olvidar rangos, no descargar todo)
- No escalable (imposible para grandes volúmenes)

**Solución IDP-App:** Descarga automática programada vía web service SOAP, sin intervención manual, con capacidad de 200,000+ CFDI por solicitud.

#### Algoritmo 1: Cliente de Descarga Masiva SAT

```python
import requests
from lxml import etree
from datetime import datetime, timedelta
from typing import Dict, List, Optional, Tuple
from pathlib import Path
import base64
import hashlib
import zipfile
import io

from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.backends import default_backend
from cryptography.x509 import load_pem_x509_certificate


class SATDescargaMasivaClient:
    """
    Cliente para descarga masiva de CFDI desde el SAT.
    Implementa autenticación con e.firma, solicitud, verificación y descarga.
    """
    
    # URLs del servicio web (Versión 1.5 - 2025)
    URL_AUTENTICACION = "https://cfdiws.sat.gob.mx/DescargaMasiva/Autenticacion.svc"
    URL_SOLICITUD = "https://cfdiws.sat.gob.mx/DescargaMasiva/SolicitaDescargaService.svc"
    URL_VERIFICACION = "https://cfdiws.sat.gob.mx/DescargaMasiva/VerificaSolicitudService.svc"
    URL_DESCARGA = "https://cfdiws.sat.gob.mx/DescargaMasiva/DescargaService.svc"
    
    # Namespaces SOAP y del servicio
    NS_SOAP = "http://schemas.xmlsoap.org/soap/envelope/"
    NS_SOLICITUD = "http://tempuri.org/"
    NS_DESCARGA = "http://schemas.datacontract.org/2004/07/Sat.Df.Masivas.Servicios"
    
    def __init__(self, cert_path: str, key_path: str, password: str, rfc: str):
        """
        Inicializa el cliente de descarga masiva.
        
        Args:
            cert_path: Ruta al certificado .cer del SAT
            key_path: Ruta a la llave privada .key
            password: Contraseña de la llave privada
            rfc: RFC del contribuyente
        """
        self.rfc = rfc
        self.cert_path = Path(cert_path)
        self.key_path = Path(key_path)
        self.password = password.encode('utf-8')
        
        # Cargar certificado y llave
        self._load_cert_and_key()
        
        # Token de sesión (se obtiene en autenticación)
        self.token: Optional[str] = None
        self.token_expires: Optional[datetime] = None
        
        # Session para reutilizar conexiones
        self.session = requests.Session()
    
    def _load_cert_and_key(self):
        """Carga certificado y llave privada desde archivos."""
        # Cargar certificado
        with open(self.cert_path, 'rb') as f:
            cert_data = f.read()
            self.cert = load_pem_x509_certificate(cert_data, default_backend())
        
        # Cargar llave privada
        with open(self.key_path, 'rb') as f:
            key_data = f.read()
            self.private_key = serialization.load_pem_private_key(
                key_data,
                password=self.password,
                backend=default_backend()
            )
    
    def authenticate(self) -> Dict:
        """
        Autentica con el servicio web del SAT usando e.firma.
        
        Returns:
            Dict con resultado de autenticación:
            - success: bool
            - token: str (si exitoso)
            - expires: datetime (si exitoso)
            - error: str (si fallido)
        """
        try:
            # Construir mensaje de autenticación
            timestamp = datetime.now().strftime('%Y-%m-%dT%H:%M:%S')
            
            # Crear cadena original para firma
            cadena_original = f"{self.rfc}|{timestamp}"
            
            # Firmar con llave privada (RSA-SHA256)
            firma = self.private_key.sign(
                cadena_original.encode('utf-8'),
                padding.PKCS1v15(),
                hashes.SHA256()
            )
            firma_b64 = base64.b64encode(firma).decode('utf-8')
            
            # Construir request SOAP
            soap_request = self._build_auth_request(cadena_original, firma_b64)
            
            # Enviar request
            response = self.session.post(
                self.URL_AUTENTICACION,
                headers={
                    'Content-Type': 'text/xml; charset=utf-8',
                    'SOAPAction': 'http://tempuri.org/IAutenticacion/Autenticar'
                },
                data=soap_request,
                timeout=30
            )
            response.raise_for_status()
            
            # Parsear respuesta SOAP
            result = self._parse_auth_response(response.text)
            
            if result['success']:
                self.token = result['token']
                self.token_expires = datetime.now() + timedelta(hours=24)
            
            return result
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error en autenticación: {str(e)}'
            }
    
    def solicitar_descarga(self, 
                          fecha_inicial: datetime,
                          fecha_final: datetime,
                          tipo_solicitud: str = 'Emitidos',
                          tipo_comprobante: Optional[str] = None,
                          rfc_receptor: Optional[str] = None) -> Dict:
        """
        Solicita descarga masiva de CFDI.
        
        Args:
            fecha_inicial: Fecha de inicio del rango
            fecha_final: Fecha de fin del rango
            tipo_solicitud: 'Emitidos' o 'Recibidos'
            tipo_comprobante: Filtro por tipo (I, E, T, N, P) - opcional
            rfc_receptor: RFC del receptor (para emitidos) - opcional
            
        Returns:
            Dict con resultado:
            - success: bool
            - id_solicitud: UUID de la solicitud (si exitoso)
            - error: str (si fallido)
        """
        try:
            # Validar token vigente
            if not self._is_token_valid():
                auth_result = self.authenticate()
                if not auth_result['success']:
                    return auth_result
            
            # Construir request SOAP
            soap_request = self._build_solicitud_request(
                fecha_inicial, fecha_final, tipo_solicitud,
                tipo_comprobante, rfc_receptor
            )
            
            # Enviar request
            response = self.session.post(
                self.URL_SOLICITUD,
                headers={
                    'Content-Type': 'text/xml; charset=utf-8',
                    'SOAPAction': 'http://tempuri.org/ISolicitaDescarga/SolicitarDescarga'
                },
                data=soap_request,
                timeout=60
            )
            response.raise_for_status()
            
            # Parsear respuesta
            result = self._parse_solicitud_response(response.text)
            
            return result
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error en solicitud: {str(e)}'
            }
    
    def verificar_solicitud(self, id_solicitud: str) -> Dict:
        """
        Verifica el estado de una solicitud de descarga.
        
        Args:
            id_solicitud: UUID de la solicitud a verificar
            
        Returns:
            Dict con estado de la solicitud:
            - success: bool
            - estado: str (EnProceso, Terminada, Error, Vacia)

                    'Content-Type': 'text/xml; charset=utf-8',

                },
                data=soap_request,
                timeout=30
            )

            # Parsear respuesta

            return {

    def descargar_paquete(self, id_paquete: str) -> Dict:
        """
        Descarga un paquete de CFDI.
        
        Args:
            id_paquete: ID del paquete a descargar

            # Parsear respuesta

            return result

    def descargar_lote_completo(self,
                               fecha_inicial: datetime,
                               fecha_final: datetime,
                               tipo_solicitud: str = 'Emitidos',
                               destino: str = "xmls_descargados/") -> Dict:
        """
        Descarga un lote completo de CFDI (solicitud + verificación + descarga).
        
        Args:
            fecha_inicial: Fecha de inicio del rango
            fecha_final: Fecha de fin del rango
            tipo_solicitud: 'Emitidos' o 'Recibidos'
            destino: Directorio para almacenar XMLs
            
        Returns:
            Dict con resultado del lote:
            - success: bool
            - total_xmls: int
            - xmls_guardados: List[str]
            - error: str (si fallido)
        """
        try:
            # Crear directorio de destino
            destino_path = Path(destino)
            destino_path.mkdir(parents=True, exist_ok=True)
            
            # Paso 1: Solicitar descarga
            print(f"[{datetime.now()}] Solicitando descarga...")
            solicitud_result = self.solicitar_descarga(
                fecha_inicial, fecha_final, tipo_solicitud
            )
            
            if not solicitud_result['success']:
                return solicitud_result
            
            id_solicitud = solicitud_result['id_solicitud']
            print(f"[{datetime.now()}] Solicitud aceptada: {id_solicitud}")
            
            # Paso 2: Verificar estado (polling cada 30s, máximo 10 min)
            print(f"[{datetime.now()}] Verificando estado de solicitud...")
            max_intentos = 20  # 10 minutos
            intento = 0
            
            while intento < max_intentos:
                verificacion_result = self.verificar_solicitud(id_solicitud)
                
                if not verificacion_result['success']:
                    return verificacion_result
                
                estado = verificacion_result['estado']
                print(f"[{datetime.now()}] Estado: {estado}")
                
                if estado == 'Terminada':
                    ids_paquetes = verificacion_result.get('ids_paquetes', [])
                    break
                elif estado == 'Error':
                    return {
                        'success': False,
                        'error': 'La solicitud terminó con error'
                    }
                elif estado == 'Vacia':
                    return {
                        'success': True,
                        'total_xmls': 0,
                        'xmls_guardados': [],
                        'mensaje': 'No hay CFDI en el rango especificado'
                    }
                
                # Esperar 30 segundos antes de siguiente verificación
                import time
                time.sleep(30)
                intento += 1
            
            if intento >= max_intentos:
                return {
                    'success': False,
                    'error': 'Timeout: La solicitud no terminó en 10 minutos'
                }
            
            # Paso 3: Descargar paquetes
            print(f"[{datetime.now()}] Descargando {len(ids_paquetes)} paquete(s)...")
            xmls_guardados = []
            total_xmls = 0
            
            for id_paquete in ids_paquetes:
                descarga_result = self.descargar_paquete(id_paquete)
                
                if not descarga_result['success']:
                    print(f"Error descargando paquete {id_paquete}: {descarga_result['error']}")
                    continue
                
                # Extraer XMLs del paquete ZIP
                xmls = descarga_result.get('xmls', [])
                for xml_data in xmls:
                    # Guardar XML en archivo
                    uuid = xml_data.get('uuid', f'cfdi_{total_xmls}')
                    xml_path = destino_path / f"{uuid}.xml"
                    
                    with open(xml_path, 'w', encoding='utf-8') as f:
                        f.write(xml_data['contenido'])
                    
                    xmls_guardados.append(str(xml_path))
                    total_xmls += 1
            
            print(f"[{datetime.now()}] Descarga completada: {total_xmls} XMLs guardados")
            
            return {
                'success': True,
                'total_xmls': total_xmls,
                'xmls_guardados': xmls_guardados
            }
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error en descarga de lote: {str(e)}'
            }
```

#### Algoritmo 2: Procesamiento de XMLs Descargados

```python
import xml.etree.ElementTree as ET
from typing import Dict, List, Optional
from datetime import datetime
import hashlib

class CFDIProcessor:
    """
    Procesa XMLs de CFDI descargados del SAT.
    Extrae metadata, valida estructura y almacena en base de datos.
    """
    
    NAMESPACE_CFDI = '{http://www.sat.gob.mx/cfd/4}'
    NAMESPACE_TFD = '{http://www.sat.gob.mx/TimbreFiscalDigital}'
    
    def __init__(self, db_session):
        """
        Inicializa el procesador de CFDI.
        
        Args:
            db_session: Sesión de base de datos para almacenamiento
        """
        self.db = db_session
    
    def procesar_xml(self, xml_path: str) -> Dict:
        """
        Procesa un XML de CFDI y extrae metadata.
        
        Args:
            xml_path: Ruta al archivo XML
            
        Returns:
            Dict con metadata del CFDI:
            - uuid: Folio fiscal
            - fecha: Fecha de emisión
            - emisor_rfc: RFC del emisor
            - emisor_nombre: Nombre del emisor
            - receptor_rfc: RFC del receptor
            - receptor_nombre: Nombre del receptor
            - subtotal: Subtotal
            - total: Total
            - tipo_comprobante: I, E, T, N, P
            - metodo_pago: PUE, PPD
            - forma_pago: 01, 02, 03, etc.
            - moneda: MXN, USD, etc.
            - estado: Vigente, Cancelado
            - xml_hash: Hash SHA256 del XML
        """
        try:
            # Parsear XML
            tree = ET.parse(xml_path)
            root = tree.getroot()
            
            # Extraer nodo Comprobante
            comprobante = root.find(f'{self.NAMESPACE_CFDI}Comprobante')
            if comprobante is None:
                return {
                    'success': False,
                    'error': 'No se encontró nodo Comprobante'
                }
            
            # Extraer datos del emisor
            emisor = comprobante.find(f'{self.NAMESPACE_CFDI}Emisor')
            emisor_rfc = emisor.get('Rfc', '') if emisor is not None else ''
            emisor_nombre = emisor.get('Nombre', '') if emisor is not None else ''
            
            # Extraer datos del receptor
            receptor = comprobante.find(f'{self.NAMESPACE_CFDI}Receptor')
            receptor_rfc = receptor.get('Rfc', '') if receptor is not None else ''
            receptor_nombre = receptor.get('Nombre', '') if receptor is not None else ''
            
            # Extraer datos del comprobante
            uuid = self._extract_uuid(root)
            fecha = comprobante.get('Fecha', '')
            subtotal = float(comprobante.get('SubTotal', 0))
            total = float(comprobante.get('Total', 0))
            tipo_comprobante = comprobante.get('TipoDeComprobante', '')
            metodo_pago = comprobante.get('MetodoPago', '')
            forma_pago = comprobante.get('FormaPago', '')
            moneda = comprobante.get('Moneda', '')
            
            # Calcular hash del XML
            with open(xml_path, 'rb') as f:
                xml_content = f.read()
                xml_hash = hashlib.sha256(xml_content).hexdigest()
            
            # Determinar estado (Vigente o Cancelado)
            # Nota: El SAT no incluye estado en XML descargado
            # Se debe verificar contra lista de cancelados o metadata
            estado = 'Vigente'  # Asumir vigente por defecto
            
            return {
                'success': True,
                'uuid': uuid,
                'fecha': fecha,
                'emisor_rfc': emisor_rfc,
                'emisor_nombre': emisor_nombre,
                'receptor_rfc': receptor_rfc,
                'receptor_nombre': receptor_nombre,
                'subtotal': subtotal,
                'total': total,
                'tipo_comprobante': tipo_comprobante,
                'metodo_pago': metodo_pago,
                'forma_pago': forma_pago,
                'moneda': moneda,
                'estado': estado,
                'xml_hash': xml_hash,
                'xml_path': xml_path
            }
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error procesando XML: {str(e)}'
            }
    
    def _extract_uuid(self, root: ET.Element) -> str:
        """
        Extrae UUID (Folio Fiscal) del Timbre Fiscal Digital.
        
        Args:
            root: Elemento raíz del XML
            
        Returns:
            UUID del CFDI
        """
        # Buscar complemento de Timbre Fiscal Digital
        complemento = root.find(f'{self.NAMESPACE_CFDI}Complemento')
        if complemento is None:
            return ''
        
        # Buscar TimbreFiscalDigital
        timbre = complemento.find(f'{self.NAMESPACE_TFD}TimbreFiscalDigital')
        if timbre is None:
            return ''
        
        # Extraer UUID
        return timbre.get('UUID', '')
    
    def procesar_lote(self, xml_paths: List[str]) -> Dict:
        """
        Procesa un lote de XMLs y los almacena en base de datos.
        
        Args:
            xml_paths: Lista de rutas a archivos XML
            
        Returns:
            Dict con resultado del procesamiento:
            - success: bool
            - total_procesados: int
            - exitosos: int
            - fallidos: int
            - errores: List[Dict]
        """
        total_procesados = len(xml_paths)
        exitosos = 0
        fallidos = 0
        errores = []
        
        for xml_path in xml_paths:
            resultado = self.procesar_xml(xml_path)
            
            if resultado['success']:
                # Almacenar en base de datos
                self._almacenar_cfdi(resultado)
                exitosos += 1
            else:
                fallidos += 1
                errores.append({
                    'xml_path': xml_path,
                    'error': resultado['error']
                })
        
        return {
            'success': fallidos == 0,
            'total_procesados': total_procesados,
            'exitosos': exitosos,
```
