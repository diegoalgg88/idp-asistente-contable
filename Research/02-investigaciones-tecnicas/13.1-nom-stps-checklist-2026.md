## Marco Normativo

### Ley Federal del Trabajo (LFT)

**Artículo 994**: Establece el catálogo de infracciones y sanciones.

| Tipo de Infracción | Multa (UMAs) | Multa (MXN 2026) |
|-------------------|--------------|------------------|
| **Leve** | 50 - 250 | $5,428 - $27,142 |
| **Media** | 251 - 1,000 | $27,250 - $108,570 |
| **Grave** | 1,001 - 2,500 | $108,678 - $271,425 |
| **Muy Grave** | 2,501 - 5,000 | $271,533 - $542,850 |

**Nota**: Las multas se calculan con **VUMA** (Unidad de Medida y Actualización para la STPS), no con UMA regular.

### UMA vs. VUMA 2026

| Concepto | UMA (Regular) | VUMA (STPS) |
|----------|---------------|-------------|
| **Valor diario 2026** | $108.57 MXN | $117.31 MXN |
| **Uso principal** | IMSS, INFONAVIT, créditos | Multas STPS |
| **Actualización** | Anual (febrero) | Anual (febrero) |
| **Fundamento** | CFF Art. 18-A | LFT Art. 994 |

**Cálculo de actualización VUMA:**
```
VUMA_2026 = VUMA_2025 × (INPC_diciembre_2025 / INPC_diciembre_2024)
VUMA_2026 = $106.19 × (132.573 / 120.282) = $117.31 MXN
```

## Cálculo de Multas STPS

### Funciones Python para Cálculo

```python
"""
Módulo: calculador_multas_stps.py
Propósito: Calcular multas de la STPS en UMAs/VUMAs y pesos mexicanos
Versión: 1.0
Fecha: 2026-03-10
"""

from dataclasses import dataclass
from typing import Dict, List, Optional
from decimal import Decimal
from enum import Enum


class TipoInfraccion(Enum):
    """Tipos de infracción según LFT Art. 994."""
    LEVE = "leve"
    MEDIA = "media"
    GRAVE = "grave"
    MUY_GRAVE = "muy_grave"


@dataclass
class RangoMulta:
    """Representa un rango de multa en UMAs."""
    tipo: TipoInfraccion
    min_umas: int
    max_umas: int
    descripcion: str


class CalculadorMultasSTPS:
    """
    Calcula multas de la STPS basadas en UMAs/VUMAs.
    """
    
    # Valores 2026
    UMA_DIARIA = Decimal('108.57')  # Para IMSS, INFONAVIT
    VUMA_DIARIA = Decimal('117.31')  # Para multas STPS
    
    # Catálogo de infracciones
    INFRACCIONES = {
        'NOM-001': [
            RangoMulta(TipoInfraccion.GRAVE, 1000, 2500, 
                      'Sin dictamen de protección civil'),
            RangoMulta(TipoInfraccion.MEDIA, 250, 500,
                      'Áreas obstruidas o sin señalización'),
        ],
        'NOM-002': [
            RangoMulta(TipoInfraccion.MEDIA, 500, 1000,
                      'Extintores sin vigencia o mantenimiento'),
            RangoMulta(TipoInfraccion.MEDIA, 250, 500,
                      'Sin simulacros de evacuación'),
            RangoMulta(TipoInfraccion.LEVE, 100, 250,
                      'Sin capacitación de brigadistas'),
        ],
        'NOM-017': [
            RangoMulta(TipoInfraccion.GRAVE, 1000, 2500,
                      'Sin entrega de EPP'),
            RangoMulta(TipoInfraccion.MEDIA, 250, 500,
                      'Sin registro de entrega de EPP'),
        ],
        'NOM-019': [
            RangoMulta(TipoInfraccion.GRAVE, 1000, 2500,
                      'Sin comisión de seguridad constituida'),
            RangoMulta(TipoInfraccion.LEVE, 250, 500,
                      'Sin reuniones mensuales de comisión'),
            RangoMulta(TipoInfraccion.MEDIA, 500, 1000,
                      'Sin recorridos de inspección'),
        ],
        'NOM-035': [
            RangoMulta(TipoInfraccion.GRAVE, 1000, 2500,
                      'Sin evaluación de riesgos psicosociales'),
            RangoMulta(TipoInfraccion.MEDIA, 500, 1000,
                      'Sin capacitación en riesgos psicosociales'),
            RangoMulta(TipoInfraccion.LEVE, 250, 500,
                      'Sin política de prevención documentada'),
        ],
        'NOM-036': [
            RangoMulta(TipoInfraccion.MEDIA, 500, 1000,
                      'Sin evaluación ergonómica'),
            RangoMulta(TipoInfraccion.LEVE, 250, 500,
                      'Sin capacitación en técnicas de levantamiento'),
        ]
    }
    
    def calcular_multa(self, nom: str, infraccion: str,
                       gravedad: TipoInfraccion) -> Dict:
        """
        Calcula multa para una infracción específica.
        
        Args:
            nom: Código de la NOM (ej. 'NOM-035')
            infraccion: Descripción de la infracción
            gravedad: Tipo de infracción
        
        Returns:
            Diccionario con detalles de la multa
        """
        # Buscar rango de multa
        rango = None
        for r in self.INFRACCIONES.get(nom, []):
            if r.descripcion.lower() in infraccion.lower():
                rango = r
                break
        
        if not rango:
            # Rango default por gravedad
            rangos_por_gravedad = {
                TipoInfraccion.LEVE: (50, 250),
                TipoInfraccion.MEDIA: (251, 1000),
                TipoInfraccion.GRAVE: (1001, 2500),
                TipoInfraccion.MUY_GRAVE: (2501, 5000)
            }
            min_umas, max_umas = rangos_por_gravedad[gravedad]
            rango = RangoMulta(gravedad, min_umas, max_umas, infraccion)
        
        # Calcular montos
        multa_min_vumas = rango.min_umas * self.VUMA_DIARIA
        multa_max_vumas = rango.max_umas * self.VUMA_DIARIA
        
        multa_min_usd = multa_min_vumas / Decimal('18.50')  # Tipo de cambio aprox
        multa_max_usd = multa_max_vumas / Decimal('18.50')
        
        return {
            'nom': nom,
            'infraccion': infraccion,
            'gravedad': gravedad.value,
            'multa_vumas': {
                'min': rango.min_umas,
                'max': rango.max_umas,
                'monto_min_mx': f'${multa_min_vumas:,.2f} MXN',
                'monto_max_mx': f'${multa_max_vumas:,.2f} MXN'
            },
            'multa_usd_aprox': {
                'min': f'${multa_min_usd:,.2f} USD',
                'max': f'${multa_max_usd:,.2f} USD'
            }
        }
    
    def calcular_multa_multiple(self, infracciones: List[Dict]) -> Dict:
        """
        Calcula multa total por múltiples infracciones.
        
        Args:
            infracciones: Lista de infracciones [{'nom': 'NOM-035', 'descripcion': '...', 'gravedad': 'grave'}, ...]
        
        Returns:
            Diccionario con multa total
        """
        total_vumas_min = 0
        total_vumas_max = 0
        detalles = []
        
        for infraccion in infracciones:
            resultado = self.calcular_multa(
                nom=infraccion['nom'],
                infraccion=infraccion['descripcion'],
                gravedad=TipoInfraccion(infraccion['gravedad'])
            )
            detalles.append(resultado)
            total_vumas_min += resultado['multa_vumas']['min']
            total_vumas_max += resultado['multa_vumas']['max']
        
        total_mx_min = total_vumas_min * self.VUMA_DIARIA
        total_mx_max = total_vumas_max * self.VUMA_DIARIA
        
        return {
            'total_infracciones': len(infracciones),
            'total_vumas': {
                'min': total_vumas_min,
                'max': total_vumas_max
            },
            'total_mx': {
                'min': f'${total_mx_min:,.2f} MXN',
                'max': f'${total_mx_max:,.2f} MXN'
            },
            'total_usd_aprox': {
                'min': f'${total_mx_min / Decimal("18.50"):,.2f} USD',
                'max': f'${total_mx_max / Decimal("18.50"):,.2f} USD'
            },
            'desglose': detalles
        }


# Ejemplo de uso
if __name__ == "__main__":
    calculador = CalculadorMultasSTPS()
    
    # Ejemplo 1: Multa individual
    multa_nom035 = calculador.calcular_multa(
        nom='NOM-035',
        infraccion='Sin evaluación de riesgos psicosociales',
        gravedad=TipoInfraccion.GRAVE
    )
    
    print("=== Multa Individual ===")
    print(f"NOM: {multa_nom035['nom']}")
    print(f"Infracción: {multa_nom035['infraccion']}")
    print(f"Gravedad: {multa_nom035['gravedad']}")
    print(f"Multa: {multa_nom035['multa_vumas']['monto_min_mx']} - {multa_nom035['multa_vumas']['monto_max_mx']}")
    print()
    
    # Ejemplo 2: Múltiples infracciones
    infracciones = [
        {'nom': 'NOM-035', 'descripcion': 'Sin evaluación de riesgos', 'gravedad': 'grave'},
        {'nom': 'NOM-019', 'descripcion': 'Sin comisión de seguridad', 'gravedad': 'grave'},
        {'nom': 'NOM-002', 'descripcion': 'Extintores sin vigencia', 'gravedad': 'media'},
        {'nom': 'NOM-017', 'descripcion': 'Sin registro de EPP', 'gravedad': 'media'}
    ]
    
    multa_total = calculador.calcular_multa_multiple(infracciones)
    
    print("=== Multa Total por Múltiples Infracciones ===")
    print(f"Total infracciones: {multa_total['total_infracciones']}")
    print(f"Total VUMAs: {multa_total['total_vumas']['min']} - {multa_total['total_vumas']['max']}")
    print(f"Total MXN: {multa_total['total_mx']['min']} - {multa_total['total_mx']['max']}")
    print(f"Total USD (aprox): {multa_total['total_usd_aprox']['min']} - {multa_total['total_usd_aprox']['max']}")
```

        if not self.checklist_completo:
            self.generar_checklist_completo()
        
        resultados = {}
        total_documentos = 0
        total_cumplidos = 0
        
        for nom, datos in self.checklist_completo.items():
            if not datos['aplicable']:
                continue
            
            documentos = datos['documentos']
            requeridos = [d for d in documentos if d['requerido']]
            cumplidos = [d for d in requeridos if d['cumplido']]
            
            porcentaje = (len(cumplidos) / len(requeridos) * 100) if requeridos else 0
            
            resultados[nom] = {
                'titulo': datos['titulo'],
                'documentos_requeridos': len(requeridos),
                'documentos_cumplidos': len(cumplidos),
                'porcentaje': f'{porcentaje:.1f}%',
                'estatus': '✅ Cumplido' if porcentaje == 100 else '⚠️ Pendiente' if porcentaje >= 50 else '❌ Crítico'
            }
            
            total_documentos += len(requeridos)
            total_cumplidos += len(cumplidos)
        
        porcentaje_total = (total_cumplidos / total_documentos * 100) if total_documentos else 0
        
        resultados['TOTAL'] = {
            'documentos_requeridos': total_documentos,
            'documentos_cumplidos': total_cumplidos,
            'porcentaje': f'{porcentaje_total:.1f}%',
            'estatus': '✅ Cumplido' if porcentaje_total == 100 else '⚠️ Pendiente' if porcentaje_total >= 50 else '❌ Crítico'
        }
        
        return resultados
