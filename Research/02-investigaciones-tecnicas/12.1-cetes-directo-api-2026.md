## Instrumentos Disponibles 2026

### 1. CETES (Certificados de la Tesorería)

**Descripción**: Instrumento de deuda de corto plazo, colocado bajo la modalidad de descuento.

| Característica | Detalle |
|----------------|---------|
| **Plazos** | 28, 91, 182, 364 días |
| **Tasa actual (28 días)** | 9.75% anual |
| **Tasa actual (91 días)** | 9.85% anual |
| **Tasa actual (182 días)** | 9.95% anual |
| **Tasa actual (364 días)** | 10.05% anual |
| **Monto mínimo** | $100 MXN |
| **Monto máximo** | $20,000,000 MXN (personas físicas) |
| **Pago** | Al vencimiento (interés + capital) |
| **Retención ISR** | 0.90% (2026) |
| **Frecuencia** | Subastas semanales (martes) |

**Fórmula de rendimiento:**
```
Precio = Valor Nominal / (1 + (Tasa × Días / 360))
Rendimiento = Valor Nominal - Precio
```

**Ejemplo práctico:**
```
Inversión: $100,000 MXN
Plazo: 28 días
Tasa: 9.75% anual

Precio = 100,000 / (1 + (0.0975 × 28 / 360))
Precio = 100,000 / (1 + 0.007583)
Precio = 100,000 / 1.007583
Precio = $99,247.52 MXN

Rendimiento = 100,000 - 99,247.52 = $752.48 MXN
Rendimiento neto (después ISR 0.90%) = $752.48 × (1 - 0.009) = $745.71 MXN
```

### 2. Bondes D (Bonos de Desarrollo)

**Descripción**: Instrumento de deuda que paga intereses mensualmente a tasa fija.

| Característica | Detalle |
|----------------|---------|
| **Plazos** | 28, 91, 182, 365 días |
| **Tasa actual** | 9.50% anual |
| **Monto mínimo** | $100 MXN |
| **Pago de intereses** | Mensual |
| **Pago de capital** | Al vencimiento |
| **Retención ISR** | 0.90% sobre intereses |

**Ventaja**: Flujo de efectivo mensual (ideal para tesorería que requiere liquidez)

**Ejemplo:**
```
Inversión: $500,000 MXN
Plazo: 365 días
Tasa: 9.50% anual

Interés mensual = 500,000 × (0.095 / 12) = $3,958.33 MXN
Interés neto (después ISR) = $3,958.33 × (1 - 0.009) = $3,922.70 MXN

Flujo anual: $3,922.70 × 12 = $47,072.40 MXN
Capital al vencimiento: $500,000 MXN
```

### 3. Udibonos (Unidades de Inversión)

**Descripción**: Instrumento de deuda protegido contra la inflación, denominado en UDIS.

| Característica | Detalle |
|----------------|---------|
| **Plazos** | 3, 5, 10, 20, 30 años |
| **Tasa real** | 4.5-6.0% anual (sobre inflación) |
| **Monto mínimo** | $100 MXN (en UDIS) |
| **Protección** | Inflación (INPC) |
| **Pago de intereses** | Semestral |
| **Retención ISR** | 0.90% sobre intereses |

**Ventaja**: Protección contra inflación (ideal para largo plazo)

**Ejemplo:**
```
Inversión: $1,000,000 MXN
Plazo: 5 años
Tasa real: 5.0% anual
Inflación promedio: 4.0% anual

Rendimiento nominal ≈ Tasa real + Inflación
Rendimiento nominal ≈ 5.0% + 4.0% = 9.0% anual

Valor al vencimiento (con inflación 4%):
VF = 1,000,000 × (1.09)^5 = $1,538,624 MXN
```

### 4. BPAS (Bonos de Protección al Ahorro)

**Descripción**: Instrumento con tasa mínima garantizada más participación en alzas de tasas.

| Característica | Detalle |
|----------------|---------|
| **Plazo** | 5 años |
| **Tasa mínima** | 4.0% anual (garantizada) |
| **Tasa variable** | TIIE 28 días - 4% (si es positiva) |
| **Monto mínimo** | $100 MXN |
| **Pago** | Al vencimiento |
| **Retención ISR** | 0.90% |

**Ventaja**: Piso garantizado + upside en tasas altas

### Autenticación

#### OAuth2 Flow

```python
import requests
from typing import Optional, Dict

class CetesDirectoClient:
    """
    Cliente para API de CETES Directo.
    """
    
    BASE_URL = "https://api.cetesdirecto.com"
    SANDBOX_URL = "https://sandbox-api.cetesdirecto.com"
    
    def __init__(self, client_id: str, client_secret: str, 
                 sandbox: bool = False):
        """
        Inicializa el cliente.
        
        Args:
            client_id: Client ID de CETES Directo
            client_secret: Client Secret
            sandbox: Si True, usa ambiente sandbox
        """
        self.client_id = client_id
        self.client_secret = client_secret
        self.base_url = self.SANDBOX_URL if sandbox else self.BASE_URL
        self.access_token: Optional[str] = None
        self.session = requests.Session()
    
    def autenticar(self) -> bool:
        """
        Obtiene token de acceso OAuth2.
        
        Returns:
            True si la autenticación fue exitosa
        """
        url = f"{self.base_url}/oauth/token"
        
        data = {
            'grant_type': 'client_credentials',
            'client_id': self.client_id,
            'client_secret': self.client_secret,
            'scope': 'read write'
        }
        
        try:
            response = self.session.post(url, data=data, timeout=30)
            response.raise_for_status()
            
            token_data = response.json()
            self.access_token = token_data['access_token']
            
            # Agregar token a headers
            self.session.headers.update({
                'Authorization': f'Bearer {self.access_token}'
            })
            
            return True
            
        except requests.RequestException as e:
            print(f"Error de autenticación: {e}")
            return False
    
    def obtener_instrumentos(self) -> Dict:
        """
        Obtiene catálogo de instrumentos disponibles.
        
        Returns:
            Diccionario con instrumentos
        """
        if not self.access_token:
            if not self.autenticar():
                return {}
        
        url = f"{self.base_url}/instruments"
        
        try:
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            return response.json()
            
        except requests.RequestException as e:
            print(f"Error al obtener instrumentos: {e}")
            return {}
    
    def obtener_tasas(self) -> Dict:
        """
        Obtiene tasas actuales de instrumentos.
        
        Returns:
            Diccionario con tasas por instrumento
        """
        if not self.access_token:
            if not self.autenticar():
                return {}
        
        url = f"{self.base_url}/rates"
        
        try:
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            return response.json()
            
        except requests.RequestException as e:
            print(f"Error al obtener tasas: {e}")
            return {}
    
    def crear_orden(self, instrumento: str, monto: float,
                    plazo: int) -> Dict:
        """
        Crea orden de inversión.
        
        Args:
            instrumento: Código del instrumento (CETES, BONDES_D, etc.)
            monto: Monto a invertir en MXN
            plazo: Plazo en días
        
        Returns:
            Diccionario con resultado de orden
        """
        if not self.access_token:
            if not self.autenticar():
                return {}
        
        url = f"{self.base_url}/orders"
        
        data = {
            'instrument': instrumento,
            'amount': monto,
            'term': plazo,
            'order_type': 'market'
        }
        
        try:
            response = self.session.post(url, json=data, timeout=30)
            response.raise_for_status()
            return response.json()
            
        except requests.RequestException as e:
            print(f"Error al crear orden: {e}")
            return {'error': str(e)}
    
    def obtener_portafolio(self) -> Dict:
        """
        Obtiene portafolio actual del inversionista.
        
        Returns:
            Diccionario con portafolio
        """
        if not self.access_token:
            if not self.autenticar():
                return {}
        
        url = f"{self.base_url}/portfolio"
        
        try:
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            return response.json()
            
        except requests.RequestException as e:
            print(f"Error al obtener portafolio: {e}")
            return {}
    
    def obtener_transacciones(self, fecha_inicio: str,
                               fecha_fin: str) -> Dict:
        """
        Obtiene historial de transacciones.
        
        Args:
            fecha_inicio: Fecha inicial (YYYY-MM-DD)
            fecha_fin: Fecha final (YYYY-MM-DD)
        
        Returns:
            Diccionario con transacciones
        """
        if not self.access_token:
            if not self.autenticar():
                return {}
        
        url = f"{self.base_url}/transactions"
        params = {
            'start_date': fecha_inicio,
            'end_date': fecha_fin
        }
        
        try:
            response = self.session.get(url, params=params, timeout=30)
            response.raise_for_status()
            return response.json()
            
        except requests.RequestException as e:
            print(f"Error al obtener transacciones: {e}")
            return {}


# Ejemplo de uso

        print(f"Portafolio: {portafolio}")
```

## Consideraciones Fiscales 2026

### Retención de ISR

**LISR Art. 134**: Los intereses obtenidos de CETES están sujetos a retención de ISR.

| Concepto | Tasa 2026 |
|----------|-----------|
| **Retención ISR** | 0.90% sobre rendimiento |
| **Base de retención** | Intereses/devengamiento |
| **Momento** | Al pago o vencimiento |
| **Carácter** | Definitivo (personas físicas) |

**Ejemplo de cálculo:**
```python
def calcular_retencion_isr(rendimiento_bruto: float, 
                            tasa_isr: float = 0.009) -> float:
    """
    Calcula retención de ISR sobre rendimiento de CETES.
    
    Args:
        rendimiento_bruto: Rendimiento antes de impuestos
        tasa_isr: Tasa de ISR (default 0.90% para 2026)
    
    Returns:
        Rendimiento neto después de ISR
    """
    retencion = rendimiento_bruto * tasa_isr
    rendimiento_neto = rendimiento_bruto - retencion
    
    return rendimiento_neto


# Ejemplo
rendimiento_bruto = 1000.00  # $1,000 MXN
rendimiento_neto = calcular_retencion_isr(rendimiento_bruto)
print(f"Rendimiento bruto: ${rendimiento_bruto:.2f}")
print(f"Retención ISR (0.90%): ${rendimiento_bruto * 0.009:.2f}")
print(f"Rendimiento neto: ${rendimiento_neto:.2f}")
```

### Declaración Anual

**Personas Físicas:**
- **Intereses acumulables**: Sí (como ingresos de capital)
- **Retención definitiva**: Sí (0.90% es definitivo, no se ajusta en anual)
- **Declaración informativa**: No requerida (retención es definitiva)

**Personas Morales:**
- **Intereses acumulables**: Sí (como ingresos financieros)
- **Retención acreditable**: Sí (contra ISR propio)
- **Declaración mensual**: Incluir en ingresos acumulables

### DIOT (Declaración Informativa de Operaciones con Terceros)

- **CETES Directo**: No requiere reporte en DIOT (gobierno federal)
- **Intereses percibidos**: No son pagos a terceros

## Estrategias de Inversión

### 1. Escalera de CETES

**Descripción**: Invertir mensualmente en CETES a diferentes plazos para mantener liquidez constante.

**Ejemplo con $600,000 MXN:**
```python
class EstrategiaEscaleraCETES:
    """
    Implementa estrategia de escalera de CETES.
    """
    
    def __init__(self, capital_total: float,
                 num_tramos: int = 4):
        """
        Inicializa la estrategia.
        
        Args:
            capital_total: Capital total a invertir
            num_tramos: Número de tramos (default 4)
        """
        self.capital_total = capital_total
        self.num_tramos = num_tramos
        self.capital_por_tramo = capital_total / num_tramos
        self.plazos = [28, 91, 182, 364]  # Días
    
    def distribuir_capital(self) -> list:
        """
        Distribuye capital en tramos.
        
        Returns:
            Lista de inversiones por tramo
        """
        inversiones = []
        
        for i, plazo in enumerate(self.plazos[:self.num_tramos]):
            inversiones.append({
                'tramo': i + 1,
                'plazo_dias': plazo,
                'monto': self.capital_por_tramo,
                'vencimiento': f'+{plazo} días'
            })
        
        return inversiones
    
    def proyectar_rendimientos(self, tasas: dict) -> dict:
        """
        Proyecta rendimientos anuales.
        
        Args:
            tasas: Diccionario con tasas por plazo
        
        Returns:
            Diccionario con proyecciones
        """
        proyeccion = {
            'rendimiento_anual_bruto': 0,
            'rendimiento_anual_neto': 0,
            'vencimientos_mensuales': []
        }
        
        for inversion in self.distribuir_capital():
            plazo = inversion['plazo_dias']
            monto = inversion['monto']
            tasa = tasas.get(plazo, 0.0975)
            
            # Rendimiento por ciclo
            rendimiento_ciclo = monto * (tasa * plazo / 360)
            
            # Ciclos por año
            ciclos_por_anio = 365 / plazo
            
            # Rendimiento anual
            rendimiento_anual = rendimiento_ciclo * ciclos_por_anio
            rendimiento_neto = rendimiento_anual * (1 - 0.009)
            
            proyeccion['rendimiento_anual_bruto'] += rendimiento_anual
            proyeccion['rendimiento_anual_neto'] += rendimiento_neto
            
            # Vencimientos mensuales (aproximado)
            vencimientos_mes = (monto / plazo) * 30
            proyeccion['vencimientos_mensuales'].append(vencimientos_mes)
        
        return proyeccion


# Ejemplo de uso

        capital_total=600000,
        num_tramos=4
    )

    print("=== Estrategia Escalera de CETES ===")
    print(f"Capital total: ${estrategia.capital_total:,.2f} MXN")
    print(f"Número de tramos: {estrategia.num_tramos}")
    print()
    
    for inversion in distribucion:
        print(f"Tramo {inversion['tramo']}:")

        print(f"  Monto: ${inversion['monto']:,.2f} MXN")
        print(f"  Vencimiento: {inversion['vencimiento']}")
        print()
    
    # Proyectar rendimientos
    tasas = {
        28: 0.0975,
        91: 0.0985,
        182: 0.0995,
        364: 0.1005
    }
    
    proyeccion = estrategia.proyectar_rendimientos(tasas)

    print(f"Vencimiento mensual promedio: ${sum(proyeccion['vencimientos_mensuales'])/len(proyeccion['vencimientos_mensuales']):,.2f} MXN")
```

### 2. Reinversión Automática

**Descripción**: Configurar reinversión automática de capital + intereses al vencimiento.

**Configuración:**
```python
def configurar_reinversion_automatica(client: CetesDirectoClient,
                                       instrumento: str = 'CETES',
                                       plazo_reinversion: int = 28) -> bool:
    """
    Configura reinversión automática al vencimiento.
    
    Args:
        client: Cliente de CETES Directo
        instrumento: Instrumento para reinversión
        plazo_reinversion: Plazo para reinversión
    
    Returns:
        True si la configuración fue exitosa
    """
    # Nota: CETES Directo actualmente no soporta reinversión automática vía API
    # Esta es una implementación simulada
    
    portafolio = client.obtener_portafolio()
    
    for inversion in portafolio.get('investments', []):
        if inversion['status'] == 'active':
            # Programar reinversión
            orden_reinversion = {
                'instrument': instrumento,
                'amount': inversion['maturity_value'],
                'term': plazo_reinversion,
                'auto_reinvest': True,
                'source_investment_id': inversion['id']
            }
            
            # Crear orden condicional (se ejecuta al vencimiento)
            resultado = client.crear_orden(**orden_reinversion)
            
            if 'error' not in resultado:
                print(f"✅ Reinversión configurada para {inversion['id']}")
            else:
                print(f"❌ Error al configurar reinversión: {resultado['error']}")
    
    return True
```

### 3. Comparador de Instrumentos

```python
class ComparadorInstrumentos:
    """
    Compara rendimientos de diferentes instrumentos.
    """
    
    def __init__(self, monto: float, plazo_dias: int):
        """
        Inicializa el comparador.
        
        Args:
            monto: Monto a invertir
            plazo_dias: Plazo de inversión en días
        """
        self.monto = monto
        self.plazo_dias = plazo_dias
    
    def comparar(self, tasas: dict) -> pd.DataFrame:
        """
        Compara instrumentos con diferentes tasas.
        
        Args:
            tasas: Diccionario {instrumento: tasa_anual}
        
        Returns:
            DataFrame con comparación
        """
        import pandas as pd
        
        resultados = []
        
        for instrumento, tasa in tasas.items():
            # Rendimiento bruto
            rendimiento_bruto = self.monto * (tasa * self.plazo_dias / 360)
            
            # ISR
            isr = rendimiento_bruto * 0.009
            
            # Rendimiento neto
            rendimiento_neto = rendimiento_bruto - isr
            
            # Rendimiento anualizado
            rendimiento_anualizado = ((1 + rendimiento_neto / self.monto) ** (365 / self.plazo_dias) - 1) * 100
            
            resultados.append({
                'Instrumento': instrumento,
                'Tasa Anual': f'{tasa * 100:.2f}%',
                'Rendimiento Bruto': f'${rendimiento_bruto:,.2f}',
                'ISR (0.90%)': f'${isr:,.2f}',
                'Rendimiento Neto': f'${rendimiento_neto:,.2f}',
```

## Generador de Reporte de Inversión

```python
class GeneradorReporteInversion:
    """
    Genera reporte de rendimientos y retenciones.
    """
    
    def __init__(self, portafolio: dict):
        """
        Inicializa el generador.
        
        Args:
            portafolio: Diccionario con portafolio de CETES Directo
        """
        self.portafolio = portafolio
    
    def generar_reporte_mensual(self, mes: int, anio: int) -> str:
        """
        Genera reporte mensual de rendimientos.
        
        Args:
            mes: Mes (1-12)
            anio: Año
        
        Returns:
            Reporte en formato texto
        """
        reporte = f"""
================================================================================
                    REPORTE DE INVERSIONES - CETES DIRECTO
================================================================================
Período: {mes:02d}/{anio}
================================================================================

RESUMEN DEL PORTAFOLIO
----------------------
"""
        
        # Resumen
        total_invertido = sum(inv['amount'] for inv in self.portafolio.get('investments', []))
        total_rendimientos = sum(inv.get('accrued_interest', 0) for inv in self.portafolio.get('investments', []))
        total_isr = total_rendimientos * 0.009
        
        reporte += f"""
Total Invertido: ${total_invertido:,.2f} MXN
Rendimientos Acumulados: ${total_rendimientos:,.2f} MXN
ISR Retenido (0.90%): ${total_isr:,.2f} MXN
Rendimientos Netos: ${total_rendimientos - total_isr:,.2f} MXN

INVERSIONES ACTIVAS
-------------------
"""
        
        for inversion in self.portafolio.get('investments', []):
            if inversion.get('status') == 'active':
                reporte += f"""
Instrumento: {inversion['instrument']}
Monto: ${inversion['amount']:,.2f} MXN
Tasa: {inversion.get('rate', 0) * 100:.2f}% anual
Fecha Inversión: {inversion['purchase_date']}
Fecha Vencimiento: {inversion['maturity_date']}
Días Restantes: {inversion.get('days_to_maturity', 0)}
Rendimiento Acumulado: ${inversion.get('accrued_interest', 0):,.2f} MXN

"""
        
        reporte += """
================================================================================
"""
        
        return reporte
```

### Anexo C: Fórmulas Financieras

**CETES (Descuento):**
```
Precio = Valor Nominal / (1 + (Tasa × Días / 360))
Rendimiento = Valor Nominal - Precio
Tasa Efectiva = (Rendimiento / Precio) × (360 / Días)
```

**Bondes D (Interés Simple):**
```
Interés Mensual = Capital × (Tasa / 12)
Interés Total = Interés Mensual × Meses
```

**Udibonos (Inflación + Tasa Real):**
```
Valor UDI Actual = Valor UDI Inicial × (INPC Actual / INPC Inicial)
Rendimiento Nominal ≈ Tasa Real + Inflación
```
