## 1. Descripción del Módulo

### 1.1 Propósito

Este módulo proporciona automatización robótica para la presentación de declaraciones mensuales (DM-1, DM-2, DIM) ante el SAT mediante browser automation con Playwright/Selenium, eliminando la carga manual de archivos XML y descarga de acuses que consume 15-20 minutos por cliente mensualmente.

El sistema automatiza:
- Login en portal SAT con e.firma/contraseña
- Navegación a sección de declaraciones
- Carga de archivos XML generados
- Captura y resolución de captcha
- Descarga de acuses de recepción
- Validación de estatus de presentación

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Login portal SAT | Mensual | 3 min/cliente | 30s | 83% |

### 1.3 Dolor Principal que Resuelve

**Problema central:** Los contadores dedican 15-20 minutos por cliente mensualmente a la presentación manual de declaraciones en el portal SAT, un proceso repetitivo donde errores de carga, captchas fallidos o timeouts del portal generan retrasos y multas por presentación extemporánea (2.07% mensual + actualización).

**Dolores específicos:**
- Portal SAT inestable con timeouts frecuentes (especialmente días 15-17)
- Captcha obligatorio que requiere intervención manual
- Sesiones que expiran sin aviso durante carga de archivos
- Sin API oficial para presentación automatizada
- Riesgo de bloqueo por múltiples intentos fallidos

### 2.4 Consideraciones Legales de Automatización

**Términos de Servicio SAT:**
- El portal SAT no prohíbe explícitamente automation en sus términos públicos
- Sin embargo, el uso de bots puede violar políticas implícitas de uso aceptable
- **Recomendación:** Usar automation solo para cuentas propias del cliente con autorización escrita
- **Riesgo:** Bloqueo temporal de IP por comportamiento sospechoso (mitigar con delays y rate limiting)

### 2.5 Tendencias de Mercado

- **APIs de terceros:** Crecimiento de PACs (Proveedores Autorizados de Certificación) con APIs RESTful
- **Browser automation:** Playwright reemplazando a Selenium por mejor detección de evasión
- **Captcha solving:** Servicios humanos (2Captcha) vs. ML (CapSolver)
- **Compliance:** Mayor escrutinio en protección de credenciales e.firma

### 3.2 Algoritmo: Login en Portal SAT con e.firma

```python
"""
Módulo de autenticación en portal SAT con e.firma/contraseña.

Autor: IDP-App Development Team
Fecha: 10 de marzo de 2026
Versión: 1.0
"""

from playwright.sync_api import sync_playwright, Page, Browser, BrowserContext
from typing import Dict, Optional, Tuple
import base64
import time
from pathlib import Path


class SATLoginAutomation:
    """
    Automatiza el login en el portal del SAT usando e.firma o contraseña.
    
    Soporta:
    - Login con contraseña (CIEC): RFC + contraseña 8 dígitos
    - Login con e.firma: .cer + .key + contraseña
    - Manejo de captcha con 2Captcha/Anti-Captcha
    - Persistencia de sesión con cookies
    
    Ejemplo:
        >>> login = SATLoginAutomation()
        >>> success = login.con_password("XAXX010101000", "micontra123")
        >>> if success:
        ...     print("Login exitoso")
    """
    
    SAT_LOGIN_URL = "https://www.sat.gob.mx/aplicacion/operacion/31064/realiza-tu-tramite-de-inscripcion-al-regimen-fiscal"
    SAT_DECLARACIONES_URL = "https://www.sat.gob.mx/portal/public/tramites/declaraciones-pm"
    
    def __init__(
        self,
        headless: bool = False,
        slow_mo: int = 100,
        timeout: int = 60000
    ):
        """
        Inicializa el automatizador de login.
        
        Args:
            headless: Ejecutar navegador sin interfaz gráfica
            slow_mo: Milisegundos de delay entre acciones (anti-detección)
            timeout: Timeout en ms para operaciones
        """
        self.headless = headless
        self.slow_mo = slow_mo
        self.timeout = timeout
        self.browser: Optional[Browser] = None
        self.context: Optional[BrowserContext] = None
        self.page: Optional[Page] = None
    
    def __enter__(self):
        """Context manager entry."""
        self.start()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        """Context manager exit."""
        self.close()
    
    def start(self):
        """
        Inicia el navegador Playwright.
        
        Configura:
        - User-Agent realista
        - Viewport desktop estándar
        - JavaScript habilitado
        - Cookies habilitadas
        """
        playwright = sync_playwright().start()
        
        # User-Agent realista para evitar detección
        user_agent = (
            "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
            "AppleWebKit/537.36 (KHTML, like Gecko) "
            "Chrome/120.0.0.0 Safari/537.36"
        )
        
        self.browser = playwright.chromium.launch(
            headless=self.headless,
            slow_mo=self.slow_mo,
            args=[
                "--disable-blink-features=AutomationControlled",
                "--disable-dev-shm-usage",
                "--no-sandbox",
                "--disable-setuid-sandbox",
                "--disable-web-security",
                "--disable-features=IsolateOrigins,site-per-process"
            ]
        )
        
        self.context = self.browser.new_context(
            viewport={"width": 1920, "height": 1080},
            user_agent=user_agent,
            locale="es-MX",
            timezone_id="America/Mexico_City",
            permissions=["geolocation"],
            geolocation={"latitude": 19.4326, "longitude": -99.1332}  # CDMX
        )
        
        # Inyectar script para evadir detección de automation
        self.context.add_init_script("""
            Object.defineProperty(navigator, 'webdriver', {
                get: () => undefined
            });
            Object.defineProperty(navigator, 'plugins', {
                get: () => [1, 2, 3, 4, 5]
            });
            Object.defineProperty(navigator, 'languages', {
                get: () => ['es-MX', 'es', 'en']
            });
        """)
        
        self.page = self.context.new_page()
        self.page.set_default_timeout(self.timeout)
    
    def close(self):
        """Cierra el navegador y limpia recursos."""
        if self.browser:
            self.browser.close()
    
    def con_password(
        self,
        rfc: str,
        password: str,
        captcha_token: Optional[str] = None
    ) -> Tuple[bool, str]:
        """
        Realiza login con contraseña (CIEC).
        
        Args:
            rfc: RFC del contribuyente (12-13 caracteres)
            password: Contraseña de 8 dígitos
            captcha_token: Token de captcha resuelto (opcional)
        
        Returns:
            Tuple[bool, str]: (éxito, mensaje)
        
        Ejemplo:
            >>> login = SATLoginAutomation()
            >>> login.start()
            >>> success, msg = login.con_password("XAXX010101000", "12345678")
            >>> print(msg)
            'Login exitoso'
        """
        try:
            # Navegar a página de login
            self.page.goto(self.SAT_LOGIN_URL, wait_until="networkidle")
            
            # Esperar formulario
            self.page.wait_for_selector("#rfc", timeout=10000)
            
            # Llenar RFC
            rfc_input = self.page.locator("#rfc")
            rfc_input.fill(rfc.upper())
            
            # Llenar contraseña
            pwd_input = self.page.locator("#password")
            pwd_input.fill(password)
            
            # Manejar captcha si existe
            captcha_present = self._detectar_captcha()
            if captcha_present:
                if not captcha_token:
                    return False, "Captcha detectado, requiere token"
                self._resolver_captcha(captcha_token)
            
            # Click en entrar
            submit_btn = self.page.locator("button[type='submit']")
            submit_btn.click()
            
            # Esperar redirección
            time.sleep(3)
            
            # Verificar éxito
            if self._verificar_login_exitoso():
                return True, "Login exitoso"
            else:
                return False, "Credenciales inválidas o error en portal"
                
        except Exception as e:
            return False, f"Error en login: {str(e)}"
    
    def con_efirma(
        self,
        rfc: str,
        cer_path: str,
        key_path: str,
        password: str
    ) -> Tuple[bool, str]:
        """
        Realiza login con e.firma (FIEL).
        
        Args:
            rfc: RFC del contribuyente
            cer_path: Path al archivo .cer
            key_path: Path al archivo .key
            password: Contraseña de la e.firma
        
        Returns:
            Tuple[bool, str]: (éxito, mensaje)
        
        Ejemplo:
            >>> login = SATLoginAutomation()
            >>> login.start()
            >>> success, msg = login.con_efirma(
            ...     "XAXX010101000",
            ...     "fiel.cer",
            ...     "fiel.key",
            ...     "mipassword123"
            ... )
        """
        try:
            # Navegar a login con e.firma
            self.page.goto(f"{self.SAT_LOGIN_URL}?tipo=efirma", wait_until="networkidle")
            
            # Esperar selector de archivos
            self.page.wait_for_selector("#archivoCer", timeout=10000)
            
            # Subir archivo .cer
            cer_input = self.page.locator("#archivoCer")
            cer_input.set_input_files(cer_path)
            
            # Subir archivo .key
            key_input = self.page.locator("#archivoKey")
            key_input.set_input_files(key_path)
            
            # Llenar contraseña
            pwd_input = self.page.locator("#passwordFiel")
            pwd_input.fill(password)
            
            # Click en aceptar
            submit_btn = self.page.locator("button[type='submit']")
            submit_btn.click()
            
            # Esperar procesamiento
            time.sleep(5)
            
            # Verificar éxito
            if self._verificar_login_exitoso():
                return True, "Login con e.firma exitoso"
            else:
                return False, "e.firma inválida o expirada"
                
        except Exception as e:
            return False, f"Error en login con e.firma: {str(e)}"
    
    def _detectar_captcha(self) -> bool:
        """
        Detecta si hay captcha en la página.
        
        Returns:
            bool: True si captcha está presente
        """
        try:
            # Buscar iframe de reCAPTCHA
            recaptcha = self.page.locator(
                "iframe[src*='recaptcha']"
            )
            return recaptcha.count() > 0
        except:
            return False
    
    def _resolver_captcha(self, token: str):
        """
        Inyecta token de captcha resuelto.
        
        Args:
            token: Token de 2Captcha/Anti-Captcha
        """
        # Inyectar token en campo oculto
        self.page.evaluate(f"""
            document.querySelector('#g-recaptcha-response').value = '{token}';
        """)
    
    def _verificar_login_exitoso(self) -> bool:
        """
        Verifica si el login fue exitoso.
        
        Returns:
            bool: True si login exitoso
        """
        try:
            # Buscar indicador de sesión activa
            welcome = self.page.locator("text=Bienvenido")
            return welcome.count() > 0
        except:
            return False
    
    def guardar_sesion(self, path: str):
        """
        Guarda cookies de sesión para reutilización.
        
        Args:
            path: Path donde guardar cookies JSON
        """
        if self.context:
            cookies = self.context.cookies()
            Path(path).write_text(json.dumps(cookies, indent=2))
    
    def cargar_sesion(self, path: str):
        """
        Carga cookies de sesión previamente guardadas.
        
        Args:
            path: Path de cookies JSON a cargar
        """
        if self.context and Path(path).exists():
            cookies = json.loads(Path(path).read_text())
            self.context.add_cookies(cookies)
```

"""
Módulo de carga de declaraciones mensuales (DM-1, DM-2, DIM) al SAT.

Autor: IDP-App Development Team
Fecha: 10 de marzo de 2026
Versión: 1.0
"""

from playwright.sync_api import Page, expect
from typing import Dict, List, Optional, Tuple
import time
from pathlib import Path


class SATDeclaracionesLoader:
    """
    Automatiza la carga de declaraciones mensuales al portal SAT.
    
    Soporta:
    - DM-1 (ISR mensual)
    - DM-2 (IVA mensual)
    - DIM (Declaración Informativa Múltiple)
    - Validación de acuse de recepción
    
    Ejemplo:
        >>> loader = SATDeclaracionesLoader(page)
        >>> success = loader.cargar_dm1("DM1_XAXX010101000_2026-03.xml")
    """
    
    def __init__(self, page: Page, timeout: int = 120000):
        """
        Inicializa el loader de declaraciones.
        
        Args:
            page: Instancia de Page de Playwright
            timeout: Timeout en ms para operaciones de carga
        """
        self.page = page
        self.timeout = timeout
        self.page.set_default_timeout(timeout)
    
    def navegar_a_declaraciones(self) -> Tuple[bool, str]:
        """
        Navega a la sección de declaraciones del portal SAT.
        
        Returns:
            Tuple[bool, str]: (éxito, mensaje)
        """
        try:
            # URL directa a declaraciones
            self.page.goto(
                "https://www.sat.gob.mx/portal/public/tramites/declaraciones-pm",
                wait_until="networkidle"
            )
            
            # Esperar que cargue el menú
            self.page.wait_for_selector(
                "text=Declaraciones",
                timeout=10000
            )
            
            return True, "Navegación exitosa a declaraciones"
            
        except Exception as e:
            return False, f"Error navegando: {str(e)}"
    
    def cargar_dm1(
        self,
        xml_path: str,
        periodo: str,
        rfc: str
    ) -> Tuple[bool, str, Optional[str]]:
        """
        Carga declaración mensual de ISR (DM-1).
        
        Args:
            xml_path: Path al archivo XML DM-1
            periodo: Periodo en formato YYYY-MM
            rfc: RFC del contribuyente
        
        Returns:
            Tuple[bool, str, Optional[str]]: (éxito, mensaje, folio_acuse)
        
        Ejemplo:
            >>> loader = SATDeclaracionesLoader(page)
            >>> success, msg, folio = loader.cargar_dm1(
            ...     "DM1_XAXX010101000_2026-03.xml",
            ...     "2026-03",
            ...     "XAXX010101000"
            ... )
        """
        try:
            # Validar que el archivo existe
            if not Path(xml_path).exists():
                return False, f"Archivo no encontrado: {xml_path}", None
            
            # Navegar a sección DM-1
            self.page.click("text=ISR Mensual")
            self.page.wait_for_timeout(2000)
            
            # Seleccionar periodo
            self.page.select_option(
                "select#periodo",
                periodo
            )
            
            # Subir archivo XML
            file_input = self.page.locator("input[type='file']")
            file_input.set_input_files(xml_path)
            
            # Esperar validación del SAT
            self.page.wait_for_timeout(5000)
            
            # Verificar que el archivo se cargó correctamente
            validacion = self.page.locator("text=Archivo válido")
            if validacion.count() == 0:
                return False, "El archivo XML no es válido", None
            
            # Click en enviar declaración
            submit_btn = self.page.locator("button[type='submit']")
            submit_btn.click()
            
            # Esperar procesamiento (puede tardar 30-60s)
            self.page.wait_for_timeout(30000)
            
            # Capturar folio de acuse
            folio = self._capturar_folio_acuse()
            
            if folio:
                return True, "Declaración presentada exitosamente", folio
            else:
                return False, "No se pudo capturar el folio", None
                
        except Exception as e:
            return False, f"Error cargando DM-1: {str(e)}", None
    
    def cargar_dm2(
        self,
        xml_path: str,
        periodo: str,
        rfc: str
    ) -> Tuple[bool, str, Optional[str]]:
        """
        Carga declaración mensual de IVA (DM-2).
        
        Args:
            xml_path: Path al archivo XML DM-2
            periodo: Periodo en formato YYYY-MM
            rfc: RFC del contribuyente
        
        Returns:
            Tuple[bool, str, Optional[str]]: (éxito, mensaje, folio_acuse)
        """
        try:
            if not Path(xml_path).exists():
                return False, f"Archivo no encontrado: {xml_path}", None
            
            # Navegar a sección DM-2
            self.page.click("text=IVA Mensual")
            self.page.wait_for_timeout(2000)
            
            # Seleccionar periodo
            self.page.select_option("select#periodo", periodo)
            
            # Subir archivo XML
            file_input = self.page.locator("input[type='file']")
            file_input.set_input_files(xml_path)
            
            # Esperar validación
            self.page.wait_for_timeout(5000)
            
            # Verificar validez
            validacion = self.page.locator("text=Archivo válido")
            if validacion.count() == 0:
                return False, "El archivo XML no es válido", None
            
            # Enviar
            self.page.locator("button[type='submit']").click()
            
            # Esperar procesamiento
            self.page.wait_for_timeout(30000)
            
            # Capturar folio
            folio = self._capturar_folio_acuse()
            
            if folio:
                return True, "Declaración IVA presentada", folio
            else:
                return False, "No se pudo capturar el folio", None
                
        except Exception as e:
            return False, f"Error cargando DM-2: {str(e)}", None
    
    def descargar_acuse(self, folio: str, output_path: str) -> Tuple[bool, str]:
        """
        Descarga el acuse de recepción de una declaración.
        
        Args:
            folio: Folio de la declaración
            output_path: Path donde guardar el acuse
        
        Returns:
            Tuple[bool, str]: (éxito, mensaje)
        """
        try:
            # Navegar a consulta de acuses
            self.page.goto(
                "https://www.sat.gob.mx/portal/public/consultas/acuses",
                wait_until="networkidle"
            )
            
            # Buscar por folio
            search_input = self.page.locator("input#folio")
            search_input.fill(folio)
            
            # Click en buscar
            self.page.locator("button[type='submit']").click()

            self.page.wait_for_timeout(3000)
            
            # Click en descargar
            download_btn = self.page.locator("text=Descargar Acuse")
            
            # Configurar descarga
            with self.page.expect_download() as download_info:
                download_btn.click()
            
            download = download_info.value
            
            # Guardar archivo
            download.save_as(output_path)
            
            return True, f"Acuse guardado en {output_path}"
            
        except Exception as e:
            return False, f"Error descargando acuse: {str(e)}"
    
    def _capturar_folio_acuse(self) -> Optional[str]:
        """
        Captura el folio del acuse de recepción.
        
        Returns:
            Optional[str]: Folio capturado o None
        """
        try:
            # Buscar patrón de folio en pantalla
            folio_text = self.page.locator(
                "text=/Folio:\\s*[A-Z0-9]{20,40}/i"
            ).first
            
            if folio_text.count() > 0:
                texto = folio_text.inner_text()
                # Extraer folio con regex
                import re
                match = re.search(r'[A-Z0-9]{20,40}', texto)
                if match:
                    return match.group(0)
            
            return None
        except:
            return None

import requests

from typing import Optional, Tuple


class TwoCaptchaSolver:
    """
    Integra con el servicio 2Captcha para resolver captchas automáticamente.
    
    Soporta:
    - reCAPTCHA v2
    - reCAPTCHA v3
    - hCaptcha
    - Captcha de imagen tradicional
    
    API: https://2captcha.com/api-docs
    """
    
    API_BASE = "https://2captcha.com"
    
    def __init__(self, api_key: str):
        """
        Inicializa el solver de captcha.
        
        Args:
            api_key: API key de 2Captcha
        
        Ejemplo:
            >>> solver = TwoCaptchaSolver("TU_API_KEY")
        """
        self.api_key = api_key
    
    def resolver_recaptcha_v2(
        self,
        site_key: str,
        page_url: str,
        invisible: bool = False,
        enterprise: bool = False
    ) -> Tuple[bool, Optional[str], str]:
        """
        Resuelve reCAPTCHA v2.
        
        Args:
            site_key: Site key del reCAPTCHA
            page_url: URL de la página donde está el captcha
            invisible: Si es reCAPTCHA invisible
            enterprise: Si es reCAPTCHA Enterprise
        
        Returns:
            Tuple[bool, Optional[str], str]: (éxito, token, mensaje)
        
        Ejemplo:
            >>> solver = TwoCaptchaSolver("api_key")
            >>> success, token, msg = solver.resolver_recaptcha_v2(
            ...     "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_kl-",
            ...     "https://www.sat.gob.mx/"
            ... )
        """
        try:
            # Crear tarea
            create_url = f"{self.API_BASE}/in.php"
            create_params = {
                "key": self.api_key,
                "method": "userrecaptcha",
                "googlekey": site_key,
                "pageurl": page_url,
                "json": 1
            }
            
            if invisible:
                create_params["invisible"] = 1
            if enterprise:
                create_params["enterprise"] = 1
            
            response = requests.post(create_url, data=create_params, timeout=30)
            result = response.json()
            
            if result.get("status") != 1:
                return False, None, f"Error creando tarea: {result.get('request')}"
            
            task_id = result.get("request")
            
            # Esperar solución (polling cada 5s, máximo 120s)
            return self._poll_result(task_id)
            
        except Exception as e:
            return False, None, f"Error: {str(e)}"
    
    def resolver_hcaptcha(
        self,
        site_key: str,
        page_url: str
    ) -> Tuple[bool, Optional[str], str]:
        """
        Resuelve hCaptcha.
        
        Args:
            site_key: Site key de hCaptcha
            page_url: URL de la página
        
        Returns:
            Tuple[bool, Optional[str], str]: (éxito, token, mensaje)
        """
        try:
            create_url = f"{self.API_BASE}/in.php"
            create_params = {
                "key": self.api_key,
                "method": "hcaptcha",
                "sitekey": site_key,
                "pageurl": page_url,
                "json": 1
            }
            
            response = requests.post(create_url, data=create_params, timeout=30)
            result = response.json()
            
            if result.get("status") != 1:
                return False, None, f"Error: {result.get('request')}"
            
            task_id = result.get("request")
            return self._poll_result(task_id)
            
        except Exception as e:
            return False, None, f"Error: {str(e)}"
    
    def _poll_result(
        self,
        task_id: str,
        max_attempts: int = 24,
        delay: int = 5
    ) -> Tuple[bool, Optional[str], str]:
        """
        Hace polling para obtener resultado del captcha.
        
        Args:
            task_id: ID de la tarea
            max_attempts: Máximo número de intentos
            delay: Delay entre intentos en segundos
        
        Returns:
            Tuple[bool, Optional[str], str]: (éxito, token, mensaje)
        """
        result_url = f"{self.API_BASE}/res.php"
        
        for attempt in range(max_attempts):
            try:
                params = {
                    "key": self.api_key,
                    "action": "get",
                    "id": task_id,
                    "json": 1
                }
                
                response = requests.get(result_url, params=params, timeout=30)
                result = response.json()
                
                if result.get("status") == 1:
                    token = result.get("request")
                    return True, token, "Captcha resuelto exitosamente"
                
                if result.get("request") == "CAPCHA_NOT_READY":
                    time.sleep(delay)
                    continue
                
                return False, None, f"Error: {result.get('request')}"
                
            except Exception as e:
                time.sleep(delay)
                continue
        
        return False, None, "Timeout esperando solución del captcha"
    
    def reportar_solucion_incorrecta(self, task_id: str) -> bool:
        """
        Reporta una solución incorrecta para reembolso.
        
        Args:
            task_id: ID de la tarea
        
        Returns:
            bool: True si reporte exitoso
        """
        try:
            report_url = f"{self.API_BASE}/res.php"
            params = {
                "key": self.api_key,
                "action": "reportbad",
                "id": task_id,
                "json": 1
            }
            
            response = requests.get(report_url, params=params, timeout=30)
            result = response.json()
            
            return result.get("status") == 1
            
        except:
            return False

### 3.6 Manejo de Errores y Reintentos

```python
"""
Módulo de manejo de errores y reintentos para automatización SAT.

Autor: IDP-App Development Team
Fecha: 10 de marzo de 2026
Versión: 1.0
"""

import time
import logging
from typing import Callable, Any, Optional, Tuple
from functools import wraps
from playwright.sync_api import TimeoutError as PlaywrightTimeout


class SATErrorHandler:
    """
    Manejador de errores específico para automatización SAT.
    
    Maneja:
    - Timeouts del portal
    - Errores de sesión expirada
    - Bloqueos por captcha
    - Errores de validación XML
    - Rate limiting
    """
    
    # Errores conocidos del SAT
    ERRORES_SAT = {
        "Sesión expirada": "Iniciar sesión nuevamente",
        "Archivo no válido": "Verificar estructura XML",
        "Servicio no disponible": "Reintentar en 5 minutos",
        "Demasiados intentos": "Esperar 15 minutos",
        "RFC inválido": "Verificar RFC del contribuyente",
        "Periodo incorrecto": "Verificar periodo de declaración",
        "Captcha incorrecto": "Resolver captcha nuevamente",
    }
    
    def __init__(self, max_retries: int = 3, base_delay: int = 5):
        """
        Inicializa el manejador de errores.
        
        Args:
            max_retries: Máximo número de reintentos
            base_delay: Delay base entre reintentos en segundos
        """
        self.max_retries = max_retries
        self.base_delay = base_delay
        self.logger = logging.getLogger(__name__)
    
    def retry_on_error(
        self,
        retryable_errors: Optional[list] = None,
        exponential_backoff: bool = True
    ) -> Callable:
        """
        Decorador para reintentar funciones ante errores específicos.
        
        Args:
            retryable_errors: Lista de errores que activan reintento
            exponential_backoff: Usar delay exponencial
        
        Returns:
            Callable: Función decorada
        
        Ejemplo:
            >>> handler = SATErrorHandler()
            >>> @handler.retry_on_error(["Sesión expirada", "Timeout"])
            ... def cargar_declaracion():
            ...     pass
        """
        def decorator(func: Callable) -> Callable:
            @wraps(func)
            def wrapper(*args, **kwargs) -> Any:
                last_error = None
                
                for attempt in range(self.max_retries + 1):
                    try:
                        return func(*args, **kwargs)
                    
                    except Exception as e:
                        last_error = e
                        error_msg = str(e)
                        
                        # Verificar si es error retryable
                        if retryable_errors:
                            is_retryable = any(
                                err in error_msg for err in retryable_errors
                            )
                            if not is_retryable:
                                raise
                        
                        # Calcular delay
                        if exponential_backoff:
                            delay = self.base_delay * (2 ** attempt)
                        else:
                            delay = self.base_delay
                        
                        self.logger.warning(
                            f"Intento {attempt + 1}/{self.max_retries + 1} falló: "
                            f"{error_msg}. Reintentando en {delay}s..."
                        )
                        
                        if attempt < self.max_retries:
                            time.sleep(delay)
                
                # Se agotaron reintentos
                raise last_error
            
            return wrapper
        return decorator
    
    def manejar_error_sat(self, error: Exception) -> Tuple[bool, str]:
        """
        Proporciona solución para error específico del SAT.
        
        Args:
            error: Excepción ocurrida
        
        Returns:
            Tuple[bool, str]: (es_recuperable, solución)
        """
        error_msg = str(error)
        
        for patron, solucion in self.ERRORES_SAT.items():
            if patron.lower() in error_msg.lower():
                return True, solucion
        
        # Error desconocido
        return False, f"Error desconocido: {error_msg}"
    
    def verificar_bloqueo_ip(self, page) -> bool:
        """
        Verifica si la IP ha sido bloqueada por el SAT.
        
        Args:
            page: Instancia de Playwright Page
        
        Returns:
            bool: True si hay bloqueo detectado
        """
        try:
            # Buscar mensajes de bloqueo
            bloqueo_indicators = [
                "acceso denegado",
                "bloqueado",
                "demasiadas solicitudes",
                "intente más tarde",
                "403 Forbidden"
            ]
            
            page_content = page.content().lower()
            
            return any(
                indicator in page_content for indicator in bloqueo_indicators
            )
            
        except:
            return False
```

### 8.3 Ejemplo: Integración con Finkok API

```python
"""
Ejemplo de integración con API de Finkok para timbrado CFDI.

Documentación: https://wiki.finkok.com/
"""

import requests
from typing import Dict, Tuple, Optional
import base64


class FinkokAPI:
    """
    Cliente para API de Finkok.
    
    Ejemplo:
        >>> finkok = FinkokAPI(username="demo", password="demo", sandbox=True)
        >>> success, uuid, msg = finkok.timbrar(xml_content)
    """
    
    SANDBOX_URL = "https://sandbox.finkok.com/timbrar"
    PRODUCTION_URL = "https://services.finkok.com/timbrar"
    
    def __init__(
        self,
        username: str,
        password: str,
        sandbox: bool = True
    ):
        """
        Inicializa cliente Finkok.
        
        Args:
            username: Usuario Finkok
            password: Password/Token Finkok
            sandbox: Usar ambiente de pruebas
        """
        self.username = username
        self.password = password
        self.base_url = self.SANDBOX_URL if sandbox else self.PRODUCTION_URL
    
    def timbrar(self, xml_content: str) -> Tuple[bool, Optional[str], str]:
        """
        Timbra un CFDI ante el SAT.
        
        Args:
            xml_content: Contenido del XML CFDI (string)
        
        Returns:
            Tuple[bool, Optional[str], str]: (éxito, UUID, mensaje)
        
        Ejemplo:
            >>> finkok = FinkokAPI("demo", "demo")
            >>> xml = open("cfdi.xml").read()
            >>> success, uuid, msg = finkok.timbrar(xml)
            >>> if success:
            ...     print(f"UUID: {uuid}")
        """
        try:
            # Codificar XML a base64
            xml_b64 = base64.b64encode(xml_content.encode('utf-8')).decode('utf-8')
            
            # Payload para Finkok
            payload = {
                "usuario": self.username,
                "password": self.password,
                "xml": xml_b64
            }
            
            # Hacer request
            response = requests.post(self.base_url, json=payload, timeout=30)
            result = response.json()
            
            # Verificar respuesta
            if result.get("status") == "success":
                uuid = result.get("uuid")
                xml_timbrado = base64.b64decode(result.get("xml_timbrado")).decode('utf-8')
                return True, uuid, f"Timbrado exitoso: {uuid}"
            else:
                error = result.get("error", "Error desconocido")
                return False, None, f"Error timbrando: {error}"
                
        except Exception as e:
            return False, None, f"Excepción: {str(e)}"
    
    def cancelar(self, uuid: str, rfc: str) -> Tuple[bool, str]:
        """
        Cancela un CFDI timbrado.
        
        Args:
            uuid: UUID del CFDI a cancelar
            rfc: RFC del emisor
        
        Returns:
            Tuple[bool, str]: (éxito, mensaje)
        """
        try:
            payload = {
                "usuario": self.username,
                "password": self.password,
                "uuid": uuid,
                "rfc": rfc
            }
            
            response = requests.post(
                f"{self.base_url}/cancelar",
                json=payload,
                timeout=30
            )
            
            result = response.json()
            
            if result.get("status") == "success":
                return True, "Cancelación exitosa"
            else:
                return False, f"Error cancelando: {result.get('error')}"
                
        except Exception as e:
            return False, f"Excepción: {str(e)}"
```
