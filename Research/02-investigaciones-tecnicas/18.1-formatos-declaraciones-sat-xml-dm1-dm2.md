## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación técnica documenta la estructura XML, campos obligatorios y procesos de generación de los formatos de declaraciones mensuales del SAT: DM-1 (pagos provisionales ISR), DM-2 (IVA trasladado/acreditable), y DIM (Declaración Informativa Múltiple). El objetivo es proporcionar especificaciones técnicas completas para automatizar la generación de estos formatos, eliminando el llenado manual que consume 30 minutos por cliente y es propenso a errores de cálculo que generan multas de $15,000-$30,000 MXN.

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Llenado manual formato DM-1 | Mensual | 10 min/cliente | Automático | 100% |

### 1.3 Dolor Principal que Resuelve

**Problema central:** Los contadores dedican 30-45 minutos por cliente mensualmente al llenado manual de formatos DM-1, DM-2 y DIM, un proceso repetitivo donde errores de captura en campos obligatorios generan rechazo automático del SAT y multas por declaración extemporánea (2.07% mensual + actualización).

**Dolores específicos:**
- Estructuras XML complejas con 40+ campos obligatorios por formato
- Validaciones de esquema XSD que rechazan archivos con errores de tipo de dato
- Proceso de firmado digital con FIEL/e.firma que requiere pasos manuales
- Cambios normativos constantes (RMF 2026, Anexos actualizados)

### 3.2 Estructura XML DM-1 (Pagos Provisionales ISR)

#### 3.2.1 Esquema General

```xml
<?xml version="1.0" encoding="UTF-8"?>
<DeclaracionISR version="1.0" fecha="2026-03-17T10:30:00">
    <!-- Encabezado: Datos del contribuyente -->
    <Encabezado>
        <RFC>XAXX010101000</RFC>                    <!-- RFC obligatorio, 12-13 caracteres -->
        <RazonSocial>EMPRESA EJEMPLO SA DE CV</RazonSocial>
        <Periodo>2026-03</Periodo>                   <!-- Formato AAAA-MM -->
        <TipoDeclaracion>Normal</TipoDeclaracion>    <!-- Normal, Complementaria -->
        <FolioAnterior></FolioAnterior>              <!-- Solo si es complementaria -->
        <FechaPresentacionAnterior></FechaPresentacionAnterior>
    </Encabezado>
    
    <!-- Cuerpo: Cálculo del ISR mensual -->
    <ISRMensual>
        <!-- Sección 1: Ingresos -->
        <Ingresos>
            <IngresosAcumulables>500000.00</IngresosAcumulables>  <!-- Campo obligatorio -->
            <IngresosExentos>0.00</IngresosExentos>               <!-- Opcional, default 0 -->
            <TotalIngresos>500000.00</TotalIngresos>
        </Ingresos>
        
        <!-- Sección 2: Deducciones -->
        <Deducciones>
            <DeduccionesAutorizadas>300000.00</DeduccionesAutorizadas>  <!-- Obligatorio -->
            <DeduccionesNoAutorizadas>0.00</DeduccionesNoAutorizadas>
            <TotalDeducciones>300000.00</TotalDeducciones>
        </Deducciones>
        
        <!-- Sección 3: Utilidad Fiscal -->
        <UtilidadFiscal>
            <UtilidadFiscalMensual>200000.00</UtilidadFiscalMensual>  <!-- Ingresos - Deducciones -->
            <CoeficienteUtilidad>0.40</CoeficienteUtilidad>            <!-- DA / Ingresos anuales -->
        </UtilidadFiscal>
        
        <!-- Sección 4: Cálculo ISR -->
        <CalculoISR>
            <ISRTasa>0.30</ISRTasa>                              <!-- Tasa aplicable según tabla -->
            <ISRCalculado>45000.00</ISRCalculado>                <!-- Utilidad × Tasa -->
            <PagosProvisionalesMesAnterior>40000.00</PagosProvisionalesMesAnterior>
            <EstimulosFiscales>0.00</EstimulosFiscales>          <!-- Opcional -->
        </CalculoISR>
    </ISRMensual>
    
    <!-- Resultado: ISR a pagar o saldo a favor -->
    <Resultado>
        <ISRApagar>5000.00</ISRApagar>              <!-- ISR Calculado - Pagos Provisionales -->
        <SaldoAFavor>0.00</SaldoAFavor>             <!-- Si Pagos > ISR Calculado -->
        <Recargos>0.00</Recargos>                   <!-- Si presentación extemporánea -->
        <TotalAPagar>5000.00</TotalAPagar>
    </Resultado>
</DeclaracionISR>
```

#### 3.2.2 Campos Obligatorios DM-1

| Campo | Tipo | Longitud | Valores Válidos | Validación |
|-------|------|----------|-----------------|------------|
| `RFC` | String | 12-13 | Patrón SAT | Regex: `[A-ZÑ&]{3,4}[0-9]{6}[A-Z0-9]{3}` |
| `Periodo` | String | 7 | `AAAA-MM` | Debe ser mes anterior al actual |
| `TipoDeclaracion` | String | 1-15 | `Normal`, `Complementaria` | Si es Complementaria, requiere FolioAnterior |
| `IngresosAcumulables` | Decimal | 15,2 | ≥ 0 | No negativo, 2 decimales |
| `DeduccionesAutorizadas` | Decimal | 15,2 | ≥ 0 | No negativo, 2 decimales |
| `UtilidadFiscalMensual` | Decimal | 15,2 | ≥ 0 | = IngresosAcumulables - DeduccionesAutorizadas |
| `ISRCalculado` | Decimal | 15,2 | ≥ 0 | Según tablas Anexo 8 RMF 2026 |
| `ISRApagar` | Decimal | 15,2 | ≥ 0 | = ISRCalculado - PagosProvisionalesMesAnterior |

### 3.5 Proceso de Firmado Digital con FIEL/e.firma

#### 3.5.1 Flujo de Firmado

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    PROCESO DE FIRMADO DIGITAL                            │
│                                                                          │
│  1. Generar Cadena Original                                             │
│     └─> Aplicar XSLT al XML                                             │
│     └─> Obtener string hashable                                         │
│                                                                          │
│  2. Calcular Hash SHA-256                                               │
│     └─> Input: Cadena Original                                          │
│     └─> Output: Hash 64 caracteres hex                                  │
│                                                                          │
│  3. Firmar con FIEL/e.firma                                             │
│     └─> Leer archivo .key (clave privada RSA 2048-bit)                  │
│     └─> Aplicar PKCS#1 v1.5                                             │
│     └─> Output: Sello Digital (base64)                                  │
│                                                                          │
│  4. Insertar Sello en XML                                               │
│     └─> Agregar nodo <SelloDigital>                                     │
│     └─> Agregar nodo <NoCertificado>                                    │
│     └─> Agregar nodo <FechaSello>                                       │
│                                                                          │
│  5. Validar con XSD                                                     │
│     └─> Validar estructura                                              │
│     └─> Validar tipos de dato                                           │
│     └─> Output: XML válido SAT                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 3.5.2 Código Python: Generación de Sello Digital

```python
import hashlib
import base64
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.backends import default_backend
from lxml import etree
from datetime import datetime
from typing import Tuple

def generar_cadena_original(xml_content: str, xslt_path: str) -> str:
    """
    Genera la cadena original aplicando XSLT al XML.
    
    Args:
        xml_content: Contenido XML de la declaración
        xslt_path: Path al archivo XSLT del SAT
    
    Returns:
        Cadena original (string para hash)
    
    Ejemplo:
        >>> xml = '<DeclaracionISR>...</DeclaracionISR>'
        >>> cadena = generar_cadena_original(xml, 'xslt/cadena_original_dm1.xslt')
        >>> print(len(cadena))
        1250
    """
    xml_doc = etree.fromstring(xml_content.encode('utf-8'))
    xslt_doc = etree.parse(xslt_path)
    transform = etree.XSLT(xslt_doc)
    result = transform(xml_doc)
    return str(result)


def calcular_hash_sha256(cadena_original: str) -> bytes:
    """
    Calcula hash SHA-256 de la cadena original.
    
    Args:
        cadena_original: Cadena original del SAT
    
    Returns:
        Hash en bytes (32 bytes)
    """
    return hashlib.sha256(cadena_original.encode('utf-8')).digest()


def firmar_con_fiel(hash_bytes: bytes, key_path: str, password: str) -> str:
    """
    Firma el hash usando la FIEL/e.firma (clave privada .key).
    
    Args:
        hash_bytes: Hash SHA-256 en bytes
        key_path: Path al archivo .key (clave privada)
        password: Contraseña de la FIEL
    
    Returns:
        Sello digital en base64
    
    Ejemplo:
        >>> sello = firmar_con_fiel(hash_bytes, 'fiel/XAXX010101000.key', 'mi_password')
        >>> print(len(sello))
        344
    """
    # Leer clave privada
    with open(key_path, 'rb') as key_file:
        private_key = serialization.load_pem_private_key(
            key_file.read(),
            password=password.encode('utf-8'),
            backend=default_backend()
        )
    
    # Firmar con PKCS#1 v1.5
    signature = private_key.sign(
        hash_bytes,
        padding.PKCS1v15(),
        hashes.SHA256()
    )
    
    # Retornar en base64
    return base64.b64encode(signature).decode('utf-8')


def insertar_sello_en_xml(xml_content: str, sello: str, no_certificado: str) -> str:
    """
    Inserta el sello digital y número de certificado en el XML.
    
    Args:
        xml_content: XML original
        sello: Sello digital en base64
        no_certificado: Número de certificado (20 caracteres)
    
    Returns:
        XML con sello insertado
    """
    root = etree.fromstring(xml_content.encode('utf-8'))
    
    # Crear nodos de sello
    sello_elem = etree.SubElement(root, 'SelloDigital')
    sello_elem.text = sello
    
    cert_elem = etree.SubElement(root, 'NoCertificado')
    cert_elem.text = no_certificado
    
    fecha_elem = etree.SubElement(root, 'FechaSello')
    fecha_elem.text = datetime.now().isoformat()
    
    return etree.tostring(root, encoding='utf-8', xml_declaration=True).decode('utf-8')


def firmar_declaracion_completa(
    xml_path: str,
    xslt_path: str,
    key_path: str,
    cert_path: str,
    password: str
) -> Tuple[str, str]:
    """
    Proceso completo de firmado de declaración.
    
    Args:
        xml_path: Path al XML de la declaración
        xslt_path: Path al XSLT de cadena original
        key_path: Path a la clave privada (.key)
        cert_path: Path al certificado (.cer)
        password: Contraseña de la FIEL
    
    Returns:
        Tupla (XML firmado, acuse)
    
    Ejemplo:
        >>> xml_firmado, acuse = firmar_declaracion_completa(
        ...     'dm1.xml',
        ...     'xslt/cadena_original.xslt',
        ...     'fiel/XAXX010101000.key',
        ...     'fiel/XAXX010101000.cer',
        ...     'mi_password'
        ... )
        >>> print("Declaración firmada exitosamente")
    """
    # Leer XML
    with open(xml_path, 'r', encoding='utf-8') as f:
        xml_content = f.read()
    
    # Generar cadena original
    cadena = generar_cadena_original(xml_content, xslt_path)
    
    # Calcular hash
    hash_bytes = calcular_hash_sha256(cadena)
    
    # Firmar
    sello = firmar_con_fiel(hash_bytes, key_path, password)
    
    # Leer número de certificado
    with open(cert_path, 'rb') as cert_file:
        cert_data = serialization.load_pem_x509_certificate(
            cert_file.read(),
            backend=default_backend()
        )
        # Extraer número de certificado (serial number en hex)
        no_certificado = format(cert_data.serial_number, '020d')
    
    # Insertar sello en XML
    xml_firmado = insertar_sello_en_xml(xml_content, sello, no_certificado)
    
    # Guardar XML firmado
    output_path = xml_path.replace('.xml', '_firmado.xml')
    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(xml_firmado)
    
    # Generar acuse (simplificado)
    acuse = f"Declaración presentada exitosamente. Folio: {datetime.now().strftime('%Y%m%d%H%M%S')}"
    
    return xml_firmado, acuse


# Ejemplo de uso completo

        xml_path='dm1_marcio_2026.xml',
```

### 3.7 Validaciones de Esquema XSD

#### 3.7.1 Errores Comunes y Soluciones

| Error XSD | Causa | Solución |
|-----------|-------|----------|
| `cvc-datatype-valid.1.2.1: '500000' is not a valid value for 'decimal'` | Falta decimales explícitos | Usar `500000.00` en lugar de `500000` |
| `cvc-pattern-valid: Value 'XAXX010101' is not facet-valid` | RFC incompleto (10 chars) | RFC debe tener 12-13 caracteres |
| `cvc-enumeration-valid: Value 'Complementaria' is not facet-valid` | Typo en valor de enumeración | Verificar mayúsculas/minúsculas exactas |
| `src-resolve: Cannot resolve name 't_Monto' to a type definition` | Namespace XSD no declarado | Agregar `xmlns:xsd="http://www.w3.org/2001/XMLSchema"` |
| `cvc-maxInclusive-valid: Value '999999999999.99' is not valid` | Excede máximo permitido | Validar contra `maxInclusive` del XSD |

#### 3.7.2 Código Python: Validación XSD

```python
from lxml import etree
from typing import List, Dict

def validar_xml_con_xsd(xml_path: str, xsd_path: str) -> Dict:
    """
    Valida un archivo XML contra un esquema XSD del SAT.
    
    Args:
        xml_path: Path al archivo XML a validar
        xsd_path: Path al archivo XSD (schema)
    
    Returns:
        Diccionario con resultado de validación
    
    Ejemplo:
        >>> resultado = validar_xml_con_xsd('dm1.xml', 'xsd/dm1_v1.xsd')
        >>> print(resultado['valido'])
        False
        >>> print(resultado['errores'][0])
        'cvc-datatype-valid.1.2.1: '500000' is not a valid value for 'decimal''
    """
    try:
        # Cargar XSD
        with open(xsd_path, 'r', encoding='utf-8') as xsd_file:
            xsd_doc = etree.parse(xsd_file)
            xsd_schema = etree.XMLSchema(xsd_doc)
        
        # Cargar XML
        with open(xml_path, 'r', encoding='utf-8') as xml_file:
            xml_doc = etree.parse(xml_file)
        
        # Validar
        valido = xsd_schema.validate(xml_doc)
        
        # Obtener errores si los hay
        errores = []
        if not valido:
            for error in xsd_schema.error_log:
                errores.append({
                    'linea': error.line,
                    'columna': error.column,
                    'mensaje': error.message.strip(),
                    'nivel': error.level_name
                })
        
        return {
            'valido': valido,
            'errores': errores,
            'total_errores': len(errores)
        }
    
    except etree.XMLSchemaError as e:
        return {
            'valido': False,
            'errores': [{'mensaje': f'Error en XSD: {str(e)}'}],
            'total_errores': 1
        }
    except etree.XMLParseError as e:
        return {
            'valido': False,
            'errores': [{'mensaje': f'Error al parsear XML: {str(e)}'}],
            'total_errores': 1
        }


# Ejemplo de uso
if __name__ == "__main__":
    resultado = validar_xml_con_xsd(
        xml_path='dm1_marcio_2026.xml',
        xsd_path='xsd/dm1_schema_v1.xsd'
    )
    
    if resultado['valido']:
        print("✅ XML válido contra XSD del SAT")
    else:
        print(f"❌ {resultado['total_errores']} errores encontrados:")
        for error in resultado['errores']:
            print(f"  Línea {error['linea']}: {error['mensaje']}")
```

**Problema:**
El firmado digital requiere acceso a la clave privada (.key) de la FIEL/e.firma, lo que implica riesgos de seguridad si no se almacena adecuadamente.

**Solución:**
```python
import os
from cryptography.fernet import Fernet

class FIELSegura:
    """
    Gestiona FIEL/e.firma con encriptación AES-256.
    """
    
    def __init__(self, encryption_key: bytes):
        self.cipher = Fernet(encryption_key)
    
    def encriptar_fiel(self, key_path: str, output_path: str):
        """Encripta archivo .key con AES-256."""
        with open(key_path, 'rb') as f:
            key_content = f.read()
        
        encrypted = self.cipher.encrypt(key_content)
        
        with open(output_path, 'wb') as f:
            f.write(encrypted)
    
    def desencriptar_fiel(self, encrypted_path: str) -> bytes:
        """Desencripta archivo .key para uso temporal."""
        with open(encrypted_path, 'rb') as f:
            encrypted_content = f.read()
        
        return self.cipher.decrypt(encrypted_content)
    
    def firmar_sin_guardar_key(self, xml_path: str, encrypted_key_path: str, password: str) -> str:
        """
        Firma XML sin guardar .key desencriptado en disco.
        
        Returns:
            Sello digital
        """
        # Desencriptar en memoria
        key_bytes = self.desencriptar_fiel(encrypted_key_path)
        
        # Usar clave desde memoria (no se guarda en disco)
        private_key = serialization.load_pem_private_key(
            key_bytes,
            password=password.encode('utf-8'),
            backend=default_backend()
        )
```

**Impacto:**
- Requiere gestión segura de claves de encriptación
- Añade complejidad al proceso de firmado
- Necesita protocolo de rotación de claves
