## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación documenta las APIs de pago disponibles en México para 2026, permitiendo la integración de métodos de cobro digitales automatizados en el IDP-App Asistente Contable. El módulo resuelve la necesidad de cobrar a clientes de forma electrónica, conciliar pagos automáticamente y reducir la cartera vencida mediante facilidades de pago digital.

**Problema que resuelve:** Los contadores públicos y despachos contables pierden 8-15 horas semanales gestionando cobros manuales, verificando transferencias SPEI, conciliando pagos con facturas emitidas, y persiguiendo clientes morosos. La falta de integración entre sistemas de cobro y contabilidad genera errores de conciliación, cartera vencida innecesaria y flujo de efectivo impredecible.

**Dolor 1: Incertidumbre de cobro**
- Los clientes no pagan a tiempo porque no tienen facilidades de pago inmediato

#### Algoritmo 1: Router Inteligente de Pagos

```python
from dataclasses import dataclass
from typing import Optional, List
from decimal import Decimal
from enum import Enum

class MetodoPago(Enum):
    TARJETA_CREDITO = "tarjeta_credito"
    TARJETA_DEBITO = "tarjeta_debito"
    SPEI = "spei"
    EFECTIVO_OXXO = "efectivo_oxxo"
    PAYPAL = "paypal"

@dataclass
class ConfiguracionProveedor:
    nombre: str
    comision_porcentaje: Decimal
    comision_fija_mxn: Decimal
    soporta_metodos: List[MetodoPago]
    tiempo_liquidacion_dias: int
    chargeback_fee: Decimal
    tiene_3d_secure: bool

class RouterPagosInteligente:
    """
    Selecciona automáticamente el proveedor de pago óptimo
    basado en costo, método de pago preferido y tiempo de liquidación.
    
    Ejemplo:
        >>> router = RouterPagosInteligente()
        >>> proveedor = router.seleccionar_proveedor(
        ...     monto=Decimal("1000.00"),
        ...     metodo_preferido=MetodoPago.SPEI,
        ...     prioridad="menor_costo"
        ... )
        >>> print(proveedor.nombre)
        'Stripe'
    """
    
    def __init__(self):
        self.proveedores = self._cargar_proveedores()
    
    def _cargar_proveedores(self) -> List[ConfiguracionProveedor]:
        """Carga configuración de proveedores desde variables de entorno."""
        return [
            ConfiguracionProveedor(
                nombre="Stripe",
                comision_porcentaje=Decimal("2.9"),
                comision_fija_mxn=Decimal("3.00"),
                soporta_metodos=[MetodoPago.TARJETA_CREDITO, MetodoPago.TARJETA_DEBITO, MetodoPago.SPEI, MetodoPago.EFECTIVO_OXXO],
                tiempo_liquidacion_dias=1,
                chargeback_fee=Decimal("15.00"),
                tiene_3d_secure=True
            ),
            ConfiguracionProveedor(
                nombre="Mercado Pago",
                comision_porcentaje=Decimal("3.5"),
                comision_fija_mxn=Decimal("2.50"),
                soporta_metodos=[MetodoPago.TARJETA_CREDITO, MetodoPago.TARJETA_DEBITO, MetodoPago.SPEI, MetodoPago.EFECTIVO_OXXO],
                tiempo_liquidacion_dias=1,
                chargeback_fee=Decimal("12.00"),
                tiene_3d_secure=True
            ),
            ConfiguracionProveedor(
                nombre="PayPal",
                comision_porcentaje=Decimal("3.9"),
                comision_fija_mxn=Decimal("4.00"),
                soporta_metodos=[MetodoPago.PAYPAL, MetodoPago.TARJETA_CREDITO, MetodoPago.TARJETA_DEBITO],
                tiempo_liquidacion_dias=2,
                chargeback_fee=Decimal("20.00"),
                tiene_3d_secure=False
            ),
            ConfiguracionProveedor(
                nombre="Conekta",
                comision_porcentaje=Decimal("3.5"),
                comision_fija_mxn=Decimal("3.00"),
                soporta_metodos=[MetodoPago.TARJETA_CREDITO, MetodoPago.TARJETA_DEBITO, MetodoPago.SPEI, MetodoPago.EFECTIVO_OXXO],
                tiempo_liquidacion_dias=2,
                chargeback_fee=Decimal("10.00"),
                tiene_3d_secure=True
            ),
        ]
    
    def calcular_costo_total(
        self,
        proveedor: ConfiguracionProveedor,
        monto: Decimal
    ) -> Decimal:
        """
        Calcula el costo total de procesamiento para un monto dado.
        
        Args:
            proveedor: Configuración del proveedor
            monto: Monto de la transacción en MXN
            
        Returns:
            Costo total en MXN (comisión porcentual + fija)
            
        Ejemplo:
            >>> stripe = ConfiguracionProveedor("Stripe", Decimal("2.9"), Decimal("3.00"), [], 1, Decimal("15.00"), True)
            >>> router = RouterPagosInteligente()
            >>> costo = router.calcular_costo_total(stripe, Decimal("1000.00"))
            >>> print(costo)
            32.00
        """
        comision_variable = monto * (proveedor.comision_porcentaje / Decimal("100"))
        return comision_variable + proveedor.comision_fija_mxn
    
    def seleccionar_proveedor(
        self,
        monto: Decimal,
        metodo_preferido: MetodoPago,
        prioridad: str = "menor_costo"
    ) -> Optional[ConfiguracionProveedor]:
        """
        Selecciona el proveedor óptimo según criterios.
        
        Args:
            monto: Monto de la transacción
            metodo_preferido: Método de pago que usará el cliente
            prioridad: Criterio de selección ("menor_costo", "mas_rapido", "menor_riesgo")
            
        Returns:
            Proveedor seleccionado o None si no hay compatible
        """
        # Filtrar proveedores que soporten el método de pago
        compatibles = [
            p for p in self.proveedores
            if metodo_preferido in p.soporta_metodos
        ]
        
        if not compatibles:
            return None
        
        if prioridad == "menor_costo":
            return min(compatibles, key=lambda p: self.calcular_costo_total(p, monto))
        elif prioridad == "mas_rapido":
            return min(compatibles, key=lambda p: p.tiempo_liquidacion_dias)
        elif prioridad == "menor_riesgo":
            # Priorizar proveedores con 3D Secure
            con_3ds = [p for p in compatibles if p.tiene_3d_secure]
            return min(con_3ds or compatibles, key=lambda p: self.calcular_costo_total(p, monto))
        
        return compatibles[0]
```

#### Algoritmo 2: Conciliador de Pagos vs CFDI

```python
from datetime import datetime, timedelta
from dataclasses import dataclass
from typing import List, Optional
from decimal import Decimal

@dataclass
class PagoRecibido:
    """Representa un pago recibido desde API de pagos."""
    id_transaccion: str
    id_cliente: str
    monto: Decimal
    moneda: str
    fecha_pago: datetime
    metodo_pago: str
    estado: str  # "aprobado", "pendiente", "rechazado", "chargeback"
    comisiones: Decimal
    referencia: str  # UUID del CFDI o número de factura

@dataclass
class CFDIEmitido:
    """Representa un CFDI emitido desde el SAT."""
    uuid: str
    rfc_emisor: str
    rfc_receptor: str
    monto_total: Decimal
    moneda: str
    fecha_emision: datetime
    estado: str  # "vigente", "pagado", "cancelado"
    pagos_parciales: List[Decimal]

class ConciliadorPagosCFDI:
    """
    Concilia automáticamente pagos recibidos con CFDI emitidos.
    Detecta pagos incompletos, excesos y chargebacks.
    
    Ejemplo:
        >>> conciliador = ConciliadorPagosCFDI()
        >>> resultado = conciliador.conciliar_pago(
        ...     pago=PagoRecibido(...),
        ...     cfdi=CFDIEmitido(...)
        ... )
        >>> print(resultado.estado_conciliacion)
        'conciliado_total'
    """
    
    TOLERANCIA_CONCILIACION = Decimal("0.01")  # 1 centavo de tolerancia
    
    def conciliar_pago(
        self,
        pago: PagoRecibido,
        cfdi: CFDIEmitido
    ) -> dict:
        """
        Concilia un pago individual con un CFDI.
        
        Args:
            pago: Pago recibido desde API
            cfdi: CFDI emitido que se espera pagar
            
        Returns:
            Diccionario con resultado de conciliación:
            - estado_conciliacion: "conciliado_total", "conciliado_parcial", "exceso", "no_conciliado"
            - diferencia: Monto faltante o sobrante
            - requiere_complemento_pago: bool para Complemento de Recepción de Pagos
        """
        # Calcular monto ya pagado del CFDI (sumando pagos parciales previos)
        monto_ya_pagado = sum(cfdi.pagos_parciales)
        monto_pendiente = cfdi.monto_total - monto_ya_pagado
        
        # Comparar pago con monto pendiente
        diferencia = pago.monto - monto_pendiente
        
        if abs(diferencia) <= self.TOLERANCIA_CONCILIACION:
            # Pago exacto (dentro de tolerancia)
            return {
                "estado_conciliacion": "conciliado_total",
                "diferencia": Decimal("0.00"),
                "requiere_complemento_pago": True,
                "monto_a_timbrar": pago.monto
            }
        elif diferencia < 0:
            # Pago parcial (falta dinero)
            return {
                "estado_conciliacion": "conciliado_parcial",
                "diferencia": diferencia,  # Negativo = faltante
                "requiere_complemento_pago": True,
                "monto_a_timbrar": pago.monto,
                "monto_pendiente_restante": abs(diferencia)
            }
        else:
            # Pago excesivo (sobró dinero)
            return {
                "estado_conciliacion": "exceso",
                "diferencia": diferencia,  # Positivo = sobrante
                "requiere_complemento_pago": True,
                "monto_a_timbrar": monto_pendiente,
                "monto_sobrante": diferencia,
                "accion_recomendada": "aplicar_a_siguiente_factura"
            }
    
    def detectar_chargeback(self, pago: PagoRecibido) -> bool:
        """Detecta si un pago tuvo chargeback."""
        return pago.estado == "chargeback"
    
    def generar_reporte_conciliacion(
        self,
        pagos: List[PagoRecibido],
        cfdi_list: List[CFDIEmitido],
        periodo_inicio: datetime,
        periodo_fin: datetime
    ) -> dict:
        """
        Genera reporte ejecutivo de conciliación para un periodo.
        
        Returns:
            Reporte con:
            - total_pagados: Cantidad de CFDI conciliados totalmente
            - total_parciales: Cantidad de CFDI con pagos parciales
            - total_excesos: Cantidad de pagos con exceso
            - total_chargebacks: Cantidad de chargebacks detectados
            - monto_total_chargebacks: Suma de chargebacks
            - tasa_conciliacion: % de CFDI conciliados vs emitidos
        """
        reporte = {
            "periodo": {
                "inicio": periodo_inicio.isoformat(),
                "fin": periodo_fin.isoformat()
            },
            "total_pagados": 0,
            "total_parciales": 0,
            "total_excesos": 0,
            "total_chargebacks": 0,
            "monto_total_chargebacks": Decimal("0.00"),
            "tasa_conciliacion": Decimal("0.00")
        }
        
        # Procesar cada pago
        for pago in pagos:
            if self.detectar_chargeback(pago):
                reporte["total_chargebacks"] += 1
                reporte["monto_total_chargebacks"] += pago.monto
                continue
            
            # Buscar CFDI correspondiente
            cfdi_match = next(
                (c for c in cfdi_list if c.uuid == pago.referencia),
                None
            )
            
            if cfdi_match:
                resultado = self.conciliar_pago(pago, cfdi_match)
                
                if resultado["estado_conciliacion"] == "conciliado_total":
                    reporte["total_pagados"] += 1
                elif resultado["estado_conciliacion"] == "conciliado_parcial":
                    reporte["total_parciales"] += 1
                elif resultado["estado_conciliacion"] == "exceso":
                    reporte["total_excesos"] += 1
        
        # Calcular tasa de conciliación
        total_cfdi = len(cfdi_list)
        if total_cfdi > 0:
            reporte["tasa_conciliacion"] = Decimal(reporte["total_pagados"]) / Decimal(total_cfdi) * Decimal("100")
        
        return reporte
```

### 4.2 Limitación 2: Complemento de Recepción de Pagos (SAT)

**Problema:**
El SAT requiere timbrar un Complemento de Recepción de Pagos (CRP) dentro de los 3 días naturales posteriores al pago. Las APIs de pago no generan automáticamente este complemento, requiere integración con PAC.

**Solución:**
```python
from datetime import datetime, timedelta

class GeneradorComplementoPago:
    """
    Genera Complemento de Recepción de Pagos (CRP) según SAT.
    Requiere integración con PAC (Finkok, SW, Ecodex, etc.)
    """
    
    PLAZO_MAXIMO_DIAS = 3  # Días naturales según SAT
    
    def calcular_fecha_limite_timbrado(self, fecha_pago: datetime) -> datetime:
        """
        Calcula fecha límite para timbrar CRP.
        
        Args:
            fecha_pago: Fecha y hora de recepción del pago
            
        Returns:
            Fecha límite (3 días naturales después)
            
        Ejemplo:
            >>> generador = GeneradorComplementoPago()
            >>> limite = generador.calcular_fecha_limite_timbrado(datetime(2026, 3, 10, 15, 30))
            >>> print(limite)
            2026-03-13 23:59:59
        """
        from datetime import time
        fecha_pago_date = fecha_pago.date()
        fecha_limite = fecha_pago_date + timedelta(days=self.PLAZO_MAXIMO_DIAS)
        return datetime.combine(fecha_limite, time(23, 59, 59))
    
    def verificar_pendiente_timbrado(
        self,
        pagos: List[PagoRecibido],
        cfdi_list: List[CFDIEmitido]
    ) -> List[dict]:
        """
        Identifica pagos que requieren CRP y están por vencer.
        
        Returns:
            Lista de pagos con:
            - pago: Datos del pago
            - cfdi: CFDI asociado
            - fecha_limite: Fecha límite de timbrado
            - dias_restantes: Días restantes para vencer
            - estado: "pendiente", "por_vencer", "vencido"
        """
        ahora = datetime.now()
        pendientes = []
        
        for pago in pagos:
            if pago.estado != "aprobado":
                continue
            
            cfdi_match = next((c for c in cfdi_list if c.uuid == pago.referencia), None)
            if not cfdi_match:
                continue
            
            fecha_limite = self.calcular_fecha_limite_timbrado(pago.fecha_pago)
            dias_restantes = (fecha_limite - ahora).days
            
            if dias_restantes >= 1:
                estado = "pendiente"
            elif dias_restantes == 0:
                estado = "por_vencer"
            else:
                estado = "vencido"
            
            pendientes.append({
                "pago": pago,
                "cfdi": cfdi_match,
                "fecha_limite": fecha_limite.isoformat(),
                "dias_restantes": dias_restantes,
                "estado": estado
            })
        
        return sorted(pendientes, key=lambda x: x["dias_restantes"])
```

**Impacto:**
- Requiere integración adicional con PAC (costo: $0.50-$1.50 por timbre)
- Riesgo de multa si no se timbra en plazo (Art. 83 CFF: $1,490-$2,980 MXN)
- Complejidad de generar CRP para pagos en parcialidades
