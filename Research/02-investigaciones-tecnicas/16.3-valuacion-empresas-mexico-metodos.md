## 1. Método DCF (Descuento de Flujos de Caja)

### Fundamentos Teóricos

**Fórmula básica:**
```
Valor de la Empresa = Σ [FCF_t / (1 + WACC)^t] + Valor Terminal / (1 + WACC)^n

Donde:
- FCF_t: Flujo de Caja Libre en el año t
- WACC: Costo Promedio Ponderado de Capital
- t: Año de proyección (1, 2, 3, ..., n)
- n: Período de proyección (típicamente 5-10 años)
- Valor Terminal: Valor al final del período de proyección
```

### Componentes del DCF

#### A. Proyección de Flujos de Caja Libre (FCF)

**Fórmula del FCF:**
```
FCF = EBITDA - Impuestos - CAPEX - ΔCapital de Trabajo

O alternativamente:
FCF = Utilidad Neta + Depreciación/Amortización - CAPEX - ΔCapital de Trabajo
```

**Período de proyección:**
| Tipo de Empresa | Período Recomendado | Justificación |
|-----------------|---------------------|---------------|
| **Startup/Empresa joven** | 3-5 años | Alta incertidumbre |
| **PYME establecida** | 5 años | Visibilidad media |
| **Empresa madura** | 5-10 años | Flujos predecibles |
| **Infraestructura/Concesiones** | 10-20 años | Vida útil del activo |

#### B. Cálculo del WACC (Costo Promedio Ponderado de Capital)

**Fórmula:**
```
WACC = (E/V × Ke) + (D/V × Kd × (1 - T))

Donde:
- E: Valor de mercado del capital (equity)
- D: Valor de mercado de la deuda
- V: Valor total (E + D)
- Ke: Costo del capital (usando CAPM)
- Kd: Costo de la deuda
- T: Tasa de impuestos (30% ISR en México)
```

**Cálculo de Ke (Costo del Capital) usando CAPM:**
```
Ke = Rf + β × (Rm - Rf) + Rp

Donde:
- Rf: Tasa libre de riesgo (CETES 10 años: 9.5-10.5%)
- β: Beta de la empresa (riesgo sistemático)
- Rm: Retorno esperado del mercado (10-12% para BMV)
- (Rm - Rf): Prima de riesgo de mercado (4-6%)
- Rp: Prima de riesgo específica de la empresa (0-5%)
```

**WACC típico por industria en México 2026:**

| Industria | WACC | Rango |
|-----------|------|-------|
| **Tecnología/Software** | 14-18% | Alto riesgo |
| **Retail/Comercio** | 12-15% | Riesgo medio-alto |
| **Manufactura** | 11-14% | Riesgo medio |
| **Servicios** | 10-13% | Riesgo medio-bajo |
| **Infraestructura/Utilities** | 9-11% | Bajo riesgo |
| **Bienes Raíces (FIBRAs)** | 8-10% | Bajo riesgo |

#### C. Cálculo del Valor Terminal

**Método de Crecimiento Perpetuo (Gordon Growth):**
```
Valor Terminal = FCF_n × (1 + g) / (WACC - g)

Donde:
- FCF_n: Flujo de caja del último año proyectado
- g: Tasa de crecimiento perpetuo (2-4% en México)
- WACC: Costo promedio de capital
```

**Restricciones:**
- g debe ser menor que WACC (de lo contrario, la fórmula no converge)
- g no debe exceder el crecimiento del PIB a largo plazo (2-4% en México)

**Método de Múltiplo de Salida (Exit Multiple):**
```
Valor Terminal = EBITDA_n × Múltiplo_EV/EBITDA_comparable

Ejemplo:
EBITDA año 5: $100 millones
Múltiplo EV/EBITDA: 8x
Valor Terminal = $100M × 8 = $800 millones
```

### Ejemplo Práctico de DCF

```python
# Datos de la empresa
empresa = {
    'nombre': 'Empresa Ejemplo SA de CV',
    'ebitda_actual': 50_000_000,  # $50M MXN
    'tasa_crecimiento_anual': 0.08,  # 8% anual
    'margen_ebitda': 0.20,  # 20%
    'capex_porcentaje_ventas': 0.05,  # 5% de ventas
    'capital_trabajo_porcentaje_ventas': 0.10,  # 10% de ventas
    'tasa_impuestos': 0.30,  # 30% ISR
}

# Parámetros de valuación
parametros = {
    'wacc': 0.12,  # 12% WACC
    'crecimiento_terminal': 0.03,  # 3% crecimiento perpetuo
    'periodo_proyeccion': 5,  # 5 años
}

# Proyección de flujos
proyeccion = []

for año in range(1, parametros['periodo_proyeccion'] + 1):
    # Crecimiento del EBITDA
    ebitda = empresa['ebitda_actual'] * (1 + empresa['tasa_crecimiento_anual']) ** año
    
    # Calcular FCF
    impuestos = ebitda * empresa['tasa_impuestos']
    capex = ebitda * empresa['capex_porcentaje_ventas'] / empresa['margen_ebitda']
    delta_capital_trabajo = ebitda * empresa['capital_trabajo_porcentaje_ventas'] / empresa['margen_ebitda']
    
    fcf = ebitda - impuestos - capex - delta_capital_trabajo
    
    proyeccion.append({
        'año': año,
        'ebitda': ebitda,
        'fcf': fcf
    })

# Calcular valor presente de flujos
valor_presente_flujos = sum(
    p['fcf'] / (1 + parametros['wacc']) ** p['año']
    for p in proyeccion
)

# Calcular valor terminal (método crecimiento perpetuo)
fcf_ultimo_año = proyeccion[-1]['fcf']
valor_terminal = fcf_ultimo_año * (1 + parametros['crecimiento_terminal']) / (parametros['wacc'] - parametros['crecimiento_terminal'])
valor_presente_terminal = valor_terminal / (1 + parametros['wacc']) ** parametros['periodo_proyeccion']

# Valor de la empresa
valor_empresa = valor_presente_flujos + valor_presente_terminal

print(f"Valor presente de flujos: ${valor_presente_flujos:,.2f} MXN")
print(f"Valor terminal: ${valor_terminal:,.2f} MXN")
print(f"Valor presente terminal: ${valor_presente_terminal:,.2f} MXN")
print(f"VALOR TOTAL DE LA EMPRESA: ${valor_empresa:,.2f} MXN")
```

## 3. Método de Valor Contable Ajustado

### Fórmula Básica

```
Valor Contable Ajustado = Activos Totales - Pasivos Totales ± Ajustes

Ajustes comunes:
+ Plusvalía no registrada (terrenos, edificios)
- Activos obsoletos o incobrables
+ Activos intangibles no capitalizados (marcas, patentes)
- Pasivos contingentes no registrados
+ Exceso de valor de mercado sobre valor en libros
```

### Cuándo Usar Este Método

| Situación | Recomendación |
|-----------|---------------|
| **Empresas en quiebra/liquidación** | Método principal |
| **Empresas con muchos activos fijos** | Método complementario |
| **Holding de inversiones** | Método principal |
| **Empresas de servicios (pocos activos)** | No recomendado |
| **Startups tecnológicas** | No recomendado |

### Valor de Liquidación

```
Valor de Liquidación = Activos Realizables - Pasivos Urgentes - Costos de Liquidación

Descuentos típicos:
- Cuentas por cobrar: 20-40% (por incobrabilidad)
- Inventarios: 30-60% (por obsolescencia, venta forzada)
- Activos fijos: 20-50% (por venta rápida)
- Activos intangibles: 50-100% (poco valor en liquidación)
```

## Implementación Técnica

### Funciones Python para Valuación

```python
"""
Módulo: valuacion_empresas_mexico.py
Propósito: Métodos de valuación de empresas en México 2026
Versión: 1.0
Fecha: 2026-03-10
"""

from dataclasses import dataclass
from typing import Dict, List, Optional, Tuple
from decimal import Decimal
import numpy as np


@dataclass
class Empresa:
    """Representa una empresa para valuación."""
    nombre: str
    ventas_anuales: float
    ebitda_anual: float
    utilidad_neta: float
    activos_totales: float
    pasivos_totales: float
    capital_contable: float
    deuda_neta: float  # Deuda - Efectivo
    industria: str


@dataclass
class ParametrosValuacion:
    """Parámetros para valuación."""
    wacc: float  # Costo promedio de capital
    crecimiento_terminal: float  # Crecimiento perpetuo
    periodo_proyeccion: int  # Años de proyección
    tasa_impuestos: float  # ISR (30% en México)
    crecimiento_ventas: float  # Crecimiento anual proyectado


class ValuadorEmpresas:
    """
    Realiza valuación de empresas usando múltiples métodos.
    """
    
    # Múltiplos promedio por industria en México 2026
    MULTIPLOS_POR_INDUSTRIA = {
        'tecnologia': {'ev_ebitda': 15.0, 'p_e': 25.0, 'ev_ventas': 8.0},
        'retail': {'ev_ebitda': 10.0, 'p_e': 18.0, 'ev_ventas': 1.2},
        'manufactura': {'ev_ebitda': 9.0, 'p_e': 15.0, 'ev_ventas': 1.2},
        'servicios': {'ev_ebitda': 11.0, 'p_e': 17.0, 'ev_ventas': 2.5},
        'financiero': {'ev_ebitda': 10.5, 'p_e': 12.0, 'p_vc': 2.0},
        'infraestructura': {'ev_ebitda': 8.0, 'p_e': 14.0, 'ev_ventas': 3.0},
    }
    
    # WACC típico por industria
    WACC_POR_INDUSTRIA = {
        'tecnologia': 0.16,
        'retail': 0.13,
        'manufactura': 0.12,
        'servicios': 0.11,
        'financiero': 0.12,
        'infraestructura': 0.10,
    }
    
    def __init__(self, empresa: Empresa):
        """
        Inicializa el valuador.
        
        Args:
            empresa: Objeto Empresa con datos financieros
        """
        self.empresa = empresa
        self.parametros = None
    
    def configurar_parametros(self, parametros: ParametrosValuacion):
        """
        Configura parámetros de valuación.
        
        Args:
            parametros: Objeto ParametrosValuacion
        """
        self.parametros = parametros
    
    def calcular_wacc(self, 
                      ke: float,
                      kd: float,
                      proporcion_capital: float,
                      proporcion_deuda: float) -> float:
        """
        Calcula WACC (Costo Promedio Ponderado de Capital).
        
        Args:
            ke: Costo del capital (CAPM)
            kd: Costo de la deuda
            proporcion_capital: E/V (equity/valor total)
            proporcion_deuda: D/V (debt/valor total)
        
        Returns:
            WACC como decimal
        """
        tasa_impuestos = self.parametros.tasa_impuestos if self.parametros else 0.30
        
        wacc = (proporcion_capital * ke) + (proporcion_deuda * kd * (1 - tasa_impuestos))
        
        return wacc
    
    def calcular_ke_capm(self,
                         rf: float,
                         beta: float,
                         rm: float,
                         prima_riesgo_especifico: float = 0.0) -> float:
        """
        Calcula costo de capital usando CAPM.
        
        Args:
            rf: Tasa libre de riesgo (CETES 10 años)
            beta: Beta de la empresa
            rm: Retorno esperado del mercado
            prima_riesgo_especifico: Prima adicional por riesgo específico
        
        Returns:
            Ke (costo de capital) como decimal
        """
        ke = rf + beta * (rm - rf) + prima_riesgo_especifico
        
        return ke
    
    def valuar_dcf(self, 
                   proyeccion_flujos: List[float],
                   valor_terminal: float) -> Dict:
        """
        Realiza valuación usando método DCF.
        
        Args:
            proyeccion_flujos: Lista de flujos de caja proyectados (año 1 a n)
            valor_terminal: Valor terminal al final del período
        
        Returns:
            Diccionario con resultados de la valuación DCF
        """
        if not self.parametros:
            raise ValueError("Debe configurar parámetros primero")
        
        wacc = self.parametros.wacc
        periodo = len(proyeccion_flujos)
        
        # Calcular valor presente de flujos
        flujos_descontados = [
            flujo / (1 + wacc) ** (i + 1)
            for i, flujo in enumerate(proyeccion_flujos)
        ]
        
        valor_presente_flujos = sum(flujos_descontados)
        
        # Calcular valor presente del valor terminal
        valor_presente_terminal = valor_terminal / (1 + wacc) ** periodo
        
        # Valor de la empresa (Enterprise Value)
        enterprise_value = valor_presente_flujos + valor_presente_terminal
        
        # Valor del capital (Equity Value)
        equity_value = enterprise_value - self.empresa.deuda_neta
        
        return {
            'metodo': 'DCF',
            'enterprise_value': enterprise_value,
            'equity_value': equity_value,
            'valor_presente_flujos': valor_presente_flujos,
            'valor_presente_terminal': valor_presente_terminal,
            'wacc_utilizado': wacc,
            'periodo_proyeccion': periodo
        }
    
    def calcular_flujos_proyectados(self,
                                     años: int = 5) -> List[float]:
        """
        Proyecta flujos de caja libre.
        
        Args:
            años: Número de años a proyectar
        
        Returns:
            Lista de flujos de caja libre proyectados
        """
        if not self.parametros:
            raise ValueError("Debe configurar parámetros primero")
        
        flujos = []
        
        for año in range(1, años + 1):
            # Proyectar EBITDA con crecimiento
            ebitda_proyectado = self.empresa.ebitda_anual * (1 + self.parametros.crecimiento_ventas) ** año
            
            # Calcular impuestos
            impuestos = ebitda_proyectado * self.parametros.tasa_impuestos
            
            # Estimar CAPEX y capital de trabajo (como % de ventas)
            # Suposición: CAPEX = 5% de ventas, ΔCapital de Trabajo = 2% de ventas
            ventas_proyectadas = self.empresa.ventas_anuales * (1 + self.parametros.crecimiento_ventas) ** año
            capex = ventas_proyectadas * 0.05
            delta_capital_trabajo = ventas_proyectadas * 0.02
            
            # Calcular FCF
            fcf = ebitda_proyectado - impuestos - capex - delta_capital_trabajo
            
            flujos.append(fcf)
        
        return flujos
    
    def calcular_valor_terminal_gordon(self,
                                       fcf_ultimo_año: float) -> float:
        """
        Calcula valor terminal usando método de crecimiento perpetuo (Gordon).
        
        Args:
            fcf_ultimo_año: Flujo de caja libre del último año proyectado
        
        Returns:
            Valor terminal
        """
        if not self.parametros:
            raise ValueError("Debe configurar parámetros primero")
        
        g = self.parametros.crecimiento_terminal
        wacc = self.parametros.wacc
        
        if g >= wacc:
            raise ValueError(f"El crecimiento terminal ({g}) debe ser menor que WACC ({wacc})")
        
        valor_terminal = fcf_ultimo_año * (1 + g) / (wacc - g)
        
        return valor_terminal
    
    def valuar_multiplos_comparables(self) -> Dict:
        """
        Realiza valuación usando múltiplos de mercado comparables.
        
        Returns:
            Diccionario con resultados de valuación por múltiplos
        """
        industria = self.empresa.industria.lower()
        
        if industria not in self.MULTIPLOS_POR_INDUSTRIA:
            raise ValueError(f"Industria '{industria}' no encontrada en base de datos")
        
        multiplos = self.MULTIPLOS_POR_INDUSTRIA[industria]
        
        # Valuación por EV/EBITDA
        ev_ebitda = self.empresa.ebitda_anual * multiplos['ev_ebitda']
        equity_ebitda = ev_ebitda - self.empresa.deuda_neta
        
        # Valuación por P/E
        equity_p_e = self.empresa.utilidad_neta * multiplos['p_e']
        
        # Valuación por EV/Ventas (si aplica)
        ev_ventas = self.empresa.ventas_anuales * multiplos['ev_ventas']
        equity_ventas = ev_ventas - self.empresa.deuda_neta
        
        # Calcular promedio
        valuaciones = [equity_ebitda, equity_p_e]
        if 'ev_ventas' in multiplos:
            valuaciones.append(equity_ventas)
        
        equity_promedio = sum(valuaciones) / len(valuaciones)
        
        return {
            'metodo': 'Múltiplos Comparables',
            'industria': industria,
            'multiplos_utilizados': multiplos,
            'valuacion_por_ebitda': equity_ebitda,
            'valuacion_por_p_e': equity_p_e,
            'valuacion_por_ventas': equity_ventas if 'ev_ventas' in multiplos else None,
            'equity_value_promedio': equity_promedio
        }
    
    def valuar_valor_contable(self,
                               ajustes: Dict[str, float] = None) -> Dict:
        """
        Realiza valuación usando valor contable ajustado.
        
        Args:
            ajustes: Diccionario de ajustes {concepto: monto}
        
        Returns:
            Diccionario con resultados de valuación por valor contable
        """
        # Valor contable en libros
        valor_contable_libros = self.empresa.capital_contable
        
        # Aplicar ajustes
        total_ajustes = sum(ajustes.values()) if ajustes else 0
        
        valor_contable_ajustado = valor_contable_libros + total_ajustes
        
        return {
            'metodo': 'Valor Contable Ajustado',
            'valor_contable_libros': valor_contable_libros,
            'ajustes': ajustes if ajustes else {},
            'total_ajustes': total_ajustes,
            'valor_contable_ajustado': valor_contable_ajustado
        }
    
    def valuar_completo(self) -> Dict:
        """
        Realiza valuación completa usando los 3 métodos.
        
        Returns:
            Diccionario con valuación por los 3 métodos y promedio
        """
        resultados = {}
        
        # 1. DCF
        if self.parametros:
            flujos = self.calcular_flujos_proyectados(self.parametros.periodo_proyeccion)
            valor_terminal = self.calcular_valor_terminal_gordon(flujos[-1])
            resultados['dcf'] = self.valuar_dcf(flujos, valor_terminal)
        
        # 2. Múltiplos comparables
        resultados['multiplos'] = self.valuar_multiplos_comparables()
        
        # 3. Valor contable
        resultados['valor_contable'] = self.valuar_valor_contable()
        
        # Calcular promedio de los 3 métodos (si están disponibles)
        valuaciones = []
        if 'dcf' in resultados:
            valuaciones.append(resultados['dcf']['equity_value'])
        if 'multiplos' in resultados:
            valuaciones.append(resultados['multiplos']['equity_value_promedio'])
        if 'valor_contable' in resultados:
            valuaciones.append(resultados['valor_contable']['valor_contable_ajustado'])
        
        if valuaciones:
            resultados['valuacion_promedio'] = sum(valuaciones) / len(valuaciones)
            resultados['rango_valuacion'] = {
                'minimo': min(valuaciones),
                'maximo': max(valuaciones),
                'promedio': resultados['valuacion_promedio']
            }
        
        return resultados
```
