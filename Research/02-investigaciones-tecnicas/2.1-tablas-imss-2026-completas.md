## 1. Descripción del Módulo

### 1.1 Propósito

El módulo de Cálculo de Nómina IMSS automatiza el cálculo de cuotas obrero-patronales de seguridad social conforme a la Ley del Seguro Social vigente en 2026, incluyendo el cuarto año del incremento gradual de la reforma 2020 en el ramo de Cesantía en Edad Avanzada y Vejez (CyV).

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Cálculo manual de cuotas IMSS | Quincenal | 4-6 horas/quincena | 30 minutos/quincena | 90% |
| Determinación de SBC por empleado | Por alta/modificación | 30 min/empleado | 2 minutos/empleado | 93% |
| Cálculo de factor de integración | Anual | 2-3 horas/empleado | Automático | 95% |
| Pago vía SIPARE/IDSE | Bimestral | 1-2 horas/bimestre | 15 minutos/bimestre | 85% |
| Validación de cuotas con SUA | Bimestral | 3-4 horas/bimestre | 30 minutos/bimestre | 85% |

### 1.3 Dolor Principal que Resuelve

**Problema central:** El cálculo de cuotas IMSS es complejo, propenso a errores y requiere actualización constante por cambios en UMA, salario mínimo y tablas progresivas CyV.

**Dolores específicos:**
- **Complejidad de cálculo:** 10+ ramas de seguro con diferentes bases y tasas
- **Tablas progresivas CyV:** 8 rangos salariales con tasas diferentes (3.15% - 7.51% en 2026)
- **Actualización anual:** UMA cambia cada febrero, salario mínimo cada enero
- **Errores costosos:** Multas del IMSS por cuotas mal calculadas (20-40% de cuotas omitidas)

### 3.2 Algoritmo 1: Cálculo del SBC

```python
from dataclasses import dataclass
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

@dataclass
class ParametrosIMSS2026:
    uma_diaria: Decimal = Decimal('117.31')
    uma_mensual: Decimal = Decimal('3566.22')
    salario_minimo_diario: Decimal = Decimal('315.04')
    tope_maximo_cotizacion: Decimal = Decimal('2932.75')  # 25 UMA

class FactorIntegracion:
    TABLA_FACTORES = [
        (0, 1.0493), (1, 1.0520), (2, 1.0548), (3, 1.0575), (4, 1.0603),
        (5, 1.0666), (6, 1.0693), (7, 1.0721), (8, 1.0748), (9, 1.0776),
        (10, 1.0835), (11, 1.0863), (12, 1.0890), (13, 1.0918),
        (14, 1.0945), (15, 1.1004), (16, 1.1032), (17, 1.1059),
        (18, 1.1087), (19, 1.1114), (20, 1.1173),
    ]
    
    @classmethod
    def obtener_factor(cls, anos_antiguedad: int) -> Decimal:
        for anos_min, factor in cls.TABLA_FACTORES:
            if anos_antiguedad >= anos_min:
                return Decimal(str(factor))
        return Decimal('1.1173')

def calcular_sbc(salario_diario: Decimal, anos_antiguedad: int,
                 parametros: Optional[ParametrosIMSS2026] = None) -> Decimal:
    """Calcula el Salario Base de Cotización (SBC) integrado."""
    if parametros is None:
        parametros = ParametrosIMSS2026()
    
    factor = FactorIntegracion.obtener_factor(anos_antiguedad)
    sdi = salario_diario * factor
    
    limite_inferior = parametros.uma_diaria
    limite_superior = parametros.tope_maximo_cotizacion
    sbc = max(limite_inferior, min(sdi, limite_superior))
    
    return sbc.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)

# Ejemplo: Salario $500, 5 años antigüedad
# SBC = 500 * 1.0666 = $533.30
```

### 3.3 Algoritmo 2: Cuotas Progresivas CyV 2026

```python
from enum import Enum
from typing import Tuple

class RangoCyV(Enum):
    SM_1_00 = "1.00_SM"
    SM_1_01_UMA_1_50 = "1.01_SM_a_1.50_UMA"
    UMA_1_51_2_00 = "1.51_a_2.00_UMA"
    UMA_2_01_2_50 = "2.01_a_2.50_UMA"
    UMA_2_51_3_00 = "2.51_a_3.00_UMA"
    UMA_3_01_3_50 = "3.01_a_3.50_UMA"
    UMA_3_51_4_00 = "3.51_a_4.00_UMA"
    UMA_4_01_ADELANTE = "4.01_UMA_en_adelante"

TABLA_CYV_2026 = {
    RangoCyV.SM_1_00: Decimal('0.03150'),
    RangoCyV.SM_1_01_UMA_1_50: Decimal('0.03676'),
    RangoCyV.UMA_1_51_2_00: Decimal('0.04851'),
    RangoCyV.UMA_2_01_2_50: Decimal('0.05556'),
    RangoCyV.UMA_2_51_3_00: Decimal('0.06026'),
    RangoCyV.UMA_3_01_3_50: Decimal('0.06361'),
    RangoCyV.UMA_3_51_4_00: Decimal('0.06613'),
    RangoCyV.UMA_4_01_ADELANTE: Decimal('0.07513'),
}

CUOTA_OBRERA_CYV = Decimal('0.01125')

def calcular_cuota_cyv(sbc_diario: Decimal, dias_cotizados: int,
                       parametros: Optional[ParametrosIMSS2026] = None) -> Tuple[Decimal, Decimal]:
    """Calcula cuotas patronal y obrera de CyV."""
    if parametros is None:
        parametros = ParametrosIMSS2026()
    
    uma_diaria = parametros.uma_diaria
    sm_diario = parametros.salario_minimo_diario
    
    # Determinar rango
    if sbc_diario <= sm_diario:
        rango = RangoCyV.SM_1_00
    elif sbc_diario <= uma_diaria * 1.50:
        rango = RangoCyV.SM_1_01_UMA_1_50
    elif sbc_diario <= uma_diaria * 2.00:
        rango = RangoCyV.UMA_1_51_2_00
    elif sbc_diario <= uma_diaria * 2.50:
        rango = RangoCyV.UMA_2_01_2_50
    elif sbc_diario <= uma_diaria * 3.00:
        rango = RangoCyV.UMA_2_51_3_00
    elif sbc_diario <= uma_diaria * 3.50:
        rango = RangoCyV.UMA_3_01_3_50
    elif sbc_diario <= uma_diaria * 4.00:
        rango = RangoCyV.UMA_3_51_4_00
    else:
        rango = RangoCyV.UMA_4_01_ADELANTE
    
    tasa_patronal = TABLA_CYV_2026[rango]
    base_cotizacion = sbc_diario * Decimal(str(dias_cotizados))
    
    cuota_patronal = base_cotizacion * tasa_patronal
    cuota_obrera = base_cotizacion * CUOTA_OBRERA_CYV
    
    return (
        cuota_patronal.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
        cuota_obrera.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
    )

# Ejemplo: SBC $600, 60 días
# Rango: 4.01+ UMA (600 > 469.24)
# Cuota patronal: 600 * 60 * 7.513% = $270.47
# Cuota obrera: 600 * 60 * 1.125% = $40.50
```

### 3.4 Algoritmo 3: Cálculo Completo (10 Ramas)

```python
def calcular_cuotas_imss_completas(sbc_diario: Decimal, dias_cotizados: int,
                                    prima_riesgo_trabajo: Decimal = Decimal('0.00')) -> Dict:
    """Calcula todas las cuotas obrero-patronales (10 ramas)."""
    base_bimestral = sbc_diario * Decimal(str(dias_cotizados))
    uma_triple = ParametrosIMSS2026().uma_diaria * 3
    
    # Cuotas patronales
    cuotas_patronales = {
        'riesgos_trabajo': base_bimestral * prima_riesgo_trabajo,
        'enfermedad_maternidad_especie': (
            uma_triple * Decimal('0.2040') * Decimal(str(dias_cotizados)) +
            max(Decimal('0'), sbc_diario - uma_triple) * Decimal('0.0110') * Decimal(str(dias_cotizados))
        ),
        'enfermedad_maternidad_dinero': base_bimestral * Decimal('0.0070'),
        'invalidez_vida': base_bimestral * Decimal('0.0175'),
        'retiro': base_bimestral * Decimal('0.0200'),
        'cesantia_vejez': calcular_cuota_cyv(sbc_diario, dias_cotizados)[0],
        'guarderias': base_bimestral * Decimal('0.0100'),
        'gastos_medicos_pensionados': base_bimestral * Decimal('0.0105'),
        'infonavit': base_bimestral * Decimal('0.0500'),
    }
    
    # Cuotas obreras
    cuotas_obreras = {
        'enfermedad_maternidad_dinero': base_bimestral * Decimal('0.0025'),
        'invalidez_vida': base_bimestral * Decimal('0.00625'),
        'cesantia_vejez': calcular_cuota_cyv(sbc_diario, dias_cotizados)[1],
        'gastos_medicos_pensionados': base_bimestral * Decimal('0.00375'),
    }
    
    total_patronal = sum(cuotas_patronales.values())
    total_obrero = sum(cuotas_obreras.values())
    
    return {
        'patronales': cuotas_patronales,
        'obreras': cuotas_obreras,
        'total_patronal': total_patronal,
        'total_obrero': total_obrero,
        'total_general': total_patronal + total_obrero
    }
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Actualización de Parámetros

**Problema:** UMA (febrero) y salario mínimo (enero) cambian anualmente.

**Solución:** Clase `ActualizadorParametrosIMSS` con alertas automáticas en enero/febrero.

**Impacto:** Requiere monitoreo de DOF/INEGI + testing exhaustivo después de actualización.

### 4.2 Limitación 2: Prima de Riesgo de Trabajo Variable

**Problema:** Varía según siniestralidad (0.00% - 8.50%), se determina anualmente.

**Solución:** Usuario ingresa manualmente + validación con resolución IMSS.

### 4.3 Riesgos Técnicos

| Riesgo | Probabilidad | Impacto | Mitigación |
|--------|--------------|---------|------------|
| Parámetros desactualizados | MEDIA | CRÍTICO | Alertas automáticas ene/feb |
| Error en factor integración | BAJA | ALTO | Validación con SUA |
| Multas por cuotas incorrectas | MEDIA | CRÍTICO | Validación con contador |
