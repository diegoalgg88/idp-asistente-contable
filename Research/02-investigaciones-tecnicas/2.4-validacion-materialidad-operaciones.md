## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía práctica para validar la materialidad de operaciones según el artículo 29-A, fracción IX del CFF reformado 2026, incluyendo:
- Requisitos de operaciones reales/existentes/verdaderas
- Evidencia documental requerida
- Procedimiento de validación del SAT
- Consecuencias de CFDI falsos
- Estrategias de mitigación de riesgos

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Validación de materialidad | Por proveedor | 30 min/proveedor | 5 min/proveedor | 80-85% |
| Recopilación de evidencia | Por operación | 15 min/operación | 2 min/operación | 85-90% |
| Verificación de congruencia | Por lote | 20 min/lote | 3 min/lote | 80-85% |
| Respuesta a requerimientos SAT | Por auditoría | 8-40 horas | 2-4 horas | 70-80% |

### 1.3 Dolor Principal que Resuelve

**Problema:** A partir del 1 de enero de 2026, el SAT puede declarar CFDI como **FALSOS** si no se prueba la materialidad de la operación, incluso si el CFDI está técnicamente correcto. Las consecuencias son:
- Pérdida de deducciones (ISR) y acreditamientos (IVA)
- Multas de 55-75% del monto de la operación
- Posible delito fiscal (hasta 9 años de prisión)

**Solución IDP-App:** Checklist automatizado de materialidad + almacenamiento de evidencia + alertas de riesgos.

#### Algoritmo 1: Validación de Materialidad Pre-Emisión

```python
from datetime import datetime, timedelta
from typing import Dict, List, Optional
from enum import Enum

class MaterialidadRiskLevel(Enum):
    LOW = "LOW"
    MEDIUM = "MEDIUM"
    HIGH = "HIGH"
    CRITICAL = "CRITICAL"

class MaterialidadValidator:
    """
    Valida la materialidad de operaciones antes de emitir/recibir CFDI.
    Implementa checklist de validación según CFF Art. 29-A reformado 2026.
    """
    
    def __init__(self, sat_client, erp_client, bank_client):
        """
        Inicializa el validador de materialidad.
        
        Args:
            sat_client: Cliente para consultas SAT (69-B, opinión, RFC)
            erp_client: Cliente para consultas ERP (órdenes de compra, histórico)
            bank_client: Cliente para consultas bancarias (pagos, transferencias)
        """
        self.sat = sat_client
        self.erp = erp_client
        self.bank = bank_client
    
    def validate_operation(self, 
                          rfc_proveedor: str,
                          monto: float,
                          concepto: str,
                          tipo_operacion: str) -> Dict:
        """
        Valida la materialidad de una operación antes de emitir/recibir CFDI.
        
        Args:
            rfc_proveedor: RFC del proveedor/cliente
            monto: Monto de la operación
            concepto: Concepto del CFDI
            tipo_operacion: Tipo de operación (ingreso/egreso)
            
        Returns:
            Dict con resultado de validación:
            - is_valid: bool
            - risk_level: MaterialidadRiskLevel
            - factors: List de factores de riesgo detectados
            - recommendations: List de recomendaciones
        """
        risk_factors = []
        recommendations = []
        
        # 1. Validar que RFC NO esté en lista 69-B
        status_69b = self.sat.check_lista_69b(rfc_proveedor)
        if status_69b['in_list']:
            risk_factors.append({
                'factor': 'PROVEEDOR_EN_69B',
                'severity': MaterialidadRiskLevel.CRITICAL,
                'description': f"RFC {rfc_proveedor} está en lista 69-B ({status_69b['situacion']})",
                'recommendation': 'NO emitir/recibir CFDI. Solicitar factura a proveedor alterno.'
            })
        
        # 2. Validar opinión de cumplimiento SAT
        opinion = self.sat.check_opinion_cumplimiento(rfc_proveedor)
        if not opinion['is_positive']:
            risk_factors.append({
                'factor': 'OPINION_NEGATIVA',
                'severity': MaterialidadRiskLevel.HIGH,
                'description': 'Proveedor tiene opinión de cumplimiento negativa',
                'recommendation': 'Solicitar regularización antes de operar'
            })
        
        # 3. Validar congruencia concepto vs actividad económica
        actividad_economica = self.sat.get_actividad_economica(rfc_proveedor)
        if not self._es_congruente(concepto, actividad_economica):
            risk_factors.append({
                'factor': 'INCONGRUENCIA_ACTIVIDAD',
                'severity': MaterialidadRiskLevel.MEDIUM,
                'description': f'Concepto "{concepto}" no es congruente con actividad "{actividad_economica}"',
                'recommendation': 'Solicitar justificación por escrito del proveedor'
            })
        
        # 4. Validar monto vs histórico de operaciones
        historico = self.erp.get_historico_proveedor(rfc_proveedor)
        if historico:
            monto_promedio = historico['monto_promedio']
            if monto > (monto_promedio * 5):  # 5x más del promedio
                risk_factors.append({
                    'factor': 'MONTO_ATIPICO',
                    'severity': MaterialidadRiskLevel.HIGH,
                    'description': f'Monto ${monto:,.2f} es 5x mayor al histórico (${monto_promedio:,.2f})',
                    'recommendation': 'Solicitar cotización formal y justificación de precio'
                })
        
        # 5. Validar capacidad operativa del proveedor
        capacidad = self._evaluar_capacidad_operativa(rfc_proveedor, monto, concepto)
        if not capacidad['es_suficiente']:
            risk_factors.append({
                'factor': 'CAPACIDAD_INSUFICIENTE',
                'severity': MaterialidadRiskLevel.HIGH,
                'description': 'Proveedor no tiene capacidad operativa para la operación',
                'recommendation': 'Solicitar referencias comerciales y capacidad de entrega'
            })
        
        # 6. Validar que exista orden de compra/solicitud
        orden_compra = self.erp.check_orden_compra(rfc_proveedor, monto)
        if not orden_compra:
            risk_factors.append({
                'factor': 'SIN_ORDEN_COMPRA',
                'severity': MaterialidadRiskLevel.MEDIUM,
                'description': 'No existe orden de compra registrada para esta operación',
                'recommendation': 'Generar orden de compra antes de recibir factura'
            })
        
        # 7. Validar fecha de operación vs fecha de entrega/servicio
        fecha_cfdi = datetime.now()
        dias_diferencia = abs((fecha_cfdi - orden_compra['fecha']).days) if orden_compra else 999
        if dias_diferencia > 30:  # Más de 30 días de diferencia
            risk_factors.append({
                'factor': 'FECHA_INCONSISTENTE',
                'severity': MaterialidadRiskLevel.MEDIUM,
                'description': f'Más de 30 días entre orden de compra y factura ({dias_diferencia} días)',
                'recommendation': 'Verificar fechas de entrega/servicio reales'
            })
        
        # Calcular nivel de riesgo general
        risk_level = self._calculate_overall_risk(risk_factors)
        
        return {
            'is_valid': len([f for f in risk_factors if f['severity'] == MaterialidadRiskLevel.CRITICAL]) == 0,
            'risk_level': risk_level,
            'factors': risk_factors,
            'recommendations': recommendations,
            'timestamp': datetime.now().isoformat()
        }
    
    def _es_congruente(self, concepto: str, actividad_economica: str) -> bool:
        """
        Valida si el concepto del CFDI es congruente con la actividad económica del proveedor.
        
        Args:
            concepto: Concepto del CFDI
            actividad_economica: Actividad económica del proveedor según SAT
            
        Returns:
            bool: True si es congruente, False si no
        """
        # Implementación con NLP o reglas simples
        # Ejemplo: si actividad es "Servicios de consultoría" y concepto es "Acero", es incongruente
        
        palabras_clave_actividad = {
            'consultoría': ['consultoría', 'consultor', 'asesoría', 'asesor', 'servicios profesionales'],
            'construcción': ['construcción', 'obra', 'construir', 'edificación', 'materiales de construcción'],
            'tecnología': ['software', 'computo', 'tecnología', 'sistemas', 'licencia', 'servicios TI'],
            'transporte': ['transporte', 'flete', 'envío', 'logística', 'mensajería'],
            'alimentos': ['alimentos', 'bebidas', 'comida', 'restaurante', 'catering']
        }
        
        concepto_lower = concepto.lower()
        actividad_lower = actividad_economica.lower()
        
        # Buscar palabras clave de actividad en concepto
        for actividad, palabras in palabras_clave_actividad.items():
            if actividad in actividad_lower:
                # Verificar si alguna palabra clave aparece en el concepto
                for palabra in palabras:
                    if palabra in concepto_lower:
                        return True
        
        # Si no hay coincidencia, marcar como incongruente
        return False
    
    def _evaluar_capacidad_operativa(self, rfc: str, monto: float, concepto: str) -> Dict:
        """
        Evalúa si el proveedor tiene capacidad operativa para la operación.
        
        Args:
            rfc: RFC del proveedor
            monto: Monto de la operación
            concepto: Concepto del CFDI
            
        Returns:
            Dict con evaluación de capacidad
        """
        # Obtener información del proveedor desde SAT
        info_proveedor = self.sat.get_info_contribuyente(rfc)
        
        # Evaluar según tipo de operación
        if 'construcción' in concepto.lower() and monto > 1_000_000:
            # Para construcciones > $1M, verificar que tenga empleados registrados
            empleados_imss = self.sat.get_empleados_registrados(rfc)
            if empleados_imss < 10:
                return {
                    'es_suficiente': False,
                    'razon': f'Solo tiene {empleados_imss} empleados registrados para obra >$1M'
                }
        
        # Para servicios profesionales, verificar que tenga actividad activa
        if info_proveedor.get('estatus') != 'ACTIVO':
            return {
                'es_suficiente': False,
                'razon': 'Contribuyente no está activo en el padrón del SAT'
            }
        
        return {'es_suficiente': True}
    
    def _calculate_overall_risk(self, risk_factors: List[Dict]) -> MaterialidadRiskLevel:
        """
        Calcula el nivel de riesgo general de la operación.
        
        Args:
            risk_factors: Lista de factores de riesgo detectados
            
        Returns:
            MaterialidadRiskLevel: Nivel de riesgo general
        """
        if any(f['severity'] == MaterialidadRiskLevel.CRITICAL for f in risk_factors):
            return MaterialidadRiskLevel.CRITICAL
        
        critical_count = len([f for f in risk_factors if f['severity'] == MaterialidadRiskLevel.HIGH])
        if critical_count >= 2:
            return MaterialidadRiskLevel.HIGH
        
        if len(risk_factors) >= 3:
            return MaterialidadRiskLevel.MEDIUM
        
        return MaterialidadRiskLevel.LOW
```

#### Algoritmo 2: Almacenamiento de Evidencia Digital

```python
import hashlib
from datetime import datetime
from typing import List, Dict

class EvidenciaDigital:
    """
    Gestiona el almacenamiento de evidencia digital para materialidad de operaciones.
    Implementa hash SHA256 para integridad y no repudio.
    """
    
    def __init__(self, storage_client):
        """
        Inicializa el gestor de evidencia digital.
        
        Args:
            storage_client: Cliente de almacenamiento (AWS S3, Azure Blob, etc.)
        """
        self.storage = storage_client
    
    def almacenar_evidencia(self, 
                           rfc_proveedor: str,
                           uuid_cfdi: str,
                           tipo_documento: str,
                           archivo_bytes: bytes,
                           metadata: Dict) -> Dict:
        """
        Almacena evidencia digital de una operación.
        
        Args:
            rfc_proveedor: RFC del proveedor
            uuid_cfdi: Folio fiscal del CFDI
            tipo_documento: Tipo de documento (contrato, orden, bitacora, pago, etc.)
            archivo_bytes: Contenido del archivo
            metadata: Metadatos adicionales
            
        Returns:
            Dict con información de almacenamiento
        """
        # Calcular hash SHA256 para integridad
        hash_sha256 = hashlib.sha256(archivo_bytes).hexdigest()
        
        # Generar ruta de almacenamiento
        fecha = datetime.now().strftime('%Y/%m/%d')
        ruta = f"evidencia/{rfc_proveedor}/{uuid_cfdi}/{fecha}/{tipo_documento}_{hash_sha256[:8]}.pdf"
        
        # Almacenar archivo
        self.storage.upload(
            bucket='materialidad-operaciones',
            key=ruta,
            data=archivo_bytes,
            metadata={
                'rfc_proveedor': rfc_proveedor,
                'uuid_cfdi': uuid_cfdi,
                'tipo_documento': tipo_documento,
                'hash_sha256': hash_sha256,
                'fecha_alta': datetime.now().isoformat(),
                **metadata
            }
        )
        
        return {
            'success': True,
            'ruta': ruta,
            'hash_sha256': hash_sha256,
            'timestamp': datetime.now().isoformat()
        }
    
    def obtener_evidencia(self, rfc_proveedor: str, uuid_cfdi: str) -> List[Dict]:
        """
        Obtiene toda la evidencia almacenada para un CFDI.
        
        Args:
            rfc_proveedor: RFC del proveedor
            uuid_cfdi: Folio fiscal del CFDI
            
        Returns:
            Lista de documentos de evidencia
        """
        # Listar todos los archivos en la ruta del CFDI
        ruta_base = f"evidencia/{rfc_proveedor}/{uuid_cfdi}"
        archivos = self.storage.list(bucket='materialidad-operaciones', prefix=ruta_base)
        
        return [
            {
                'ruta': archivo['key'],
                'tipo': self._extract_tipo_from_filename(archivo['key']),
                'hash_sha256': archivo['metadata']['hash_sha256'],
                'fecha_alta': archivo['metadata']['fecha_alta'],
                'tamano': archivo['size']
            }
            for archivo in archivos
        ]
    
    def verificar_integridad(self, rfc_proveedor: str, uuid_cfdi: str, 
                           tipo_documento: str, archivo_bytes: bytes) -> Dict:
        """
        Verifica la integridad de un documento almacenado.
        
        Args:
            rfc_proveedor: RFC del proveedor
            uuid_cfdi: Folio fiscal del CFDI
            tipo_documento: Tipo de documento
            archivo_bytes: Contenido del archivo a verificar
            
        Returns:
            Dict con resultado de verificación
        """
        # Calcular hash del archivo proporcionado
        hash_actual = hashlib.sha256(archivo_bytes).hexdigest()
        
        # Obtener hash almacenado
        evidencia = self.obtener_evidencia(rfc_proveedor, uuid_cfdi)
        documento = next((d for d in evidencia if d['tipo'] == tipo_documento), None)
        
        if not documento:
            return {
                'is_valid': False,
                'error': 'Documento no encontrado en evidencia almacenada'
            }
        
        # Comparar hashes
        if hash_actual == documento['hash_sha256']:
            return {
                'is_valid': True,
                'message': 'Integridad verificada. Documento no ha sido alterado.'
            }
        else:
            return {
                'is_valid': False,
                'error': 'INTEGRIDAD COMPROMETIDA. El archivo ha sido alterado.',
                'hash_esperado': documento['hash_sha256'],
                'hash_actual': hash_actual
            }
    
    def _extract_tipo_from_filename(self, filename: str) -> str:
        """Extrae el tipo de documento del nombre del archivo."""
        # Implementación según convención de nombres
        return filename.split('_')[0]
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Carga de la Prueba se Invierte

**Problema:**
Con la reforma 2026, el SAT presume que los CFDI son falsos. El contribuyente debe probar la materialidad (inversión de carga de la prueba).

**Solución:**
```python
# Checklist automatizado de materialidad
class MaterialidadChecklist:
    DOCUMENTOS_REQUERIDOS = {
        'servicios': ['contrato', 'bitacora_servicio', 'correo_confirmacion', 'pago'],
        'productos': ['orden_compra', 'remision_entrega', 'fotografia_entrega', 'pago'],
        'arrendamiento': ['contrato_arrendamiento', 'comprobante_dominio', 'pago'],
        'construccion': ['contrato_obra', 'bitacora_obra', 'estimaciones', 'pago']
    }
    
    def generate_checklist(self, tipo_operacion: str) -> List[str]:
        """Genera checklist de documentos requeridos por tipo de operación."""
        return self.DOCUMENTOS_REQUERIDOS.get(tipo_operacion, [])
```

**Impacto:**
- Requiere almacenamiento de 4-6 documentos por operación
- Necesidad de digitalización de documentos físicos

### 4.2 Limitación 2: Validación de Capacidad Operativa

**Problema:**
No hay API pública para verificar capacidad operativa real de proveedores (empleados, activos, infraestructura).

**Solución:**
```python
# Validación indirecta de capacidad operativa
def validar_capacidad_operativa_indirecta(rfc: str, monto: float, concepto: str) -> Dict:
    """
    Valida capacidad operativa usando datos indirectos disponibles.
    
    Args:
        rfc: RFC del proveedor
        monto: Monto de la operación
        concepto: Concepto del CFDI
        
    Returns:
        Dict con evaluación de capacidad
    """
    # 1. Verificar empleados registrados en IMSS (disponible vía SAT)
    empleados_imss = sat_api.get_empleados_registrados(rfc)
    
    # 2. Verificar antigüedad del contribuyente
    fecha_alta = sat_api.get_fecha_alta(rfc)
    antiguedad_anios = (datetime.now() - fecha_alta).days / 365
    
    # 3. Verificar operaciones históricas con otros clientes
    operaciones_sat = sat_api.get_operaciones_sat(rfc)
    clientes_unicos = len(set(op['rfc_contraparte'] for op in operaciones_sat))
    
    # Evaluar según tipo de operación
    if 'construcción' in concepto.lower():
        # Para construcción, requerir mínimo 10 empleados y 2+ años de antigüedad
        if empleados_imss < 10 or antiguedad_anios < 2:
            return {'capacidad_suficiente': False, 'razon': 'Capacidad operativa insuficiente para construcción'}
    
    elif 'servicios profesionales' in concepto.lower():
        # Para servicios, requerir mínimo 3 empleados y 1+ años
        if empleados_imss < 3 or antiguedad_anios < 1:
            return {'capacidad_suficiente': False, 'razon': 'Capacidad operativa insuficiente para servicios'}
    
    # Si tiene múltiples clientes, es buena señal
    if clientes_unicos >= 5:
        return {'capacidad_suficiente': True, 'observacion': f'{clientes_unicos} clientes únicos en histórico'}
    
    return {'capacidad_suficiente': True}
```

**Impacto:**
- Validación indirecta puede tener falsos positivos
- Necesidad de documentación adicional para proveedores nuevos

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **Carga de prueba invertida:** SAT presume CFDI falsos. Contribuyente debe probar materialidad.
2. **4-6 documentos por operación:** Mínimo requerido para acreditar materialidad (contrato, orden, entrega, pago).
3. **Validación pre-emisión crítica:** Prevenir es mejor que responder requerimientos.
4. **Hash SHA256 obligatorio:** Para acreditar integridad de documentos ante auditoría.
5. **Conciliación automática:** CFDI vs ERP vs Banco vs SAT reduce riesgos 80-90%.
