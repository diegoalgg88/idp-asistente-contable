## Marco Teórico

### ¿Qué es una Cobertura Cambiaria?

Una **cobertura cambiaria** es un instrumento financiero derivado que permite a una empresa fijar hoy el tipo de cambio para una transacción futura, eliminando la incertidumbre sobre fluctuaciones del tipo de cambio.

**Objetivos principales:**
1. **Proteger márgenes**: Fijar costos/ingresos en moneda funcional
2. **Reducir volatilidad**: Minimizar impacto de fluctuaciones en resultados
3. **Planificación financiera**: Presupuestar con certeza flujos futuros
4. **Competitividad**: Evitar sorpresas en cotizaciones a clientes

### Tipos de Exposición Cambiaria

| Tipo de Exposición | Descripción | Ejemplo |
|-------------------|-------------|---------|
| **Transacción** | Flujos futuros contractualmente definidos | Cuentas por cobrar/pagar en USD |
| **Traducción** | Conversión de estados financieros de subsidiarias | Consolidación de filial en EE.UU. |
| **Económica** | Impacto en competitividad por tipo de cambio | Exportador con costos en MXN y ventas en USD |
| **Competitiva** | Competidores en diferentes monedas | Empresa mexicana vs. china en mercado EE.UU. |

## Tipos de Cobertura Cambiaria

### 1. Forward de Tipo de Cambio

**Descripción**: Contrato OTC (Over-The-Counter) para comprar o vender una cantidad específica de divisas a un tipo de cambio predeterminado en una fecha futura.

**Características:**

| Característica | Detalle |
|----------------|---------|
| **Mercado** | OTC (personalizado) |
| **Monto mínimo** | USD $10,000 - $50,000 (según banco) |
| **Plazos** | 7 - 365 días (típico) |
| **Liquidación** | Física (entrega de divisas) o NDF (diferencial) |
| **Costo** | Diferencial de tasas (2-4% anual implícito) |
| **Garantía** | Línea de crédito o margen inicial (5-10%) |
| **Regulación** | CNBV, Banxico |

**Fórmula de Cálculo:**

```
Puntos Forward = Spot × (Tasa_MXN - Tasa_USD) × Días / 360

Forward = Spot + Puntos Forward (si Tasa_MXN > Tasa_USD)
Forward = Spot - Puntos Forward (si Tasa_MXN < Tasa_USD)
```

**Ejemplo Práctico:**

```python
# Datos de mercado
spot_usd_mxn = 17.5000      # Tipo de cambio spot
tiie_28 = 0.1050            # TIIE 28 días (10.50%)
sofr = 0.0525               # SOFR (5.25%)
dias = 28                   # Plazo del forward

# Calcular puntos forward
puntos_forward = spot_usd_mxn * (tiie_28 - sofr) * dias / 360
# = 17.50 * (0.1050 - 0.0525) * 28 / 360
# = 17.50 * 0.0525 * 0.0778
# = 0.0714

# Forward (MXN tiene tasa mayor, se cotiza con prima)
forward = spot_usd_mxn + puntos_forward
# = 17.50 + 0.0714 = 17.5714

print(f"Spot: ${spot_usd_mxn:.4f}")
print(f"Puntos Forward: {puntos_forward:.4f}")
print(f"Forward: ${forward:.4f}")
```

**Resultado:**
```
Spot: $17.5000
Puntos Forward: 0.0714
Forward: $17.5714
```

**Interpretación:**
- El forward cotiza con **prima** de 0.0714 pesos (7.14 centavos)
- La prima refleja el diferencial de tasas (MXN 10.50% vs. USD 5.25%)
- El importador paga 7.14 centavos más por dólar para eliminar incertidumbre

### 2. Opciones de Tipo de Cambio

**Descripción**: Contrato que otorga el **derecho** (no la obligación) de comprar o vender divisas a un precio determinado (strike) en una fecha futura.

**Tipos de opciones:**

| Tipo | Derecho | Cuándo se ejerce |
|------|---------|------------------|
| **Call** | Comprar USD al strike | Si spot > strike (dólar sube) |
| **Put** | Vender USD al strike | Si spot < strike (dólar baja) |

**Características:**

| Característica | Detalle |
|----------------|---------|
| **Mercado** | OTC o交易所 (MexDer) |
| **Monto mínimo** | USD $25,000 - $100,000 |
| **Plazos** | 1 - 12 meses (típico) |
| **Prima** | 1-3% del monto nocional (pago inicial) |
| **Strike** | A la par (ATM), dentro del dinero (ITM), fuera del dinero (OTM) |
| **Liquidación** | Física o en efectivo |
| **Estilo** | Europeo (solo al vencimiento) o Americano (cualquier momento) |

**Cálculo de Prima (Modelo Black-Scholes Simplificado):**

```python
from scipy.stats import norm
import numpy as np

def calcular_prima_opcion(spot: float, strike: float, tasa_mx: float,
                          tasa_us: float, volatilidad: float,
                          dias: int, tipo: str = 'call') -> float:
    """
    Calcula prima de opción cambiaria (Black-Scholes simplificado).
    
    Args:
        spot: Tipo de cambio spot
        strike: Precio de ejercicio
        tasa_mx: Tasa de interés MXN (anual)
        tasa_us: Tasa de interés USD (anual)
        volatilidad: Volatilidad anualizada (ej. 0.15 para 15%)
        dias: Días al vencimiento
        tipo: 'call' o 'put'
    
    Returns:
        Prima de la opción (en pesos por dólar)
    """
    # Tiempo en años
    T = dias / 365.0
    
    # Componentes de Black-Scholes
    d1 = (np.log(spot / strike) + (tasa_mx - tasa_us + 0.5 * volatilidad**2) * T) / (volatilidad * np.sqrt(T))
    d2 = d1 - volatilidad * np.sqrt(T)
    
    if tipo == 'call':
        prima = spot * np.exp(-tasa_us * T) * norm.cdf(d1) - strike * np.exp(-tasa_mx * T) * norm.cdf(d2)
    else:  # put
        prima = strike * np.exp(-tasa_mx * T) * norm.cdf(-d2) - spot * np.exp(-tasa_us * T) * norm.cdf(-d1)
    
    return prima


# Ejemplo
spot = 17.50
strike = 17.50  # ATM (at-the-money)
tasa_mx = 0.1050
tasa_us = 0.0525
volatilidad = 0.15  # 15% anual
dias = 90

prima_call = calcular_prima_opcion(spot, strike, tasa_mx, tasa_us, volatilidad, dias, 'call')
prima_put = calcular_prima_opcion(spot, strike, tasa_mx, tasa_us, volatilidad, dias, 'put')

print(f"Prima Call (90 días): ${prima_call:.4f} por dólar")
print(f"Prima Put (90 días): ${prima_put:.4f} por dólar")
print(f"Costo total para USD $100,000: ${prima_call * 100000:,.2f} MXN")
```

**Resultado:**
```
Prima Call (90 días): $0.2847 por dólar
Prima Put (90 días): $0.2621 por dólar
Costo total para USD $100,000: $28,470.00 MXN
```

**Interpretación:**
- La prima es el **costo máximo** de la cobertura (se paga al inicio)
- A diferencia del forward, la opción permite participar en movimientos favorables
- Si el tipo de cambio se mueve en tu favor, solo pierdes la prima

### 3. Collar Cambiario

**Descripción**: Combinación de una opción call comprada y una opción put vendida (o viceversa). Reduce el costo de la prima.

**Estructura:**
```
Importador (necesita comprar USD):
  - Compra Call USD/MXN @ strike 17.60 (protege contra alza)
  - Vende Put USD/MXN @ strike 17.40 (financia la prima)
  
Costo neto = Prima Call - Prima Put (puede ser cero o negativo)
```

**Ventajas:**
- ✅ Costo reducido (prima neta cercana a cero)
- ✅ Protección contra movimientos adversos
- ❌ Limita participación en movimientos favorables

### 4. Swap Cambiario (FX Swap)

**Descripción**: Combinación de una transacción spot y una forward simultáneas. Intercambia flujos en diferentes monedas.

**Estructura:**
```
Empresa mexicana con USD $1,000,000 (necesita pesos por 90 días):

Pierna 1 (Spot):
  - Vende USD $1,000,000 @ 17.50 = Recibe $17,500,000 MXN

Pierna 2 (Forward 90 días):
  - Compra USD $1,000,000 @ 17.5714 = Paga $17,571,400 MXN

Costo del swap = $17,571,400 - $17,500,000 = $71,400 MXN
Tasa implícita = ($71,400 / $17,500,000) × (360/90) = 4.08% anual
```

**Casos de uso:**
- Financiamiento temporal en moneda extranjera
- Arbitraje de tasas de interés
- Gestión de liquidez multinacional

## Estrategias por Tipo de Empresa

### Importador (Necesita Comprar USD)

**Perfil**: Empresa que importa mercancía y debe pagar en USD en 30-90 días.

**Riesgo**: Alza del dólar (aumenta costo de mercancía)

**Estrategia recomendada**: **Forward de Compra**

```python
class EstrategiaCoberturaImportador:
    """
    Estrategia de cobertura para importador.
    """
    
    def __init__(self, monto_usd: float, dias_pago: int):
        """
        Inicializa la estrategia.
        
        Args:
            monto_usd: Monto a pagar en USD
            dias_pago: Días para el pago
        """
        self.monto_usd = monto_usd
        self.dias_pago = dias_pago
    
    def calcular_cobertura_forward(self, spot: float,
                                    tiie: float, sofr: float) -> dict:
        """
        Calcula cobertura con forward.
        
        Args:
            spot: Tipo de cambio spot
            tiie: TIIE 28 días
            sofr: SOFR (tasa USD)
        
        Returns:
            Diccionario con detalles de cobertura
        """
        # Calcular forward
        puntos_forward = spot * (tiie - sofr) * self.dias_pago / 360
        forward = spot + puntos_forward
        
        # Costo en pesos (con forward)
        costo_pesos_forward = self.monto_usd * forward
        
        # Costo en pesos (sin cobertura, al spot actual)
        costo_pesos_spot = self.monto_usd * spot
        
        # Diferencial (costo de cobertura)
        diferencial = costo_pesos_forward - costo_pesos_spot
        
        # Escenarios al vencimiento
        escenarios = {
            'dolar_18_00': self.monto_usd * 18.00,
            'dolar_18_50': self.monto_usd * 18.50,
            'dolar_17_00': self.monto_usd * 17.00
        }
        
        # Ahorro/pérdida vs. no cobertura
        ahorro = {
            'dolar_18_00': escenarios['dolar_18_00'] - costo_pesos_forward,
            'dolar_18_50': escenarios['dolar_18_50'] - costo_pesos_forward,
            'dolar_17_00': escenarios['dolar_17_00'] - costo_pesos_forward
        }
        
        return {
            'monto_usd': self.monto_usd,
            'dias': self.dias_pago,
            'spot': spot,
            'forward': forward,
            'puntos_forward': puntos_forward,
            'costo_pesos_forward': costo_pesos_forward,
            'costo_pesos_spot': costo_pesos_spot,
            'diferencial': diferencial,
            'escenarios': escenarios,
            'ahorro_vs_no_cobertura': ahorro
        }


# Ejemplo práctico
if __name__ == "__main__":
    # Importador de autopartes debe pagar USD $100,000 en 90 días
    importador = EstrategiaCoberturaImportador(monto_usd=100000, dias_pago=90)
    
    cobertura = importador.calcular_cobertura_forward(
        spot=17.50,
        tiie=0.1050,
        sofr=0.0525
    )
    
    print("=== Estrategia Importador ===")
    print(f"Monto a pagar: USD ${cobertura['monto_usd']:,.2f}")
    print(f"Plazo: {cobertura['dias']} días")
    print()
    print(f"Spot actual: ${cobertura['spot']:.4f}")
    print(f"Forward 90 días: ${cobertura['forward']:.4f}")
    print(f"Puntos forward: {cobertura['puntos_forward']:.4f}")
    print()
    print(f"Costo con forward: ${cobertura['costo_pesos_forward']:,.2f} MXN")
    print(f"Costo al spot: ${cobertura['costo_pesos_spot']:,.2f} MXN")
    print(f"Diferencial (costo cobertura): ${cobertura['diferencial']:,.2f} MXN")
    print()
    print("=== Escenarios al Vencimiento ===")
    for escenario, monto in cobertura['escenarios'].items():
        ahorro = cobertura['ahorro_vs_no_cobertura'][escenario]
        print(f"{escenario.replace('_', ' ')}: ${monto:,.2f} MXN")
        print(f"  Ahorro vs. no cobertura: ${ahorro:,.2f} MXN")
```

```
Costo con forward: $1,765,750.00 MXN
```

### Empresa con Deuda en USD

**Perfil**: Empresa con préstamo bancario en USD que debe pagar intereses y principal.

**Riesgo**: Alza del dólar (aumenta servicio de deuda en pesos)

**Estrategia recomendada**: **Forward Escalonado** (para cada pago de deuda)

```python
def estrategia_cobertura_deuda(pagos_deuda: list, spot: float,
                                tiie: float, sofr: float) -> list:
    """
    Estrategia de cobertura para deuda en USD.
    
    Args:
        pagos_deuda: Lista de pagos futuros [{'fecha': '2026-06-30', 'monto_usd': 50000}, ...]
        spot: Tipo de cambio spot
        tiie: TIIE
        sofr: SOFR
    
    Returns:
        Lista de forwards recomendados
    """
    from datetime import datetime, timedelta
    
    forwards_recomendados = []
    hoy = datetime.now()
    
    for pago in pagos_deuda:
        fecha_pago = datetime.strptime(pago['fecha'], '%Y-%m-%d')
        dias = (fecha_pago - hoy).days
        
        if dias <= 0:
            continue
        
        # Calcular forward para esta fecha
        puntos_forward = spot * (tiie - sofr) * dias / 360
        forward = spot + puntos_forward
        
        # Costo en pesos
        costo_pesos = pago['monto_usd'] * forward
        
        forwards_recomendados.append({
            'fecha_pago': pago['fecha'],
            'monto_usd': pago['monto_usd'],
            'dias': dias,
            'forward': forward,
            'costo_pesos': costo_pesos,
            'tipo': 'compra'  # Empresa necesita comprar USD para pagar deuda
        })
    
    return forwards_recomendados


# Ejemplo
if __name__ == "__main__":
    # Deuda de USD $200,000 con pagos trimestrales
    pagos_deuda = [
        {'fecha': '2026-06-30', 'monto_usd': 50000},
        {'fecha': '2026-09-30', 'monto_usd': 50000},
        {'fecha': '2026-12-31', 'monto_usd': 50000},
        {'fecha': '2027-03-31', 'monto_usd': 50000}
    ]
    
    forwards = estrategia_cobertura_deuda(
        pagos_deuda,
        spot=17.50,
        tiie=0.1050,
        sofr=0.0525
    )
    
    print("=== Cobertura de Deuda en USD ===")
    total_pesos = 0
    
    for fwd in forwards:
        print(f"Fecha: {fwd['fecha_pago']}")
        print(f"  Monto: USD ${fwd['monto_usd']:,.2f}")
        print(f"  Días: {fwd['dias']}")
        print(f"  Forward: ${fwd['forward']:.4f}")
        print(f"  Costo en pesos: ${fwd['costo_pesos']:,.2f} MXN")
        print()
        total_pesos += fwd['costo_pesos']
    
    print(f"Total comprometido en pesos: ${total_pesos:,.2f} MXN")
```

```python
class ComparadorCoberturas:
    """
    Compara costos de diferentes coberturas.
    """
    
    def __init__(self, monto_usd: float, dias: int):
        """
        Inicializa el comparador.
        
        Args:
            monto_usd: Monto en USD a cubrir
            dias: Plazo de cobertura
        """
        self.monto_usd = monto_usd
        self.dias = dias
    
    def comparar_bancos(self, spot: float, tiie: float, sofr: float) -> pd.DataFrame:
        """
        Compara costos entre bancos.
        
        Args:
            spot: Tipo de cambio spot
            tiie: TIIE
            sofr: SOFR
        
        Returns:
            DataFrame con comparación
        """
        import pandas as pd
        
        # Bancos con sus márgenes aproximados
        bancos = {
            'BBVA': {'margen': 0.025, 'monto_min': 50000},
            'Santander': {'margen': 0.030, 'monto_min': 25000},
            'Banorte': {'margen': 0.030, 'monto_min': 10000},
            'Citibanamex': {'margen': 0.020, 'monto_min': 100000},
            'Scotiabank': {'margen': 0.025, 'monto_min': 50000},
            'HSBC': {'margen': 0.025, 'monto_min': 100000},
            'Inbursa': {'margen': 0.035, 'monto_min': 50000},
            'Banregio': {'margen': 0.035, 'monto_min': 25000}
        }
        
        resultados = []
        
        for banco, datos in bancos.items():
            if self.monto_usd >= datos['monto_min']:
                # Puntos forward base
                puntos_base = spot * (tiie - sofr) * self.dias / 360
                
                # Agregar margen del banco
                puntos_con_margen = puntos_base + (spot * datos['margen'] * self.dias / 360)
                
                # Forward con margen
                forward = spot + puntos_con_margen
                
                # Costo total (diferencial vs. spot)
                costo_total = self.monto_usd * puntos_con_margen
                
                # Costo anualizado
                costo_anualizado = (costo_total / (self.monto_usd * spot)) * (360 / self.dias) * 100
                
                resultados.append({
                    'Banco': banco,
                    'Monto Mín': f"USD ${datos['monto_min']:,.0f}",
                    'Forward': f"${forward:.4f}",
                    'Costo Total': f"${costo_total:,.2f}",
                    'Costo Anualizado': f"{costo_anualizado:.2f}%"
                })
        
        df = pd.DataFrame(resultados)
        return df.sort_values('Costo Anualizado')


# Ejemplo

        tiie=0.1050,
        sofr=0.0525
    )
    
    print("=== Comparativa de Coberturas (USD $100,000, 90 días) ===")
```

```python
def valuar_forward_cierre(monto_usd: float, forward_contrato: float,
                          forward_cierre: float, es_compra: bool = True) -> dict:
    """
    Valúa forward al cierre del periodo.
    
    Args:
        monto_usd: Monto en USD del contrato
        forward_contrato: Tipo de cambio del contrato
        forward_cierre: Tipo de cambio forward al cierre
        es_compra: Si True, es forward de compra
    
    Returns:
        Diccionario con valuación
    """
    # Diferencia en pesos
    diferencia = (forward_cierre - forward_contrato) * monto_usd
    
    if es_compra:
        if diferencia > 0:
            # Ganancia (forward se apreció)
            registro = {
                'tipo': 'ganancia_no_realizada',
                'monto': diferencia,
                'asiento': {
                    'cargo': 'Forward de tipo de cambio (activo)',
                    'abono': 'Utilidad no realizada por valuación de forward'
                }
            }
        else:
            # Pérdida (forward se depreció)
            registro = {
                'tipo': 'perdida_no_realizada',
                'monto': abs(diferencia),
                'asiento': {
                    'cargo': 'Pérdida no realizada por valuación de forward',
                    'abono': 'Forward de tipo de cambio (pasivo)'
                }
            }
    else:  # venta
        if diferencia > 0:
            # Pérdida (para forward de venta)
            registro = {
                'tipo': 'perdida_no_realizada',
                'monto': diferencia,
                'asiento': {
                    'cargo': 'Pérdida no realizada por valuación de forward',
                    'abono': 'Forward de tipo de cambio (pasivo)'
                }
            }
        else:
            # Ganancia
            registro = {
                'tipo': 'ganancia_no_realizada',
                'monto': abs(diferencia),
                'asiento': {
                    'cargo': 'Forward de tipo de cambio (activo)',
                    'abono': 'Utilidad no realizada por valuación de forward'
                }
            }
    
    return registro


# Ejemplo
```

### Anexo C: Fórmulas Financieras

**Forward:**
```
Puntos Forward = Spot × (Tasa_MXN - Tasa_USD) × Días / 360
Forward = Spot + Puntos Forward
```

**Opción (Black-Scholes):**
```
d1 = [ln(S/K) + (r_d - r_f + σ²/2) × T] / (σ × √T)
d2 = d1 - σ × √T

Call = S × e^(-r_f × T) × N(d1) - K × e^(-r_d × T) × N(d2)
Put = K × e^(-r_d × T) × N(-d2) - S × e^(-r_f × T) × N(-d1)
```

**Pérdida/Ganancia Forward:**
```
Pérdida/Ganancia = (Forward_Cierre - Forward_Contrato) × Monto_USD
```
