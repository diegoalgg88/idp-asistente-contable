- **Publicación**: Diciembre 2024

## Los 30 Indicadores Básicos de Sostenibilidad (IBSO)

### Indicadores Ambientales (16 indicadores)

#### 1. Emisiones de Gases de Efecto Invernadero (GEI) - Alcance 1

**Fórmula:**
```
GEI Alcance 1 = Σ (Actividad_i × Factor_Emision_i × PCA_i)

Donde:
- Actividad_i: Cantidad de actividad que genera emisiones (ej. litros de combustible)
- Factor_Emision_i: Factor de emisión del gas i (kg CO2e/unidad)
- PCA_i: Potencial de Calentamiento Atmosférico del gas i
```

**Unidad**: Toneladas de CO2 equivalente (tCO2e)

**Fuentes de datos**:
- Registros de consumo de combustibles
- Inventarios de equipos móviles
- Sistemas de calefacción/refrigeración

**Ejemplo de cálculo:**
```python
# Consumo de diesel: 50,000 litros
# Factor de emisión diesel: 2.68 kg CO2e/litro
emisiones_diesel = 50000 * 2.68 / 1000  # = 134 tCO2e
```

#### 2. Emisiones GEI - Alcance 2 (Energía Comprada)

**Fórmula:**
```
GEI Alcance 2 = Consumo_Electricidad × Factor_Emision_Red
```

**Unidad**: tCO2e

**Factor de emisión red eléctrica México 2025**: 0.4806 tCO2e/MWh (CFE)

#### 3. Emisiones GEI - Alcance 3 (Cadena de Valor)

**Fórmula:**
```
GEI Alcance 3 = Σ (Categoría_i × Factor_Emision_i)

Categorías incluidas:
- Bienes de capital
- Combustibles relacionados con energía
- Actividades upstream de transporte
- Residuos generados en operaciones
- Viajes de negocios
- Desplazamiento de empleados
```

**Unidad**: tCO2e

#### 4. Intensidad de Emisiones de GEI

**Fórmula:**
```
Intensidad_GEI = Emisiones_GEI_Totales / Unidad_Producción

Unidades comunes:
- tCO2e / millón de pesos de ingresos
- tCO2e / unidad producida
- tCO2e / empleado
```

#### 5. Consumo Total de Energía

**Fórmula:**
```
Energía_Total = Energía_Renovable + Energía_No_Renovable

Desglose requerido:
- Electricidad comprada (MWh)
- Combustibles consumidos (GJ)
- Energía renovable generada in situ (MWh)
```

**Unidad**: Gigajoules (GJ) o Megavatios-hora (MWh)

#### 6. Consumo de Agua Total

**Fórmula:**
```
Agua_Total = Agua_Superficial + Agua_Subterranea + Agua_Municipal

Desglose por fuente:
- Agua superficial (ríos, lagos)
- Agua subterránea (pozos)
- Agua municipal (red pública)
- Agua de mar (desalinizada)
```

**Unidad**: Metros cúbicos (m³)

#### 7. Consumo de Agua en Zonas de Estrés Hídrico

**Fórmula:**
```
Agua_Estrés = Σ (Fuente_i × Factor_Estrés_i)

Factor_Estrés:
- Alto estrés: 1.0
- Medio estrés: 0.5
- Bajo estrés: 0.0
```

**Unidad**: m³

#### 8. Descargas de Agua Residual

**Fórmula:**
```
Agua_Residual = Agua_Descargada_Total - Agua_Tratada

Parámetros a reportar:
- DBO5 (Demanda Bioquímica de Oxígeno) mg/L
- DQO (Demanda Química de Oxígeno) mg/L
- SST (Sólidos Suspendidos Totales) mg/L
- Grasas y Aceites mg/L
```

**Unidad**: m³ y mg/L para parámetros

#### 9. Generación Total de Residuos

**Fórmula:**
```
Residuos_Totales = Residuos_Peligrosos + Residuos_No_Peligrosos

Desglose:
- Residuos reciclados
- Residuos recuperados (energía)
- Residuos dispuestos en relleno
- Residuos incinerados
```

**Unidad**: Toneladas

#### 10. Residuos Peligrosos

**Fórmula:**
```
Residuos_Peligrosos = Σ (Tipo_Residuo_i × Peso_i)

Tipos comunes:
- Solventes usados
- Aceites lubricantes
- Baterías
- Lámparas fluorescentes
- Residuos con metales pesados
```

**Unidad**: Toneladas

#### 11. Biodiversidad - Áreas Protegidas o Restauradas

**Fórmula:**
```
Áreas_Protegidas = Área_Total_Interviniente - Área_Impactada

Métricas:
- Hectáreas en áreas naturales protegidas
- Hectáreas restauradas
- Inversión en conservación de biodiversidad
```

**Unidad**: Hectáreas

#### 12. Eficiencia Energética - Mejoras Implementadas

**Fórmula:**
```
Mejora_Eficiencia = (Consumo_Anterior - Consumo_Actual) / Consumo_Anterior × 100

Línea base: Consumo del año anterior
```

**Unidad**: Porcentaje de mejora

#### 13. Inversión en Tecnologías Limpias

**Fórmula:**
```
Inversión_Limpia = Σ (Proyecto_i × Monto_Invertido_i)

Categorías:
- Energías renovables
- Eficiencia energética
- Control de emisiones
- Tratamiento de agua
- Economía circular
```

**Unidad**: Pesos mexicanos (MXN)

#### 14. Huella de Carbono de Productos

**Fórmula:**
```
Huella_Producto = Σ (Etapa_i × Emisiones_i) / Unidades_Producidas

Etapas del ciclo de vida:
- Extracción de materias primas
- Manufactura
- Distribución
- Uso
- Fin de vida
```

**Unidad**: kg CO2e / unidad de producto

#### 15. Incidentes Ambientales

**Fórmula:**
```
Incidentes_Ambientales = Count(Incidentes_Reportados)

Tipos:
- Derrames de materiales peligrosos
- Emisiones no autorizadas
- Multas por incumplimiento ambiental
- Quejas de comunidades por impacto ambiental
```

**Unidad**: Número de incidentes

#### 16. Cumplimiento Normativo Ambiental

**Fórmula:**
```
Cumplimiento_Ambiental = (Permisos_Vigentes / Permisos_Requiredos) × 100

Permisos comunes:
- Licencia ambiental
- Permiso de descargas
- Permiso de emisiones atmosféricas
- Manifestación de impacto ambiental
```

**Unidad**: Porcentaje de cumplimiento

### Indicadores Sociales (6 indicadores)

#### 17. Diversidad de Género en Consejo de Administración

**Fórmula:**
```
Diversidad_Género_Consejo = (Mujeres_en_Consejo / Total_Consejeros) × 100
```

**Unidad**: Porcentaje

**Meta recomendada**: ≥30% mujeres en consejo

#### 18. Brecha Salarial de Género

**Fórmula:**
```
Brecha_Salarial = (Salario_Promedio_Hombres - Salario_Promedio_Mujeres) / Salario_Promedio_Hombres × 100

Cálculo por nivel:
- Alta dirección
- Mandos medios
- Operativos
```

**Unidad**: Porcentaje

#### 19. Rotación de Personal

**Fórmula:**
```
Rotación = (Bajas_Voluntarias + Bajas_Involuntarias) / Promedio_Empleados × 100

Desglose:
- Rotación voluntaria
- Rotación involuntaria
- Rotación por género
- Rotación por edad (<30, 30-50, >50)
```

**Unidad**: Porcentaje anual

#### 20. Capacitación y Desarrollo

**Fórmula:**
```
Horas_Capacitación = Total_Horas_Capacitación / Total_Empleados

Inversión_Capacitación = Total_Invertido_Capacitación / Total_Nómina × 100
```

**Unidad**: Horas/empleado, Porcentaje de nómina

#### 21. Accidentes y Enfermedades de Trabajo

**Fórmula:**
```
Índice_Frecuencia = (Número_Accidentes / Horas_Hombre_Trabajadas) × 1,000,000
Índice_Gravedad = (Días_Perdidos / Horas_Hombre_Trabajadas) × 1,000

Accidentes reportables:
- Con tiempo perdido
- Con tiempo restringido
- Sin tiempo perdido
- Enfermedades ocupacionales
```

**Unidad**: Índice por millón de horas

#### 22. Inversión en Comunidades

**Fórmula:**
```
Inversión_Comunidades = Σ (Programa_i × Monto_Invertido_i)

Categorías:
- Educación
- Salud
- Infraestructura comunitaria
- Desarrollo económico local
- Voluntariado corporativo (horas)
```

**Unidad**: Pesos mexicanos (MXN), Horas de voluntariado

### Indicadores de Gobernanza (8 indicadores)

#### 23. Composición del Consejo de Administración

**Fórmula:**
```
Consejo_Independiente = (Consejeros_Independientes / Total_Consejeros) × 100

Composición requerida:
- Consejeros independientes (%)
- Consejeros propietarios (%)
- Consejeros suplentes (%)
- Diversidad de género (%)
- Diversidad de edad (%)
```

**Unidad**: Porcentaje

#### 24. Remuneración de Ejecutivos

**Fórmula:**
```
Ratio_CEO_Promedio = Remuneración_CEO / Remuneración_Promedio_Empleados

Remuneración_CEO incluye:
- Sueldo fijo
- Bonos variables
- Opciones sobre acciones
- Prestaciones
```

**Unidad**: Ratio (veces)

#### 25. Ética y Compliance

**Fórmula:**
```
Capacitación_Ética = (Empleados_Capacitados / Total_Empleados) × 100

Canales_Denuncia = Count(Canales_Disponibles)

Seguimiento:
- Denuncias recibidas
- Denuncias investigadas
- Denuncias resueltas
- Tiempo promedio de resolución
```

**Unidad**: Porcentaje, Número de canales

#### 26. Gestión de Riesgos

**Fórmula:**
```
Riesgos_Identificados = Count(Riesgos_ESG_Mapeados)

Riesgos_Cuántificados = (Riesgos_Con_Impacto_Económico / Riesgos_Totales) × 100

Categorías de riesgo:
- Riesgos climáticos físicos
- Riesgos de transición
- Riesgos sociales
- Riesgos de gobernanza
```

**Unidad**: Número, Porcentaje

#### 27. Ciberseguridad y Protección de Datos

**Fórmula:**
```
Inversión_Ciberseguridad = Total_Invertido_Seguridad_TI / Presupuesto_TI_Total × 100

Incidentes_Seguridad = Count(Incidentes_Reportados)

Incidentes incluyen:
- Brechas de datos
- Ataques de ransomware
- Phishing exitoso
- Pérdida de información
```

**Unidad**: Porcentaje, Número de incidentes

#### 28. Calidad de Auditoría

**Fórmula:**
```
Rotación_Auditor = Años_Desde_Ultimo_Cambio

Comité_Auditoría = (Miembros_Independientes / Total_Miembros) × 100

Reuniones_Comité = Count(Reuniones_Realizadas)
```

**Unidad**: Años, Porcentaje, Número de reuniones

#### 29. Derechos de Accionistas Minoritarios

**Fórmula:**
```
Accionistas_Minoritarios_en_Consejo = (Consejeros_Minoritarios / Total_Consejeros) × 100

Voto_Distinto = Count(Temas_Con_Voto_Distinto)

Transparencia = (Información_Revelada / Información_Requerida) × 100
```

**Unidad**: Porcentaje, Número

#### 30. Transparencia Fiscal

**Fórmula:**
```
Tasa_Efectiva_ISR = (ISR_Pagado / Utilidad_Antes_Impuestos) × 100

Pago_ISR_Por_País = Σ (País_i × ISR_Pagado_i)

Revelación país por país requerida para empresas multinacionales
```

**Unidad**: Porcentaje, Pesos mexicanos por país

## Implementación Técnica

### Funciones Python para Cálculo de Indicadores

```python
"""
Módulo: calculadora_indicadores_nis_b1.py
Propósito: Calcular los 30 indicadores básicos de sostenibilidad NIS B-1
Versión: 1.0
Fecha: 2026-03-10
"""

from dataclasses import dataclass
from typing import Dict, List, Optional
from decimal import Decimal
from datetime import datetime


@dataclass
class IndicadorESG:
    """Representa un indicador ESG de la NIS B-1."""
    codigo: str  # ej. 'A1', 'S3', 'G5'
    nombre: str
    categoria: str  # 'ambiental', 'social', 'gobernanza'
    valor: float
    unidad: str
    meta: Optional[float] = None
    cumplimiento: Optional[float] = None


class CalculadoraIndicadoresNISB1:
    """
    Calcula indicadores básicos de sostenibilidad según NIS B-1.
    """
    
    def __init__(self):
        """Inicializa la calculadora."""
        self.indicadores: List[IndicadorESG] = []
    
    def calcular_emisiones_gei_alcance1(self, 
                                         combustibles: Dict[str, float]) -> float:
        """
        Calcula emisiones GEI Alcance 1 (emisiones directas).
        
        Args:
            combustibles: Diccionario {tipo_combustible: cantidad_litros_kg}
        
        Returns:
            Emisiones totales en tCO2e
        """
        # Factores de emisión (kg CO2e/unidad)
        factores_emision = {
            'diesel': 2.68,  # kg CO2e/litro
            'gasolina': 2.31,  # kg CO2e/litro
            'gas_natural': 2.02,  # kg CO2e/m³
            'carbón': 2.86,  # kg CO2e/kg
            'propano': 1.55,  # kg CO2e/litro
        }
        
        emisiones_totales = 0
        
        for combustible, cantidad in combustibles.items():
            if combustible in factores_emision:
                emisiones = cantidad * factores_emision[combustible]
                emisiones_totales += emisiones
        
        # Convertir a toneladas
        return emisiones_totales / 1000
    
    def calcular_emisiones_alcance2(self, 
                                     consumo_electricidad_mwh: float,
                                     factor_emision_red: float = 0.4806) -> float:
        """
        Calcula emisiones GEI Alcance 2 (energía comprada).
        
        Args:
            consumo_electricidad_mwh: Consumo en MWh
            factor_emision_red: Factor de emisión de CFE (default 0.4806 tCO2e/MWh)
        
        Returns:
            Emisiones en tCO2e
        """
        return consumo_electricidad_mwh * factor_emision_red
    
    def calcular_intensidad_emisiones(self, 
                                       emisiones_totales: float,
                                       ingresos_millones: float) -> float:
        """
        Calcula intensidad de emisiones de GEI.
        
        Args:
            emisiones_totales: Emisiones totales en tCO2e
            ingresos_millones: Ingresos en millones de pesos
        
        Returns:
            Intensidad en tCO2e/millón de pesos
        """
        if ingresos_millones == 0:
            return 0
        
        return emisiones_totales / ingresos_millones
    
    def calcular_consumo_agua_total(self, 
                                     fuentes: Dict[str, float]) -> float:
        """
        Calcula consumo total de agua.
        
        Args:
            fuentes: Diccionario {fuente: volumen_m3}
        
        Returns:
            Consumo total en m³
        """
        return sum(fuentes.values())
    
    def calcular_agua_zonas_estres(self, 
                                    fuentes: Dict[str, float],
                                    factores_estres: Dict[str, float]) -> float:
        """
        Calcula consumo de agua en zonas de estrés hídrico.
        
        Args:
            fuentes: Diccionario {fuente: volumen_m3}
            factores_estres: Diccionario {fuente: factor_estres 0-1}
        
        Returns:
            Consumo ponderado en m³
        """
        consumo_ponderado = 0
        
        for fuente, volumen in fuentes.items():
            factor = factores_estres.get(fuente, 0)
            consumo_ponderado += volumen * factor
        
        return consumo_ponderado
    
    def calcular_rotacion_personal(self, 
                                    bajas_voluntarias: int,
                                    bajas_involuntarias: int,
                                    promedio_empleados: int) -> float:
        """
        Calcula rotación de personal.
        
        Args:
            bajas_voluntarias: Número de bajas voluntarias
            bajas_involuntarias: Número de bajas involuntarias
            promedio_empleados: Promedio de empleados en el período
        
        Returns:
            Porcentaje de rotación
        """
        if promedio_empleados == 0:
            return 0
        
        total_bajas = bajas_voluntarias + bajas_involuntarias
        rotacion = (total_bajas / promedio_empleados) * 100
        
        return rotacion
    
    def calcular_brecha_salarial_genero(self, 
                                         salario_promedio_hombres: float,
                                         salario_promedio_mujeres: float) -> float:
        """
        Calcula brecha salarial de género.
        
        Args:
            salario_promedio_hombres: Salario promedio de hombres
            salario_promedio_mujeres: Salario promedio de mujeres
        
        Returns:
            Brecha salarial en porcentaje
        """
        if salario_promedio_hombres == 0:
            return 0
        
        brecha = ((salario_promedio_hombres - salario_promedio_mujeres) 
                  / salario_promedio_hombres * 100)
        
        return brecha
    
    def calcular_diversidad_genero_consejo(self, 
                                            mujeres_consejo: int,
                                            total_consejeros: int) -> float:
        """
        Calcula diversidad de género en consejo.
        
        Args:
            mujeres_consejo: Número de mujeres en consejo
            total_consejeros: Total de consejeros
        
        Returns:
            Porcentaje de mujeres en consejo
        """
        if total_consejeros == 0:
            return 0
        
        return (mujeres_consejo / total_consejeros) * 100
    
    def calcular_indice_frecuencia_accidentes(self, 
                                               numero_accidentes: int,
                                               horas_hombre_trabajadas: int) -> float:
        """
        Calcula índice de frecuencia de accidentes.
        
        Args:
            numero_accidentes: Número de accidentes
            horas_hombre_trabajadas: Total de horas-hombre trabajadas
        
        Returns:
            Índice por millón de horas-hombre
        """
        if horas_hombre_trabajadas == 0:
            return 0
        
        indice = (numero_accidentes / horas_hombre_trabajadas) * 1_000_000
        
        return indice
    
    def calcular_tasa_efectiva_isr(self, 
                                    isr_pagado: float,
                                    utilidad_antes_impuestos: float) -> float:
        """
        Calcula tasa efectiva de ISR.
        
        Args:
            isr_pagado: ISR pagado en el ejercicio
            utilidad_antes_impuestos: Utilidad antes de impuestos
        
        Returns:
            Tasa efectiva en porcentaje
        """
        if utilidad_antes_impuestos == 0:
            return 0
        
        tasa = (isr_pagado / utilidad_antes_impuestos) * 100
        
        return tasa
    
    def agregar_indicador(self, indicador: IndicadorESG):
        """
        Agrega un indicador calculado.
        
        Args:
            indicador: Objeto IndicadorESG
        """
        self.indicadores.append(indicador)
    
    def generar_reporte_completo(self, 
                                  empresa: str,
                                  ejercicio: int) -> str:
        """
        Genera reporte completo de indicadores NIS B-1.
        
        Args:
            empresa: Nombre de la empresa
            ejercicio: Año del ejercicio
        
        Returns:
            Reporte en formato texto
        """
        reporte = f"""
================================================================================
         REPORTE DE INDICADORES BÁSICOS DE SOSTENIBILIDAD (NIS B-1)
================================================================================
Empresa: {empresa}
Ejercicio: {ejercicio}
Fecha de generación: {datetime.now().strftime('%Y-%m-%d')}
================================================================================

RESUMEN EJECUTIVO
-----------------
Total de indicadores calculados: {len(self.indicadores)}

Indicadores Ambientales: {len([i for i in self.indicadores if i.categoria == 'ambiental'])}
Indicadores Sociales: {len([i for i in self.indicadores if i.categoria == 'social'])}
Indicadores de Gobernanza: {len([i for i in self.indicadores if i.categoria == 'gobernanza'])}

INDICADORES AMBIENTALES
-----------------------
"""
        
        for ind in self.indicadores:
            if ind.categoria == 'ambiental':
                reporte += f"""
{ind.codigo} - {ind.nombre}
  Valor: {ind.valor} {ind.unidad}
  Meta: {ind.meta if ind.meta else 'N/A'}
  Cumplimiento: {ind.cumplimiento if ind.cumplimiento else 'N/A'}%
"""
        
        reporte += """
INDICADORES SOCIALES
--------------------
"""
        
        for ind in self.indicadores:
            if ind.categoria == 'social':
                reporte += f"""
{ind.codigo} - {ind.nombre}
  Valor: {ind.valor} {ind.unidad}
  Meta: {ind.meta if ind.meta else 'N/A'}
  Cumplimiento: {ind.cumplimiento if ind.cumplimiento else 'N/A'}%
"""
        
        reporte += """
INDICADORES DE GOBERNANZA
-------------------------
"""
        
        for ind in self.indicadores:
            if ind.categoria == 'gobernanza':
                reporte += f"""
{ind.codigo} - {ind.nombre}
  Valor: {ind.valor} {ind.unidad}
  Meta: {ind.meta if ind.meta else 'N/A'}
  Cumplimiento: {ind.cumplimiento if ind.cumplimiento else 'N/A'}%
"""
        
        reporte += """
================================================================================
"""
        
        return reporte
```
