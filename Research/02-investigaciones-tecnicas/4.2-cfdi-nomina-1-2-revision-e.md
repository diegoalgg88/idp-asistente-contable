## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar guía técnica completa del Complemento de Nómina 1.2 Revisión E vigente desde el 1 de enero de 2026, incluyendo:
- Estructura XML del complemento (nomina12.xsd)
- Catálogos actualizados 2026 (TipoPercepción, TipoDeducción, TipoHoras, TipoRegimen, etc.)
- Nuevas claves agregadas en 2026 (054, 055, 108, 109, 110, 111)
- Reglas de validación de la matriz de errores (NOM75, NOM101, NOM108, NOM109, NOM110)
- Campos obligatorios del CFDI 4.0 con complemento de nómina
- Generación de cadena original del complemento
- Ejemplos de XML completo con todos los conceptos

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Captura manual de conceptos | Por nómina | 30-60 min/nómina | 5 min/nómina | 85-90% |
| Búsqueda de claves en catálogos | Por concepto | 2-3 min/concepto | 10 seg/concepto | 90-95% |
| Validación de importes gravados/exentos | Por trabajador | 5-10 min/trabajador | Automático | 100% |
| Verificación de reglas SAT | Por timbrado | 10-15 min/timbrado | Automático | 100% |
| Corrección de errores de timbrado | Por error | 15-30 min/error | 2-5 min/error | 70-80% |

### 1.3 Dolor Principal que Resuelve

**Problema:** El Complemento de Nómina 1.2 Revisión E tiene reglas de validación estrictas que causan rechazos de timbrado:
- Importes gravados y exentos no pueden ser ambos cero
- Clave 038 "Otros ingresos por salarios" debe ser 100% gravada
- Nuevas claves obligatorias para días de descanso laborados
- Subsidio al empleo actualizado a $628.00 mensuales

Un rechazo de timbrado causa:
- Retraso en pago de nómina (multas STPS)
- Horas extra de personal de nómina
- Insatisfacción de empleados

**Solución IDP-App:** Validación pre-timbrado con reglas de la matriz de errores, sugerencia automática de claves correctas, y corrección de errores antes de enviar a PAC.

### 3.2 Algoritmos Específicos

#### Algoritmo 1: Generador de CFDI de Nómina 1.2 Revisión E

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional
from datetime import datetime, date
from decimal import Decimal, ROUND_HALF_UP
import xml.etree.ElementTree as ET
from xml.dom import minidom


@dataclass
class Percepcion:
    """Representa una percepción de nómina."""
    TipoPercepcion: str  # Clave del catálogo c_TipoPercepcion
    Clave: str  # Clave interna de la empresa
    Concepto: str  # Descripción del concepto
    ImporteGravado: Decimal
    ImporteExento: Decimal


@dataclass
class Deduccion:
    """Representa una deducción de nómina."""
    TipoDeduccion: str  # Clave del catálogo c_TipoDeduccion
    Clave: str  # Clave interna de la empresa
    Concepto: str  # Descripción del concepto
    ImporteGravado: Decimal
    ImporteExento: Decimal


@dataclass
class OtroPago:
    """Representa un otro pago de nómina."""
    TipoOtroPago: str  # Clave del catálogo c_TipoOtroPago
    Clave: str  # Clave interna de la empresa
    Concepto: str  # Descripción del concepto
    Importe: Decimal


@dataclass
class DatosTrabajador:
    """Datos del trabajador para el complemento de nómina."""
    NumEmpleado: str
    Curp: str
    TipoContrato: str  # Catálogo c_TipoContrato
    TipoJornada: str  # Catálogo c_TipoJornada
    Puesto: str  # Código de puesto
    ClaveEntidadFederativa: str  # Catálogo c_Estado
    ClaveMunicipio: str  # Catálogo c_Municipio
    RiesgoPuesto: str  # Clase de riesgo (1-5)


@dataclass
class DatosNomina:
    """Datos de la nómina para el complemento."""
    TipoNomina: str = 'O'  # O=Ordinaria, C=Complementaria
    TipoRegimen: str = '01'  # Catálogo c_TipoRegimen
    FechaPago: date
    FechaInicialPago: date
    FechaFinalPago: date
    NumDiasPagados: int
    SalarioDiarioIntegrado: Decimal
    Trabajador: DatosTrabajador
    Percepciones: List[Percepcion] = field(default_factory=list)
    Deducciones: List[Deduccion] = field(default_factory=list)
    OtrosPagos: List[OtroPago] = field(default_factory=list)


class CFDINominaGenerator:
    """
    Genera CFDI de Nómina 1.2 Revisión E válido según especificaciones del SAT.
    Implementa validaciones de la matriz de errores 2026.
    """
    
    VERSION_CFDI = '4.0'
    VERSION_NOMINA = '1.2'
    REVISION_NOMINA = 'E'
    NAMESPACE_CFDI = 'http://www.sat.gob.mx/cfd/4'
    NAMESPACE_NOMINA12 = 'http://www.sat.gob.mx/nomina12'
    
    def __init__(self, rfc_emisor: str, nombre_emisor: str, regimen_fiscal: str):
        """
        Inicializa el generador de CFDI de nómina.
        
        Args:
            rfc_emisor: RFC del patrón
            nombre_emisor: Nombre o razón social del patrón
            regimen_fiscal: Régimen fiscal del patrón (catálogo c_RegimenFiscal)
        """
        self.rfc_emisor = rfc_emisor
        self.nombre_emisor = nombre_emisor
        self.regimen_fiscal = regimen_fiscal
    
    def validar_reglas_nomina(self, datos_nomina: DatosNomina) -> List[Dict]:
        """
        Valida reglas de la matriz de errores 2026.
        
        Args:
            datos_nomina: Datos de la nómina a validar
            
        Returns:
            Lista de errores encontrados (vacía si todo es válido)
        """
        errores = []
        
        # Validar NOM75: Importe gravado y exento no pueden ser ambos cero
        for percepcion in datos_nomina.Percepciones:
            if percepcion.ImporteGravado == 0 and percepcion.ImporteExento == 0:
                errores.append({
                    'codigo': 'NOM75',
                    'concepto': percepcion.Concepto,
                    'mensaje': 'Importe gravado y exento no pueden ser ambos cero',
                    'severidad': 'ERROR'
                })
        
        for deduccion in datos_nomina.Deducciones:
            if deduccion.ImporteGravado == 0 and deduccion.ImporteExento == 0:
                errores.append({
                    'codigo': 'NOM75',
                    'concepto': deduccion.Concepto,
                    'mensaje': 'Importe gravado y exento no pueden ser ambos cero',
                    'severidad': 'ERROR'
                })
        
        # Validar NOM101: Clave 038 debe ser 100% gravada
        for percepcion in datos_nomina.Percepciones:
            if percepcion.TipoPercepcion == '038' and percepcion.ImporteExento > 0:
                errores.append({
                    'codigo': 'NOM101',
                    'concepto': percepcion.Concepto,
                    'mensaje': 'Clave 038 "Otros ingresos por salarios" debe ser 100% gravada (ImporteExento=0)',
                    'severidad': 'ERROR'
                })
        
        # Validar NOM108: Subsidio causado en rango
        for otro_pago in datos_nomina.OtrosPagos:
            if otro_pago.TipoOtroPago == '001':  # Subsidio al empleo
                if not (Decimal('628.00') <= otro_pago.Importe <= Decimal('12976.88')):
                    errores.append({
                        'codigo': 'NOM108',
                        'concepto': otro_pago.Concepto,
                        'mensaje': f'Subsidio al empleo fuera de rango ($628.00 - $12,976.88). Importe: ${otro_pago.Importe}',
                        'severidad': 'ERROR'
                    })
        
        # Validar NOM109: Días de descanso deben usar claves 054 o 055
        for percepcion in datos_nomina.Percepciones:
            if 'descanso' in percepcion.Concepto.lower():
                if percepcion.TipoPercepcion not in ['054', '055']:
                    errores.append({
                        'codigo': 'NOM109',
                        'concepto': percepcion.Concepto,
                        'mensaje': f'Días de descanso deben usar TipoPercepcion 054 o 055. Actual: {percepcion.TipoPercepcion}',
                        'severidad': 'ERROR'
                    })
        
        # Validar NOM110: Ajustes de días de descanso deben usar deducciones 108-111
        for deduccion in datos_nomina.Deducciones:
            if 'ajuste' in deduccion.Concepto.lower() and 'descanso' in deduccion.Concepto.lower():
                if deduccion.TipoDeduccion not in ['108', '109', '110', '111']:
                    errores.append({
                        'codigo': 'NOM110',
                        'concepto': deduccion.Concepto,
                        'mensaje': f'Ajuste de días de descanso debe usar TipoDeduccion 108, 109, 110 o 111. Actual: {deduccion.TipoDeduccion}',
                        'severidad': 'ERROR'
                    })
        
        return errores
    
    def calcular_totales(self, datos_nomina: DatosNomina) -> Dict:
        """
        Calcula totales de percepciones y deducciones.
        
        Args:
            datos_nomina: Datos de la nómina
            
        Returns:
            Dict con totales calculados
        """
        total_percepciones_gravado = sum(p.ImporteGravado for p in datos_nomina.Percepciones)
        total_percepciones_exento = sum(p.ImporteExento for p in datos_nomina.Percepciones)
        total_deducciones_gravado = sum(d.ImporteGravado for d in datos_nomina.Deducciones)
        total_deducciones_exento = sum(d.ImporteExento for d in datos_nomina.Deducciones)
        total_otros_pagos = sum(o.Importe for o in datos_nomina.OtrosPagos)
        
        # Total de nómina = Total percepciones - Total deducciones + Otros pagos
        total_nomina = (total_percepciones_gravado + total_percepciones_exento) - \
                       (total_deducciones_gravado + total_deducciones_exento) + \
                       total_otros_pagos
        
        return {
            'TotalPercepcionesGravado': total_percepciones_gravado.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'TotalPercepcionesExento': total_percepciones_exento.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'TotalDeduccionesGravado': total_deducciones_gravado.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'TotalDeduccionesExento': total_deducciones_exento.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'TotalOtrosPagos': total_otros_pagos.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'TotalNomina': total_nomina.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        }
    
    def generar_xml(self, datos_nomina: DatosNomina, lugar_expedicion: str, 
                    serie: str, folio: int) -> str:
        """
        Genera XML de CFDI de Nómina 1.2 Revisión E.
        
        Args:
            datos_nomina: Datos de la nómina
            lugar_expedicion: Código postal del lugar de expedición
            serie: Serie del comprobante
            folio: Folio del comprobante
            
        Returns:
            str: Contenido XML del CFDI de nómina
        """
        # Validar reglas antes de generar
        errores = self.validar_reglas_nomina(datos_nomina)
        if errores:
            raise ValueError(f"Errores de validación: {errores}")
        
        # Calcular totales
        totales = self.calcular_totales(datos_nomina)
        
        # Crear elemento raíz Comprobante
        comprobante = ET.Element('{http://www.sat.gob.mx/cfd/4}Comprobante')
        comprobante.set('Version', self.VERSION_CFDI)
        comprobante.set('Serie', serie)
        comprobante.set('Folio', str(folio))
        comprobante.set('Fecha', datetime.now().strftime('%Y-%m-%dT%H:%M:%S'))
        comprobante.set('FormaPago', '99')  # 99 = Por definir
        comprobante.set('SubTotal', str(totales['TotalPercepcionesGravado'] + totales['TotalPercepcionesExento']))
        comprobante.set('Descuento', '0.00')
        comprobante.set('Moneda', 'MXN')
        comprobante.set('Total', str(totales['TotalNomina']))
        comprobante.set('TipoDeComprobante', 'N')  # N = Nómina
        comprobante.set('MetodoPago', 'PUE')  # PUE = Pago en una sola exhibición
        comprobante.set('LugarExpedicion', lugar_expedicion)
        comprobante.set('Exportacion', '01')  # 01 = No aplica
        
        # Emisor

        xml_pretty = dom.toprettyxml(indent='  ', encoding='utf-8').decode('utf-8')
```
