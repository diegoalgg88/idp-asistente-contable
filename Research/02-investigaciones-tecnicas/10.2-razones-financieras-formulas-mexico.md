## Razones de Liquidez (8 Razones)

### 1. Liquidez Circulante (Current Ratio)

**Fórmula:**
```
Liquidez Circulante = Activo Circulante / Pasivo Circulante
```

**Interpretación:**
Mide la capacidad de la empresa para cubrir sus obligaciones a corto plazo con sus activos más líquidos. Indica cuántos pesos de activo circulante existen por cada peso de pasivo circulante.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 1.2 | 1.5-2.0 | 2.5 |
| Servicios | 1.0 | 1.3-1.8 | 2.2 |
| Manufactura | 1.5 | 2.0-2.5 | 3.0 |
| Tecnología | 1.5 | 2.0-3.0 | 4.0 |

**Ejemplo Práctico (Empresa Mexicana):**
```
FEMSA (2024):
Activo Circulante: $342,311 millones MXN
Pasivo Circulante: $202,930 millones MXN

Liquidez Circulante = 342,311 / 202,930 = 1.69
```

**Interpretación del Ejemplo:**
FEMSA tiene $1.69 pesos de activo circulante por cada peso de pasivo circulante. Está dentro del rango óptimo para comercio (1.5-2.5), indicando liquidez adecuada.

**Limitaciones:**
- No considera la calidad de los activos (inventarios obsoletos, cuentas incobrables)
- Es una fotografía estática (puede mejorar con ventana de pago)

---

### 2. Prueba Ácida (Quick Ratio)

**Fórmula:**
```
Prueba Ácida = (Activo Circulante - Inventarios) / Pasivo Circulante
```

**Interpretación:**
Mide la capacidad de pago inmediato sin depender de la venta de inventarios. Más conservadora que la liquidez circulante.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 0.8 | 1.0-1.5 | 1.8 |
| Servicios | 0.9 | 1.2-1.6 | 2.0 |
| Manufactura | 0.7 | 1.0-1.3 | 1.6 |
| Tecnología | 1.0 | 1.5-2.0 | 2.5 |

**Ejemplo Práctico:**
```
Empresa Comercial SA:
Activo Circulante: $5,000,000 MXN
Inventarios: $2,000,000 MXN
Pasivo Circulante: $2,500,000 MXN

Prueba Ácida = (5,000,000 - 2,000,000) / 2,500,000 = 1.20
```

**Interpretación:**
La empresa puede cubrir 120% de sus obligaciones inmediatas sin vender inventarios. Rango óptimo para comercio.

---

### 3. Capital de Trabajo

**Fórmula:**
```
Capital de Trabajo = Activo Circulante - Pasivo Circulante
```

**Interpretación:**
Representa los recursos líquidos disponibles para operar el negocio después de cubrir obligaciones corto plazo. Se expresa en pesos, no como razón.

**Ejemplo Práctico:**
```
Grupo Bimbo (2024):
Activo Circulante: $85,000 millones MXN
Pasivo Circulante: $65,000 millones MXN

Capital de Trabajo = 85,000 - 65,000 = $20,000 millones MXN
```

**Interpretación:**
Bimbo tiene $20,000 millones de pesos libres para operar, invertir o crecer después de pagar sus deudas corto plazo.

---

### 4. Liquidez Inmediata (Cash Ratio)

**Fórmula:**
```
Liquidez Inmediata = Disponible / Pasivo Circulante
```

Donde **Disponible** = Efectivo + Equivalentes al efectivo

**Interpretación:**
Mide la capacidad de pago inmediato con el efectivo disponible. Es la medida más conservadora de liquidez.

**Rango Óptimo:**
- **Mínimo**: 0.2 (20% de cobertura)
- **Óptimo**: 0.3-0.5 (30-50% de cobertura)
- **Máximo**: 0.6 (exceso de efectivo puede indicar ineficiencia)

**Ejemplo Práctico:**
```
América Móvil (2024):
Efectivo y equivalentes: $180,000 millones MXN
Pasivo Circulante: $450,000 millones MXN

Liquidez Inmediata = 180,000 / 450,000 = 0.40
```

**Interpretación:**
América Móvil puede cubrir 40% de sus obligaciones inmediatas con el efectivo disponible. Dentro del rango óptimo.

---

### 5. Intervalo Defensivo

**Fórmula:**
```
Intervalo Defensivo = (Activo Circulante - Inventarios) / Gastos Operativos Diarios
```

Donde **Gastos Operativos Diarios** = (Costo de Ventas + Gastos de Operación) / 365

**Interpretación:**
Número de días que la empresa puede operar con sus activos líquidos sin generar ingresos. Mide resistencia en escenarios de crisis.

**Ejemplo Práctico:**
```
Empresa Servicios SA:
Activo Circulante: $3,000,000 MXN
Inventarios: $300,000 MXN
Costo de Ventas Anual: $8,000,000 MXN
Gastos de Operación Anual: $4,000,000 MXN

Gastos Operativos Diarios = (8,000,000 + 4,000,000) / 365 = $32,877 MXN

Intervalo Defensivo = (3,000,000 - 300,000) / 32,877 = 82 días
```

**Interpretación:**
La empresa puede operar 82 días sin ingresos antes de agotar sus recursos líquidos. **Mínimo recomendado: 60 días**.

---

### 6. Razón de Efectivo

**Fórmula:**
```
Razón de Efectivo = Efectivo / Pasivo Circulante
```

**Interpretación:**
Similar a liquidez inmediata pero solo considera efectivo en caja y bancos (no incluye inversiones temporales).

**Rango Óptimo:**
- **Mínimo**: 0.15
- **Óptimo**: 0.25-0.40
- **Máximo**: 0.50

---

### 7. Ciclo de Conversión de Efectivo (CCC)

**Fórmula:**
```
CCC = Período Promedio de Cobro + Período Promedio de Inventario - Período Promedio de Pago
```

Donde:
- **Período Promedio de Cobro** = (Cuentas por Cobrar Promedio × 365) / Ventas a Crédito
- **Período Promedio de Inventario** = (Inventario Promedio × 365) / Costo de Ventas
- **Período Promedio de Pago** = (Cuentas por Pagar Promedio × 365) / Compras a Crédito

**Interpretación:**
Número de días que transcurren entre el desembolso de efectivo para adquirir/crear un producto y el cobro de la venta. **Menor es mejor**.

**Ejemplo Práctico (Walmart de México):**
```
Cuentas por Cobrar Promedio: $15,000 millones MXN
Ventas a Crédito: $450,000 millones MXN
Inventario Promedio: $90,000 millones MXN
Costo de Ventas: $380,000 millones MXN
Cuentas por Pagar Promedio: $120,000 millones MXN
Compras a Crédito: $400,000 millones MXN

Período de Cobro = (15,000 × 365) / 450,000 = 12 días
Período de Inventario = (90,000 × 365) / 380,000 = 86 días
Período de Pago = (120,000 × 365) / 400,000 = 109 días

CCC = 12 + 86 - 109 = -11 días
```

**Interpretación:**
Walmart tiene un **CCC negativo**, lo que significa que cobra antes de pagar a proveedores. Modelo de negocio muy eficiente (financia operaciones con dinero de proveedores).

**Rango por Industria:**

| Industria | CCC Óptimo |
|-----------|------------|
| Retail | -10 a 20 días |
| Manufactura | 30-60 días |
| Servicios | 15-30 días |
| Tecnología | 20-45 días |

---

### 8. Período Promedio de Pago (PPP)

**Fórmula:**
```
PPP = (Cuentas por Pagar Promedio × 365) / Compras a Crédito
```

**Interpretación:**
Días promedio que la empresa tarda en pagar a sus proveedores. Un PPP muy alto puede indicar problemas de liquidez; muy bajo, desaprovechamiento de financiamiento de proveedores.

**Rango Óptimo:**
- **Mínimo**: 30 días
- **Óptimo**: 45-75 días
- **Máximo**: 90 días (puede afectar relaciones con proveedores)

## Razones de Solvencia/Endeudamiento (7 Razones)

### 9. Deuda/Patrimonio (Debt-to-Equity)

**Fórmula:**
```
Deuda/Patrimonio = Pasivo Total / Patrimonio Contable
```

**Interpretación:**
Mide el grado de apalancamiento financiero. Indica cuánto se debe por cada peso de capital de los accionistas.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 0.3 | 0.5-1.0 | 1.5 |
| Servicios | 0.2 | 0.4-0.8 | 1.2 |
| Manufactura | 0.4 | 0.6-1.2 | 1.8 |
| Tecnología | 0.1 | 0.3-0.7 | 1.0 |
| Utilities | 0.8 | 1.2-2.0 | 2.5 |

**Ejemplo Práctico (Grupo México):**
```
Pasivo Total: $280,000 millones MXN
Patrimonio: $320,000 millones MXN

Deuda/Patrimonio = 280,000 / 320,000 = 0.875
```

**Interpretación:**
Grupo México tiene $0.875 pesos de deuda por cada peso de capital. Dentro del rango óptimo para manufactura (0.6-1.2).

---

### 10. Deuda/Activo (Debt Ratio)

**Fórmula:**
```
Deuda/Activo = Pasivo Total / Activo Total
```

**Interpretación:**
Porcentaje de los activos financiado con deuda. Mide el riesgo financiero total de la empresa.

**Rango Óptimo:**
- **Mínimo**: 0.2 (20%)
- **Óptimo**: 0.3-0.6 (30-60%)
- **Máximo**: 0.7 (70% - alto riesgo)

**Ejemplo Práctico:**
```
Cemex (2024):
Pasivo Total: $350,000 millones MXN
Activo Total: $500,000 millones MXN

Deuda/Activo = 350,000 / 500,000 = 0.70
```

**Interpretación:**
70% de los activos de Cemex están financiados con deuda. **Nivel alto de riesgo**, requiere monitoreo cercano.

---

### 11. Cobertura de Intereses (Times Interest Earned)

**Fórmula:**
```
Cobertura de Intereses = UAII / Gastos por Intereses
```

Donde **UAII** = Utilidad Antes de Impuestos e Intereses (EBIT)

**Interpretación:**
Número de veces que la utilidad operativa cubre los gastos por intereses. Mide la capacidad de pagar intereses de la deuda.

**Rango Óptimo:**
- **Mínimo**: 2.0x
- **Óptimo**: 3.0-5.0x
- **Máximo**: >5.0x (puede indicar sub-apalancamiento)

**Ejemplo Práctico:**
```
Grupo Carso (2024):
UAII: $45,000 millones MXN
Gastos por Intereses: $12,000 millones MXN

Cobertura de Intereses = 45,000 / 12,000 = 3.75x
```

**Interpretación:**
La utilidad operativa cubre 3.75 veces los intereses. Dentro del rango óptimo (3-5x).

---

### 12. Apalancamiento Financiero

**Fórmula:**
```
Apalancamiento Financiero = Activo Total / Patrimonio
```

**Interpretación:**
Mide cuántos pesos de activos hay por cada peso de capital. Indica el uso de deuda para financiar activos.

**Ejemplo Práctico:**
```
Banorte (2024):
Activo Total: $2,800,000 millones MXN
Patrimonio: $280,000 millones MXN

Apalancamiento = 2,800,000 / 280,000 = 10.0x
```

**Interpretación:**
Banorte tiene 10 pesos de activos por cada peso de capital. **Alto para banco** (normal en sector financiero, típicamente 8-12x).

---

### 13. Cobertura de Deuda (Debt Service Coverage)

**Fórmula:**
```
Cobertura de Deuda = Flujo Operativo / Servicio de Deuda
```

Donde **Servicio de Deuda** = Principal + Intereses del periodo

**Interpretación:**
Capacidad del flujo operativo para cubrir pagos de principal e intereses de la deuda.

**Rango Óptimo:**
- **Mínimo**: 1.2x
- **Óptimo**: 1.5-2.5x
- **Máximo**: >3.0x

---

### 14. Razón de Cobertura de Flujo de Efectivo

**Fórmula:**
```
Cobertura de Flujo = Efectivo de Operación / Pasivo Total
```

**Interpretación:**
Capacidad del efectivo generado por operaciones para cubrir el pasivo total.

**Rango Óptimo:**
- **Mínimo**: 0.15
- **Óptimo**: 0.20-0.40
- **Máximo**: >0.50

---

### 15. Índice de Solvencia a Largo Plazo

**Fórmula:**
```
Solvencia Largo Plazo = (UAII + Depreciación) / (Intereses + Pago de Principal / (1 - Tasa ISR))
```

**Interpretación:**
Mide la capacidad de cubrir obligaciones de largo plazo con el flujo operativo.

**Rango Óptimo:**
- **Mínimo**: 1.5x
- **Óptimo**: 2.0-3.0x

## Razones de Rentabilidad (8 Razones)

### 16. ROA (Return on Assets)

**Fórmula:**
```
ROA = Utilidad Neta / Activo Total Promedio
```

**Interpretación:**
Rendimiento que genera la empresa sobre sus activos. Mide la eficiencia en el uso de activos para generar utilidades.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 3% | 5-10% | 15% |
| Servicios | 5% | 8-15% | 20% |
| Manufactura | 4% | 6-12% | 18% |
| Tecnología | 8% | 12-20% | 30% |
| Financiero | 1% | 1.5-3% | 5% |

**Ejemplo Práctico (FEMSA):**
```
Utilidad Neta 2024: $45,000 millones MXN
Activo Total Promedio: ($805,856 + $851,536) / 2 = $828,696 millones MXN

ROA = 45,000 / 828,696 = 5.43%
```

**Interpretación:**
FEMSA genera 5.43% de rendimiento sobre sus activos. Dentro del rango óptimo para comercio (5-10%).

---

### 17. ROE (Return on Equity)

**Fórmula:**
```
ROE = Utilidad Neta / Patrimonio Promedio
```

**Interpretación:**
Rendimiento sobre el capital de los accionistas. Mide la rentabilidad financiera de la empresa.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 10% | 15-25% | 35% |
| Servicios | 12% | 18-30% | 40% |
| Manufactura | 8% | 12-22% | 30% |
| Tecnología | 15% | 20-35% | 50% |
| Financiero | 10% | 15-25% | 35% |

**Ejemplo Práctico (Grupo Bimbo):**
```
Utilidad Neta 2024: $12,000 millones MXN
Patrimonio Promedio: ($95,000 + $88,000) / 2 = $91,500 millones MXN

ROE = 12,000 / 91,500 = 13.11%
```

**Interpretación:**
Bimbo genera 13.11% de rendimiento sobre el capital. En el límite inferior del rango óptimo (15-25%).

**Relación ROE-ROA (Ecuación DuPont):**
```
ROE = ROA × Apalancamiento
ROE = (Utilidad Neta/Activo) × (Activo/Patrimonio)
```

---

### 18. Margen Bruto

**Fórmula:**
```
Margen Bruto = (Utilidad Bruta / Ventas Netas) × 100
```

Donde **Utilidad Bruta** = Ventas Netas - Costo de Ventas

**Interpretación:**
Porcentaje de cada peso de venta que queda después de cubrir el costo directo. Mide eficiencia en producción/compra.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio (Retail) | 15% | 20-35% | 45% |
| Servicios | 30% | 40-60% | 75% |
| Manufactura | 20% | 25-40% | 50% |
| Tecnología (Software) | 60% | 70-85% | 95% |
| Restaurantes | 25% | 30-40% | 50% |

**Ejemplo Práctico (Starbucks México):**
```
Ventas Netas: $8,500 millones MXN
Costo de Ventas: $3,400 millones MXN
Utilidad Bruta: $5,100 millones MXN

Margen Bruto = (5,100 / 8,500) × 100 = 60%
```

**Interpretación:**
Starbucks México retiene 60 centavos de cada peso de venta después de costos directos. Excelente para el sector restaurantes.

---

### 19. Margen Operativo

**Fórmula:**
```
Margen Operativo = (UAII / Ventas Netas) × 100
```

**Interpretación:**
Porcentaje de utilidad operativa sobre ventas. Mide la eficiencia del negocio principal antes de impuestos y gastos financieros.

**Rango Óptimo:**
- **Mínimo**: 8%
- **Óptimo**: 10-20%
- **Máximo**: >25%

**Ejemplo Práctico:**
```
Grupo Elektra (2024):
UAII: $28,000 millones MXN
Ventas Netas: $180,000 millones MXN

Margen Operativo = (28,000 / 180,000) × 100 = 15.56%
```

---

### 20. Margen Neto

**Fórmula:**
```
Margen Neto = (Utilidad Neta / Ventas Netas) × 100
```

**Interpretación:**
Porcentaje de utilidad final sobre ventas. Mide la rentabilidad total del negocio.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 2% | 5-10% | 15% |
| Servicios | 5% | 10-20% | 30% |
| Manufactura | 3% | 6-12% | 18% |
| Tecnología | 10% | 15-25% | 40% |

**Ejemplo Práctico (Walmart de México):**
```
Utilidad Neta: $28,000 millones MXN
Ventas Netas: $680,000 millones MXN

Margen Neto = (28,000 / 680,000) × 100 = 4.12%
```

**Interpretación:**
Walmart México retiene 4.12 centavos de cada peso de venta. Típico para retail de alto volumen (margen bajo, rotación alta).

---

### 21. EBITDA

**Fórmula:**
```
EBITDA = UAII + Depreciación + Amortización
```

**Interpretación:**
Utilidad antes de intereses, impuestos, depreciación y amortización. Mide el flujo de efectivo operativo antes de decisiones financieras y contables.

**Ejemplo Práctico:**
```
América Móvil (2024):
UAII: $280,000 millones MXN
Depreciación: $120,000 millones MXN
Amortización: $40,000 millones MXN

EBITDA = 280,000 + 120,000 + 40,000 = $440,000 millones MXN
```

---

### 22. Margen EBITDA

**Fórmula:**
```
Margen EBITDA = (EBITDA / Ventas Netas) × 100
```

**Rango Óptimo:**
- **Mínimo**: 12%
- **Óptimo**: 15-30%
- **Máximo**: >35%

---

### 23. ROI (Return on Investment)

**Fórmula:**
```
ROI = [(Ganancia de la Inversión - Costo de la Inversión) / Costo de la Inversión] × 100
```

**Interpretación:**
Rendimiento sobre una inversión específica. Se usa para evaluar proyectos de inversión.

**Ejemplo Práctico:**
```
Inversión en maquinaria: $5,000,000 MXN
Ganancia anual generada: $1,200,000 MXN

ROI = [(1,200,000 - 5,000,000) / 5,000,000] × 100 = -76% (primer año)
ROI acumulado 5 años = [(6,000,000 - 5,000,000) / 5,000,000] × 100 = 20%
```

## Razones de Actividad/Rotación (7 Razones)

### 24. Rotación de Inventarios

**Fórmula:**
```
Rotación de Inventarios = Costo de Ventas / Inventario Promedio
```

**Interpretación:**
Número de veces que el inventario se vende y repone en un año. **Mayor rotación = mayor eficiencia**.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Retail (alimentos) | 8x | 12-20x | 30x |
| Retail (ropa) | 3x | 4-6x | 8x |
| Manufactura | 4x | 6-10x | 15x |
| Automotriz | 6x | 8-12x | 20x |

**Ejemplo Práctico (Walmart de México):**
```
Costo de Ventas: $580,000 millones MXN
Inventario Promedio: $90,000 millones MXN

Rotación de Inventarios = 580,000 / 90,000 = 6.44 veces al año
```

**Interpretación:**
Walmart rota su inventario 6.44 veces al año (cada 57 días). Excelente para retail.

---

### 25. Días de Inventario

**Fórmula:**
```
Días de Inventario = 365 / Rotación de Inventarios
```

**Interpretación:**
Días promedio que el inventario permanece en almacén antes de venderse.

**Ejemplo Práctico:**
```
Días de Inventario = 365 / 6.44 = 57 días
```

**Interpretación:**
El inventario de Walmart permanece 57 días en almacén antes de venderse.

---

### 26. Rotación de Cuentas por Cobrar (CxC)

**Fórmula:**
```
Rotación de CxC = Ventas a Crédito / Cuentas por Cobrar Promedio
```

**Interpretación:**
Número de veces que se cobran las cuentas por cobrar en un año.

**Rango Óptimo:**
- **Mínimo**: 6x (60 días)
- **Óptimo**: 10-15x (24-36 días)
- **Máximo**: >20x (<18 días)

---

### 27. Período Promedio de Cobro

**Fórmula:**
```
Período Promedio de Cobro = 365 / Rotación de CxC
```

**O alternativamente:**
```
Período Promedio de Cobro = (Cuentas por Cobrar Promedio × 365) / Ventas a Crédito
```

**Interpretación:**
Días promedio que tarda la empresa en cobrar a sus clientes.

**Ejemplo Práctico:**
```
Cuentas por Cobrar Promedio: $25,000,000 MXN
Ventas a Crédito: $180,000,000 MXN

Período de Cobro = (25,000,000 × 365) / 180,000,000 = 51 días
```

**Interpretación:**
La empresa tarda 51 días en cobrar. **Óptimo: 30-45 días**. 51 días puede indicar política de crédito muy laxa o problemas de cobranza.

---

### 28. Rotación de Cuentas por Pagar (CxP)

**Fórmula:**
```
Rotación de CxP = Compras a Crédito / Cuentas por Pagar Promedio
```

**Interpretación:**
Número de veces que se pagan las cuentas por pagar en un año.

---

### 29. Rotación de Activos Fijos

**Fórmula:**
```
Rotación de Activos Fijos = Ventas Netas / Activo Fijo Neto Promedio
```

**Interpretación:**
Eficiencia en el uso de activos fijos para generar ventas.

**Rango Óptimo:**
- **Mínimo**: 1.5x
- **Óptimo**: 2.0-4.0x
- **Máximo**: >5.0x

---

### 30. Rotación de Activos Totales

**Fórmula:**
```
Rotación de Activos Totales = Ventas Netas / Activo Total Promedio
```

**Interpretación:**
Eficiencia en el uso de todos los activos para generar ventas.

**Rango Óptimo por Industria:**

| Industria | Mínimo | Óptimo | Máximo |
|-----------|--------|--------|--------|
| Comercio | 1.5x | 2.0-3.5x | 5.0x |
| Servicios | 0.8x | 1.0-2.0x | 3.0x |
| Manufactura | 0.6x | 0.8-1.5x | 2.5x |
| Tecnología | 0.5x | 0.7-1.2x | 2.0x |

**Ejemplo Práctico (FEMSA):**
```
Ventas Netas: $950,000 millones MXN
Activo Total Promedio: $828,696 millones MXN

Rotación de Activos Totales = 950,000 / 828,696 = 1.15x
```

**Interpretación:**
FEMSA genera $1.15 pesos de venta por cada peso de activos. Dentro del rango óptimo para comercio.

```python
"""
Módulo: calculadora_razones_financieras.py
Propósito: Cálculo automatizado de 30+ razones financieras con interpretación
Versión: 1.0
Fecha: 2026-03-10

from typing import Dict, Optional, Tuple
from decimal import Decimal

class Semaforo(Enum):

    AMARILLO = "amarillo"  # En límites, requiere atención
    ROJO = "rojo"        # Fuera de rango, acción requerida


@dataclass
class RazonFinanciera:
    """Representa una razón financiera calculada."""
    nombre: str
    valor: Decimal
    unidad: str  # 'veces', 'porcentaje', 'dias', 'pesos'
    semaforo: Semaforo
    interpretacion: str
    rango_optimo: str
    industria: Optional[str] = None


class CalculadoraRazonesFinancieras:
    """
    Calcula 30+ razones financieras a partir de estados financieros.
    """

        Inicializa la calculadora.
        
        Args:
            industria: Industria de la empresa (comercio, servicios, manufactura, tecnología)
        """
        self.industria = industria

    def calcular_liquidez_circulante(self, activo_circulante: Decimal, 
                                      pasivo_circulante: Decimal) -> RazonFinanciera:
        """Calcula la razón de liquidez circulante."""
        if pasivo_circulante == 0:
            return RazonFinanciera(
                nombre="Liquidez Circulante",
                valor=Decimal('0'),
                unidad='veces',
                semaforo=Semaforo.ROJO,
                interpretacion="Pasivo circulante cero. No aplica.",
                rango_optimo="1.5-2.5",
                industria=self.industria
            )
        
        valor = activo_circulante / pasivo_circulante
        
        # Determinar semáforo según industria
        if self.industria == 'comercio':
            if 1.5 <= valor <= 2.5:
                semaforo = Semaforo.VERDE
                interpretacion = "Liquidez adecuada. Puede cubrir obligaciones corto plazo."
            elif 1.2 <= valor < 1.5 or 2.5 < valor <= 3.0:
                semaforo = Semaforo.AMARILLO
                interpretacion = "Liquidez aceptable pero requiere monitoreo."
            else:
                semaforo = Semaforo.ROJO
                interpretacion = "Liquidez insuficiente o exceso de activos improductivos."
        else:  # general
            if 1.5 <= valor <= 2.5:
                semaforo = Semaforo.VERDE
                interpretacion = "Liquidez adecuada."
            else:
                semaforo = Semaforo.AMARILLO if 1.0 <= valor <= 3.0 else Semaforo.ROJO
                interpretacion = "Revisar política de liquidez."
        
        razon = RazonFinanciera(
            nombre="Liquidez Circulante",
            valor=valor.quantize(Decimal('0.01')),
            unidad='veces',
            semaforo=semaforo,
            interpretacion=interpretacion,
            rango_optimo="1.5-2.5",
            industria=self.industria
        )
        
        self.resultados['liquidez_circulante'] = razon
        return razon
    
    def calcular_prueba_acida(self, activo_circulante: Decimal,

class AnalizadorLiquidez:
    """Analiza 8 razones de liquidez con semáforo financiero."""
    
    def __init__(self):
        self.calculadora = CalculadoraRazonesFinancieras()
    
    def analizar(self, datos_financieros: Dict[str, Decimal]) -> Dict[str, RazonFinanciera]:
        """
        Realiza análisis completo de liquidez.
        
        Args:
            datos_financieros: Diccionario con activos, pasivos, etc.
            
        Returns:
            Diccionario con 8 razones de liquidez calculadas
        """
        razones = {}
        
        # 1. Liquidez Circulante
        razon = self.calculadora.calcular_liquidez_circulante(
            datos_financieros['activo_circulante'],
            datos_financieros['pasivo_circulante']
        )
        razones['liquidez_circulante'] = razon
        
        # 2. Prueba Ácida
        razon = self.calculadora.calcular_prueba_acida(
            datos_financieros['activo_circulante'],
            datos_financieros['inventarios'],
            datos_financieros['pasivo_circulante']
        )
        razones['prueba_acida'] = razon
        
        # 3. Capital de Trabajo
        capital_trabajo = datos_financieros['activo_circulante'] - datos_financieros['pasivo_circulante']
        razones['capital_trabajo'] = RazonFinanciera(
            nombre="Capital de Trabajo",
            valor=capital_trabajo,
            unidad='pesos',
            semaforo=Semaforo.VERDE if capital_trabajo > 0 else Semaforo.ROJO,
            interpretacion="Positivo" if capital_trabajo > 0 else "Negativo - revisar liquidez",
            rango_optimo="> 0"
        )
        
        # 4. Liquidez Inmediata
        if datos_financieros['pasivo_circulante'] > 0:
            valor = datos_financieros['efectivo'] / datos_financieros['pasivo_circulante']
            razones['liquidez_inmediata'] = RazonFinanciera(
                nombre="Liquidez Inmediata",
                valor=valor.quantize(Decimal('0.01')),
                unidad='veces',
                semaforo=Semaforo.VERDE if 0.3 <= valor <= 0.5 else Semaforo.AMARILLO,
                interpretacion="Adecuada" if 0.3 <= valor <= 0.5 else "Revisar",
                rango_optimo="0.3-0.5"
            )
        
        # 5. Intervalo Defensivo
        gastos_diarios = (datos_financieros['costo_ventas'] + datos_financieros['gastos_operacion']) / 365
        if gastos_diarios > 0:
            valor = (datos_financieros['activo_circulante'] - datos_financieros['inventarios']) / gastos_diarios
            razones['intervalo_defensivo'] = RazonFinanciera(
                nombre="Intervalo Defensivo",
                valor=valor.quantize(Decimal('0')),
                unidad='dias',
                semaforo=Semaforo.VERDE if valor >= 60 else Semaforo.ROJO,
                interpretacion=f"Puede operar {valor:.0f} días sin ingresos",
                rango_optimo=">= 60 días"
            )
        
        return razones

class AnalizadorActividad:
    """Analiza 7 razones de actividad/rotación."""

        self.calculadora = CalculadoraRazonesFinancieras()
    
    def analizar(self, datos: Dict[str, Decimal]) -> Dict[str, RazonFinanciera]:
        """Analiza actividad con 7 razones."""
        razones = {}
        
        # Rotación de Inventarios
        razones['rotacion_inventarios'] = self.calculadora.calcular_rotacion_inventarios(
            datos['costo_ventas'],
            datos['inventario_promedio']
        )
        
        # Días de Inventario
        rotacion = razones['rotacion_inventarios'].valor
        razones['dias_inventario'] = self.calculadora.calcular_dias_inventario(rotacion)
        
        # Rotación de CxC
        if datos['cxc_promedio'] > 0:
            valor = datos['ventas_credito'] / datos['cxc_promedio']
            razones['rotacion_cxc'] = RazonFinanciera(
                nombre="Rotación de CxC",
                valor=valor.quantize(Decimal('0.01')),
                unidad='veces',
                semaforo=Semaforo.VERDE if 10 <= valor <= 15 else Semaforo.AMARILLO,
                interpretacion="Eficiencia de cobranza",
                rango_optimo="10-15 veces"
            )
        
        # Período de Cobro
        if 'rotacion_cxc' in razones and razones['rotacion_cxc'].valor > 0:
            valor = 365 / razones['rotacion_cxc'].valor
            razones['periodo_cobro'] = RazonFinanciera(
                nombre="Período de Cobro",
                valor=valor.quantize(Decimal('0')),
                unidad='dias',
                semaforo=Semaforo.VERDE if 24 <= valor <= 36 else Semaforo.AMARILLO,
                interpretacion=f"Cobra en {valor:.0f} días promedio",
                rango_optimo="24-36 días"
            )
        
        return razones


class GeneradorReporteFinanciero:
    """
    Genera reporte ejecutivo con interpretación de razones financieras.
    """
    
    def __init__(self):
        self.resultados: Dict[str, RazonFinanciera] = {}
    
    def agregar_resultados(self, razones: Dict[str, RazonFinanciera]):
        """Agrega razones calculadas al reporte."""
        self.resultados.update(razones)
    
    def generar_reporte(self, empresa: str, fecha: str) -> str:
        """
        Genera reporte ejecutivo en formato texto.
        
        Args:
            empresa: Nombre de la empresa
            fecha: Fecha del análisis
            
        Returns:
            Reporte en formato texto
        """

================================================================================
                    REPORTE DE ANÁLISIS FINANCIERO
================================================================================
Empresa: {empresa}
Fecha: {fecha}
================================================================================

RESUMEN EJECUTIVO
-----------------
Total de razones calculadas: {len(self.resultados)}
"""
        
        # Contar por semáforo
        verdes = sum(1 for r in self.resultados.values() if r.semaforo == Semaforo.VERDE)
        amarillas = sum(1 for r in self.resultados.values() if r.semaforo == Semaforo.AMARILLO)
        rojas = sum(1 for r in self.resultados.values() if r.semaforo == Semaforo.ROJO)
        
        reporte += f"""
Semáforo Financiero:
  ✅ Verdes:   {verdes} razones
  ⚠️  Amarillas: {amarillas} razones
  ❌ Rojas:    {rojas} razones

================================================================================
                    RAZONES DE LIQUIDEZ
================================================================================
"""
        
        for clave, razon in self.resultados.items():
            if 'liquidez' in clave or 'prueba' in clave or 'capital' in clave:
                icono = '✅' if razon.semaforo == Semaforo.VERDE else '⚠️' if razon.semaforo == Semaforo.AMARILLO else '❌'
                reporte += f"""
{icono} {razon.nombre}
   Valor: {razon.valor} {razon.unidad}
   Rango óptimo: {razon.rango_optimo}
   Interpretación: {razon.interpretacion}
"""
        
        reporte += """
================================================================================
                    RAZONES DE SOLVENCIA
================================================================================
"""
        
        for clave, razon in self.resultados.items():
            if 'deuda' in clave or 'cobertura' in clave or 'solvencia' in clave:
                icono = '✅' if razon.semaforo == Semaforo.VERDE else '⚠️' if razon.semaforo == Semaforo.AMARILLO else '❌'
                reporte += f"""
{icono} {razon.nombre}
   Valor: {razon.valor} {razon.unidad}
   Rango óptimo: {razon.rango_optimo}
   Interpretación: {razon.interpretacion}
"""
        
        reporte += """
================================================================================
                    RAZONES DE RENTABILIDAD
================================================================================
"""
        
        for clave, razon in self.resultados.items():
            if 'roa' in clave or 'roe' in clave or 'margen' in clave:
                icono = '✅' if razon.semaforo == Semaforo.VERDE else '⚠️' if razon.semaforo == Semaforo.AMARILLO else '❌'
                reporte += f"""
{icono} {razon.nombre}
   Valor: {razon.valor} {razon.unidad}
   Rango óptimo: {razon.rango_optimo}
   Interpretación: {razon.interpretacion}
"""
        
        reporte += """
================================================================================
                    RAZONES DE ACTIVIDAD
================================================================================
"""
        
        for clave, razon in self.resultados.items():
            if 'rotacion' in clave or 'inventario' in clave or 'cobro' in clave:
                icono = '✅' if razon.semaforo == Semaforo.VERDE else '⚠️' if razon.semaforo == Semaforo.AMARILLO else '❌'
                reporte += f"""
{icono} {razon.nombre}
   Valor: {razon.valor} {razon.unidad}
   Rango óptimo: {razon.rango_optimo}
   Interpretación: {razon.interpretacion}
"""
        
        reporte += """
================================================================================
                    RECOMENDACIONES GENERALES
================================================================================
"""
        
        # Generar recomendaciones basadas en semáforos rojos
        rojas = [r for r in self.resultados.values() if r.semaforo == Semaforo.ROJO]
        if rojas:
            reporte += "\n⚠️  ÁREAS QUE REQUIEREN ATENCIÓN INMEDIATA:\n"
            for razon in rojas:
                reporte += f"   - {razon.nombre}: {razon.interpretacion}\n"
        else:
            reporte += "\n✅ No se identificaron áreas críticas.\n"
        
        reporte += """
================================================================================
"""
        
        return reporte
```
