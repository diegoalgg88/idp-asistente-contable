## 1. Descripción del Módulo

### 1.1 Propósito

Esta investigación documenta la aplicación de la Ley de Benford como herramienta de auditoría forense para detección de irregularidades financieras, manipulación de cifras y posibles fraudes en información contable. El módulo permite analizar grandes volúmenes de datos financieros (facturas, nóminas, pagos, compras) para identificar patrones anómalos que merecen investigación profunda.

**Problema que resuelve:** Los auditores tradicionales revisan muestras pequeñas (5-10% de transacciones) mediante muestreo estadístico, lo que permite que fraudes significativos pasen desapercibidos. La Ley de Benford permite analizar el 100% de las transacciones de forma automatizada, identificando patrones sospechosos en 15-30 minutos que tomarían días detectar manualmente.

**Dolor 1: Fraude no detectado en muestras pequeñas**
- El muestreo tradicional (5-10% de transacciones) deja pasar 90-95% de datos sin revisar

**Dolor 3: Dependencia de experiencia del auditor**

#### Algoritmo 1: Implementación de Ley de Benford

```python
from typing import List, Dict, Tuple
from dataclasses import dataclass
from decimal import Decimal
import math

@dataclass
class ResultadoBenford:
    """Resultado del análisis de Benford para un dígito."""
    digito: int
    frecuencia_esperada: float
    frecuencia_observada: float
    diferencia: float
    z_score: float
    es_anomalo: bool

class AnalizadorBenford:
    """
    Implementa la Ley de Benford para detección de anomalías en datos financieros.
    
    La Ley de Benford establece que en conjuntos de datos naturales,
    el primer dígito tiende a ser 1 aproximadamente 30.1% del tiempo,
    disminuyendo progresivamente hasta 9 (4.6%).
    
    Fórmula: P(d) = log₁₀(1 + 1/d) para d = 1, 2, ..., 9
    
    Ejemplo:
        >>> analizador = AnalizadorBenford()
        >>> datos = [1234, 1567, 2345, 1890, 9876, 1234, 1111]
        >>> resultados = analizador.analizar(datos)
        >>> print(resultados[0].frecuencia_esperada)
        0.301
    """
    
    # Frecuencias esperadas según Ley de Benford
    FRECUENCIAS_ESPERADAS = {
        1: 0.301,  # 30.1%
        2: 0.176,  # 17.6%
        3: 0.125,  # 12.5%
        4: 0.097,  # 9.7%
        5: 0.079,  # 7.9%
        6: 0.067,  # 6.7%
        7: 0.058,  # 5.8%
        8: 0.051,  # 5.1%
        9: 0.046   # 4.6%
    }
    
    # Umbrales de alerta
    UMBRAL_Z_SCORE_ALERTA = 2.0  # Z > 2.0 indica desviación significativa
    UMBRAL_Z_SCORE_CRITICO = 3.0  # Z > 3.0 indica desviación crítica
    UMBRAL_DESVIACION_PORCENTUAL = 0.25  # 25% de desviación
    
    def calcular_frecuencia_esperada(self, digito: int) -> float:
        """
        Calcula la frecuencia esperada según Ley de Benford.
        
        Args:
            digito: Dígito del 1 al 9
            
        Returns:
            Frecuencia esperada (0-1)
            
        Ejemplo:
            >>> analizador = AnalizadorBenford()
            >>> frecuencia = analizador.calcular_frecuencia_esperada(1)
            >>> print(f"{frecuencia:.3f}")
            0.301
        """
        if digito < 1 or digito > 9:
            raise ValueError("El dígito debe estar entre 1 y 9")
        
        # Fórmula: P(d) = log₁₀(1 + 1/d)
        return math.log10(1 + 1/digito)
    
    def extraer_primer_digito(self, numero: int) -> int:
        """
        Extrae el primer dígito de un número.
        
        Args:
            numero: Número entero positivo
            
        Returns:
            Primer dígito (1-9)
            
        Ejemplo:
            >>> analizador = AnalizadorBenford()
            >>> digito = analizador.extraer_primer_digito(5678)
            >>> print(digito)
            5
        """
        if numero <= 0:
            raise ValueError("El número debe ser positivo")
        
        while numero >= 10:
            numero = numero // 10
        
        return numero
    
    def analizar(self, datos: List[int]) -> List[ResultadoBenford]:
        """
        Analiza un conjunto de datos usando la Ley de Benford.
        
        Args:
            datos: Lista de números enteros positivos (montos de facturas, pagos, etc.)
            
        Returns:
            Lista de resultados por dígito (1-9)
            
        Ejemplo:
            >>> analizador = AnalizadorBenford()
            >>> datos = [1234, 1567, 2345, 1890, 9876, 1234, 1111, 2222, 3333]
            >>> resultados = analizador.analizar(datos)
            >>> print(f"Total dígitos analizados: {len(resultados)}")
            Total dígitos analizados: 9
        """
        if len(datos) < 10:
            raise ValueError("Se requieren al menos 10 datos para un análisis válido")
        
        # Contar frecuencias observadas
        conteos = {d: 0 for d in range(1, 10)}
        total_validos = 0
        
        for numero in datos:
            if numero > 0:  # Ignorar ceros y negativos
                primer_digito = self.extraer_primer_digito(abs(int(numero)))
                conteos[primer_digito] += 1
                total_validos += 1
        
        # Calcular resultados
        resultados = []
        
        for digito in range(1, 10):
            frecuencia_esperada = self.FRECUENCIAS_ESPERADAS[digito]
            frecuencia_observada = conteos[digito] / total_validos if total_validos > 0 else 0
            diferencia = frecuencia_observada - frecuencia_esperada
            
            # Calcular Z-score (prueba de proporciones)
            # Z = (p_obs - p_exp) / sqrt(p_exp * (1 - p_exp) / n)
            error_estandar = math.sqrt(frecuencia_esperada * (1 - frecuencia_esperada) / total_validos)
            z_score = diferencia / error_estandar if error_estandar > 0 else 0
            
            # Determinar si es anómalo
            es_anomalo = abs(z_score) > self.UMBRAL_Z_SCORE_ALERTA
            
            resultados.append(ResultadoBenford(
                digito=digito,
                frecuencia_esperada=frecuencia_esperada,
                frecuencia_observada=frecuencia_observada,
                diferencia=diferencia,
                z_score=z_score,
                es_anomalo=es_anomalo
            ))
        
        return resultados
    
    def calcular_chi_cuadrada(self, datos: List[int]) -> Tuple[float, bool]:
        """
        Calcula estadístico Chi-cuadrada para bondad de ajuste.
        
        Args:
            datos: Lista de números enteros positivos
            
        Returns:
            Tuple con (chi_cuadrada, es_significativo)
            
        Ejemplo:
            >>> analizador = AnalizadorBenford()
            >>> datos = [1234, 1567, 2345, 1890, 9876] * 100
            >>> chi, significativo = analizador.calcular_chi_cuadrada(datos)
            >>> print(f"Chi-cuadrada: {chi:.2f}")
        """
        if len(datos) < 10:
            raise ValueError("Se requieren al menos 10 datos")
        
        # Contar frecuencias observadas
        conteos = {d: 0 for d in range(1, 10)}
        total = 0
        
        for numero in datos:
            if numero > 0:
                primer_digito = self.extraer_primer_digito(abs(int(numero)))
                conteos[primer_digito] += 1
                total += 1
        
        # Calcular Chi-cuadrada
        chi_cuadrada = 0
        
        for digito in range(1, 10):
            frecuencia_esperada = self.FRECUENCIAS_ESPERADAS[digito]
            esperado = frecuencia_esperada * total
            observado = conteos[digito]
            
            if esperado > 0:
                chi_cuadrada += ((observado - esperado) ** 2) / esperado
        
        # Valor crítico para 8 grados de libertad (α = 0.05)
        valor_critico = 15.507
        es_significativo = chi_cuadrada > valor_critico
        
        return chi_cuadrada, es_significativo
    
    def generar_reporte(self, resultados: List[ResultadoBenford]) -> str:
        """
        Genera reporte textual del análisis.
        
        Args:
            resultados: Lista de resultados del análisis
            
        Returns:
            Reporte formateado
        """
        reporte = "=" * 70 + "\n"
        reporte += "ANÁLISIS DE LEY DE BENFORD\n"
        reporte += "=" * 70 + "\n\n"
        
        reporte += f"{'Dígito':<8} {'Esperado':<10} {'Observado':<10} {'Diferencia':<12} {'Z-Score':<10} {'Alerta':<8}\n"
        reporte += "-" * 70 + "\n"
        
        anomalias = 0
        
        for resultado in resultados:
            alerta = "⚠️ SÍ" if resultado.es_anomalo else "✓ NO"
            if resultado.es_anomalo:
                anomalias += 1
            
            reporte += f"{resultado.digito:<8} {resultado.frecuencia_esperada:<10.3f} {resultado.frecuencia_observada:<10.3f} {resultado.diferencia:<12.3f} {resultado.z_score:<10.2f} {alerta:<8}\n"
        
        reporte += "-" * 70 + "\n"
        reporte += f"\nTotal de anomalías detectadas: {anomalias} de 9 dígitos\n"
        
        if anomalias >= 3:
            reporte += "⚠️  ALERTA: Múltiples anomalías detectadas. Se recomienda investigación profunda.\n"
        elif anomalias >= 1:
            reporte += "⚡ PRECAUCIÓN: Algunas anomalías detectadas. Revisar transacciones relacionadas.\n"
        else:
            reporte += "✅ SIN NOVEDAD: Los datos siguen la distribución de Benford.\n"
        
        return reporte
```

#### Algoritmo 2: Detector de Fraude con Benford + Reglas de Negocio

```python
from dataclasses import dataclass
from typing import List, Dict, Optional
from datetime import datetime
from enum import Enum

class NivelRiesgo(Enum):
    BAJO = "bajo"
    MEDIO = "medio"
    ALTO = "alto"
    CRITICO = "critico"

@dataclass
class TransaccionSospechosa:
    """Representa una transacción flagged como sospechosa."""
    id_transaccion: str
    monto: float
    primer_digito: int
    cuenta_contable: str
    proveedor: str
    fecha: datetime
    razon_anomalia: str
    nivel_riesgo: NivelRiesgo
    z_score: float

class DetectorFraudeBenford:
    """
    Combina Ley de Benford con reglas de negocio para detección de fraude.
    
    Reglas implementadas:
    1. Desviación de Benford (>25-30%)
    2. Montos redondos sospechosos ($10,000, $50,000)
    3. Transacciones justo debajo de umbrales ($9,999)
    4. Duplicados exactos
    5. Frecuencia anómala por proveedor
    
    Ejemplo:
        >>> detector = DetectorFraudeBenford()
        >>> transacciones = [...]
        >>> sospechosas = detector.detectar(transacciones)
        >>> print(f"Transacciones sospechosas: {len(sospechosas)}")
    """
    
    # Umbrales de montos redondos sospechosos
    MONTOS_REDONDOS_SOSPECHOSOS = [
        1000, 5000, 10000, 20000, 50000, 100000
    ]
    
    # Umbral para transacciones "casi redondas"
    TOLERANCIA_CASI_REDONDO = 10  # $9,990 - $9,999
    
    # Umbral de duplicados
    UMBRAL_DUPLICADOS = 2  # Más de 2 transacciones iguales
    
    def __init__(self):
        self.analizador_benford = AnalizadorBenford()
    
    def es_monto_redondo_sospechoso(self, monto: float) -> bool:
        """Verifica si el monto es sospechosamente redondo."""
        return monto in self.MONTOS_REDONDOS_SOSPECHOSOS
    
    def es_casi_redondo(self, monto: float) -> bool:
        """
        Verifica si el monto está justo debajo de un número redondo.
        
        Ejemplo: $9,999 (para evitar aprobaciones de $10,000+)
        """
        for monto_redondo in self.MONTOS_REDONDOS_SOSPECHOSOS:
            if monto_redondo - self.TOLERANCIA_CASI_REDONDO <= monto < monto_redondo:
                return True
        return False
    
    def detectar_duplicados(self, transacciones: List[dict]) -> List[dict]:
        """Detecta transacciones duplicadas exactas."""
        from collections import Counter
        
        # Contar ocurrencias de cada monto
        conteo_montos = Counter([t['monto'] for t in transacciones])
        
        duplicados = []
        for transaccion in transacciones:
            if conteo_montos[transaccion['monto']] > self.UMBRAL_DUPLICADOS:
                duplicados.append(transaccion)
        
        return duplicados
    
    def detectar(self, transacciones: List[dict]) -> List[TransaccionSospechosa]:
        """
        Detecta transacciones sospechosas combinando Benford + reglas.
        
        Args:
            transacciones: Lista de dicts con:
                - id_transaccion: str
                - monto: float
                - cuenta_contable: str
                - proveedor: str
                - fecha: datetime
        
        Returns:
            Lista de transacciones sospechosas
        """
        sospechosas = []
        
        # Extraer montos para análisis Benford
        montos = [int(t['monto']) for t in transacciones if t['monto'] > 0]
        
        if len(montos) < 10:
            return sospechosas  # Datos insuficientes
        
        # Análisis Benford
        resultados_benford = self.analizador_benford.analizar(montos)
        
        # Crear mapa de dígitos anómalos
        digitos_anomalos = {r.digito for r in resultados_benford if r.es_anomalo}
        
        # Analizar cada transacción
        for transaccion in transacciones:
            monto = transaccion['monto']
            if monto <= 0:
                continue
            
            razones = []
            nivel_riesgo = NivelRiesgo.BAJO
            z_score_max = 0
            
            # Regla 1: Primer dígito anómalo según Benford
            primer_digito = self.analizador_benford.extraer_primer_digito(int(abs(monto)))
            if primer_digito in digitos_anomalos:
                razones.append(f"Primer dígito ({primer_digito}) fuera de distribución Benford")
                nivel_riesgo = NivelRiesgo.MEDIO
                # Obtener Z-score máximo
                for r in resultados_benford:
                    if r.digito == primer_digito:
                        z_score_max = max(z_score_max, abs(r.z_score))
            
            # Regla 2: Monto redondo sospechoso
            if self.es_monto_redondo_sospechoso(monto):
                razones.append(f"Monto redondo sospechoso (${monto:,.2f})")
                nivel_riesgo = max(nivel_riesgo, NivelRiesgo.MEDIO, key=lambda x: ['bajo', 'medio', 'alto', 'critico'].index(x.value))
            
            # Regla 3: Casi redondo (posible evasión de umbrales)
            if self.es_casi_redondo(monto):
                razones.append(f"Monto casi redondo (${monto:,.2f}) - posible evasión de aprobación")
                nivel_riesgo = NivelRiesgo.ALTO
            
            # Agregar a lista si hay razones
            if razones:
                sospechosas.append(TransaccionSospechosa(
                    id_transaccion=transaccion['id_transaccion'],
                    monto=monto,
                    primer_digito=primer_digito,
                    cuenta_contable=transaccion.get('cuenta_contable', 'N/A'),
                    proveedor=transaccion.get('proveedor', 'N/A'),
                    fecha=transaccion.get('fecha', datetime.now()),
                    razon_anomalia="; ".join(razones),
                    nivel_riesgo=nivel_riesgo,
                    z_score=z_score_max
                ))
        
        # Ordenar por nivel de riesgo
        sospechosas.sort(key=lambda x: ['critico', 'alto', 'medio', 'bajo'].index(x.nivel_riesgo.value), reverse=True)
        
        return sospechosas
    
    def generar_reporte_ejecutivo(self, sospechosas: List[TransaccionSospechosa]) -> str:
        """
        Genera reporte ejecutivo para comité de auditoría.
        
        Returns:
            Reporte formateado
        """
        if not sospechosas:
            return "No se detectaron transacciones sospechosas."
        
        reporte = "=" * 80 + "\n"
        reporte += "REPORTE EJECUTIVO: TRANSACCIONES SOSPECHOSAS\n"
        reporte += "=" * 80 + "\n\n"
        
        # Resumen por nivel de riesgo
        conteo_riesgos = {}
        for t in sospechosas:
            conteo_riesgos[t.nivel_riesgo.value] = conteo_riesgos.get(t.nivel_riesgo.value, 0) + 1
        
        reporte += "RESUMEN POR NIVEL DE RIESGO:\n"
        for nivel in ['critico', 'alto', 'medio', 'bajo']:
            if nivel in conteo_riesgos:
                reporte += f"  - {nivel.upper()}: {conteo_riesgos[nivel]} transacciones\n"
        
        reporte += f"\nTotal transacciones sospechosas: {len(sospechosas)}\n"
        reporte += f"Monto total bajo revisión: ${sum(t.monto for t in sospechosas):,.2f}\n\n"
        
        # Top 10 por riesgo
        reporte += "TOP 10 TRANSACCIONES DE MAYOR RIESGO:\n"
        reporte += "-" * 80 + "\n"
        
        for i, t in enumerate(sospechosas[:10], 1):
            reporte += f"{i}. ID: {t.id_transaccion}\n"
            reporte += f"   Monto: ${t.monto:,.2f} | Proveedor: {t.proveedor}\n"
            reporte += f"   Riesgo: {t.nivel_riesgo.value.upper()}\n"
            reporte += f"   Razón: {t.razon_anomalia}\n\n"
        
        # Recomendaciones
        reporte += "RECOMENDACIONES:\n"
        if conteo_riesgos.get('critico', 0) > 0:
            reporte += "⚠️  CRÍTICO: Investigar inmediatamente transacciones de riesgo crítico.\n"
        if conteo_riesgos.get('alto', 0) > 0:
            reporte += "⚡ ALTO: Revisar documentación soporte de transacciones de riesgo alto.\n"
        if conteo_riesgos.get('medio', 0) > 0:
            reporte += "📋 MEDIO: Solicitar aclaraciones por escrito a responsables.\n"
        
        reporte += "\n" + "=" * 80 + "\n"
        reporte += f"Reporte generado: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}\n"
        
        return reporte
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Requiere Muestra Grande (>100 datos)

**Problema:**
La Ley de Benford es estadísticamente válida solo con muestras grandes (>100 datos). Con muestras pequeñas (<50), las frecuencias observadas pueden desviarse naturalmente sin indicar fraude.

**Solución:**
```python
def validar_muestra_minima(datos: List[int], minimo: int = 100) -> dict:
    """
    Valida si la muestra es suficiente para análisis Benford.
    
    Returns:
        Diccionario con:
        - es_valida: bool
        - tamano_muestra: int
        - recomendacion: str
    """
    tamano = len(datos)
    
    if tamano < minimo:
        return {
            "es_valida": False,
            "tamano_muestra": tamano,
            "recomendacion": (
                f"Muestra insuficiente ({tamano} datos). "
                f"Se recomiendan al menos {minimo} transacciones para análisis Benford confiable. "
                "Considere ampliar el periodo de análisis o combinar múltiples cuentas."
            )
        }
    
    return {
        "es_valida": True,
        "tamano_muestra": tamano,
        "recomendacion": "Muestra adecuada para análisis Benford."
    }
```

**Impacto:**
- No aplicable a auditorías de cuentas con <100 transacciones
- Requiere consolidar múltiples periodos o cuentas
- Puede generar falsos positivos en muestras pequeñas

### 4.2 Limitación 2: No Aplica a Datos con Límites Artificiales

**Problema:**
La Ley de Benford no aplica a datos con límites impuestos (ej. viáticos con tope de $5,000, compras que requieren aprobación >$10,000). Estos datos tendrán distribuciones sesgadas naturalmente.

**Solución:**
```python
def detectar_limites_artificiales(datos: List[int]) -> Optional[int]:
    """
    Detecta si hay límites artificiales en los datos.
    
    Busca acumulaciones anómalas cerca de montos redondos.
    
    Returns:
        Límite detectado o None
    """
    from collections import Counter
    
    # Buscar acumulaciones cerca de montos redondos
    montos_redondos = [1000, 5000, 10000, 20000, 50000]
    
    for limite in montos_redondos:
        # Contar transacciones en rango 90-100% del límite
        inferior = int(limite * 0.9)
        superior = limite
        acumulacion = sum(1 for d in datos if inferior <= d <= superior)
        
        if acumulacion > len(datos) * 0.3:  # >30% cerca del límite
            return limite
    
    return None
```

**Impacto:**
- Falsos positivos en cuentas con políticas de aprobación
- Requiere conocimiento de políticas internas del cliente
- Necesita ajuste de umbrales por cuenta
