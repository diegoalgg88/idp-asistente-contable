## 1. Descripción del Módulo

### 1.1 Propósito

Proporcionar una guía completa de los **tratados para evitar la doble tributación** que México tiene vigentes con 60+ países, incluyendo:
- Tasas de retención por tipo de ingreso (dividendos, intereses, regalías, salarios)
- Artículos específicos de cada tratado
- Excepciones y casos especiales
- Procedimientos de aplicación
- Constancia de residencia fiscal requerida

Este módulo permite a contadores y auditores aplicar correctamente las tasas reducidas de retención previstas en los tratados, evitando doble tributación para residentes extranjeros que obtienen ingresos de fuente mexicana.

### 1.2 Actividades del Contador que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Consulta de tasas de retención por tratado | Semanal | 2 horas | 5 minutos | 96% |
| Validación de residencia fiscal | Semanal | 1 hora | 3 minutos | 95% |
| Cálculo de retenciones con tratado | Semanal | 1.5 horas | 5 minutos | 94% |
| Elaboración de documentación para tratado | Mensual | 3 horas | 15 minutos | 92% |

### 1.3 Dolor Principal que Resuelve

Los contadores enfrentan los siguientes problemas al aplicar tratados tributarios:

1. **Información dispersa:** 60+ tratados en diferentes documentos del SAT y DOF
2. **Tasas inconsistentes:** Dificultad para identificar tasa correcta por país y tipo de ingreso
3. **Requisitos documentales:** Incertidumbre sobre documentación requerida (constancia de residencia)
4. **Actualizaciones frecuentes:** Tratados renegociados (ej: Austria 2012, Reino Unido 2007)
5. **Interpretación compleja:** Artículos técnicos con lenguaje jurídico especializado

            participacion_accionaria: % de participación en la empresa (para dividendos)
            es_banco: Si True, aplica tasa reducida para bancos (intereses)
            es_gobierno: Si True, aplica tasa 0% para gobierno (intereses)
        
        Returns:
            Diccionario con:
                - pais: País consultado
                - tipo_ingreso: Tipo de ingreso
                - tasa_aplicable: % de retención aplicable
                - tasa_general: % de retención general
                - articulo_tratado: Artículo del tratado
                - observaciones: Notas adicionales
                - tratado_vigente: True si existe tratado
        """

        if pais not in self.PAISES_CON_TRATADO:
            return {
                'pais': pais,
                'tipo_ingreso': tipo_ingreso.value,
                'tasa_aplicable': 25.0,  # Tasa general LISR sin tratado
                'tasa_general': 25.0,
                'articulo_tratado': 'N/A',
                'observaciones': 'Sin tratado - Aplica tasa general LISR Art. 166',
                'tratado_vigente': False

        # Buscar tasas para el país y tipo de ingreso
        tasas_pais = self.TRATADOS.get(pais, [])
        tasas_tipo = [t for t in tasas_pais if t.tipo_ingreso == tipo_ingreso]
        
        if not tasas_tipo:

                'pais': pais,
                'tipo_ingreso': tipo_ingreso.value,
                'tasa_aplicable': 25.0,
                'tasa_general': 25.0,

                'observaciones': 'Tratado no especifica este tipo de ingreso',
                'tratado_vigente': True
            }

        tasa_aplicable = tasa.tasa_general
        
        # Verificar si aplica tasa reducida
        if tipo_ingreso == TipoIngreso.DIVIDENDOS and participacion_accionaria:
            if '≥25%' in str(tasa.condicion_tasa_reducida) and participacion_accionaria >= 25:
                tasa_aplicable = tasa.tasa_reducida
            elif '≥10%' in str(tasa.condicion_tasa_reducida) and participacion_accionaria >= 10:
                tasa_aplicable = tasa.tasa_reducida
            elif '≥80%' in str(tasa.condicion_tasa_reducida) and participacion_accionaria >= 80:
                tasa_aplicable = 0.0
        
        if tipo_ingreso == TipoIngreso.INTERESES:
            if es_banco and tasa.tasa_reducida and 'banc' in str(tasa.condicion_tasa_reducida).lower():
                tasa_aplicable = tasa.tasa_reducida
            if es_gobierno and tasa.tasa_reducida and 'gobierno' in str(tasa.condicion_tasa_reducida).lower():
                tasa_aplicable = 0.0
        
        return {
            'pais': pais,
            'tipo_ingreso': tipo_ingreso.value,
            'tasa_aplicable': tasa_aplicable,
            'tasa_general': tasa.tasa_general,
            'tasa_reducida': tasa.tasa_reducida,
            'condicion_tasa_reducida': tasa.condicion_tasa_reducida,
            'articulo_tratado': tasa.articulo_tratado,
            'observaciones': tasa.observaciones,
            'tratado_vigente': True
        }
    
    def validar_residencia_fiscal(self, pais: str, rfc: str = None) -> Dict[str, Any]:

                'Identificación oficial del beneficiario',

            ],

#### Algoritmo 2: Cálculo de Retención con Tratado

```python
def calcular_retencion_con_tratado(
    monto_bruto: float,
    pais: str,
    tipo_ingreso: TipoIngreso,
    participacion_accionaria: Optional[float] = None,
    es_banco: bool = False,
    es_gobierno: bool = False
) -> Dict[str, Any]:
    """
    Calcula retención de ISR aplicando tratado tributario.
    
    Args:
        monto_bruto: Monto bruto del pago
        pais: País de residencia del beneficiario
        tipo_ingreso: Tipo de ingreso
        participacion_accionaria: % de participación (dividendos)
        es_banco: Si aplica tasa reducida para bancos
        es_gobierno: Si aplica tasa 0% para gobierno
    
    Returns:
        Diccionario con cálculo detallado de retención
    """
    consultor = ConsultorTratadosTributarios()
    
    # Obtener tasa aplicable
    tasa_info = consultor.obtener_tasa_retencion(
        pais=pais,
        tipo_ingreso=tipo_ingreso,
        participacion_accionaria=participacion_accionaria,
        es_banco=es_banco,
        es_gobierno=es_gobierno
    )
    
    # Calcular retención
    monto_retencion = monto_bruto * (tasa_info['tasa_aplicable'] / 100)
    monto_neto = monto_bruto - monto_retencion
    
    # Calcular sin tratado (para comparación)
    tasa_sin_tratado = 25.0  # Tasa general LISR Art. 166
    retencion_sin_tratado = monto_bruto * (tasa_sin_tratado / 100)
    ahorro = retencion_sin_tratado - monto_retencion
    
    return {
        'monto_bruto': monto_bruto,
        'pais': pais,
        'tipo_ingreso': tipo_ingreso.value,
        'tasa_aplicable': tasa_info['tasa_aplicable'],
        'monto_retencion': monto_retencion,
        'monto_neto': monto_neto,
        'tasa_sin_tratado': tasa_sin_tratado,
        'retencion_sin_tratado': retencion_sin_tratado,
        'ahorro_fiscal': ahorro,
        'articulo_tratado': tasa_info['articulo_tratado'],
        'tratado_vigente': tasa_info['tratado_vigente'],
        'observaciones': tasa_info.get('observaciones', '')
    }


# Ejemplo de uso
if __name__ == "__main__":
    # Calcular retención de dividendos a residente de España
    resultado = calcular_retencion_con_tratado(
        monto_bruto=1_000_000,  # $1M MXN
        pais="España",
        tipo_ingreso=TipoIngreso.DIVIDENDOS,
        participacion_accionaria=30  # 30% de participación
    )
    
    print(f"Monto bruto: ${resultado['monto_bruto']:,.2f} MXN")
    print(f"País: {resultado['pais']}")
    print(f"Tipo de ingreso: {resultado['tipo_ingreso']}")
    print(f"Tasa aplicable: {resultado['tasa_aplicable']}%")
    print(f"Retención: ${resultado['monto_retencion']:,.2f} MXN")
    print(f"Monto neto: ${resultado['monto_neto']:,.2f} MXN")
    print(f"Retención sin tratado (25%): ${resultado['retencion_sin_tratado']:,.2f} MXN")
    print(f"Ahorro fiscal: ${resultado['ahorro_fiscal']:,.2f} MXN")
    print(f"Artículo del tratado: {resultado['articulo_tratado']}")
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Tratados No Actualizados

**Problema:**
Algunos tratados pueden estar renegociados pero la información oficial del SAT no está actualizada (ej: tratados antiguos de 2001 vs tratados de 2002-2018).

**Solución:**
```python
def verificar_vigencia_tratado(pais: str) -> Dict[str, Any]:
    """
    Verifica vigencia de tratado consultando SAT y DOF.
    
    Args:
        pais: País a verificar
    
    Returns:
        Diccionario con información de vigencia
    """
    # Lista de tratados renegociados
    tratados_renegociados = {
        "Austria": {"original": 1996, "renegociado": 2012, "vigente": True},
        "Reino Unido": {"original": 1994, "renegociado": 2007, "vigente": True},
        "Singapur": {"original": 1996, "protocolo": 2012, "vigente": True},
    }
    
    if pais in tratados_renegociados:
        info = tratados_renegociados[pais]
        return {
            'pais': pais,
            'tratado_original': info['original'],
            'tratado_renegociado': info['renegociado'],
            'vigente': info['vigente'],
            'observaciones': f"Usar tratado renegociado de {info['renegociado']}"
        }
    
    return {
        'pais': pais,
        'vigente': True,
        'observaciones': 'Tratado vigente sin renegociaciones'
    }
```

**Impacto:**
- Requiere validación manual con SAT para tratados antiguos
- Posible aplicación incorrecta de tasas si no se verifica vigencia

### 4.2 Limitación 2: Interpretación de Tratados

**Problema:**
Los tratados pueden tener interpretaciones diferentes según la autoridad (SAT vs TFJA). La jurisprudencia puede modificar la aplicación práctica.

**Solución:**
- **Múltiples interpretaciones:** Presentar ambas posturas cuando exista controversia
- **Actualización con jurisprudencia:** Incluir criterios del TFJA en la base de datos
- **Validación profesional:** Escalar casos complejos a contador certificado

**Impacto:**
- Respuestas más largas pero más precisas
- Requiere validación humana para casos complejos

### 4.3 Riesgos Técnicos Identificados

| Riesgo | Probabilidad | Impacto | Mitigación | Owner |
|--------|--------------|---------|------------|-------|
| **Tasa incorrecta por tratado desactualizado** | MEDIA | ALTO | Verificación con SAT trimestral | Fiscal Lead |
| **Cálculo erróneo de retención** | BAJA | ALTO | Tests unitarios con casos conocidos | QA Lead |
| **Constancia de residencia inválida** | MEDIA | MEDIO | Validación de formato y vigencia | Backend Lead |
| **MLI (BEPS) modifica tratado** | BAJA | MEDIO | Monitoreo de actualizaciones OCDE | Fiscal Lead |
