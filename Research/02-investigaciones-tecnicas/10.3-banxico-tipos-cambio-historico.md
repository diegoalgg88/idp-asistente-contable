## API de Banxico: Especificaciones Técnicas

### Sistema de Información Económica (SIE)

Banxico proporciona la **API del Sistema de Información Económica (SIE)** para consultar series de tiempo de indicadores económicos mexicanos.

**Documentación oficial**: https://www.banxico.org.mx/SieAPIRest/

### Endpoints Disponibles

#### 1. Obtener Datos de Serie

```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/{idSeries}/datos/{startDate}/{endDate}
```

**Parámetros:**
- `idSeries`: Identificador de la serie (ej. SF43718 para USD FIX)
- `startDate`: Fecha de inicio (formato: dd/MM/yyyy)
- `endDate`: Fecha de fin (formato: dd/MM/yyyy)

**Ejemplo:**
```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/SF43718/datos/01/01/2026/31/01/2026
```

#### 2. Obtener Metadatos de Serie

```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/{idSeries}
```

**Ejemplo:**
```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/SF43718
```

#### 3. Obtener Catálogo de Series

```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/catalogos/series
```

#### 4. Obtener Datos Oportunos (Último Valor)

```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/{idSeries}/datos/oportuno
```

**Ejemplo:**
```http
GET https://www.banxico.org.mx/SieAPIRest/service/v1/series/SF43718/datos/oportuno
```

## Casos de Uso Contable

### 1. Conversión de CFDI en Moneda Extranjera

#### Fundamento Legal (LISR Art. 27)

> **Artículo 27, fracción III, LISR**: "Las adquisiciones de bienes, obtención de servicios e importaciones que se paguen en moneda extranjera, se convertirán a pesos mexicanos al tipo de cambio de venta publicado en el Diario Oficial de la Federación, aplicable en la fecha en que se efectúe el pago."

#### Tipo de Cambio para DEDUCCIONES

```
Tipo de cambio aplicable = FIX Banxico del día ANTERIOR al pago
```

**Ejemplo:**
```
Fecha de pago: 15 de marzo 2026
Tipo de cambio aplicable = FIX del 14 de marzo 2026
Si 14 de marzo es sábado/domingo: FIX del viernes anterior
```

#### Tipo de Cambio para INGRESOS

```
Tipo de cambio aplicable = FIX Banxico del día de PAGO
```

**Ejemplo:**
```
Fecha de cobro: 15 de marzo 2026
Tipo de cambio aplicable = FIX del 15 de marzo 2026
```

#### Ejemplo Práctico: Conversión de Factura de Proveedor

```python
# Datos del CFDI
proveedor = "Microsoft Corporation"
monto_usd = 10000.00  # USD
fecha_pago = "2026-03-15"

# Obtener tipo de cambio FIX del día anterior (14 de marzo 2026)

# Convertir a pesos mexicanos
monto_mxn = monto_usd * tipo_cambio  # $178,540.00 MXN

# Registro contable

    'fecha': fecha_pago,
```

### 2. Cálculo de Diferencias Cambiarias (NIF B-15)

#### Fundamento Contable (NIF B-15)

**NIF B-15**: "Diferencias Cambiarias" establece las normas para el reconocimiento contable de las diferencias cambiarias derivadas de la conversión de activos y pasivos en moneda extranjera.

#### Conceptos Clave

| Concepto | Definición |
|----------|------------|
| **Moneda funcional** | Moneda del entorno económico principal (MXN para empresas mexicanas) |
| **Moneda extranjera** | Cualquier moneda diferente a la funcional |
| **Diferencia cambiaria** | Diferencia entre tipo de cambio de registro y tipo de cambio de valuación |
| **Realizada** | Cuando se liquida la operación (se paga o cobra) |
| **No realizada** | Cuando solo se valúa al cierre del periodo |

#### Fórmula de Cálculo

```
Diferencia Cambiaria = (Tipo de Cambio Cierre - Tipo de Cambio Registro) × Saldo en Moneda Extranjera
```

**Signo de la diferencia:**
- **Positiva**: Ganancia cambiaria (activo se aprecia o pasivo se deprecia)
- **Negativa**: Pérdida cambiaria (activo se deprecia o pasivo se aprecia)

#### Ejemplo Práctico: Diferencia Cambiaria No Realizada

```python
# Datos de la operación
fecha_registro = "2026-02-15"
saldo_usd = 50000.00  # Saldo en dólares (cuenta por cobrar)
tipo_cambio_registro = 17.5000  # FIX del 14 de febrero 2026 (día anterior al registro)

# Valuación al cierre del mes (28 de febrero 2026)
fecha_cierre = "2026-02-28"
tipo_cambio_cierre = 17.8500  # FIX del 28 de febrero 2026

# Calcular diferencia cambiaria
diferencia_cambiaria = (tipo_cambio_cierre - tipo_cambio_registro) * saldo_usd
# = (17.8500 - 17.5000) × 50,000
# = 0.3500 × 50,000
# = $17,500.00 MXN (GANANCIA no realizada)

# Asiento de ajuste al 28 de febrero 2026
asiento_ajuste = {
    'fecha': fecha_cierre,
    'cuenta_cargo': '1105-001',  # Cuentas por cobrar - Ajuste cambiario
    'monto_cargo': 17500.00,
    'cuenta_abono': '7200-001',  # Utilidad por diferencia cambiaria
    'monto_abono': 17500.00,
    'concepto': 'Ajuste cambiario no realizado - CxC USD'
}
```

#### Ejemplo Práctico: Diferencia Cambiaria Realizada

```python
# Datos de la operación
fecha_registro = "2026-02-15"
saldo_usd = 50000.00
tipo_cambio_registro = 17.5000

# Fecha de cobro (liquidación)
fecha_cobro = "2026-03-10"
tipo_cambio_cobro = 17.9200  # FIX del 10 de marzo 2026

# Diferencia cambiaria realizada al momento del cobro
diferencia_realizada = (tipo_cambio_cobro - tipo_cambio_registro) * saldo_usd
# = (17.9200 - 17.5000) × 50,000
# = 0.4200 × 50,000
# = $21,000.00 MXN (GANANCIA realizada)

# Asiento al momento del cobro
asiento_cobro = {
    'fecha': fecha_cobro,
    'cuenta_cargo': '1100-001',  # Bancos nacional
    'monto_cargo': 896000.00,  # 50,000 × 17.9200
    'cuenta_abono': '1105-001',  # Cuentas por cobrar
    'monto_abono': 875000.00,  # 50,000 × 17.5000 (valor en libros)
    'cuenta_abono_2': '7200-001',  # Utilidad por diferencia cambiaria
    'monto_abono_2': 21000.00,
    'concepto': 'Cobro de factura USD con diferencia cambiaria'
}
```

#### Tratamiento Fiscal de Diferencias Cambiarias

**LISR Art. 27, fracción XIII**:
- **Diferencias cambiarias obtenidas**: Son ingresos acumulables
- **Diferencias cambiarias perdidas**: Son deducciones autorizadas

**Momento de reconocimiento fiscal:**
- **Realizadas**: Se acumulan/deducen en el ejercicio en que se pagan o cobran
- **No realizadas**: NO son deducibles ni acumulables fiscalmente (solo contablemente)

### 3. Valuación de Activos y Pasivos en Moneda Extranjera

#### Activos Típicos en Moneda Extranjera

| Cuenta | Descripción | Tipo de Cambio |
|--------|-------------|----------------|
| 1100-002 | Bancos en USD | Fix al cierre |
| 1105-002 | Clientes en USD | Fix al cierre |
| 1110-002 | Deudores en USD | Fix al cierre |
| 1200-002 | Inversiones en USD | Fix al cierre |

#### Pasivos Típicos en Moneda Extranjera

| Cuenta | Descripción | Tipo de Cambio |
|--------|-------------|----------------|
| 2100-002 | Proveedores en USD | Fix al cierre |
| 2105-002 | Acreedores en USD | Fix al cierre |
| 2200-002 | Préstamos bancarios en USD | Fix al cierre |

#### Proceso de Valuación Mensual

```python
def valuar_moneda_extranjera(cuentas: List[Dict], fecha_cierre: str) -> List[Dict]:
    """
    Valúa cuentas en moneda extranjera al tipo de cambio de cierre.
    
    Args:
        cuentas: Lista de cuentas con saldos en moneda extranjera
        fecha_cierre: Fecha de cierre (YYYY-MM-DD)
    
    Returns:
        Lista de asientos de ajuste por diferencia cambiaria
    """
    # Obtener tipo de cambio de Banxico
    tipo_cambio_cierre = obtener_tipo_cambio_banxico(fecha_cierre)
    
    asientos_ajuste = []
    
    for cuenta in cuentas:
        saldo_moneda_original = cuenta['saldo']  # En USD
        tipo_cambio_historico = cuenta['tipo_cambio_promedio']
        tipo_cambio_cierre = tipo_cambio_cierre
        
        # Calcular diferencia
        diferencia = (tipo_cambio_cierre - tipo_cambio_historico) * saldo_moneda_original
        
        if diferencia != 0:
            # Determinar cuentas según naturaleza
            if cuenta['naturaleza'] == 'activo':
                if diferencia > 0:
                    # Ganancia: cargo activo, abono utilidad
                    asiento = {
                        'cuenta_cargo': cuenta['codigo'],
                        'monto_cargo': abs(diferencia),
                        'cuenta_abono': '7200-001',  # Utilidad por dif. cambiaria
                        'monto_abono': abs(diferencia)
                    }
                else:
                    # Pérdida: cargo pérdida, abono activo
                    asiento = {
                        'cuenta_cargo': '8300-001',  # Pérdida por dif. cambiaria
                        'monto_cargo': abs(diferencia),
                        'cuenta_abono': cuenta['codigo'],
                        'monto_abono': abs(diferencia)
                    }
            else:  # pasivo
                if diferencia > 0:
                    # Pérdida en pasivo: cargo pérdida, abono pasivo
                    asiento = {
                        'cuenta_cargo': '8300-001',
                        'monto_cargo': abs(diferencia),
                        'cuenta_abono': cuenta['codigo'],
                        'monto_abono': abs(diferencia)
                    }
                else:
                    # Ganancia en pasivo: cargo pasivo, abono utilidad
                    asiento = {
                        'cuenta_cargo': cuenta['codigo'],
                        'monto_cargo': abs(diferencia),
                        'cuenta_abono': '7200-001',
                        'monto_abono': abs(diferencia)
                    }
            
            asiento['fecha'] = fecha_cierre
            asiento['concepto'] = f"Ajuste cambiario {cuenta['codigo']} - {cuenta['moneda']}"
            asientos_ajuste.append(asiento)
    
    return asientos_ajuste
```

## Implementación Técnica

### Funciones Python para Integración con Banxico

```python
"""
Módulo: banxico_tipo_cambio.py
Propósito: Integración con API de Banxico para tipos de cambio históricos
Versión: 1.0
Fecha: 2026-03-10
"""

import requests
from typing import Optional, Dict, List, Union
from datetime import datetime, timedelta
from decimal import Decimal
import json
from pathlib import Path


class BanxicoTipoCambioClient:
    """
    Cliente para la API de Banxico (Sistema de Información Económica).
    Permite consultar tipos de cambio históricos y actuales.
    """
    
    BASE_URL = "https://www.banxico.org.mx/SieAPIRest/service/v1"
    
    # Series de tipos de cambio
    SERIES = {
        'USD_FIX': 'SF43718',
        'EUR': 'SF46410',
        'JPY': 'SF46406',
        'GBP': 'SF46407',
        'CAD': 'SF60632',
        'TIIE_28': 'SF43783',
        'CETES_28': 'SF43936'
    }
    
    def __init__(self, token: str, cache_dir: Optional[str] = None):
        """
        Inicializa el cliente de Banxico.
        
        Args:
            token: Token de autenticación de Banxico
            cache_dir: Directorio para caché de tipos de cambio (opcional)
        """
        self.token = token
        self.cache_dir = Path(cache_dir) if cache_dir else None
        self.session = requests.Session()
        self.session.headers.update({
            'Bmx-Token': token,
            'Content-Type': 'application/json'
        })
        
        if self.cache_dir:
            self.cache_dir.mkdir(parents=True, exist_ok=True)
    
    def obtener_tipo_cambio(self, fecha: str, moneda: str = 'USD_FIX') -> Optional[Decimal]:
        """
        Obtiene el tipo de cambio para una fecha específica.
        
        Args:
            fecha: Fecha en formato YYYY-MM-DD
            moneda: Código de moneda (USD_FIX, EUR, JPY, GBP, CAD)
        
        Returns:
            Tipo de cambio como Decimal, o None si no hay datos
        """
        # Verificar caché
        if self.cache_dir:
            cache_file = self.cache_dir / f"{moneda}_{fecha}.json"
            if cache_file.exists():
                with open(cache_file, 'r', encoding='utf-8') as f:
                    data = json.load(f)
                    return Decimal(data['dato'])
        
        # Consultar API
        try:
            series_id = self.SERIES[moneda]
            url = f"{self.BASE_URL}/series/{series_id}/datos/{fecha}/{fecha}"
            
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            
            data = response.json()
            
            # Extraer tipo de cambio
            if 'bmx' in data and 'series' in data['bmx']:
                series = data['bmx']['series'][0]
                if series.get('datos'):
                    tipo_cambio = Decimal(series['datos'][0]['dato'])
                    
                    # Guardar en caché
                    if self.cache_dir:
                        cache_file = self.cache_dir / f"{moneda}_{fecha}.json"
                        with open(cache_file, 'w', encoding='utf-8') as f:
                            json.dump({'fecha': fecha, 'dato': str(tipo_cambio)}, f)
                    
                    return tipo_cambio
            
            return None
            
        except (requests.RequestException, KeyError, IndexError, json.JSONDecodeError) as e:
            print(f"Error al obtener tipo de cambio: {e}")
            return None
    
    def obtener_tipo_cambio_rango(self, fecha_inicio: str, 
                                   fecha_fin: str, 
                                   moneda: str = 'USD_FIX') -> Dict[str, Decimal]:
        """
        Obtiene tipos de cambio para un rango de fechas.
        
        Args:
            fecha_inicio: Fecha inicial (YYYY-MM-DD)
            fecha_fin: Fecha final (YYYY-MM-DD)
            moneda: Código de moneda
        
        Returns:
            Diccionario {fecha: tipo_cambio}
        """
        try:
            series_id = self.SERIES[moneda]
            url = f"{self.BASE_URL}/series/{series_id}/datos/{fecha_inicio}/{fecha_fin}"
            
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            
            data = response.json()
            resultados = {}
            
            if 'bmx' in data and 'series' in data['bmx']:
                series = data['bmx']['series'][0]
                for dato in series.get('datos', []):
                    fecha = dato['fecha']  # Formato: dd/MM/yyyy
                    tipo_cambio = Decimal(dato['dato'])
                    # Convertir a YYYY-MM-DD
                    fecha_obj = datetime.strptime(fecha, '%d/%m/%Y')
                    fecha_iso = fecha_obj.strftime('%Y-%m-%d')
                    resultados[fecha_iso] = tipo_cambio
            
            return resultados
            
        except Exception as e:
            print(f"Error al obtener rango de tipos de cambio: {e}")
            return {}
    
    def obtener_ultimo_tipo_cambio(self, moneda: str = 'USD_FIX') -> Optional[Decimal]:
        """
        Obtiene el último tipo de cambio disponible.
        
        Args:
            moneda: Código de moneda
        
        Returns:
            Último tipo de cambio disponible
        """
        try:
            series_id = self.SERIES[moneda]
            url = f"{self.BASE_URL}/series/{series_id}/datos/oportuno"
            
            response = self.session.get(url, timeout=30)
            response.raise_for_status()
            
            data = response.json()
            
            if 'bmx' in data and 'series' in data['bmx']:
                series = data['bmx']['series'][0]
                if series.get('datos'):
                    return Decimal(series['datos'][0]['dato'])
            
            return None
            
        except Exception as e:
            print(f"Error al obtener último tipo de cambio: {e}")
            return None
    
    def obtener_tipo_cambio_anterior(self, fecha: str, moneda: str = 'USD_FIX') -> Optional[Decimal]:
        """
        Obtiene el tipo de cambio del día hábil anterior.
        Útil para deducciones (LISR Art. 27).
        
        Args:
            fecha: Fecha de referencia (YYYY-MM-DD)
            moneda: Código de moneda
        
        Returns:
            Tipo de cambio del día hábil anterior
        """
        fecha_obj = datetime.strptime(fecha, '%Y-%m-%d')
        
        # Intentar días anteriores hasta encontrar uno hábil
        for i in range(1, 10):  # Máximo 9 días atrás
            fecha_anterior = fecha_obj - timedelta(days=i)
            fecha_anterior_str = fecha_anterior.strftime('%Y-%m-%d')
            
            tipo_cambio = self.obtener_tipo_cambio(fecha_anterior_str, moneda)
            if tipo_cambio:
                return tipo_cambio
        
        return None


class ConvertidorMonedaExtranjera:
    """
    Convierte montos entre monedas extranjeras y pesos mexicanos
    usando tipos de cambio de Banxico.
    """
    
    def __init__(self, banxico_client: BanxicoTipoCambioClient):
        """
        Inicializa el convertidor.
        
        Args:
            banxico_client: Instancia de BanxicoTipoCambioClient
        """
        self.client = banxico_client
    
    def convertir_a_mxn(self, monto: Decimal, moneda: str, 
                        fecha: str, tipo: str = 'deduccion') -> Decimal:
        """
        Convierte un monto en moneda extranjera a pesos mexicanos.
        
        Args:
            monto: Monto en moneda extranjera
            moneda: Código de moneda (USD, EUR, etc.)
            fecha: Fecha de la operación (YYYY-MM-DD)
            tipo: 'deduccion' (día anterior) o 'ingreso' (mismo día)
        
        Returns:
            Monto convertido a pesos mexicanos
        """
        if tipo == 'deduccion':
            # Para deducciones: tipo de cambio del día anterior
            tipo_cambio = self.client.obtener_tipo_cambio_anterior(fecha, f"{moneda}_FIX")
        else:
            # Para ingresos: tipo de cambio del mismo día
            tipo_cambio = self.client.obtener_tipo_cambio(fecha, f"{moneda}_FIX")
        
        if not tipo_cambio:
            raise ValueError(f"No se pudo obtener tipo de cambio para {fecha}")
        
        return monto * tipo_cambio
    
    def convertir_de_mxn(self, monto_mxn: Decimal, moneda: str, 
                         fecha: str) -> Decimal:
        """
        Convierte un monto de pesos mexicanos a moneda extranjera.
        
        Args:
            monto_mxn: Monto en pesos mexicanos
            moneda: Código de moneda destino
            fecha: Fecha de la operación
        
        Returns:
            Monto convertido a moneda extranjera
        """
        tipo_cambio = self.client.obtener_tipo_cambio(fecha, f"{moneda}_FIX")
        
        if not tipo_cambio:
            raise ValueError(f"No se pudo obtener tipo de cambio para {fecha}")
        
        return monto_mxn / tipo_cambio


class CalculadorDiferenciasCambiarias:
    """
    Calcula diferencias cambiarias según NIF B-15.
    """
    
    def __init__(self, banxico_client: BanxicoTipoCambioClient):
        """
        Inicializa el calculador.
        
        Args:
            banxico_client: Instancia de BanxicoTipoCambioClient
        """
        self.client = banxico_client
    
    def calcular_diferencia_no_realizada(self, saldo_moneda_original: Decimal,
                                          tipo_cambio_registro: Decimal,
                                          fecha_cierre: str,
                                          moneda: str = 'USD') -> Dict:
        """
        Calcula diferencia cambiaria no realizada al cierre del periodo.
        
        Args:
            saldo_moneda_original: Saldo en moneda extranjera
            tipo_cambio_registro: Tipo de cambio histórico de registro
            fecha_cierre: Fecha de cierre (YYYY-MM-DD)
            moneda: Código de moneda
        
        Returns:
            Diccionario con diferencia calculada y detalles
        """
        # Obtener tipo de cambio de cierre
        tipo_cambio_cierre = self.client.obtener_tipo_cambio(fecha_cierre, f"{moneda}_FIX")
        
        if not tipo_cambio_cierre:
            raise ValueError(f"No se pudo obtener tipo de cambio para {fecha_cierre}")
        
        # Calcular diferencia
        diferencia_cambiaria = (tipo_cambio_cierre - tipo_cambio_registro) * saldo_moneda_original
        
        # Determinar tipo
        if diferencia_cambiaria > 0:
            tipo = 'ganancia'
            cuenta_contrapartida = '7200-001'  # Utilidad por dif. cambiaria
        else:
            tipo = 'perdida'
            cuenta_contrapartida = '8300-001'  # Pérdida por dif. cambiaria
        
        return {
            'fecha_cierre': fecha_cierre,
            'saldo_moneda_original': saldo_moneda_original,
            'moneda': moneda,
            'tipo_cambio_registro': tipo_cambio_registro,
            'tipo_cambio_cierre': tipo_cambio_cierre,
            'diferencia_cambiaria': diferencia_cambiaria,
            'tipo': tipo,
            'cuenta_contrapartida': cuenta_contrapartida,
            'es_no_realizada': True
        }
    
    def calcular_diferencia_realizada(self, saldo_moneda_original: Decimal,
                                       tipo_cambio_registro: Decimal,
                                       fecha_liquidacion: str,
                                       moneda: str = 'USD') -> Dict:
        """
        Calcula diferencia cambiaria realizada al momento de liquidación.
        
        Args:
            saldo_moneda_original: Saldo en moneda extranjera
            tipo_cambio_registro: Tipo de cambio histórico de registro
            fecha_liquidacion: Fecha de pago/cobro (YYYY-MM-DD)
            moneda: Código de moneda
        
        Returns:
            Diccionario con diferencia calculada y detalles
        """
        # Obtener tipo de cambio de liquidación
        tipo_cambio_liquidacion = self.client.obtener_tipo_cambio(fecha_liquidacion, f"{moneda}_FIX")
        
        if not tipo_cambio_liquidacion:
            raise ValueError(f"No se pudo obtener tipo de cambio para {fecha_liquidacion}")
        
        # Calcular diferencia
        diferencia_cambiaria = (tipo_cambio_liquidacion - tipo_cambio_registro) * saldo_moneda_original
        
        # Determinar tipo
        if diferencia_cambiaria > 0:
            tipo = 'ganancia'
            cuenta_contrapartida = '7200-001'
        else:
            tipo = 'perdida'
            cuenta_contrapartida = '8300-001'
        
        return {
            'fecha_liquidacion': fecha_liquidacion,
            'saldo_moneda_original': saldo_moneda_original,
            'moneda': moneda,
            'tipo_cambio_registro': tipo_cambio_registro,
            'tipo_cambio_liquidacion': tipo_cambio_liquidacion,
            'diferencia_cambiaria': diferencia_cambiaria,
            'tipo': tipo,
            'cuenta_contrapartida': cuenta_contrapartida,
            'es_no_realizada': False
        }


class ValidadorTiposCambioCFDI:
    """
    Valida que los tipos de cambio en CFDI sean correctos según SAT.
    """
    
    def __init__(self, banxico_client: BanxicoTipoCambioClient):
        """
        Inicializa el validador.
        
        Args:
            banxico_client: Instancia de BanxicoTipoCambioClient
        """
        self.client = banxico_client
    
    def validar_cfdi_ingreso(self, cfdi: Dict) -> Dict:
        """
        Valida tipo de cambio en CFDI de ingreso (venta).
        
        Args:
            cfdi: Diccionario con datos del CFDI
        
        Returns:
            Resultado de validación
        """
        fecha_pago = cfdi['fecha_pago']  # YYYY-MM-DD
        tipo_cambio_cfdi = Decimal(cfdi['tipo_cambio'])
        moneda = cfdi['moneda']
        
        # Obtener tipo de cambio oficial del mismo día
        tipo_cambio_oficial = self.client.obtener_tipo_cambio(fecha_pago, f"{moneda}_FIX")
        
        if not tipo_cambio_oficial:
            return {
                'valido': False,
                'error': 'No se pudo obtener tipo de cambio oficial'
            }
        
        # Comparar (tolerancia de 0.01 por redondeo)
        diferencia = abs(tipo_cambio_cfdi - tipo_cambio_oficial)
        
        if diferencia <= Decimal('0.01'):
            return {
                'valido': True,
                'tipo_cambio_cfdi': tipo_cambio_cfdi,
                'tipo_cambio_oficial': tipo_cambio_oficial,
                'mensaje': 'Tipo de cambio correcto'
            }
        else:
            return {
                'valido': False,
                'tipo_cambio_cfdi': tipo_cambio_cfdi,
                'tipo_cambio_oficial': tipo_cambio_oficial,
                'diferencia': diferencia,
                'error': f'Tipo de cambio incorrecto. Diferencia: {diferencia}'
            }
    
    def validar_cfdi_egreso(self, cfdi: Dict) -> Dict:
        """
        Valida tipo de cambio en CFDI de egreso (compra).
        
        Args:
            cfdi: Diccionario con datos del CFDI
        
        Returns:
            Resultado de validación
        """
        fecha_pago = cfdi['fecha_pago']
        tipo_cambio_cfdi = Decimal(cfdi['tipo_cambio'])
        moneda = cfdi['moneda']
        
        # Obtener tipo de cambio oficial del día ANTERIOR
        tipo_cambio_oficial = self.client.obtener_tipo_cambio_anterior(fecha_pago, f"{moneda}_FIX")
        
        if not tipo_cambio_oficial:
            return {
                'valido': False,
                'error': 'No se pudo obtener tipo de cambio oficial'
            }
        
        # Comparar
        diferencia = abs(tipo_cambio_cfdi - tipo_cambio_oficial)
        
        if diferencia <= Decimal('0.01'):
            return {
                'valido': True,
                'tipo_cambio_cfdi': tipo_cambio_cfdi,
                'tipo_cambio_oficial': tipo_cambio_oficial,
                'mensaje': 'Tipo de cambio correcto para deducción'
            }
        else:
            return {
                'valido': False,
                'tipo_cambio_cfdi': tipo_cambio_cfdi,
                'tipo_cambio_oficial': tipo_cambio_oficial,
                'diferencia': diferencia,
                'error': f'Tipo de cambio incorrecto. Diferencia: {diferencia}'
            }
    
    def validar_lote_cfdi(self, cfdi_list: List[Dict]) -> List[Dict]:
        """
        Valida múltiples CFDI en lote.
        
        Args:
            cfdi_list: Lista de CFDI a validar
        
        Returns:
            Lista de resultados de validación
        """
        resultados = []
        
        for cfdi in cfdi_list:
            if cfdi['tipo'] == 'ingreso':
                resultado = self.validar_cfdi_ingreso(cfdi)
            else:
                resultado = self.validar_cfdi_egreso(cfdi)
            
            resultado['cfdi_uuid'] = cfdi.get('uuid', 'N/A')
            resultados.append(resultado)
        
        return resultados
```

## Consideraciones Fiscales (LISR 2026)

### Artículo 27 LISR - Deducciones

**Fracción III**: Tipo de cambio para deducciones

> "Las adquisiciones de bienes, obtención de servicios e importaciones que se paguen en moneda extranjera, se convertirán a pesos mexicanos al tipo de cambio de venta publicado en el Diario Oficial de la Federación, aplicable en la **fecha en que se efectúe el pago**."

**Interpretación SAT**:
- Para pagos en efectivo: Tipo de cambio del día de pago
- Para pagos con cheque: Tipo de cambio del día de expedición del cheque
- Para pagos con tarjeta: Tipo de cambio del día de liquidación de la tarjeta
- Para transferencias: Tipo de cambio del día de la transferencia

**Importante**: El tipo de cambio FIX de Banxico se publica en el DOF diariamente.

### Artículo 14 LISR - Ingresos

**Tipo de cambio para ingresos**:

> "Los ingresos que se obtengan en moneda extranjera se convertirán a pesos mexicanos al tipo de cambio de venta publicado en el Diario Oficial de la Federación, aplicable en la **fecha en que se obtenga el ingreso**."
