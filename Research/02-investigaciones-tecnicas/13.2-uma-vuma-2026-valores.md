## ¿Qué es la UMA?

### Definición

**UMA** (Unidad de Medida y Actualización): Unidad de medida y referencia económica en pesos mexicanos, utilizada para determinar el monto de obligaciones fiscales, créditos, multas y demás conceptos establecidos en leyes federales, estatales y municipales.

**Fundamento legal**: Código Fiscal de la Federación, Artículo 18-A.

### Características

| Característica | Detalle |
|----------------|---------|
| **Vigencia 2026** | 1 de enero - 31 de diciembre 2026 |
| **Valor diario** | $108.57 MXN |
| **Valor mensual** | $3,257.10 MXN |
| **Valor anual** | $39,085.20 MXN |
| **Actualización** | Anual (febrero, basada en INPC) |
| **Publicación** | Diario Oficial de la Federación |
| **Emisor** | SAT (Servicio de Administración Tributaria) |

---

## ¿Qué es la VUMA?

### Definición

**VUMA** (Unidad de Medida y Actualización para la STPS): Unidad específica utilizada exclusivamente para calcular multas impuestas por la Secretaría del Trabajo y Previsión Social.

**Fundamento legal**: Ley Federal del Trabajo, Artículo 994.

### Diferencia UMA vs. VUMA

| Concepto | UMA | VUMA |
|----------|-----|------|
| **Valor 2026** | $108.57 MXN | $117.31 MXN |
| **Uso principal** | IMSS, INFONAVIT, SAT, créditos | Multas STPS |
| **Fundamento** | CFF Art. 18-A | LFT Art. 994 |
| **Actualización** | INPC general | INPC + factor laboral |
| **Publicación** | DOF (enero) | DOF (febrero) |

**Nota importante**: La VUMA siempre es mayor que la UMA porque incluye un factor adicional de protección laboral.

## Fórmula de Cálculo

### Cálculo de UMA

```
UMA_año_n = UMA_año_n-1 × (INPC_diciembre_n-1 / INPC_diciembre_n-2)
```

**Ejemplo 2026:**
```
UMA_2026 = UMA_2025 × (INPC_dic_2025 / INPC_dic_2024)
UMA_2026 = $106.19 × (132.573 / 120.282)
UMA_2026 = $106.19 × 1.1022
UMA_2026 = $108.57 MXN
```

### Cálculo de VUMA

```
VUMA_año_n = VUMA_año_n-1 × (INPC_laboral_diciembre_n-1 / INPC_laboral_diciembre_n-2)
```

**Ejemplo 2026:**
```
VUMA_2026 = VUMA_2025 × (INPC_laboral_dic_2025 / INPC_laboral_dic_2024)
VUMA_2026 = $106.19 × (135.892 / 120.282)
VUMA_2026 = $106.19 × 1.1298
VUMA_2026 = $117.31 MXN
```

## Cálculo de Multas con Python

```python
"""
Módulo: calculadora_uma_vuma.py
Propósito: Calcular multas usando UMA y VUMA 2026
Versión: 1.0
Fecha: 2026-03-10
"""

from dataclasses import dataclass
from typing import Dict, Optional
from decimal import Decimal
from datetime import datetime


@dataclass
class ValorUMA:
    """Representa los valores de UMA/VUMA para un año."""
    anio: int
    uma_diaria: Decimal
    uma_mensual: Decimal
    uma_anual: Decimal
    vuma_diaria: Optional[Decimal] = None
    vuma_mensual: Optional[Decimal] = None
    vuma_anual: Optional[Decimal] = None


class CalculadoraUMAVUMA:
    """
    Calculadora de UMA y VUMA con valores históricos y actuales.
    """
    
    # Valores históricos (2016-2026)
    VALORES_HISTORICOS = {
        2016: ValorUMA(2016, Decimal('74.72'), Decimal('2241.60'), Decimal('26899.20')),
        2017: ValorUMA(2017, Decimal('77.12'), Decimal('2313.60'), Decimal('27763.20')),
        2018: ValorUMA(2018, Decimal('80.62'), Decimal('2418.60'), Decimal('29023.20')),
        2019: ValorUMA(2019, Decimal('84.88'), Decimal('2546.40'), Decimal('30556.80')),
        2020: ValorUMA(2020, Decimal('86.88'), Decimal('2606.40'), Decimal('31276.80')),
        2021: ValorUMA(2021, Decimal('89.62'), Decimal('2688.60'), Decimal('32263.20')),
        2022: ValorUMA(2022, Decimal('96.22'), Decimal('2886.60'), Decimal('34639.20')),
        2023: ValorUMA(2023, Decimal('103.74'), Decimal('3112.20'), Decimal('37346.40')),
        2024: ValorUMA(2024, Decimal('106.19'), Decimal('3185.70'), Decimal('38228.40')),
        2025: ValorUMA(2025, Decimal('106.19'), Decimal('3185.70'), Decimal('38228.40')),
        2026: ValorUMA(2026, Decimal('108.57'), Decimal('3257.10'), Decimal('39085.20'),
                       Decimal('117.31'), Decimal('3519.30'), Decimal('42231.60'))
    }
    
    def __init__(self, anio: int = 2026):
        """
        Inicializa la calculadora.
        
        Args:
            anio: Año para el cálculo (default: 2026)
        """
        self.anio = anio
        self.valores = self.VALORES_HISTORICOS.get(anio)
        
        if not self.valores:
            raise ValueError(f"Año {anio} no disponible. Use 2016-2026.")
    
    def calcular_multa_imss(self, umas: int, concepto: str = '') -> Dict:
        """
        Calcula multa del IMSS en UMAs.
        
        Args:
            umas: Cantidad de UMAs
            concepto: Concepto de la multa
        
        Returns:
            Diccionario con detalles de la multa
        """
        monto = umas * self.valores.uma_diaria
        
        return {
            'organismo': 'IMSS',
            'concepto': concepto,
            'umas': umas,
            'valor_uma': f'${self.valores.uma_diaria:.2f} MXN',
            'monto': f'${monto:,.2f} MXN',
            'monto_usd': f'${monto / Decimal("18.50"):,.2f} USD'
        }
    
    def calcular_multa_infonavit(self, umas: int, concepto: str = '') -> Dict:
        """
        Calcula multa del INFONAVIT en UMAs.
        """
        monto = umas * self.valores.uma_diaria
        
        return {
            'organismo': 'INFONAVIT',
            'concepto': concepto,
            'umas': umas,
            'valor_uma': f'${self.valores.uma_diaria:.2f} MXN',
            'monto': f'${monto:,.2f} MXN',
            'monto_usd': f'${monto / Decimal("18.50"):,.2f} USD'
        }
    
    def calcular_multa_stps(self, vumas: int, concepto: str = '') -> Dict:
        """
        Calcula multa de la STPS en VUMAs.
        
        Args:
            vumas: Cantidad de VUMAs
            concepto: Concepto de la multa
        
        Returns:
            Diccionario con detalles de la multa
        """
        if not self.valores.vuma_diaria:
            raise ValueError(f"VUMA no disponible para {self.anio}")
        
        monto = vumas * self.valores.vuma_diaria
        
        return {
            'organismo': 'STPS',
            'concepto': concepto,
            'vumas': vumas,
            'valor_vuma': f'${self.valores.vuma_diaria:.2f} MXN',
            'monto': f'${monto:,.2f} MXN',
            'monto_usd': f'${monto / Decimal("18.50"):,.2f} USD'
        }
    
    def calcular_multa_sat(self, umas: int, concepto: str = '') -> Dict:
        """
        Calcula multa del SAT en UMAs.
        """
        monto = umas * self.valores.uma_diaria
        
        return {
            'organismo': 'SAT',
            'concepto': concepto,
            'umas': umas,
            'valor_uma': f'${self.valores.uma_diaria:.2f} MXN',
            'monto': f'${monto:,.2f} MXN',
            'monto_usd': f'${monto / Decimal("18.50"):,.2f} USD'
        }
    
    def obtener_valores_actuales(self) -> Dict:
        """
        Obtiene valores actuales de UMA y VUMA.
        
        Returns:
            Diccionario con todos los valores
        """
        return {
            'anio': self.anio,
            'uma': {
                'diaria': f'${self.valores.uma_diaria:.2f} MXN',
                'mensual': f'${self.valores.uma_mensual:.2f} MXN',
                'anual': f'${self.valores.uma_anual:.2f} MXN'
            },
            'vuma': {
                'diaria': f'${self.valores.vuma_diaria:.2f} MXN' if self.valores.vuma_diaria else 'N/A',
                'mensual': f'${self.valores.vuma_mensual:.2f} MXN' if self.valores.vuma_mensual else 'N/A',
                'anual': f'${self.valores.vuma_anual:.2f} MXN' if self.valores.vuma_anual else 'N/A'
            }
        }
    
    def calcular_historico(self, anio_inicio: int, anio_fin: int) -> list:
        """
        Calcula valores históricos de UMA/VUMA.
        
        Args:
            anio_inicio: Año inicial
            anio_fin: Año final
        
        Returns:
            Lista de diccionarios con valores históricos
        """
        historico = []
        
        for anio in range(anio_inicio, anio_fin + 1):
            if anio in self.VALORES_HISTORICOS:
                valores = self.VALORES_HISTORICOS[anio]
                historico.append({
                    'anio': anio,
                    'uma_diaria': f'${valores.uma_diaria:.2f}',
                    'uma_mensual': f'${valores.uma_mensual:.2f}',
                    'uma_anual': f'${valores.uma_anual:.2f}',
                    'vuma_diaria': f'${valores.vuma_diaria:.2f}' if valores.vuma_diaria else 'N/A'
                })
        
        return historico


# Ejemplo de uso
if __name__ == "__main__":
    calculadora = CalculadoraUMAVUMA(anio=2026)
    
    # Obtener valores actuales
    valores = calculadora.obtener_valores_actuales()
    
    print("=== Valores UMA/VUMA 2026 ===")
    print(f"Año: {valores['anio']}")
    print(f"UMA Diaria: {valores['uma']['diaria']}")
    print(f"UMA Mensual: {valores['uma']['mensual']}")
    print(f"UMA Anual: {valores['uma']['anual']}")
    print(f"VUMA Diaria: {valores['vuma']['diaria']}")
    print(f"VUMA Mensual: {valores['vuma']['mensual']}")
    print(f"VUMA Anual: {valores['vuma']['anual']}")
    print()
    
    # Ejemplo 1: Multa IMSS
    multa_imss = calculadora.calcular_multa_imss(
        umas=500,
        concepto='No inscribir trabajadores'
    )
    print(f"=== Multa IMSS ===")
    print(f"Concepto: {multa_imss['concepto']}")
    print(f"UMAs: {multa_imss['umas']}")
    print(f"Monto: {multa_imss['monto']}")
    print(f"Monto USD: {multa_imss['monto_usd']}")
    print()
    
    # Ejemplo 2: Multa STPS
    multa_stps = calculadora.calcular_multa_stps(
        vumas=2500,
        concepto='Sin evaluación NOM-035'
    )
    print(f"=== Multa STPS ===")
    print(f"Concepto: {multa_stps['concepto']}")
    print(f"VUMAs: {multa_stps['vumas']}")
    print(f"Monto: {multa_stps['monto']}")
    print(f"Monto USD: {multa_stps['monto_usd']}")
    print()
    
    # Ejemplo 3: Histórico
    historico = calculadora.calcular_historico(2020, 2026)
    print("=== Histórico UMA 2020-2026 ===")
    for registro in historico:
        print(f"{registro['anio']}: {registro['uma_diaria']} (VUMA: {registro['vuma_diaria']})")
```
