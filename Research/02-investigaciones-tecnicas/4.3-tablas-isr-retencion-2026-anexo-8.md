#### Fórmula de Cálculo del Subsidio al Empleo 2026

```
Si Ingreso Mensual <= $8,446.00:
    Subsidio = $628.00 - ((Ingreso Mensual - $628.00) × 0.2066)
    
Si Ingreso Mensual > $8,446.00:
    Subsidio = $0.00 (No corresponde subsidio)
```

**Ejemplo:**
- Ingreso mensual: $6,000.00
- Subsidio = $628.00 - (($6,000.00 - $628.00) × 0.2066)
- Subsidio = $628.00 - ($5,372.00 × 0.2066)
- Subsidio = $628.00 - $1,109.86
- Subsidio = $0.00 (no corresponde, resultado negativo)

**Otro ejemplo:**
- Ingreso mensual: $2,000.00
- Subsidio = $628.00 - (($2,000.00 - $628.00) × 0.2066)
- Subsidio = $628.00 - ($1,372.00 × 0.2066)

```python
    def obtener_tabla(self, periodo: PeriodoPago) -> List[RenglonISR]:
        """
        Obtiene la tabla de retención correspondiente al periodo de pago.
        
        Args:
            periodo: Periodo de pago (diario, semanal, quincenal, mensual)
            
        Returns:

        """
        tablas = {
            PeriodoPago.DIARIO: self.tabla_diaria,
            PeriodoPago.SEMANAL: self.tabla_semanal,
            PeriodoPago.DECENAL: self.tabla_semanal,  # Usar tabla semanal para decenal
            PeriodoPago.QUINCENAL: self.tabla_quincenal,
            PeriodoPago.MENSUAL: self.tabla_mensual,
        }
        
        return tablas[periodo]
    
    def buscar_renglon(self, ingreso: Decimal, tabla: List[RenglonISR]) -> RenglonISR:
        """
        Busca el renglón correspondiente según el ingreso.
        
        Args:
            ingreso: Ingreso gravado del periodo
            tabla: Tabla de retención a utilizar
            
        Returns:
            RenglonISR correspondiente
        """
        for renglon in tabla:
            if renglon.limite_superior is None:
                # Último renglón ("En adelante")
                if ingreso >= renglon.limite_inferior:
                    return renglon
            else:
                if renglon.limite_inferior <= ingreso <= renglon.limite_superior:
                    return renglon
        
        # Si no encuentra en ningún renglón, retornar el último
        return tabla[-1]
    
    def calcular_isr(self, ingreso: Decimal, periodo: PeriodoPago) -> Dict:
        """
        Calcula la retención de ISR para un ingreso.
        
        Args:
            ingreso: Ingreso gravado del periodo
            periodo: Periodo de pago (diario, semanal, quincenal, mensual)
            
        Returns:
            Dict con resultado del cálculo:
            - ingreso: Ingreso gravado
            - periodo: Periodo de pago
            - limite_inferior: Límite inferior del renglón
            - limite_superior: Límite superior del renglón
            - cuota_fija: Cuota fija aplicada
            - porcentaje: Porcentaje marginal aplicado
            - excedente: Excedente sobre límite inferior
            - isr_calculado: ISR calculado antes de subsidio
            - subsidio: Subsidio al empleo aplicado
            - isr_retenido: ISR final a retener
        """
        # Obtener tabla correspondiente
        tabla = self.obtener_tabla(periodo)
        
        # Buscar renglón
        renglon = self.buscar_renglon(ingreso, tabla)
        
        # Calcular excedente
        excedente = max(Decimal('0'), ingreso - renglon.limite_inferior)
        
        # Calcular ISR: Cuota Fija + (Excedente × Porcentaje)
        isr_calculado = renglon.cuota_fija + (excedente * renglon.porcentaje)
        
        # Calcular subsidio al empleo
        subsidio = self.calcular_subsidio_empleo(ingreso, periodo)
        
        # ISR a retener = ISR calculado - Subsidio
        isr_retenido = max(Decimal('0'), isr_calculado - subsidio)
        
        return {
            'ingreso': ingreso,
            'periodo': periodo.value,
            'limite_inferior': renglon.limite_inferior,
            'limite_superior': renglon.limite_superior,
            'cuota_fija': renglon.cuota_fija,
            'porcentaje': renglon.porcentaje,
            'excedente': excedente.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'isr_calculado': isr_calculado.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'subsidio': subsidio.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
            'isr_retenido': isr_retenido.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
        }
    
    def calcular_subsidio_empleo(self, ingreso: Decimal, periodo: PeriodoPago) -> Decimal:
        """
        Calcula el subsidio al empleo para un ingreso.
        
        Args:
            ingreso: Ingreso gravado del periodo
            periodo: Periodo de pago
            
        Returns:
            Subsidio al empleo aplicable
        """
        # Convertir ingreso a mensual para comparación
        factores_conversion = {
            PeriodoPago.DIARIO: 30,
            PeriodoPago.SEMANAL: Decimal('4.3452'),  # 52 semanas / 12 meses
            PeriodoPago.DECENAL: 3,
            PeriodoPago.QUINCENAL: 2,
            PeriodoPago.MENSUAL: 1,
        }
        
        ingreso_mensual = ingreso * factores_conversion[periodo]
        
        # Verificar si corresponde subsidio
        if ingreso_mensual > self.parametros_subsidio.limite_superior_mensual:
            return Decimal('0')
        
        # Calcular subsidio proporcional al periodo
        if periodo == PeriodoPago.MENSUAL:
            subsidio_mensual = self._calcular_subsidio_mensual(ingreso_mensual)
            return subsidio_mensual
        else:
            # Calcular subsidio mensual y convertir al periodo
            subsidio_mensual = self._calcular_subsidio_mensual(ingreso_mensual)
            subsidio_periodo = subsidio_mensual / factores_conversion[periodo]
            return subsidio_periodo
    
    def _calcular_subsidio_mensual(self, ingreso_mensual: Decimal) -> Decimal:
        """
        Calcula subsidio al empleo mensual.
        
        Args:
            ingreso_mensual: Ingreso mensual gravado
            
        Returns:
            Subsidio mensual al empleo
        """
        # Fórmula del subsidio 2026:
        # Subsidio = $628.00 - ((Ingreso - $628.00) × 0.2066)
        
        if ingreso_mensual <= self.parametros_subsidio.limite_inferior:
            # Ingreso menor al límite inferior: subsidio completo
            return self.parametros_subsidio.subsidio_mensual_maximo
        
        # Calcular subsidio
        excedente = ingreso_mensual - self.parametros_subsidio.limite_inferior
        reduccion = excedente * self.parametros_subsidio.factor_diario
        subsidio = self.parametros_subsidio.subsidio_mensual_maximo - reduccion
        
        # El subsidio no puede ser negativo
        return max(Decimal('0'), subsidio)
    
    def calcular_nomina_completa(self,
                                  ingresos: List[Dict],
                                  periodo: PeriodoPago) -> Dict:
        """
        Calcula ISR para toda una nómina.
        
        Args:
            ingresos: Lista de ingresos de trabajadores
                      [{'nombre': str, 'ingreso_gravado': Decimal}, ...]
            periodo: Periodo de pago
            
        Returns:
            Dict con resultados de toda la nómina
        """
        resultados = []
        total_isr_retenido = Decimal('0')
        total_subsidio = Decimal('0')
        
        for trabajador in ingresos:
            resultado = self.calcular_isr(
                ingreso=trabajador['ingreso_gravado'],
                periodo=periodo
            )
            resultado['nombre'] = trabajador.get('nombre', 'N/A')
            resultados.append(resultado)
            
            total_isr_retenido += resultado['isr_retenido']
            total_subsidio += resultado['subsidio']
        
        return {
            'periodo': periodo.value,
            'total_trabajadores': len(resultados),
            'resultados': resultados,
            'totales': {
                'total_ingresos': sum(t['ingreso_gravado'] for t in ingresos),
                'total_isr_retenido': total_isr_retenido.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP),
                'total_subsidio': total_subsidio.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)
            }
        }
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Actualización Anual de Tablas

**Problema:**
Las tablas de ISR se actualizan anualmente en diciembre (DOF). Un sistema con tablas hardcodeadas queda obsoleto cada año.

**Solución:**
```python
class TablasISRService:
    """
    Servicio para gestión de tablas ISR actualizables.
    Permite actualización sin cambiar código.
    """
    
    def __init__(self, db_session):
        self.db = db_session
    
    def actualizar_tablas_2026(self):
        """Actualiza tablas ISR para 2026 desde configuración."""
        tablas = {
            'diaria': [...],  # 11 renglones
            'semanal': [...],
            'quincenal': [...],
            'mensual': [...],
        }
        
        parametros_subsidio = {
            'subsidio_mensual_maximo': Decimal('628.00'),
            'factor_diario': Decimal('20.66'),
            'limite_inferior': Decimal('628.00'),
            'limite_superior_mensual': Decimal('8446.00'),
            'vigencia_desde': date(2026, 1, 1),
            'vigencia_hasta': date(2026, 12, 31)
        }
        
        # Guardar en base de datos
        self._guardar_tablas(tablas, parametros_subsidio)
    
    def obtener_tablas_vigentes(self, fecha: date = None) -> Dict:
        """
        Obtiene tablas ISR vigentes para una fecha.
        
        Args:
            fecha: Fecha de vigencia (default: hoy)
            
        Returns:
            Dict con tablas vigentes
        """
        if fecha is None:
            fecha = date.today()
        
        # Consultar base de datos
        tablas = self._consultar_tablas(fecha)
        
        return tablas
```

**Impacto:**
- Requiere actualización anual de parámetros
- Sin actualización, cálculos son incorrectos

### 4.2 Limitación 2: Múltiples Periodos de Pago

**Problema:**
Las empresas pueden tener nóminas semanales, quincenales, mensuales, e incluso decenales. Cada periodo requiere su tabla específica.

**Solución:**
```python
class GestorPeriodosPago:
    """
    Gestiona múltiples periodos de pago en una misma empresa.
    Permite cálculo correcto de ISR según periodo de cada trabajador.
    """
    
    def __init__(self, db_session):
        self.db = db_session
    
    def asignar_periodo_pago(self, 
                             empleado_id: str,
                             periodo: PeriodoPago,
                             fecha_inicio: date):
        """
        Asigna periodo de pago a un empleado.
        
        Args:
            empleado_id: ID del empleado
            periodo: Periodo de pago (diario, semanal, quincenal, mensual)
            fecha_inicio: Fecha de inicio del periodo
        """
        # Guardar en DB
        self._guardar_periodo_empleado({
            'empleado_id': empleado_id,
            'periodo': periodo.value,
            'fecha_inicio': fecha_inicio
        })
    
    def obtener_periodo_empleado(self, empleado_id: str, fecha: date = None) -> PeriodoPago:
        """
        Obtiene periodo de pago de un empleado.
        
        Args:
            empleado_id: ID del empleado
            fecha: Fecha de consulta (default: hoy)
            
        Returns:
            Periodo de pago del empleado
        """
        if fecha is None:
            fecha = date.today()
        
        # Consultar DB
        periodo = self._consultar_periodo_empleado(empleado_id, fecha)
        
        return PeriodoPago(periodo)
```

**Impacto:**
- Requiere configuración de periodo por empleado
- Cálculo de ISR debe usar tabla correcta

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **4 tablas de retención:** Diaria, semanal, quincenal y mensual. Cada una con 11 renglones.
2. **Subsidio al empleo actualizado:** $628.00 mensuales (vs. $475.00 en 2025). Incremento de 32.2%.
