## 2. Estado del Arte en México (2026)

### 2.1 Algoritmos Criptográficos del SAT

| Algoritmo | Uso | Tamaño de Llave | Hash | Estándar |
|-----------|-----|-----------------|------|----------|
| **RSA** | Firma digital de CFDI | 2048 bits | SHA256 | PKCS#1 v1.5 |
| **ECDSA** | Certificados de e.firma | P-256 (256 bits) | SHA256 | ANSI X9.62 |
| **SHA256** | Hash de cadena original | 256 bits (32 bytes) | - | FIPS 180-4 |

**Nota:** El SAT usa RSA-2048 con SHA256 para todos los CFDI desde 2017.

### 2.2 Proceso de Generación de Sello Digital

```
┌─────────────────────────────────────────────────────────────┐
│  PASO 1: GENERAR CADENA ORIGINAL                            │
│  - Aplicar XSLT cadenaoriginal_4_0.xslt al XML del CFDI     │
│  - Resultado: String de texto con campos separados por "|"  │
│  - Longitud típica: 1,500-2,500 caracteres                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 2: CALCULAR HASH SHA256                               │
│  - Aplicar algoritmo SHA256 a la cadena original            │
│  - Resultado: Hash de 32 bytes (256 bits)                   │
│  - Representación hexadecimal: 64 caracteres                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 3: FIRMAR CON LLAVE PRIVADA (RSA)                     │
│  - Cargar llave privada del CSD (.key)                      │
│  - Firmar hash con RSA-SHA256 (PKCS#1 v1.5)                 │
│  - Resultado: Firma digital de 256 bytes                    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 4: CODIFICAR EN BASE64                                │
│  - Codificar firma digital en Base64                        │
│  - Resultado: String de ~344 caracteres                     │
│  - Este es el "Sello" que va en el CFDI                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Algoritmos Específicos

#### Algoritmo 1: Generación de Cadena Original y Sello Digital

```python
import hashlib
import base64
from typing import Dict, Optional, Tuple
from pathlib import Path
from lxml import etree

from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.backends import default_backend
from cryptography.hazmat.primitives.asymmetric.rsa import RSAPrivateKey


class CFDISelloGenerator:
    """
    Genera cadena original y sello digital para CFDI 4.0.
    Implementa algoritmo RSA-SHA256 según especificaciones del SAT.
    """
    
    # Ruta al XSLT oficial del SAT
    XSLT_CADENA_ORIGINAL = "xsd_schemas/cadenaoriginal_4_0.xslt"
    
    def __init__(self, cert_path: str, key_path: str, password: str):
        """
        Inicializa el generador de sellos.
        
        Args:
            cert_path: Ruta al certificado .cer del CSD
            key_path: Ruta a la llave privada .key del CSD
            password: Contraseña de la llave privada
        """
        self.cert_path = Path(cert_path)
        self.key_path = Path(key_path)
        self.password = password.encode('utf-8')
        
        # Cargar certificado y llave privada
        self._load_cert_and_key()
        
        # Cargar XSLT de cadena original
        self._load_xslt()
    
    def _load_cert_and_key(self):
        """Carga certificado y llave privada desde archivos."""
        # Cargar certificado
        with open(self.cert_path, 'rb') as f:
            cert_data = f.read()
            self.cert = serialization.load_pem_x509_certificate(
                cert_data, backend=default_backend()
            )
        
        # Cargar llave privada
        with open(self.key_path, 'rb') as f:
            key_data = f.read()
            self.private_key = serialization.load_pem_private_key(
                key_data,
                password=self.password,
                backend=default_backend()
            )
            
            # Verificar que es una llave RSA
            if not isinstance(self.private_key, RSAPrivateKey):
                raise ValueError("La llave privada debe ser RSA")
    
    def _load_xslt(self):
        """Carga XSLT de cadena original desde archivo."""
        xslt_path = Path(self.XSLT_CADENA_ORIGINAL)
        if not xslt_path.exists():
            raise FileNotFoundError(f"XSLT no encontrado: {xslt_path}")
        
        with open(xslt_path, 'rb') as f:
            xslt_content = f.read()
            self.xslt_transform = etree.XSLT(etree.XML(xslt_content))
    
    def generar_cadena_original(self, cfdi_xml: str) -> Dict:
        """
        Genera cadena original a partir de XML de CFDI.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado:
            - success: bool
            - cadena_original: str (si exitoso)
            - error: str (si fallido)
        """
        try:
            # Parsear XML del CFDI
            cfdi_tree = etree.XML(cfdi_xml.encode('utf-8'))
            
            # Aplicar transformación XSLT
            resultado_transform = self.xslt_transform(cfdi_tree)
            
            # Verificar errores de transformación
            if self.xslt_transform.error_log:
                errores = [str(e) for e in self.xslt_transform.error_log]
                return {
                    'success': False,
                    'error': f'Error en transformación XSLT: {"; ".join(errores)}'
                }
            
            # Obtener cadena original (string de texto)
            cadena_original = str(resultado_transform)
            
            # Limpiar cadena (quitar espacios en blanco extras, newlines)
            cadena_original = cadena_original.strip()
            
            # Validar formato (debe contener separadores "|")
            if '|' not in cadena_original:
                return {
                    'success': False,
                    'error': 'Cadena original no contiene separadores "|"'
                }
            
            return {
                'success': True,
                'cadena_original': cadena_original,
                'longitud': len(cadena_original)
            }
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error generando cadena original: {str(e)}'
            }
    
    def calcular_hash_sha256(self, cadena_original: str) -> Dict:
        """
        Calcula hash SHA256 de la cadena original.
        
        Args:
            cadena_original: Cadena original del CFDI
            
        Returns:
            Dict con resultado:
            - success: bool
            - hash_sha256: bytes (si exitoso)
            - hash_hex: str (representación hexadecimal)
            - error: str (si fallido)
        """
        try:
            # Calcular hash SHA256
            hash_obj = hashlib.sha256(cadena_original.encode('utf-8'))
            hash_bytes = hash_obj.digest()
            hash_hex = hash_obj.hexdigest()
            
            return {
                'success': True,
                'hash_sha256': hash_bytes,
                'hash_hex': hash_hex,
                'longitud_bits': len(hash_bytes) * 8
            }
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error calculando hash SHA256: {str(e)}'
            }
    
    def firmar_con_rsa(self, hash_sha256: bytes) -> Dict:
        """
        Firma el hash SHA256 con llave privada RSA.
        
        Args:
            hash_sha256: Hash SHA256 de la cadena original
            
        Returns:
            Dict con resultado:
            - success: bool
            - firma_bytes: bytes (si exitoso)
            - firma_base64: str (codificada en Base64)
            - error: str (si fallido)
        """
        try:
            # Firmar con RSA-SHA256 (PKCS#1 v1.5)
            firma = self.private_key.sign(
                hash_sha256,
                padding.PKCS1v15(),
                hashes.SHA256()
            )
            
            # Codificar en Base64
            firma_base64 = base64.b64encode(firma).decode('utf-8')
            
            return {
                'success': True,
                'firma_bytes': firma,
                'firma_base64': firma_base64,
                'longitud_bytes': len(firma),
                'longitud_base64': len(firma_base64)
            }
            
        except Exception as e:
            return {
                'success': False,
                'error': f'Error firmando con RSA: {str(e)}'
            }
    
    def generar_sello_completo(self, cfdi_xml: str) -> Dict:
        """
        Genera sello digital completo para un CFDI.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado completo:
            - success: bool
            - cadena_original: str
            - hash_sha256: str (hex)
            - sello: str (Base64)
            - no_certificado: str
            - error: str (si fallido)
        """
        # Paso 1: Generar cadena original
        cadena_result = self.generar_cadena_original(cfdi_xml)
        if not cadena_result['success']:
            return cadena_result
        
        cadena_original = cadena_result['cadena_original']
        
        # Paso 2: Calcular hash SHA256
        hash_result = self.calcular_hash_sha256(cadena_original)
        if not hash_result['success']:
            return hash_result
        
        hash_sha256 = hash_result['hash_sha256']
        hash_hex = hash_result['hash_hex']
        
        # Paso 3: Firmar con RSA
        firma_result = self.firmar_con_rsa(hash_sha256)
        if not firma_result['success']:
            return firma_result
        
        sello_base64 = firma_result['firma_base64']
        
        # Obtener número de certificado
        no_certificado = format(self.cert.serial_number, '020d')
        
        return {
            'success': True,
            'cadena_original': cadena_original,
            'hash_sha256': hash_hex,
            'sello': sello_base64,
            'no_certificado': no_certificado,
            'cert_emisor': base64.b64encode(
                self.cert.public_bytes(serialization.Encoding.DER)
            ).decode('utf-8')
        }
    
    def insertar_sello_en_cfdi(self, cfdi_xml: str, sello_data: Dict) -> str:
        """
        Inserta sello digital en XML del CFDI.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            sello_data: Datos del sello generados
            
        Returns:
            str: XML con sello insertado
        """
        # Parsear XML
        root = etree.XML(cfdi_xml.encode('utf-8'))
        ns = {'cfdi': 'http://www.sat.gob.mx/cfd/4'}
        
        # Encontrar nodo Comprobante
        comprobante = root.find('.//cfdi:Comprobante', namespaces=ns)
        if comprobante is None:
            raise ValueError("No se encontró nodo Comprobante")
        
        # Insertar atributos de sellado
        comprobante.set('Sello', sello_data['sello'])
        comprobante.set('NoCertificado', sello_data['no_certificado'])
        comprobante.set('Certificado', sello_data['cert_emisor'])
        
        # Retornar XML con sello
        return etree.tostring(root, encoding='utf-8', xml_declaration=True).decode('utf-8')
```

#### Algoritmo 2: Validación de Sello Digital del SAT

```python
from cryptography.x509 import load_pem_x509_certificate
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.primitives import hashes
import requests
from typing import Dict, List, Optional


class CFDISelloValidator:
    """
    Valida sello digital de CFDI contra certificado del SAT.
    Verifica autenticidad criptográfica del Timbre Fiscal Digital.
    """
    
    # URL del certificado del SAT (actualizado periódicamente)
    SAT_CERT_URL = "https://www.sat.gob.mx/aplicacion/32644/certificado-del-sat"
    
    # Certificados del SAT (se actualizan periódicamente)
    # Descargar desde portal del SAT
    SAT_CERTS_DIR = "xsd_schemas/certificados_sat/"
    
    def __init__(self):
        """Inicializa el validador de sellos."""
        self.sat_certs = {}
        self._load_sat_certificates()
    
    def _load_sat_certificates(self):
        """Carga certificados del SAT desde directorio local."""
        certs_dir = Path(self.SAT_CERTS_DIR)
        if not certs_dir.exists():
            certs_dir.mkdir(parents=True, exist_ok=True)
            raise FileNotFoundError(
                f"Directorio de certificados SAT no encontrado: {certs_dir}. "
                f"Descargar certificados desde {self.SAT_CERT_URL}"
            )
        
        # Cargar todos los certificados .cer del directorio
        for cert_file in certs_dir.glob("*.cer"):
            with open(cert_file, 'rb') as f:
                cert_data = f.read()
                cert = load_pem_x509_certificate(cert_data, default_backend())
                
                # Usar número de certificado como key
                no_certificado = format(cert.serial_number, '020d')
                self.sat_certs[no_certificado] = cert
    
    def validar_sello_sat(self, cfdi_xml: str) -> Dict:
        """
        Valida sello del SAT en Timbre Fiscal Digital.
        
        Args:
            cfdi_xml: Contenido XML del CFDI con TFD
            
        Returns:
            Dict con resultado de validación:
            - is_valid: bool
            - no_certificado_sat: str
            - sello_sat: str
            - error: str (si inválido)
        """
        try:
            # Parsear XML del CFDI
            root = etree.XML(cfdi_xml.encode('utf-8'))
            ns_tfd = {'tfd': 'http://www.sat.gob.mx/TimbreFiscalDigital'}
            
            # Extraer Timbre Fiscal Digital
            timbre = root.find('.//tfd:TimbreFiscalDigital', namespaces=ns_tfd)
            if timbre is None:
                return {
                    'is_valid': False,
                    'error': 'No se encontró Timbre Fiscal Digital (TFD)'
                }
            
            # Extraer datos del timbre
            sello_sat = timbre.get('SelloSAT', '')
            no_certificado_sat = timbre.get('NoCertificadoSAT', '')
            uuid = timbre.get('UUID', '')
            
            if not sello_sat:
                return {
                    'is_valid': False,
                    'error': 'Timbre no contiene SelloSAT'
                }
            
            if not no_certificado_sat:
                return {
                    'is_valid': False,
                    'error': 'Timbre no contiene NoCertificadoSAT'
                }
            
            # Obtener certificado del SAT
            sat_cert = self.sat_certs.get(no_certificado_sat)
            if not sat_cert:
                return {
                    'is_valid': False,
                    'error': f'Certificado SAT {no_certificado_sat} no encontrado localmente',
                    'no_certificado_sat': no_certificado_sat,
                    'sello_sat': sello_sat[:50] + '...'
                }
            
            # Extraer cadena original del TFD
            cadena_original_tfd = self._generar_cadena_original_tfd(timbre)
            
            # Calcular hash SHA256
            hash_sha256 = hashlib.sha256(cadena_original_tfd.encode('utf-8')).digest()
            
            # Decodificar sello SAT de Base64
            sello_sat_bytes = base64.b64decode(sello_sat)
            
            # Obtener llave pública del certificado SAT
            public_key = sat_cert.public_key()
            
            # Verificar firma con RSA-SHA256
            try:
                public_key.verify(
                    sello_sat_bytes,
                    hash_sha256,
                    padding.PKCS1v15(),
                    hashes.SHA256()
                )
                
                return {
                    'is_valid': True,
                    'no_certificado_sat': no_certificado_sat,
                    'sello_sat': sello_sat[:50] + '...',
                    'uuid': uuid,
                    'mensaje': 'Sello SAT válido. CFDI auténtico.'
                }
                
            except Exception as e:
                return {
                    'is_valid': False,
                    'error': f'Firma SAT inválida: {str(e)}',
                    'no_certificado_sat': no_certificado_sat,
                    'uuid': uuid
                }
            
        except Exception as e:
            return {
                'is_valid': False,
                'error': f'Error validando sello SAT: {str(e)}'
            }
    
    def _generar_cadena_original_tfd(self, timbre: etree._Element) -> str:
        """
        Genera cadena original del Timbre Fiscal Digital.
        
        La cadena original del TFD sigue este formato:
        ||1.1|UUID|FechaTimbrado|SelloCFD|NoCertificadoSAT|SelloSAT||
        
        Args:
            timbre: Elemento XML del Timbre Fiscal Digital
            
        Returns:
            str: Cadena original del TFD
        """
        version = timbre.get('Version', '1.1')
        uuid = timbre.get('UUID', '')
        fecha_timbrado = timbre.get('FechaTimbrado', '')
        sello_cfd = timbre.get('SelloCFD', '')
        no_certificado_sat = timbre.get('NoCertificadoSAT', '')
        sello_sat = timbre.get('SelloSAT', '')
        
        # Construir cadena original (separadores "||" al inicio y fin)
        cadena = f"||{version}|{uuid}|{fecha_timbrado}|{sello_cfd}|{no_certificado_sat}|{sello_sat}||"
        
        return cadena
    
    def validar_sello_emisor(self, cfdi_xml: str) -> Dict:
        """
        Valida sello digital del emisor del CFDI.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado de validación:
            - is_valid: bool
            - rfc_emisor: str
            - no_certificado: str
            - error: str (si inválido)
        """
        try:
            # Parsear XML del CFDI
            root = etree.XML(cfdi_xml.encode('utf-8'))
            ns = {'cfdi': 'http://www.sat.gob.mx/cfd/4'}
            
            # Extraer nodo Comprobante
            comprobante = root.find('.//cfdi:Comprobante', namespaces=ns)
            if comprobante is None:
                return {
                    'is_valid': False,
                    'error': 'No se encontró nodo Comprobante'
                }
            
            # Extraer datos del emisor y sello
            emisor = comprobante.find('.//cfdi:Emisor', namespaces=ns)
            rfc_emisor = emisor.get('Rfc', '') if emisor is not None else ''
            sello = comprobante.get('Sello', '')
            no_certificado = comprobante.get('NoCertificado', '')
            certificado_b64 = comprobante.get('Certificado', '')
            
            if not sello:
                return {
                    'is_valid': False,
                    'error': 'CFDI no contiene sello digital'
                }
            
            if not no_certificado:
                return {
                    'is_valid': False,
                    'error': 'CFDI no contiene NoCertificado'
                }
            
            # Obtener certificado del emisor
            try:
                certificado_der = base64.b64decode(certificado_b64)
                emisor_cert = load_pem_x509_certificate(certificado_der, default_backend())
            except Exception as e:
                return {
                    'is_valid': False,
                    'error': f'Certificado del emisor inválido: {str(e)}'
                }
            
            # Verificar que el RFC del certificado coincide con el del emisor
            cert_rfc = self._extract_rfc_from_cert(emisor_cert)
            if cert_rfc != rfc_emisor:
                return {
                    'is_valid': False,
                    'error': f'RFC del certificado ({cert_rfc}) no coincide con RFC del emisor ({rfc_emisor})'
                }
            
            # Generar cadena original del CFDI (sin el sello)
            cadena_original = self._generar_cadena_original_cfdi(comprobante, incluir_sello=False)
            
            # Calcular hash SHA256
            hash_sha256 = hashlib.sha256(cadena_original.encode('utf-8')).digest()
            
            # Decodificar sello de Base64
            sello_bytes = base64.b64decode(sello)
            
            # Obtener llave pública del certificado
            public_key = emisor_cert.public_key()
            
            # Verificar firma con RSA-SHA256
            try:
                public_key.verify(
                    sello_bytes,
                    hash_sha256,
                    padding.PKCS1v15(),
                    hashes.SHA256()
                )
                
                return {
                    'is_valid': True,
                    'rfc_emisor': rfc_emisor,
                    'no_certificado': no_certificado,
                    'mensaje': 'Sello del emisor válido.'
                }
                
            except Exception as e:
                return {
                    'is_valid': False,
                    'error': f'Firma del emisor inválida: {str(e)}',
                    'rfc_emisor': rfc_emisor
                }
            
        except Exception as e:

                'is_valid': False,
```

### 4.2 Limitación 2: XSLT de Cadena Original Complejo

**Problema:**
El XSLT de cadena original del SAT es complejo y tiene reglas específicas de ordenamiento de nodos y atributos. Una implementación manual propensa a errores.

**Solución:**
```python
# Usar XSLT oficial del SAT directamente (no implementación manual)
class CadenaOriginalGenerator:
    """
    Genera cadena original usando XSLT oficial del SAT.
    NO implementa lógica manualmente (propensa a errores).
    """
    
    XSLT_OFICIAL_URL = "https://www.sat.gob.mx/esquemas/xsd/4.0/cadenaoriginal_4_0.xslt"
    
    def __init__(self):
        # Cargar XSLT oficial desde archivo local
        # (descargar una vez, usar caché)
        self.xslt_transform = self._load_official_xslt()
    
    def _load_official_xslt(self) -> etree.XSLT:
        """Carga XSLT oficial del SAT desde archivo local."""
        xslt_path = Path("xsd_schemas/cadenaoriginal_4_0.xslt")
        
        if not xslt_path.exists():
            # Descargar XSLT desde SAT
            response = requests.get(self.XSLT_OFICIAL_URL, timeout=30)
            response.raise_for_status()
            
            with open(xslt_path, 'wb') as f:
                f.write(response.content)
        
        with open(xslt_path, 'rb') as f:
            return etree.XSLT(etree.XML(f.read()))
    
    def generar(self, cfdi_xml: str) -> str:
        """
        Genera cadena original usando XSLT oficial.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            str: Cadena original generada
        """
        cfdi_tree = etree.XML(cfdi_xml.encode('utf-8'))
        resultado = self.xslt_transform(cfdi_tree)
        return str(resultado).strip()
```

**Impacto:**
- Dependencia del XSLT oficial del SAT
- Requiere actualización cuando SAT publica nuevo XSLT
