## 1. Descripción del Módulo

### 1.1 Propósito

El módulo de Gestión de Cartera Vencida - Estrategias de Recuperación automatiza la gestión inteligente de cuentas por cobrar vencidas, implementando estrategias de cobranza escalonadas basadas en días de mora, probabilidad de recuperación y perfil del deudor. Este módulo reduce el tiempo de gestión manual de cobranza de 1-2 horas/día a 15-20 minutos/día, logrando un ahorro del 75-80% y mejorando la recuperación de cartera vencida en 25-40% mediante priorización inteligente y automatización de acciones de cobro.

La problemática que aborda es crítica para las empresas mexicanas: según datos del Centro de Estudios e Investigaciones de Comportamiento (CEIC), la cartera vencida en México mostró una disminución de apenas 0.1% en diciembre de 2024, manteniéndose en niveles que representan un riesgo significativo para la liquidez empresarial. Las empresas que no implementan estrategias estructuradas de recuperación de cartera enfrentan:

- **Pérdida de liquidez:** El efectivo atrapado en cartera vencida limita la capacidad operativa
- **Costos de financiamiento:** Necesidad de crédito externo para cubrir desfases de caja
- **Deterioro de cartera:** Cuentas que pasan de mora temprana (<30 días) a incobrables (>90 días)
- **Relaciones comerciales dañadas:** Cobranza agresiva o extemporánea afecta la relación con clientes

- Estrés por flujo de efectivo insuficiente para cubrir obligaciones

### 2.4 Cálculo de Intereses Moratorios y Actualizaciones (CFF 2026)

#### Tasa de Recargos por Mora 2026

Según la Ley de Ingresos de la Federación para 2026, la tasa de recargos por mora se incrementó:

| Concepto | 2025 | 2026 | Incremento |
|----------|------|------|------------|
| **Tasa de recargos por mora** | 1.47% mensual | **2.07% mensual** | +40.8% |
| **Tasa anual equivalente** | 17.64% | **24.84%** | +40.8% |

**Fuente:** Manuel Nevárez y Asociados - Reforma Fiscal para 2026, [URL](https://www.manuelnevarez.com.mx/es/journal/noticias/reforma-fiscal-para-2026/)

#### Fórmula de Cálculo

```python
def calcular_intereses_moratorios(
    monto_principal: float,
    fecha_vencimiento: datetime,
    fecha_pago: datetime,
    tasa_mensual: float = 0.0207
) -> Dict[str, float]:
    """
    Calcula intereses moratorios y actualización por inflación.
    
    Args:
        monto_principal: Monto original de la deuda
        fecha_vencimiento: Fecha de vencimiento de la obligación
        fecha_pago: Fecha de pago o cálculo
        tasa_mensual: Tasa de recargos por mora (2.07% para 2026)
    
    Returns:
        Dict con desglose de conceptos
    """
    from datetime import datetime
    
    # Días de mora
    dias_mora = (fecha_pago - fecha_vencimiento).days
    if dias_mora <= 0:
        return {'interes_moratorio': 0, 'actualizacion': 0, 'total': monto_principal}
    
    # Meses completos de mora
    meses_mora = dias_mora / 30.0
    
    # Intereses moratorios (compuestos mensualmente)
    interes_moratorio = monto_principal * ((1 + tasa_mensual) ** meses_mora - 1)
    
    # Actualización por inflación (INPC)
    # Se requiere consultar INPC del mes anterior al vencimiento
    # y INPC del mes anterior al pago
    inpc_vencimiento = obtener_inpc(fecha_vencimiento.month - 1)
    inpc_pago = obtener_inpc(fecha_pago.month - 1)
    factor_actualizacion = inpc_pago / inpc_vencimiento
    actualizacion = monto_principal * (factor_actualizacion - 1)
    
    total = monto_principal + interes_moratorio + actualizacion
    
    return {
        'monto_principal': round(monto_principal, 2),
        'interes_moratorio': round(interes_moratorio, 2),
        'actualizacion': round(actualizacion, 2),
        'total': round(total, 2),
        'dias_mora': dias_mora,
        'tasa_aplicada': f'{tasa_mensual * 100:.2f}%'
    }


def obtener_inpc(mes: int) -> float:
    """
    Obtiene el INPC del mes especificado.
    En producción, consultar API del Banco de México o sitio del INEGI.
    
    Args:
        mes: Número de mes (1-12)
    
    Returns:
        float: Valor del INPC
    """
    # Valores de ejemplo (consultar INEGI para valores actualizados)
    inpc_2026 = {
        1: 125.342,
        2: 125.891,
        3: 126.234,
        # ... completar con valores reales
    }
    return inpc_2026.get(mes, 125.0)
```

### 2.5 Castigo de Cuentas Incobrables - Requisitos Fiscales 2026

#### Límites y Formalidades

La LISR permite deducir créditos incobrables, siempre que se cumplan formalidades según el monto:

| Monto del Crédito | Requisitos | Plazo |
|-------------------|------------|-------|
| **Menores a 30,000 UDIS** (~$210,000 MXN en 2026) | - Notoria imposibilidad práctica de cobro<br>- Aviso al SAT (Ficha 42/ISR)<br>- Escrito libre antes del 15 de febrero | 1 año desde vencimiento |
| **Mayores a 30,000 UDIS** | - Resolución definitiva de autoridad<br>- Gestiones de cobro agotadas<br>- 2 años desde interposición de demanda | 2 años desde demanda |

**Fuente:** Veritas - Formalidades para la correcta deducción de cuentas incobrables, [URL](https://www.veritas.org.mx/Impuestos/Fiscal/Formalidades-para-la-correcta-deduccion-de-cuentas-incobrables)

#### Procedimiento de Castigo

```python
from dataclasses import dataclass
from datetime import datetime, timedelta
from typing import List, Optional
from enum import Enum


class TipoCastigo(Enum):
    """Tipo de castigo de cuenta incobrable."""
    MENOR_30K_UDIS = "menor_30k_udis"
    MAYOR_30K_UDIS = "mayor_30k_udis"
    HIPOTECARIO = "hipotecario"
    INSTITUCION_CREDITO = "institucion_credito"


@dataclass
class CreditoIncobrable:
    """Representa un crédito incobrable para castigo."""
    id: str
    cliente_id: str
    cliente_nombre: str
    monto_original: float
    fecha_vencimiento: datetime
    fecha_ultimo_pago: Optional[datetime]
    gestiones_cobro: List[str]  # Historial de gestiones
    tipo_castigo: TipoCastigo
    udis_vigentes: float = 7.59  # Valor UDI 2026 (ejemplo)


class GestorCastigoIncobrables:
    """
    Gestor de castigo de cuentas incobrables con validación de requisitos fiscales.
    
    Implementa validaciones según LISR Art. 27, fracción XV y RMF 2026.
    """
    
    LIMITE_UDIS = 30000  # Límite en UDIS para procedimiento simplificado
    
    def __init__(self):
        """Inicializa el gestor de castigo."""
        self.udis_vigentes = 7.59  # Consultar DOF para valor actual
    
    def validar_requisitos_castigo(self, credito: CreditoIncobrable) -> Dict[str, any]:
        """
        Valida si un crédito cumple requisitos para castigo fiscal.
        
        Args:
            credito: Crédito a validar
        
        Returns:
            Dict con resultado de validación y requisitos pendientes
        """
        resultado = {
            'puede_castigar': False,
            'tipo_castigo': credito.tipo_castigo.value,
            'requisitos_cumplidos': [],
            'requisitos_pendientes': [],
            'observaciones': []
        }
        
        monto_en_udis = credito.monto_original / self.udis_vigentes
        
        # Validar gestiones de cobro
        if len(credito.gestiones_cobro) >= 5:
            resultado['requisitos_cumplidos'].append('Gestiones de cobro documentadas (5+)')
        else:
            resultado['requisitos_pendientes'].append(
                f'Completar gestiones de cobro (actual: {len(credito.gestiones_cobro)}, mínimo: 5)'
            )
        
        # Validar tiempo transcurrido
        dias_vencido = (datetime.now() - credito.fecha_vencimiento).days
        
        if credito.tipo_castigo == TipoCastigo.MENOR_30K_UDIS:
            if monto_en_udis < self.LIMITE_UDIS:
                resultado['requisitos_cumplidos'].append(f'Monto menor a 30,000 UDIS ({monto_en_udis:.2f} UDIS)')
                
                if dias_vencido >= 365:
                    resultado['requisitos_cumplidos'].append('1 año transcurrido desde vencimiento')
                else:
                    resultado['requisitos_pendientes'].append(
                        f'Esperar {365 - dias_vencido} días para completar 1 año'
                    )
            else:
                resultado['requisitos_pendientes'].append(
                    f'Monto excede 30,000 UDIS ({monto_en_udis:.2f} UDIS). Requiere procedimiento mayor.'
                )
        
        elif credito.tipo_castigo == TipoCastigo.MAYOR_30K_UDIS:
            if dias_vencido >= 730:  # 2 años
                resultado['requisitos_cumplidos'].append('2 años transcurridos desde vencimiento')
            else:
                resultado['requisitos_pendientes'].append(
                    f'Esperar {730 - dias_vencido} días para completar 2 años'
                )
            
            # Para mayores a 30K UDIS, se requiere resolución definitiva
            resultado['requisitos_pendientes'].append(
                'Obtener resolución definitiva de autoridad competente'
            )
        
        # Determinar si puede castigar
        if not resultado['requisitos_pendientes']:
            resultado['puede_castigar'] = True
        
        return resultado
    
    def generar_aviso_sat(self, creditos: List[CreditoIncobrable]) -> str:
        """
        Genera aviso al SAT para deducción de créditos incobrables.
        
        Según Ficha 42/ISR y RMF 2026, regla 3.3.1.23.
        
        Args:
            creditos: Lista de créditos a deducir
        
        Returns:
            str: Contenido del aviso en formato de escrito libre
        """
        fecha_actual = datetime.now().strftime('%d de %B de %Y')
        
        aviso = f"""
===========================================
AVISO DE DEDUCCIÓN DE PÉRDIDAS POR CRÉDITOS INCOBRABLES
===========================================

Ciudad de México, a {fecha_actual}

SERVICIO DE ADMINISTRACIÓN TRIBUTARIA
Presente.

Por medio del presente escrito, y de conformidad con lo establecido en el artículo 18-A
del Código Fiscal de la Federación y la ficha de trámite 42/ISR contenida en el Anexo 2
de la Resolución Miscelánea Fiscal para 2026, informo la deducción de pérdidas por
créditos incobrables menores a 30,000 UDIS correspondientes al ejercicio fiscal {datetime.now().year - 1}.

DATOS DEL CONTRIBUYENTE:
- RFC: [RFC DEL CONTRIBUYENTE]
- Nombre o Razón Social: [NOMBRE DEL CONTRIBUYENTE]
- Régimen Fiscal: [RÉGMEN FISCAL]

CRÉDITOS DEDUCIDOS:
"""
        
        total_deducir = 0
        for i, credito in enumerate(creditos, 1):
            total_deducir += credito.monto_original
            aviso += f"""
{i}. Crédito ID: {credito.id}
   - Cliente: {credito.cliente_nombre}
   - RFC Cliente: {credito.cliente_id}
   - Monto Original: ${credito.monto_original:,.2f} MXN
   - Fecha Vencimiento: {credito.fecha_vencimiento.strftime('%Y-%m-%d')}
   - Gestiones de Cobro Realizadas: {len(credito.gestiones_cobro)}
   - Causa de Incobrabilidad: Notoria imposibilidad práctica de cobro
"""
        
        aviso += f"""
MONTO TOTAL DEDUCIDO: ${total_deducir:,.2f} MXN

MANIFESTACIÓN BAJO PROTESTA DE DECIR VERDAD:

Los créditos relacionados en este aviso cumplen con los requisitos establecidos en el
artículo 27, fracción XV de la Ley del Impuesto Sobre la Renta, y han sido castigados
en la contabilidad del contribuyente en el ejercicio fiscal correspondiente.

Se anexa documentación comprobatoria de las gestiones de cobro realizadas y la
notoria imposibilidad práctica de cobro de cada crédito.

PROTESTO LO NECESARIO.

_________________________________
[NOMBRE DEL CONTRIBUYENTE]
[RFC]
[FIRMA]
"""
        
        return aviso
```

1. **Segmentación inteligente de cartera:**

   - Establecer categorías basadas en monto, antigüedad, comportamiento histórico y nivel de exposición

2. **Adaptación del proceso al perfil del cliente:**
   - Clientes corporativos: Enfoque formal, múltiples canales, involucrar tomadores de decisión
   - PYMES: Enfoque directo, negociación flexible, planes de pago escalonados
   - Personas físicas: Recordatorios automatizados, canales digitales (WhatsApp, SMS)

3. **Automatización con IA:**
   - Modelos predictivos para identificar probabilidad de pago
   - Chatbots para negociación inicial de planes de pago
   - Optimización de timing de contactos (mejor hora/día para contactar)

#### Algoritmo 1: Priorización Inteligente de Cobranza

```python
from typing import List, Dict, Any
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum
import numpy as np


class PrioridadCobranza(Enum):
    """Prioridad de gestión de cobranza."""
    CRITICA = 1    # >90 días vencido
    ALTA = 2       # 60-90 días vencido
    MEDIA = 3      # 30-60 días vencido
    BAJA = 4       # <30 días vencido
    PREVENTIVA = 5 # Por vencer (7 días antes)


@dataclass
class CuentaPorCobrar:
    """Representa una cuenta por cobrar vencida."""
    id: str
    cliente_id: str
    cliente_nombre: str
    factura_id: str
    monto: float
    fecha_emision: datetime
    fecha_vencimiento: datetime
    dias_vencido: int
    historial_pagos: List[Dict[str, Any]]
    ultimo_contacto: Optional[datetime] = None
    promesas_pago: int = 0
    canal_preferido: str = 'email'


class GestorCobranzaInteligente:
    """
    Gestor de cobranza inteligente con priorización automática.
    
    Implementa estrategias de cobranza basadas en:
    - Días de vencimiento
    - Historial de pagos del cliente
    - Monto adeudado
    - Probabilidad de cobro (ML)
    - Canal de comunicación preferido
    """
    
    def __init__(self):
        """Inicializa el gestor de cobranza."""
        self.prioridades = {
            'critica': {'min_dias': 90, 'accion': 'llamada_inmediata', 'plazo_horas': 24},
            'alta': {'min_dias': 60, 'accion': 'whatsapp_seguimiento', 'plazo_horas': 48},
            'media': {'min_dias': 30, 'accion': 'email_recordatorio', 'plazo_horas': 72},
            'baja': {'min_dias': 0, 'accion': 'email_proactivo', 'plazo_horas': 168},
            'preventiva': {'min_dias': -7, 'accion': 'recordatorio_amable', 'plazo_horas': 168}
        }
    
    def calcular_prioridad(self, cuenta: CuentaPorCobrar) -> PrioridadCobranza:
        """
        Calcula prioridad de cobranza según días vencidos.
        
        Args:
            cuenta: Cuenta por cobrar a evaluar
        
        Returns:
            PrioridadCobranza: Prioridad asignada
        """
        dias = cuenta.dias_vencido
        
        if dias > 90:
            return PrioridadCobranza.CRITICA
        elif dias >= 60:
            return PrioridadCobranza.ALTA
        elif dias >= 30:
            return PrioridadCobranza.MEDIA
        elif dias >= 0:
            return PrioridadCobranza.BAJA
        else:
            return PrioridadCobranza.PREVENTIVA
    
    def calcular_probabilidad_cobro(self, cuenta: CuentaPorCobrar) -> float:
        """
        Calcula probabilidad de cobro basada en historial del cliente.
        
        Factores considerados:
        - Porcentaje de pagos históricos a tiempo
        - Días promedio de pago
        - Monto adeudado vs. historial
        - Frecuencia de compras
        - Promesas de pago incumplidas
        
        Args:
            cuenta: Cuenta por cobrar
        
        Returns:
            float: Probabilidad de cobro (0-1)
        """
        if not cuenta.historial_pagos:
            return 0.5  # Sin historial, probabilidad neutral
        
        # Porcentaje de pagos a tiempo
        pagos_a_tiempo = sum(
            1 for pago in cuenta.historial_pagos
            if pago.get('dias_retraso', 0) <= 5
        )
        total_pagos = len(cuenta.historial_pagos)
        porcentaje_a_tiempo = pagos_a_tiempo / total_pagos if total_pagos > 0 else 0
        
        # Días promedio de retraso
        dias_promedio_retraso = sum(
            pago.get('dias_retraso', 0) for pago in cuenta.historial_pagos
        ) / total_pagos if total_pagos > 0 else 0
        
        # Probabilidad base por historial (60% del score)
        probabilidad_historial = porcentaje_a_tiempo * 0.6
        
        # Ajuste por días de retraso promedio (30% del score)
        ajuste_retraso = max(0, (30 - dias_promedio_retraso) / 30) * 0.3
        
        # Ajuste por monto (10% del score)
        # Montos pequeños se cobran más fácil
        if cuenta.monto < 10000:
            ajuste_monto = 0.1
        elif cuenta.monto < 50000:
            ajuste_monto = 0.05
        else:
            ajuste_monto = 0.0
        
        # Penalización por promesas incumplidas
        penalizacion_promesas = min(cuenta.promesas_pago * 0.05, 0.2)
        
        probabilidad = (
            probabilidad_historial + 
            ajuste_retraso + 
            ajuste_monto - 
            penalizacion_promesas
        )
        
        return min(1.0, max(0.0, probabilidad))
    
    def generar_plan_cobranza(self, cuentas: List[CuentaPorCobrar]) -> List[Dict[str, Any]]:
        """
        Genera plan de cobranza priorizado.
        
        Args:
            cuentas: Lista de cuentas por cobrar
        
        Returns:
            List[Dict]: Plan de acciones de cobranza
        """
        plan = []
        
        for cuenta in cuentas:
            prioridad = self.calcular_prioridad(cuenta)
            probabilidad = self.calcular_probabilidad_cobro(cuenta)
            
            # Determinar acción según prioridad
            accion = self.prioridades[prioridad.name.lower()]['accion']
            
            # Ajustar acción por probabilidad
            if probabilidad < 0.3:
                accion = 'escalar_cobranza_especializada'
            elif probabilidad < 0.5:
                accion = 'llamada_personalizada'
            
            # Determinar canal óptimo
            canal = self._determinar_canal_optimo(cuenta, accion)
            
            plan.append({
                'cuenta_id': cuenta.id,
                'cliente': cuenta.cliente_nombre,
                'monto': cuenta.monto,
                'dias_vencido': cuenta.dias_vencido,
                'prioridad': prioridad.name,
                'probabilidad_cobro': round(probabilidad * 100, 1),
                'accion_recomendada': accion,
                'canal': canal,
                'plazo_horas': self.prioridades[prioridad.name.lower()]['plazo_horas'],
                'fecha_limite': self._calcular_fecha_limite(prioridad),
                'score_recuperacion': self._calcular_score_recuperacion(cuenta, probabilidad)
            })
        
        # Ordenar por prioridad y score de recuperación
        plan_ordenado = sorted(
            plan,
            key=lambda x: (
                PrioridadCobranza[x['prioridad']].value,
                -x['score_recuperacion']  # Scores mayores primero
            )
        )
        
        return plan_ordenado
    
    def _determinar_canal_optimo(self, cuenta: CuentaPorCobrar, accion: str) -> str:
        """Determina canal de comunicación óptimo según perfil y acción."""
        # Canales por defecto según acción
        canales_default = {
            'llamada_inmediata': 'teléfono',
            'whatsapp_seguimiento': 'WhatsApp',
            'email_recordatorio': 'email',
            'email_proactivo': 'email',
            'escalar_cobranza_especializada': 'despacho_cobranza',
            'llamada_personalizada': 'teléfono',
            'recordatorio_amable': cuenta.canal_preferido or 'email'
        }
        
        canal_default = canales_default.get(accion, 'email')
        
        # Si el cliente tiene canal preferido y es apropiado para la acción
        if cuenta.canal_preferido and cuenta.canal_preferido in ['WhatsApp', 'email']:
            if accion in ['email_recordatorio', 'email_proactivo', 'recordatorio_amable']:
                return cuenta.canal_preferido
        
        return canal_default
    
    def _calcular_fecha_limite(self, prioridad: PrioridadCobranza) -> datetime:
        """Calcula fecha límite para acción de cobranza."""
        hoy = datetime.now()
        plazo_horas = self.prioridades[prioridad.name.lower()]['plazo_horas']
        return hoy + timedelta(hours=plazo_horas)
    
    def _calcular_score_recuperacion(self, cuenta: CuentaPorCobrar, probabilidad: float) -> float:
        """
        Calcula score de recuperación (monto × probabilidad).
        
        Representa el valor esperado de recuperación.
        """
        return cuenta.monto * probabilidad


# Ejemplo de uso
if __name__ == "__main__":

    cuenta = CuentaPorCobrar(

            {'dias_retraso': 0, 'monto': 30000},

        ],
        canal_preferido='WhatsApp',
```

#### Algoritmo 2: Generación de Planes de Pago

```python
from dataclasses import dataclass
from typing import List, Optional
from datetime import datetime, timedelta


@dataclass
class PlanDePago:
    """Representa un plan de pago negociado."""
    id: str
    cuenta_id: str
    cliente_id: str
    monto_total: float
    numero_parcialidades: int
    monto_parcialidad: float
    frecuencia: str  # 'semanal', 'quincenal', 'mensual'
    fecha_inicio: datetime
    fecha_fin: datetime
    tasa_interes: float = 0.0  # Tasa de interés del plan
    descuento_pronto_pago: float = 0.0  # Descuento por pago anticipado
    estado: str = 'propuesto'  # 'propuesto', 'aceptado', 'activo', 'completado', 'incumplido'


class GeneradorPlanesPago:
    """
    Generador de planes de pago personalizados.
    
    Considera:
    - Capacidad de pago del cliente
    - Monto adeudado
    - Historial crediticio
    - Políticas de la empresa
    """
    
    def __init__(self, tasa_interes_mensual: float = 0.02):
        """
        Inicializa el generador de planes.
        
        Args:
            tasa_interes_mensual: Tasa de interés para planes (default 2%)
        """
        self.tasa_interes = tasa_interes_mensual
    
    def generar_plan_optimo(
        self,
        monto_deuda: float,
        capacidad_pago_mensual: float,
        historial_pagos: List[Dict],
        descuento_maximo: float = 0.15
    ) -> PlanDePago:
        """
        Genera plan de pago óptimo basado en capacidad de pago.
        
        Args:
            monto_deuda: Monto total adeudado
            capacidad_pago_mensual: Capacidad máxima de pago mensual del cliente
            historial_pagos: Historial de pagos del cliente
            descuento_maximo: Descuento máximo aplicable (default 15%)
        
        Returns:
            PlanDePago: Plan optimizado
        """
        # Calcular probabilidad de cumplimiento basada en historial
        probabilidad_cumplimiento = self._calcular_probabilidad_cumplimiento(historial_pagos)
        
        # Determinar descuento aplicable según probabilidad
        descuento = self._calcular_descuento_aplicable(
            probabilidad_cumplimiento,
            descuento_maximo
        )
        
        # Monto con descuento
        monto_con_descuento = monto_deuda * (1 - descuento)
        
        # Calcular número de parcialidades
        if capacidad_pago_mensual >= monto_con_descuento:
            # Pago de contado con descuento
            numero_parcialidades = 1
            frecuencia = 'unico'
        else:
            # Pago parcializado
            numero_parcialidades = max(
                2,
                min(12, int(monto_con_descuento / capacidad_pago_mensual) + 1)
            )
            frecuencia = self._determinar_frecuencia_optima(
                numero_parcialidades,
                historial_pagos
            )
        
        # Calcular monto de parcialidad con interés
        monto_parcialidad = self._calcular_parcialidad(
            monto_con_descuento,
            numero_parcialidades,
            self.tasa_interes
        )
        
        # Fechas del plan
        fecha_inicio = datetime.now()
        fecha_fin = self._calcular_fecha_fin(
            fecha_inicio,
            numero_parcialidades,
            frecuencia
        )
        
        return PlanDePago(
            id=f'PP-{datetime.now().strftime("%Y%m%d%H%M%S")}',
            cuenta_id='CX-001',  # Reemplazar con ID real
            cliente_id='CLI-123',  # Reemplazar con ID real
            monto_total=monto_con_descuento,
            numero_parcialidades=numero_parcialidades,
            monto_parcialidad=round(monto_parcialidad, 2),
            frecuencia=frecuencia,
            fecha_inicio=fecha_inicio,
            fecha_fin=fecha_fin,
            tasa_interes=self.tasa_interes,
            descuento_pronto_pago=descuento,
            estado='propuesto'
        )
    
    def _calcular_probabilidad_cumplimiento(self, historial_pagos: List[Dict]) -> float:
        """Calcula probabilidad de cumplimiento basada en historial."""
        if not historial_pagos:
            return 0.5
        
        pagos_cumplidos = sum(1 for pago in historial_pagos if pago.get('cumplido', True))
        return pagos_cumplidos / len(historial_pagos)
    
    def _calcular_descuento_aplicable(self, probabilidad: float, max_descuento: float) -> float:
        """
        Calcula descuento aplicable según probabilidad de cumplimiento.
        
        Estrategia:
        - Alta probabilidad (>80%): 10-15% descuento
        - Media probabilidad (50-80%): 5-10% descuento
        - Baja probabilidad (<50%): 0-5% descuento
        """
        if probabilidad >= 0.8:
            return max_descuento
        elif probabilidad >= 0.5:
            return max_descuento * 0.67
        else:
            return max_descuento * 0.33
    
    def _determinar_frecuencia_optima(
        self,
        numero_parcialidades: int,
        historial_pagos: List[Dict]
    ) -> str:
        """Determina frecuencia de pago óptima (semanal, quincenal, mensual)."""
        if numero_parcialidades <= 3:
            return 'mensual'
        elif numero_parcialidades <= 6:
            return 'quincenal'
        else:
            return 'semanal'
    
    def _calcular_parcialidad(
        self,
        monto: float,
        parcialidades: int,
        tasa_interes: float
    ) -> float:
        """
        Calcula monto de parcialidad con interés.
        
        Fórmula: PMT = PV × [r(1+r)^n] / [(1+r)^n - 1]
        """
        if parcialidades == 1:
            return monto
        
        r = tasa_interes
        n = parcialidades
        
        if r == 0:
            return monto / n
        
        pmt = monto * (r * (1 + r) ** n) / ((1 + r) ** n - 1)
        return pmt
    
    def _calcular_fecha_fin(
        self,
        fecha_inicio: datetime,
        numero_parcialidades: int,
        frecuencia: str
    ) -> datetime:
        """Calcula fecha de fin del plan según frecuencia."""
        if frecuencia == 'semanal':
            return fecha_inicio + timedelta(weeks=numero_parcialidades)
        elif frecuencia == 'quincenal':
            return fecha_inicio + timedelta(days=15 * numero_parcialidades)
        else:  # mensual
            return fecha_inicio + timedelta(days=30 * numero_parcialidades)
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Sin API Oficial del SAT para Castigo de Incobrables

**Problema:**
El SAT no proporciona una API oficial para presentar el aviso de castigo de cuentas incobrables. El proceso debe realizarse mediante:
- Escrito libre físico en oficinas del SAT
- Buzón Tributario (subida manual de PDF)

**Solución:**
```python
def generar_pdf_aviso_sat(aviso_texto: str) -> bytes:
    """
    Genera PDF del aviso al SAT para presentación en Buzón Tributario.
    
    Usa reportlab o similar para generar PDF con formato oficial.
    """
    from reportlab.lib.pagesizes import letter
    from reportlab.pdfgen import canvas
    from io import BytesIO
    
    buffer = BytesIO()
    c = canvas.Canvas(buffer, pagesize=letter)
    
    # Encabezado
    c.setFont("Helvetica-Bold", 14)
    c.drawString(100, 750, "AVISO DE DEDUCCIÓN DE PÉRDIDAS POR CRÉDITOS INCOBRABLES")
    
    # Contenido
    c.setFont("Helvetica", 11)
    y = 700
    for linea in aviso_texto.split('\n'):
        c.drawString(100, y, linea)
        y -= 15
        if y < 50:  # Nueva página
            c.showPage()
            y = 750
    
    c.save()
    buffer.seek(0)
    return buffer.getvalue()
```

**Impacto:**
- Requiere intervención manual para presentación final
- Tiempo adicional: 10-15 minutos por aviso
- Riesgo de errores en captura manual

### 4.2 Limitación 2: Cálculo de INPC para Actualizaciones

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **Marco normativo complejo:** La deducción de cuentas incobrables requiere cumplir formalidades específicas según el monto (menores/mayores a 30,000 UDIS), con plazos y documentos distintos para cada caso.

2. **Tasa de recargos incrementada:** El CFF 2026 establece una tasa de recargos por mora del 2.07% mensual (vs 1.47% en 2025), representando un incremento del 40.8% que impacta el cálculo de intereses moratorios.

3. **Estrategias de recuperación efectivas:** La segmentación inteligente de cartera y la adaptación del canal de comunicación al perfil del cliente pueden mejorar la recuperación en 25-40%, según datos de Moonflow y Colektia.

4. **Automatización con IA:** Los modelos predictivos de probabilidad de cobro y la generación automatizada de mensajes personalizados permiten reducir el tiempo de gestión en 75-80% manteniendo o mejorando las tasas de recuperación.

5. **Integración multicanal:** WhatsApp tiene 3x más efectividad que email para recordatorios de cobranza en ciertos segmentos, pero la estrategia óptima combina múltiples canales según el perfil del deudor y la antigüedad de la mora.
