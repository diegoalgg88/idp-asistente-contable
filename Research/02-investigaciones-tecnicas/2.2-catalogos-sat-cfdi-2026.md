### 3.2 Algoritmos Específicos

#### Algoritmo 1: Carga y Actualización de Catálogos

```python
import pandas as pd
import requests
from datetime import datetime
from typing import Dict, List

class SATCatalogosManager:
    """
    Gestiona la carga y actualización automática de catálogos del SAT.
    Actualización diaria a las 6:00 AM.
    """
    
    SAT_BASE_URL = "https://www.sat.gob.mx/aplicacion/29414/consulta-tu-proveedor-de-certificacion"
    
    CATALOGOS = {
        'clave_prod_serv': f"{SAT_BASE_URL}/catalogos/ClaveProdServ.csv",
        'clave_unidad': f"{SAT_BASE_URL}/catalogos/ClaveUnidad.csv",
        'uso_cfdi': f"{SAT_BASE_URL}/catalogos/UsoCFDI.csv",
        'regimen_fiscal': f"{SAT_BASE_URL}/catalogos/RegimenFiscal.csv",
        'forma_pago': f"{SAT_BASE_URL}/catalogos/FormaPago.csv",
        'metodo_pago': f"{SAT_BASE_URL}/catalogos/MetodoPago.csv",
        'moneda': f"{SAT_BASE_URL}/catalogos/Moneda.csv",
        'tipo_comprobante': f"{SAT_BASE_URL}/catalogos/TipoDeComprobante.csv",
        'codigo_postal': f"{SAT_BASE_URL}/catalogos/c_CodigoPostal.csv"
    }
    
    def __init__(self, db_session):
        """
        Inicializa el gestor de catálogos.
        
        Args:
            db_session: Sesión de base de datos para almacenamiento
        """
        self.db = db_session
        self.catalogos_cache = {}
    
    def check_and_update(self) -> Dict:
        """
        Verifica si hay nuevos catálogos y actualiza base de datos local.
        Se ejecuta diariamente a las 6:00 AM.
        
        Returns:
            Dict con resultado de actualización
        """
        resultados = {}
        
        for nombre, url in self.CATALOGOS.items():
            try:
                # Descargar catálogo
                response = requests.get(url, timeout=30)
                response.raise_for_status()
                
                # Parsear CSV
                df = pd.read_csv(pd.io.common.StringIO(response.text))
                
                # Validar cambios vs versión almacenada
                version_actual = self._get_catalogo_version(nombre)
                version_nueva = self._calculate_hash(df)
                
                if version_actual != version_nueva:
                    # Actualizar base de datos
                    self._update_catalogo_db(nombre, df)
                    resultados[nombre] = {
                        'updated': True,
                        'registros': len(df),
                        'timestamp': datetime.now().isoformat()
                    }
                else:
                    resultados[nombre] = {
                        'updated': False,
                        'registros': len(df),
                        'timestamp': datetime.now().isoformat()
                    }
                    
            except Exception as e:
                resultados[nombre] = {
                    'error': str(e),
                    'timestamp': datetime.now().isoformat()
                }
        
        return resultados
    
    def search_clave_prod_serv(self, keyword: str, limit: int = 20) -> List[Dict]:
        """
        Busca claves de producto/servicio por palabra clave.
        Usa fuzzy matching para mejores resultados.
        
        Args:
            keyword: Palabra clave a buscar
            limit: Máximo de resultados a retornar
            
        Returns:
            Lista de diccionarios con claves encontradas
        """
        from fuzzywuzzy import fuzz
        
        # Cargar catálogo (desde caché o DB)
        catalogos = self._load_catalogos()
        clave_prod_serv = catalogos['clave_prod_serv']
        
        # Búsqueda fuzzy
        resultados = []
        for _, row in clave_prod_serv.iterrows():
            descripcion = row['descripcion'].lower()
            score = fuzz.partial_ratio(keyword.lower(), descripcion)
            
            if score >= 70:  # Threshold de 70%
                resultados.append({
                    'clave': row['clave'],
                    'descripcion': row['descripcion'],
                    'score': score,
                    'vigencia_desde': row.get('vigencia_desde'),
                    'vigencia_hasta': row.get('vigencia_hasta')
                })
        
        # Ordenar por score y retornar top N
        resultados.sort(key=lambda x: x['score'], reverse=True)
        return resultados[:limit]
    
    def validate_congruencia(self, clave_prod_serv: str, descripcion: str, 
                            uso_cfdi: str, regimen_receptor: str) -> Dict:
        """
        Valida congruencia entre clave de producto, descripción, uso CFDI y régimen.
        
        Args:
            clave_prod_serv: Clave de producto/servicio
            descripcion: Descripción del concepto
            uso_cfdi: Uso del CFDI
            regimen_receptor: Régimen fiscal del receptor
            
        Returns:
            Dict con resultado de validación
        """
        errores = []
        alertas = []
        
        # Validar que la clave exista
        if not self._clave_existe('clave_prod_serv', clave_prod_serv):
            errores.append(f"ClaveProdServ inválida: {clave_prod_serv}")
        
        # Validar uso CFDI vs régimen fiscal
        if not self._validar_uso_regimen(uso_cfdi, regimen_receptor):
            errores.append(f"UsoCFDI {uso_cfdi} no compatible con régimen {regimen_receptor}")
        
        # Alerta por clave genérica
        if clave_prod_serv == '01010101':
            alertas.append({
                'tipo': 'CLAVE_GENERICA',
                'mensaje': 'Uso de clave genérica (01010101) puede detonar auditoría',
                'recomendacion': 'Usar clave específica del producto/servicio'
            })
        
        # Validar congruencia descripción vs clave
        descripcion_esperada = self._get_descripcion_clave(clave_prod_serv)
        if descripcion_esperada:
            similitud = self._calcular_similitud(descripcion, descripcion_esperada)
            if similitud < 50:
                alertas.append({
                    'tipo': 'INCONGRUENCIA_DESCRIPCION',
                    'mensaje': f'Descripción no coincide con clave {clave_prod_serv}',
                    'similitud': similitud
                })
        
        return {
            'is_valid': len(errores) == 0,
            'errors': errores,
            'warnings': alertas
        }
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Actualizaciones sin Aviso del SAT

**Problema:**
El SAT actualiza catálogos sin previo aviso (ej. 30-ene-2026, 13-feb-2026). Una clave inválida causa rechazo inmediato del PAC.

**Solución:**
```python
# Actualización automática diaria con fallback
class SATCatalogosUpdater:
    def __init__(self):
        self.last_update = self._get_last_update()
        self.update_url = "https://www.sat.gob.mx/aplicacion/29414/consulta-tu-proveedor-de-certificacion"
    
    def check_and_update(self):
        """Verifica y actualiza catálogos diariamente."""
        if self._is_new_day(self.last_update):
            try:
                response = requests.get(self.update_url, timeout=30)
                self._parse_and_save(response.text)
                self.last_update = datetime.now()
                return {'updated': True}
            except Exception as e:
                # Fallback: usar caché local
                logger.warning(f"Fallo actualización SAT: {e}")
                return {'updated': False, 'using_cache': True}
        return {'updated': False}
```

**Impacto:**
- Requiere monitoreo diario del portal SAT
- Necesidad de caché local para continuidad operativa

### 4.2 Limitación 2: 50,000+ Claves en ClaveProdServ

**Problema:**
El catálogo ClaveProdServ tiene 50,000+ claves. Búsqueda lineal es lenta (>5 segundos).

**Solución:**
```python
# Búsqueda con índice invertido + fuzzy matching
from whoosh.index import create_in
from whoosh.fields import Schema, TEXT, ID

class ClaveProdServSearchEngine:
    def __init__(self, index_dir="indexes/clave_prod_serv"):
        schema = Schema(
            clave=ID(stored=True),
            descripcion=TEXT(analyzer=whoosh.analysis.StandardAnalyzer()),
            vigencia_desde=TEXT(stored=True),
            vigencia_hasta=TEXT(stored=True)
        )
        self.index = create_in(index_dir, schema)
    
    def search(self, query: str, limit: int = 20) -> List[Dict]:
        """Búsqueda full-text con ranking."""
        with self.index.searcher() as searcher:
            parser = QueryParser("descripcion", self.index.schema)
            q = parser.parse(query)
            results = searcher.search(q, limit=limit)
            return [dict(hit) for hit in results]
```

**Impacto:**
- Requiere índice invertido (Whoosh/Elasticsearch)
- Búsqueda en <200ms vs >5s lineal

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **50,000+ claves ClaveProdServ:** Búsqueda lineal es inviable. Índice invertido es obligatorio.
2. **Actualizaciones sin aviso:** SAT actualiza catálogos sin previo aviso. Actualización automática diaria es crítica.
3. **Matriz régimen-uso compleja:** 30+ regímenes × 50+ usos CFDI = 1,500+ combinaciones posibles.
4. **Claves genéricas = riesgo:** Uso sistemático de 01010101 detona auditorías automáticas.
5. **Congruencia es clave:** Descripción debe coincidir con clave de producto (fuzzy matching 70%+).

### 8.2 Recomendaciones Finales

| Área | Recomendación | Prioridad | Owner |
|------|---------------|-----------|-------|
