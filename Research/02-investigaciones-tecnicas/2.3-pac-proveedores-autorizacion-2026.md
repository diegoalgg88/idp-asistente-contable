```
                            ↓
```

### 3.2 Algoritmos Específicos

#### Algoritmo 1: Gestión de Múltiples PACs con Fallback

```python
from abc import ABC, abstractmethod
from typing import Dict, List, Optional
import requests
from datetime import datetime

class PACProvider(ABC):
    """
    Interfaz común para todos los PACs.
    Cada PAC implementa su propio adaptador.
    """
    
    @abstractmethod
    def stamp(self, cfdi_xml: str) -> Dict:
        """
        Timbra un CFDI.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado:
            - success: bool
            - uuid: str (si exitoso)
            - sello_sat: str (si exitoso)
            - error: str (si fallido)
        """
        pass
    
    @abstractmethod
    def cancel(self, uuid: str, rfc_emisor: str) -> Dict:
        """
        Cancela un CFDI.
        
        Args:
            uuid: Folio fiscal del CFDI
            rfc_emisor: RFC del emisor
            
        Returns:
            Dict con resultado de cancelación
        """
        pass
    
    @abstractmethod
    def health_check(self) -> bool:
        """
        Verifica si el PAC está disponible.
        
        Returns:
            bool: True si disponible, False si no
        """
        pass


class FinkokPAC(PACProvider):
    """
    Implementación específica para Finkok.
    API: REST + SOAP
    """
    
    def __init__(self, api_key: str, secret: str, sandbox: bool = False):
        self.api_key = api_key
        self.secret = secret
        self.base_url = "https://api.finkok.com" if not sandbox else "https://sandbox.finkok.com"
        self.timeout = 5  # 5 segundos
    
    def stamp(self, cfdi_xml: str) -> Dict:
        """Timbra CFDI con Finkok."""
        try:
            response = requests.post(
                f"{self.base_url}/stamp",
                json={
                    'username': self.api_key,
                    'password': self.secret,
                    'xml': cfdi_xml
                },
                timeout=self.timeout
            )
            response.raise_for_status()
            result = response.json()
            
            if result.get('status') == 'success':
                return {
                    'success': True,
                    'uuid': result['data']['uuid'],
                    'sello_sat': result['data']['selloSAT'],
                    'cadena_original': result['data']['cadenaOriginal'],
                    'no_certificado_sat': result['data']['noCertificadoSAT']
                }
            else:
                return {
                    'success': False,
                    'error': result.get('message', 'Error desconocido')
                }
        except requests.Timeout:
            return {'success': False, 'error': 'Timeout del PAC'}
        except Exception as e:
            return {'success': False, 'error': str(e)}
    
    def cancel(self, uuid: str, rfc_emisor: str) -> Dict:
        """Cancela CFDI con Finkok."""
        # Implementación específica de cancelación
        pass
    
    def health_check(self) -> bool:
        """Health check de Finkok."""
        try:
            response = requests.get(f"{self.base_url}/health", timeout=2)
            return response.status_code == 200
        except:
            return False


class SWPAC(PACProvider):
    """Implementación específica para SW Sapien."""
    
    def __init__(self, token: str, sandbox: bool = False):
        self.token = token
        self.base_url = "https://api.sw.com.mx" if not sandbox else "https://sandbox.sw.com.mx"
        self.timeout = 5
    
    def stamp(self, cfdi_xml: str) -> Dict:
        """Timbra CFDI con SW Sapien."""
        try:
            response = requests.post(
                f"{self.base_url}/cfdi33/timbrar",
                headers={'Authorization': f'Bearer {self.token}'},
                json={'xml': cfdi_xml},
                timeout=self.timeout
            )
            response.raise_for_status()
            result = response.json()
            
            if result.get('status') == 'success':
                return {
                    'success': True,
                    'uuid': result['data']['uuid'],
                    'sello_sat': result['data']['selloSAT']
                }
            else:
                return {
                    'success': False,
                    'error': result.get('message', 'Error desconocido')
                }
        except Exception as e:
            return {'success': False, 'error': str(e)}
    
    def cancel(self, uuid: str, rfc_emisor: str) -> Dict:
        """Cancela CFDI con SW Sapien."""
        pass
    
    def health_check(self) -> bool:
        """Health check de SW Sapien."""
        try:
            response = requests.get(f"{self.base_url}/health", timeout=2)
            return response.status_code == 200
        except:
            return False


class PACManager:
    """
    Gestiona múltiples PACs con fallback automático.
    """
    
    def __init__(self):
        self.pacs: List[PACProvider] = []
        self.primary_pac_index = 0
        self.timeout = 5  # 5 segundos
        self.max_retries = 3
    
    def add_pac(self, pac: PACProvider, priority: int = 0):
        """
        Agrega un PAC a la lista de proveedores.
        
        Args:
            pac: Instancia del PAC
            priority: Prioridad (0 = más alto)
        """
        self.pacs.insert(priority, pac)
    
    def stamp(self, cfdi_xml: str) -> Dict:
        """
        Timbra un CFDI con fallback automático.
        
        Args:
            cfdi_xml: Contenido XML del CFDI
            
        Returns:
            Dict con resultado de timbrado
        """
        last_error = None
        
        # Intentar con cada PAC en orden de prioridad
        for i, pac in enumerate(self.pacs):
            # Reintentar hasta 3 veces con el mismo PAC
            for retry in range(self.max_retries):
                try:
                    result = pac.stamp(cfdi_xml)
                    
                    if result['success']:
                        # Éxito: retornar inmediatamente
                        return {
                            'success': True,
                            'uuid': result['uuid'],
                            'sello_sat': result['sello_sat'],
                            'pac_used': i + 1,  # Índice del PAC usado
                            'retries': retry,
                            'timestamp': datetime.now().isoformat()
                        }
                    else:
                        last_error = result['error']
                        logger.warning(f"PAC {i+1} falló (intento {retry+1}): {last_error}")
                        
                except Exception as e:
                    last_error = str(e)
                    logger.error(f"Excepción en PAC {i+1} (intento {retry+1}): {last_error}")
            
            # Si llegamos aquí, el PAC actual falló. Continuar con el siguiente.
            logger.warning(f"PAC {i+1} falló después de {self.max_retries} intentos. Switching to next PAC.")
        
        # Todos los PACs fallaron
        return {
            'success': False,
            'error': f"Todos los PACs fallaron. Último error: {last_error}",
            'pacs_tried': len(self.pacs),
            'timestamp': datetime.now().isoformat()
        }
    
    def get_health_status(self) -> List[Dict]:
        """
        Obtiene el estado de salud de todos los PACs.
        
        Returns:
            Lista de estados de PACs
        """
        return [
            {
                'pac_index': i,
                'pac_name': pac.__class__.__name__,
                'is_healthy': pac.health_check(),
                'timestamp': datetime.now().isoformat()
            }
            for i, pac in enumerate(self.pacs)
        ]
```

#### Algoritmo 2: Health Check en Tiempo Real

```python
import asyncio
from datetime import datetime, timedelta

class PACHealthMonitor:
    """
    Monitorea la salud de los PACs en tiempo real.
    Ejecuta health checks cada 30 segundos.
    """
    
    def __init__(self, pac_manager: PACManager):
        self.pac_manager = pac_manager
        self.health_status = {}
        self.check_interval = 30  # 30 segundos
    
    async def start_monitoring(self):
        """Inicia el monitoreo continuo de PACs."""
        while True:
            await self.check_all_pacs()
            await asyncio.sleep(self.check_interval)
    
    async def check_all_pacs(self):
        """Verifica la salud de todos los PACs."""
        for i, pac in enumerate(self.pac_manager.pacs):
            try:
                is_healthy = await asyncio.wait_for(
                    asyncio.get_event_loop().run_in_executor(None, pac.health_check),
                    timeout=2.0
                )
                
                self.health_status[i] = {
                    'is_healthy': is_healthy,
                    'last_check': datetime.now(),
                    'consecutive_failures': 0 if is_healthy else self.health_status.get(i, {}).get('consecutive_failures', 0) + 1
                }
                
                if not is_healthy:
                    logger.warning(f"PAC {i+1} no está saludable. Fallos consecutivos: {self.health_status[i]['consecutive_failures']}")
                    
            except asyncio.TimeoutError:
                self.health_status[i] = {
                    'is_healthy': False,
                    'last_check': datetime.now(),
                    'consecutive_failures': self.health_status.get(i, {}).get('consecutive_failures', 0) + 1
                }
                logger.error(f"PAC {i+1} timeout en health check")
    
    def get_healthy_pac_index(self) -> Optional[int]:
        """
        Obtiene el índice del primer PAC saludable.
        
        Returns:
            Índice del PAC saludable, o None si todos están enfermos
        """
        for i, status in self.health_status.items():
            if status['is_healthy'] and status['consecutive_failures'] < 3:
                return i
        return None
```

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Sin API Oficial del SAT para Timbrado

**Problema:**
El SAT no proporciona una API directa para timbrado. Es obligatorio usar un PAC autorizado.

**Solución:**
```python
# Múltiples PACs para resiliencia
pac_manager = PACManager()
pac_manager.add_pac(FinkokPAC(api_key, secret), priority=0)  # Primario
```

**Impacto:**
- Costo adicional: $0.70-$3.50 MXN por timbre
- Dependencia de terceros (PACs)
- SLA variable entre PACs (99.5%-99.9%)

### 4.2 Limitación 2: Costos Variables por Volumen

**Problema:**
Los costos por timbre varían significativamente según volumen ($0.70-$3.50 MXN).

**Solución:**
```python
# Optimización de costos basada en volumen
```

| **Logs** | Inalterables | AWS CloudTrail / Azure Monitor |

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **77 PACs autorizados:** No todos tienen la misma calidad. Top 10 son suficientes.
2. **Costos variables:** $0.70-$3.50 MXN por timbre según volumen.
3. **Fallback es crítico:** Un solo PAC = 99.5% uptime. Dos PACs = 99.9% uptime.
4. **Health checks esenciales:** Detección temprana de fallos (<30s).
5. **Abstracción necesaria:** Cada PAC tiene API diferente. Adaptadores son obligatorios.
