## 1. Descripción del Módulo

### 1.1 Propósito

El Buzón Tributario del SAT es el canal oficial digital mediante el cual los contribuyentes envían su contabilidad electrónica (Catálogo de Cuentas CT, Balanza de Comprobación BN/BC, y Pólizas del Periodo PL). Este documento técnico proporciona la guía completa para implementar la automatización del proceso de carga, desde la autenticación con e.firma hasta la obtención del acuse de recibo, eliminando el proceso manual que consume 15-20 minutos por cliente mensualmente y está sujeto a errores de navegación y validación.

### 1.2 Actividades que Automatiza

| Actividad | Frecuencia | Tiempo Actual | Tiempo Esperado | Ahorro |
|-----------|------------|---------------|-----------------|--------|
| Autenticación en Buzón Tributario | Mensual | 3 min/cliente | 30 seg/cliente | 83% |
| Navegación a módulo Contabilidad Electrónica | Mensual | 2 min/cliente | Automático | 100% |
| Carga de archivo ZIP (CT/BN/PL) | Mensual | 5 min/cliente | 1 min/cliente | 80% |
| Validación en línea del SAT | Mensual | 3 min/cliente | Automático | 100% |
| Descarga de acuse de recibo | Mensual | 2 min/cliente | 30 seg/cliente | 75% |
| Detección y corrección de errores | Mensual | 5 min/cliente | 2 min/cliente | 60% |

### 1.3 Dolor Principal que Resuelve

**Problema central:** Los contadores dedican 15-20 minutos por cliente mensualmente a navegar el portal del SAT, autenticarse, cargar archivos y validar acuses. Errores en el proceso (archivo incorrecto, RFC mal capturado, timeout de sesión) causan rechazo del SAT y requieren reiniciar el proceso, generando frustración y pérdida de tiempo. La inconsistencia del portal (caídas, lentitud, captchas) agrava el problema.

### 2.6 Nomenclatura de Archivos ZIP

**Formato obligatorio del nombre del archivo:**

```
RFC + AAAA + MM + TIPO + .zip

Donde:
- RFC: 12-13 caracteres (persona moral/física)
- AAAA: Año del ejercicio (ej: 2026)
- MM: Mes del periodo (01-13, 13=anual)
- TIPO: 
  • CT = Catálogo de cuentas
  • BN = Balanza normal
  • BC = Balanza complementaria
  • PL = Pólizas del periodo
  • XC = Auxiliar de cuentas
  • XF = Auxiliar de folios

Ejemplos:
- XAXX010101000202603CT.zip  (Catálogo, marzo 2026)
- XAXX010101000202601BN.zip  (Balanza normal, enero 2026)
- XAXX010101000202601BC.zip  (Balanza complementaria, enero 2026)
- XAXX010101000202603PL.zip  (Pólizas, marzo 2026)
```

**Validaciones de nomenclatura:**
- ✅ `XAXX010101000202603CT.zip` - Correcto
- ❌ `xaxx010101000202603ct.zip` - Debe ser mayúsculas
- ❌ `XAXX010101000_202603_CT.zip` - Sin guiones bajos
- ❌ `XAXX010101000202603CT.XML` - Debe ser .zip

class SATContabilidadLoader:
    """
    Clase para automatizar la carga de contabilidad electrónica al SAT.
    
    Esta clase maneja todo el proceso de autenticación con e.firma,
    navegación al módulo de contabilidad electrónica, carga de archivos

            raise FileNotFoundError(f"Archivo .cer no encontrado: {self.cer_path}")
        if not self.key_path.exists():
            raise FileNotFoundError(f"Archivo .key no encontrado: {self.key_path}")
        if len(self.rfc) not in [12, 13]:
            raise ValueError(f"RFC inválido: {self.rfc}. Debe tener 12-13 caracteres.")
    
    async def _iniciar_navegador(self) -> Tuple[Browser, BrowserContext, Page]:
        """
        Inicia el navegador y crea una nueva página.
        
        Returns:
            Tupla con (browser, context, page)
        """
        playwright = await async_playwright().start()
        
        browser = await playwright.chromium.launch(
            headless=self.headless,
            args=[
                '--no-sandbox',
                '--disable-setuid-sandbox',
                '--disable-dev-shm-usage',
                '--disable-accelerated-2d-canvas',
                '--disable-gpu'
            ]
        )
        
        context = await browser.new_context(
            viewport={'width': 1920, 'height': 1080},
            user_agent='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'
        )
        
        page = await context.new_page()
        page.set_default_timeout(self.timeout * 1000)
        
        return browser, context, page
    
    async def autenticar(self, page: Page) -> bool:
        """
        Autentica en el Buzón Tributario con e.firma.
        
        Args:
            page: Instancia de Page de Playwright
            
        Returns:
            True si la autenticación fue exitosa, False en caso contrario
        """
        logger.info(f"Iniciando autenticación para RFC: {self.rfc}")
        
        # Navegar al Buzón Tributario
        await page.goto(self.BUZON_URL, wait_until='networkidle')
        await asyncio.sleep(2)  # Esperar carga completa
        
        # Click en iniciar sesión
        try:
            await page.click(self.SELECTORES['btn_iniciar_sesion'])
            await asyncio.sleep(2)
        except Exception as e:
            logger.warning(f"No se encontró botón de inicio de sesión: {e}")
        
        # Llenar RFC
        try:
            await page.fill(self.SELECTORES['input_rfc'], self.rfc)
            logger.debug("RFC capturado")
        except Exception as e:
            logger.error(f"Error al capturar RFC: {e}")
            return False
        
        # Adjuntar archivo .cer
        try:
            await page.set_input_files(
                self.SELECTORES['input_cer'],
                str(self.cer_path)
            )
            logger.debug("Archivo .cer cargado")
        except Exception as e:
            logger.error(f"Error al cargar .cer: {e}")
            return False
        
        # Adjuntar archivo .key
        try:
            await page.set_input_files(
                self.SELECTORES['input_key'],
                str(self.key_path)
            )
            logger.debug("Archivo .key cargado")
        except Exception as e:
            logger.error(f"Error al cargar .key: {e}")
            return False
        
        # Capturar contraseña
        try:
            await page.fill(self.SELECTORES['input_password'], self.password)
            logger.debug("Contraseña capturada")
        except Exception as e:
            logger.error(f"Error al capturar contraseña: {e}")
            return False
        
        # Click en Aceptar
        try:
            await page.click(self.SELECTORES['btn_aceptar'])
            logger.info("Enviando credenciales...")
            
            # Esperar navegación o mensaje de error
            await asyncio.sleep(5)
            
            # Verificar si hay mensaje de error
            error_visible = await page.is_visible(self.SELECTORES['mensaje_error'])
            if error_visible:
                error_text = await page.text_content(self.SELECTORES['mensaje_error'])
                logger.error(f"Error en autenticación: {error_text}")
                return False
            
            logger.info("Autenticación exitosa")
            return True
            
        except Exception as e:
            logger.error(f"Error al enviar credenciales: {e}")
            return False
    
    async def navegar_a_contabilidad(self, page: Page) -> bool:
        """
        Navega al módulo de envío de contabilidad electrónica.
        
        Args:
            page: Instancia de Page de Playwright
            
        Returns:
            True si la navegación fue exitosa
        """
        logger.info("Navegando a Contabilidad Electrónica...")
        
        try:
            # Intentar navegación directa
            await page.goto(self.CONTABILIDAD_URL, wait_until='networkidle')
            await asyncio.sleep(3)
            
            # Verificar que estamos en la página correcta
            url_actual = page.url
            if 'contabilidad-electronica' in url_actual.lower():
                logger.info("Navegación exitosa a Contabilidad Electrónica")
                return True
            else:
                logger.warning(f"URL inesperada: {url_actual}")
                return False
                
        except Exception as e:
            logger.error(f"Error en navegación: {e}")
            return False
    
    async def cargar_archivo(
        self,
        page: Page,
        archivo_zip: str,
        ejercicio: int,
        periodo: int,
        tipo_declaracion: str = 'N'
    ) -> Dict:
        """
        Carga el archivo de contabilidad electrónica.
        
        Args:
            page: Instancia de Page de Playwright
            archivo_zip: Ruta al archivo ZIP a cargar
            ejercicio: Año del ejercicio (ej: 2026)
            periodo: Mes del periodo (1-13)
            tipo_declaracion: 'N' = Normal, 'C' = Complementaria
            
        Returns:
            Diccionario con resultado de la operación
        """
        logger.info(f"Iniciando carga de archivo: {archivo_zip}")
        
        resultado = {
            'exitoso': False,
            'numero_operacion': None,
            'fecha': None,
            'mensaje': '',
            'acuse_descargado': False
        }
        
        try:
            # Esperar que el formulario esté visible
            await page.wait_for_selector(self.SELECTORES['input_archivo'], timeout=10000)
            
            # Seleccionar tipo de declaración
            try:
                await page.select_option(
                    self.SELECTORES['select_tipo_declaracion'],
                    tipo_declaracion
                )
                logger.debug(f"Tipo de declaración: {tipo_declaracion}")
            except:
                logger.warning("No se pudo seleccionar tipo de declaración")
            
            # Adjuntar archivo ZIP
            await page.set_input_files(
                self.SELECTORES['input_archivo'],
                archivo_zip
            )
            logger.debug("Archivo ZIP cargado")
            
            # Click en Cargar/Enviar
            await page.click(self.SELECTORES['btn_cargar'])
            logger.info("Enviando archivo al SAT...")
            
            # Esperar validación del SAT (puede tomar 30-60 segundos)
            await asyncio.sleep(10)
            
            # Polling para esperar resultado
            max_intentos = 12  # 12 * 5s = 60 segundos máximo
            for intento in range(max_intentos):
                # Verificar mensaje de éxito
                if await page.is_visible(self.SELECTORES['mensaje_exito']):
                    resultado['exitoso'] = True
                    resultado['mensaje'] = await page.text_content(
                        self.SELECTORES['mensaje_exito']
                    )
                    
                    # Extraer número de operación
                    try:
                        resultado['numero_operacion'] = await page.text_content(
                            self.SELECTORES['numero_operacion']
                        )
                    except:
                        pass
                    
                    resultado['fecha'] = datetime.now().isoformat()
                    logger.info(f"Carga exitosa. Operación: {resultado['numero_operacion']}")
                    
                    # Intentar descargar acuse
                    try:
                        if await page.is_visible(self.SELECTORES['btn_descargar_acuse']):
                            await page.click(self.SELECTORES['btn_descargar_acuse'])
                            resultado['acuse_descargado'] = True
                            logger.info("Acuse descargado")
                    except:
                        logger.warning("No se pudo descargar el acuse")
                    
                    break
                
                # Verificar mensaje de error
                if await page.is_visible(self.SELECTORES['mensaje_error']):
                    resultado['mensaje'] = await page.text_content(
                        self.SELECTORES['mensaje_error']
                    )
                    logger.error(f"Carga rechazada: {resultado['mensaje']}")
                    break
                
                # Esperar y reintentar
                await asyncio.sleep(5)
                logger.debug(f"Esperando validación... intento {intento + 1}/{max_intentos}")
            
            else:
                resultado['mensaje'] = "Timeout: El SAT no respondió en el tiempo esperado"
                logger.error(resultado['mensaje'])
            
        except Exception as e:
            resultado['mensaje'] = f"Error durante la carga: {str(e)}"
            logger.error(resultado['mensaje'])
        
        return resultado
    
    async def ejecutar_carga(
        self,
        archivo_zip: str,
        ejercicio: int,
        periodo: int,
        tipo_declaracion: str = 'N'
    ) -> Dict:
        """
        Ejecuta el proceso completo de carga.
        
        Args:
            archivo_zip: Ruta al archivo ZIP
            ejercicio: Año del ejercicio
            periodo: Mes del periodo
            tipo_declaracion: 'N' o 'C'
            
        Returns:
            Diccionario con resultado de la operación
        """
        browser = None
        resultado = {'exitoso': False, 'mensaje': ''}
        
        try:
            # Iniciar navegador
            browser, context, page = await self._iniciar_navegador()
            
            # Autenticar
            if not await self.autenticar(page):
                resultado['mensaje'] = "Error en autenticación"
                return resultado
            
            # Navegar a contabilidad
            if not await self.navegar_a_contabilidad(page):
                resultado['mensaje'] = "Error en navegación"
                return resultado
            
            # Cargar archivo
            resultado = await self.cargar_archivo(
                page, archivo_zip, ejercicio, periodo, tipo_declaracion
            )
            
        except Exception as e:
            resultado['mensaje'] = f"Error general: {str(e)}"
            logger.error(resultado['mensaje'])
        
        finally:
            if browser:
                await browser.close()
        
        return resultado


async def main():
    """Función principal con argumentos de línea de comandos."""
    parser = argparse.ArgumentParser(

### 3.4 Códigos de Error Comunes del SAT

| Código | Mensaje | Causa | Solución |
|--------|---------|-------|----------|
| **CE-001** | RFC inválido | RFC no coincide con e.firma | Verificar RFC en archivos .cer/.key |
| **CE-002** | Archivo corrupto o ilegible | ZIP dañado o mal formado | Regenerar archivo ZIP, verificar integridad |
| **CE-003** | Nomenclatura incorrecta | Nombre del archivo no sigue formato SAT | Renombrar: RFC+AAAA+MM+TIPO.zip |
| **CE-004** | XML no válido contra XSD | Estructura XML incorrecta | Validar con XSD oficial antes de enviar |
| **CE-005** | Periodo ya enviado | Existe balanza normal para mismo periodo | Usar tipo declaración 'C' (complementaria) |
| **CE-006** | e.firma vencida o revocada | Certificado caducado o cancelado | Renovar e.firma en portal SAT |
| **CE-007** | Timeout en validación | Lentitud del servidor SAT | Reintentar en 5-10 minutos |
| **CE-008** | Sesión expirada | Inactividad >10 minutos | Reiniciar proceso de autenticación |
| **CE-009** | Archivo excede tamaño máximo | ZIP >10 MB (límite no oficial) | Verificar tamaño, comprimir más |
| **CE-010** | Campos obligatorios vacíos | Faltan datos en formulario | Verificar ejercicio, periodo, tipo |

### 3.5 Declaraciones Complementarias

**Cuándo usar TipoEnvio = 'C':**

| Escenario | TipoEnvio | Campos Adicionales |
|-----------|-----------|-------------------|
| Primera vez que se envía el mes | `N` (Normal) | Ninguno |
| Corrección de balanza previamente enviada | `C` (Complementaria) | FechaModBalanza (YYYY-MM-DD) |
| Sustitución de balanza con errores | `C` (Complementaria) | FechaModBalanza (YYYY-MM-DD) |
| Balanza anual (periodo 13) | `N` o `C` según corresponda | FechaModBalanza si es C |

## 4. Limitantes y Restricciones

### 4.1 Limitación 1: Cambios en Selectores del Portal SAT

**Problema:**
El portal del SAT puede cambiar selectores CSS, IDs de elementos o estructura del DOM sin previo aviso, rompiendo la automatización.

**Solución:**
```python
# Implementar sistema de selectores múltiples (fallback)
SELECTORES_FALLBACK = {
    'btn_cargar': [
        'button:has-text("Cargar")',
        'button:has-text("Enviar")',
        'input[type="submit"][value="Cargar"]',
        '.btn-cargar',
        '#btnCargar'
    ]
}

async def click_con_fallback(page, selector_group: list):
    """Intenta hacer click con múltiples selectores."""
    for selector in selector_group:
        try:
            if await page.is_visible(selector):
                await page.click(selector)
                return True
        except:
            continue
    return False
```

**Impacto:**
- Requiere mantenimiento periódico de selectores
- Posibles fallos intermitentes
- Necesidad de monitoreo de cambios en portal SAT

### 4.2 Limitación 2: Captchas y Validaciones Anti-Bot

**Problema:**
El SAT puede implementar captchas o validaciones anti-bot que bloquean la automatización.

**Solución:**
```python
# Configuración para evadir detección
context = await browser.new_context(
    viewport={'width': 1920, 'height': 1080},
    user_agent='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',

    timezone_id='America/Mexico_City'
)

# Agregar delays humanos
import random
await asyncio.sleep(random.uniform(1.5, 3.5))
```

**Impacto:**
- Si el SAT implementa captcha complejo, puede requerir intervención manual
- Velocidad reducida por delays artificiales

## 8. Conclusiones y Recomendaciones

### 8.1 Hallazgos Clave

1. **El Buzón Tributario es el único canal oficial** para envío de contabilidad electrónica. No existen APIs oficiales; la automatización requiere browser automation (Playwright/Selenium).

2. **Las fechas de envío son críticas:** Días 1-3 para personas morales, días 1-5 para personas físicas. Un día de retraso genera multas de $8,500-$17,000 MXN.

3. **La validación del SAT toma 10-60 segundos** y puede fallar por timeout. Se requieren reintentos automáticos con backoff exponencial.

4. **Los selectores CSS del portal SAT cambian sin aviso**, requiriendo mantenimiento periódico del script de automatización.

5. **Las declaraciones complementarias (TipoEnvio='C')** son obligatorias para correcciones y requieren el campo adicional `FechaModBalanza`.
